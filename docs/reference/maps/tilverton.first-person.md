## 離開這張圖的格子

⚠ **走得出去 ≠ 已經接上**：`external_exit` 沒宣告的那幾格，remake 會照 `wrap` 繞回對邊，走不到腳本安排的目的地。

| 格子 | 方向 | game pack 宣告 |
|---|---|---|
| `(10,15)` | 南 | `tilverton.guild.south-to-sewers` |
| `(14,15)` | 南 | **沒宣告** |
