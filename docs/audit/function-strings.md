# 待解讀函式的內嵌字串索引

由 `scripts/function_strings.py` 產生。每一列是一支**尚未解讀**的 overlay
函式，以及它引用到的 overlay 內嵌 Pascal 字串（最多列 6 條）。

用途有兩個：

- **判讀的錨**：字串是最快認出一支函式在做什麼的線索（spec 819 的
  `'Spits Acid'` 就是這樣找到的）。
- **中文化的工作清單**：畫面文字散在各 overlay 裡，這份表把「哪一支函式
  擁有哪些字串」對起來。

⚠ 這只是**線索**，不是判讀。位址被當成字串取出來不代表它真的是字串；一律要
把本體讀完才能標「已解讀」。清單會隨台帳推進而縮短。
