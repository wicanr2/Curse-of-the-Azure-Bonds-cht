# DOS 角色記錄的逐位元組覆蓋（`CHARREC`，1A6h bytes）

由 `cmd/save-field-coverage` 產生，不要手改。

- **狀態**來自 `internal/party.DOSPlayerRecordFields` 的人工台帳，每一段都必須有出處；`unknown` 是「還沒查到」，不是「沒有用」。
- **量到有讀**是機器量的：改一個位元組、重新解析、比對結果，有差別就是有讀。掃程式碼會漏掉算出來的索引，量測不會。
- 量測是**下界**：只在某些職業／種族才被讀的位元組，基準記錄沒涵蓋就會被判成沒讀。所以基準有多份，而且「台帳說 decoded 卻沒量到」會讓這支回非零離開碼。
- ⚠ **匯入不會因為 `unknown` 而遺失資料**：`LoadSAVGAMSlot` 保留整份原始記錄，寫回時只動已知位移（spec 185）。這份報告衡量的是**理解程度**，不是保真度。
- 對帳的粒度是**每一段**，不是每一個位元組：長度可變的內容（名字尾巴、沒用到的法術槽）在單一份基準記錄裡本來就量不到，逐位元組要求會產生一堆假警報。
