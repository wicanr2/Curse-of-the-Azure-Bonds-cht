# 未定義區段判定（RE-11）：兩平台 overlay 裡不屬於任何函式的位元組

由 `cmd/re-gap-audit` 產生，不要手改。

分母來自 IDA 匯出的 `undefined_ranges`（`workplace/re-sweep/*/out/*.json`，spec 559 的全模組掃描）。**機械分類只證明位元組的形狀，不證明語意**：「文字」是可列印比率與 Pascal 長度前綴鏈的判定、「同值填充」記的是填充值；**「待人工」再對一次函式台帳**：段完整落在台帳「已解讀」／「邊界碎片」函式範圍內的，那些 bytes 已被人逐條讀過（IDA 匯出把函式中段標成 undefined 而已，`overlay-14 0044h` 即此類）——**真正還沒回答的只有「函式外」那些**，逐段附前 16 bytes 供人工判定是資料表還是漏掉的程式碼。

⚠ 常駐執行檔不在分母：DOS `START.EXE` 的匯出 `undefined_ranges` 是 0（IDA 全數認成程式碼或資料）；PC-98 常駐檔沒有 full 匯出。
