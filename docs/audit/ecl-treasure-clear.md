# `27h TREASURE` 之後走得到的 `1Ch CLEARMONSTERS`

由 `cmd/ecl-treasure-clear` 產生，不要手改。

`1Ch` 的名字只講了一半。原作（DOS `overlay-02:120Eh`）除了釋放節點鏈與清
「有怪要打」旗標（`8B69h`，spec 1095），還把 `DS:6F70h` 起的 28 個位元組歸零、
沿 `DS:6F8Ch` 鏈逐節點 `FreeMem(63)`。那兩塊正是戰利品——
`DS:6F70h + i × 4`（`i = 0..6`）是七種貨幣／寶石／珠寶的池（spec 1059），
`DS:6F8Ch` 是 `27h` 串進去的物品節點鏈（spec 1087）。

⇒ **`1Ch` 會把還沒領走的戰利品整堆丟掉。** 這份表列的是 corpus 裡真的走得到
那條路的地方。

⚠ 前向走訪同時收跳躍邊與循序後繼；只用跳躍邊會得到假零。
⚠ 「經過 `COMBAT`」是**存在某一條路經過**，不是每一條都經過。
