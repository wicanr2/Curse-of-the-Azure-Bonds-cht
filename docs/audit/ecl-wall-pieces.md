| 結論 | 數量 |
|---|---:|
| 只發**一組**常數三元組的 block | 19 |
| 發出**多組**的 block | 0 |
| 只有記憶體參照、靜態看不出來的 block | 0 |

「照地圖查一組固定選圖」這個修法，只有在**多組 ＝ 0 且只有記憶體參照 ＝ 0** 的時候才是對的。任何一個不為零，就表示牆磚選圖是隨執行時狀態變的，查表會在那些 block 上給出**自洽但錯**的牆——而且畫面看起來仍然正常。
