# 每一段 ECL 進入時設定的天空選色

由 `cmd/ecl-sky-colours` 產生，不要手改。機制與證據見 spec 1185。

`4BFDh` ＝ 室外、`4BFEh` ＝ 室內；地圖的屋頂位元組 `>= 80h` 時用室內那一個。
選色索引經引擎的 `skyPalette` 查表才是 EGA 色號。
