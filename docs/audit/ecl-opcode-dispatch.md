# ECL opcode → handler 對照表（overlay-02 `INTERPET`）

由 `scripts/ecl_dispatch_table.py` 產生，不要手改。做法是對 opcode
`00h..FFh` 逐值符號執行 dispatcher 的比較／分支鏈，走到第一個 `call`；
分支目標一律取 IDA 的 code ref，不從助憶碼字串解析標籤。
遇到不在支援集合內的指令會停下並標記，本表的『需人工讀』為 0。

- **DOS**：dispatcher `3377h..3621h`，opcode 來源 `ds:75FFh`，handler 44 個／涵蓋 opcode 53 個／需人工讀 0 個。
- **PC98**：dispatcher `373Eh..39A5h`，opcode 來源 `ds:0A891h`，handler 44 個／涵蓋 opcode 53 個／需人工讀 0 個。
