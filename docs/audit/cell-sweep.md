# 逐格實測（站上去真的演了什麼）

由 `cmd/cell-sweep` 產生，不要手改。

對每個有地形分派的 block、每一個分派索引，直接進段、把隊伍放到那個地形碼
的第一格上、跑一次地城生命週期，記下玩家真的看到的字。對照表
（`docs/audit/ecl-cell-events.md`）只讀 bytecode，回答「會跳到哪支處理
常式」；這一份回答「跳過去之後演不演得出來、是不是中文」。

⚠ 每一格都重新進段，once-only 旗標不互相污染。
⚠ 盤點用的隊伍被撐起來過，好讓入口戰鬥不擋住盤點。**「演得出來」不等於
「正常隊伍走得到」**——可達性由主線分段測試負責。
⚠ 「前置」欄是**第二次站上去**的結果：守衛裡 `COMPARE <格子> <值> / IF <op> /
EXIT` 那幾條拆得出來，把格子設成避開 `EXIT` 的值再站一次。演得出來就代表
這一格**有接、只是缺前置劇情**（spec 1177）。⚠ 那是**滿足守衛**不是重現劇情，
擺出來的狀態不保證正常玩下來會有。
⚠ 剩下的「沒演出來」四種形狀，都是**盤點的限制**不是 remake 的缺口：
（1）守衛比的是移動前快照（`4BF0`／`4BF1`）——這支是把隊伍放上去不是走過去；
（2）擺好的旗標被該段自己的前導覆蓋（`4C01` 這一類）；
（3）擷取到的守衛跨過了真正的處理常式（開頭就有 `EXIT` 的那幾格）；
（4）處理常式本來就不講話（`PICTURE FF` 只是把圖關掉）。
⚠ 索引 0 是「沒有事件的地面」，不列。
