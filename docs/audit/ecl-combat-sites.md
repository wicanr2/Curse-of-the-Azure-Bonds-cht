# `24h COMBAT` 逐處盤點（三選一走哪一支）

由 `cmd/ecl-combat-sites` 產生，不要手改。

`24h` 沒有運算元。它是**服務分派點**（spec 1095）：先看兩個引擎寫的請求旗標，
命中就跑商店或營地並跳過戰鬥，否則才進戰鬥。所以這裡分的是「前面有沒有把怪物
擺上去」——沿控制流**往回走**找 `0Bh LOAD MONSTER`／`0Ch SETUP MONSTER`，
碰到 `1Ch CLEARMONSTERS` 就停在那一條路上。

⚠ 往回走用的是 `TraceGraph` 的邊，不是位址順序。
⚠ **「沒擺過怪」不等於「一定是商店或營地」**：也可能是前一段留在場上的怪，
或走訪跟不到的路徑。這份表只把兩堆分開，不替沒擺過的那一堆下結論。
