# 法術演出用哪個圖組槽

由 `scripts/spell_visual_table.py` 產生，判讀見 [spec 1126](../spec/1126-spell-visual-slots.md)。不要手改。

演出入口是 `<overlay-24 entry#24>(槽)`，對同一個槽連放四格。
**`槽 = COMSPR 區塊 + 13`**（`overlay-11` 開場的載入迴圈量出來的）。

⚠ 這張表只涵蓋 `entry#24` 這條路。同一個 blit（`entry#23`）還有兩類使用者不在這裡：兩種雲的持續區域格（COMSPR 區塊 4／2）與弓箭八方向（區塊 0／1／2、128..130，`overlay-13` 的 11 個直接呼叫點）。
