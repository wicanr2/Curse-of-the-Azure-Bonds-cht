# 段內可達性：從入口用走的，走得到哪些格子

由 `cmd/dungeon-walk-probe` 產生，不要手改。

★ 可達性報表說主線實跑只踏到 250 個分派索引裡的 81 個，其中提爾佛頓整整三段一格都沒踏到。那句話有兩種完全不同的成因：**主線不經過那裡**（路線的選擇）或**那些格子走不進去**（缺陷）。逐格實測分不出來——它把隊伍**直接放**到目標格上。這一支從入口出發，只用 `CanMoveDungeon`／`MoveDungeon` 廣度優先地走。

⚠ 這**不是**「從新遊戲玩到那裡」：進段是直接進的。它答的是**段內**可達性——人已經在這張地圖上，走得到幾格。

⚠ 走的時候會踩到事件、戰鬥、被劇情推走；推不回地城就停在那條分支上。⇒ **下界**：走不到不代表不可達，可能只是被某個事件擋在半路。
