# 驗證報告：世界地圖的分支與旅途場景

- 日期：2026-08-20
- 範圍：世界地圖兩個 hub 的原作選單、旅途場景的索引來源
- 結論：**通過**。`4C9D` 的算法讀出來了（spec 1143）。世界地圖從 **13 個地點**
  各掃一次，走到 **762 個分支**，敘述與選項**都沒有一條落回原文**——過程中抓到
  **4 個沒中文化的選項**（`MEET THEM`／`PASS`／`HIDE`／`BY BOAT`）與
  **11 個城市的場所提示**，都補上了。

## 一、`4C9D` ＝ 出發地 × 4 ＋ 選的方向

上一輪把「兩個世界地圖 hub 用查表分派旅途場景、索引取自 `4C9D`」解出來，剩下的
問題是 `4C9D` 從哪來。逐條讀完是：抵達一個地點時 `MULTIPLY 4C9C, 4 → 4C9D` 算出
基底並把四個鄰居載進 `4C02..4C05`；玩家選好方向之後 `ADD 7F79, 4C9D → 4C9D`。
所以它是一條**有向邊**的編號，四張表（旅行天數、走法數、到達地點、旅途場景）
都用它當索引。細節與「不宣稱什麼」見 spec 1143。

## 二、抓到的：3 個選項與 11 個城市提示

| 原作 | 補的訊息 id |
|---|---|
| `MEET THEM` | `ecl-option.meet-them` |
| `PASS` | `ecl-option.pass` |
| `HIDE` | `ecl-option.hide` |
| `BY BOAT` | `ecl-option.by-boat` |
| `YOU ARE IN <城市> . WHAT PLACE WILL YOU VISIT?` | `<城市>.places`，補了 11 個 |

⚠ 選項要**單獨判語系**。溫拉爾軍隊那一場的敘述早就中文化了，三個選項卻還是英文
——只看敘述的語系閘門會說這一場「已經接好」。**中文化的缺口會躲在沒被量的那一維。**

⚠ 城市場所提示原本只有艾森布拉、希爾斯法、阿沙本福德三個有規則，其餘 **11 個
落回原文**。那句話是執行期組出來的（`PRINT "YOU ARE IN "` ＋ 變數插入 `7B01`
＋ `PRINT ". WHAT PLACE WILL YOU VISIT?"`），一條程式路徑、14 個地名代入，所以
補齊的依據是同一條路徑，不是逐城觀察——目前實際走到並確認的只有暗影谷。

## 三、工具

`cmd/route-sweep` 從世界地圖 hub 直接進去，把**原作選單**的每個選項都選一次，
記下演出來的字與選項本身的語系。分辨「原作選單」與「remake 自己的 UI 選單」靠
新加的 `State.CurrentOriginalChoices()`：原作選單的原文是自然英文（`ENTER CITY`、
`MEET THEM`），remake 的 UI 選單用帶底線的識別字（`REST_START`、`TEMPLE_HEAL`）。

覆蓋是「每個地點各掃一次」：`State.ArriveAtWorldLocation` 直接抵達 game pack 宣告的
14 個地點，再從那裡把原作選單的每個選項都選一次。⚠ 只從開局的位置掃會漏掉一大半
——**走不到的地點與沒有內容的地點長得一模一樣**。加上這一步之後，走到的分支從
17 個變成 **762 個**（`WILDERNESS`／`TRAIL`／`BY BOAT` 三種走法、`ENTER CITY`／
`JOURNEY ON`、以及城裡的 `INN`／`STORE`／`BAR`／`TEMPLE`／`HALL`…）。

⚠ **仍然是下界**：14 個地點裡有 **1 個（迷斯卓諾）**從這個起點抵達後沒有可走的
選單——那一段要有第六章的劇情進度；另有 **161 條分支推不動**。所以產物寫在
`workplace/` 不進版控，把下界擺成 audit 產物會讓人以為那就是全集。

閘門是 `TestWorldMapBranchesAreLocalized`，⚠ 它**同時釘住分支數的下限（700）**：
走訪一旦壞掉（起點進不去、選單認錯），分支數會塌下來而剩下的每一條還是中文
——**語系全綠，其實什麼都沒驗到**。

原版資料的載入流程抽成 `internal/gamecorpus` 給 `cell-sweep` 與 `route-sweep`
共用：少載怪物表那一段就不開戰、少載物品表那一段在入口就跑不動，兩種都是安靜地
少一塊內容，集中一份至少會一起漏。
