# 驗證報告：開場到結局的完整主線

- 日期：2026-08-20

- 結論：**通關了**。同一條新遊戲 session 從開場走到擊敗提朗瑟克斯的結局選單，
  由 `TestRealNewGameRunsToTheEnding` 的 23 個段測試守著。

選存檔之後回到標題模式。

## 二、關鍵是換方法：讀 bytecode，不要在地圖上撞

墓園往外城遺跡的入口卡了好幾輪。逐格走試探很貴——那張圖不是連通的一整片，
走錯一步就被送回世界地圖，而且每次都要重跑整條 session。

改成讀 ECL 之後，三個轉移在幾分鐘內全部定位（新工具
[`cmd/ecl-window`](../../cmd/ecl-window/main.go)）：

| 轉移 | 守衛 |
|---|---|
| 墓園 → 外城遺跡 | 邊界處理是 `ON GOTO C04D`（面向÷2，0 起算）：**只有朝東跨出邊界**才走到「更多遺跡」的選單 |
| 外城 → 內城遺跡 | 同樣是 `ON GOTO C04D`，索引 0（**朝北**）走到大神殿廢墟，答兩次「要繼續嗎」 |
| 內城的每格事件 | `ON GOTO (C04F & 0x7F)`：用**地形碼**分派。樓梯是 `0x97`（索引 23，只有 `(10,7)`），最終戰是 `0x9A`（索引 26，`(6,1)`）|

⇒ **守衛條件寫在 bytecode 裡，讀它比撞它便宜。** 這條在慢回饋的情境特別划算：
一次 session 重跑要十幾秒，讀一次 ON GOTO 的表就把整個搜尋空間收斂掉。

## 三、少了什麼會走不到

- **第六章的怪物表沒載，最終戰不會開打**。測試原本只載 MON1／2／3／4／5CHA，
  少了 MON6CHA，爪牙戰那一步會安靜地跳過去——不是報錯，是「戰鬥開始！」之後
  直接回到地城。
- **黛米爾公主是「走進那一格」才出現的**：站在 `(13,14)` 上跑生命週期不會觸發。
- **紅網的解法是 `HACK IT` 不是 `SPEAK`**：說出通關語只會讓網更亮。
