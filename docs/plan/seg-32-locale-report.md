# 驗證報告：`SEG-32` 主線的語系不變量

- 日期：2026-08-20
- 範圍：主線分段驗證計畫階段 3 的 `SEG-32`（該段所有玩家看得到的字都有 `zh-TW`）
- 結論：**通過**。整條主線 260 句話，**沒有一句落回原文**。

## 一、量法

`normalCampaignObserver` 在每次 `observe()` 記下當下的 `state.Message`，
整條 session 跑完之後逐句判定。判準是「有沒有漢字」——原作文字整段是大寫英文，
沒有漢字而有**連續兩個以上英文字母**就是落回原文（單一字母多半是數字旁的單位
或原作代號，不算）。

閘門在 `TestRealNewGameRunsToTheEnding` 的「語系：整條主線沒有落回原文」，
同時擋住「記到的句子太少」——句數低於 100 就直接紅，避免記錄機制壞掉之後
變成永遠綠的裝飾。

## 二、抓到 12 句英文

第一次跑就抓到 12 句玩家看得到的英文，全部在猶拉什與散提爾堡：

| 段 | 句子 |
|---|---|
| 世界地圖 | 紅羽衛巡邏隊放行（「這裡是戰區，自己小心。」）|
| 猶拉什 | 北方的紅羽衛哨卡 |
| 散提爾堡 | 巡邏隊宣讀死刑判決 |
| 散提爾堡 | 八句街頭傳聞（祭壇的錢、迪姆斯沃特被關、手臂上的枷印、半身人的描述、城裡的火藥味、「看來她說得沒錯」、士兵祭司法師互不相讓、兩個慌張跑掉的路人）|

十二句都補進 game pack（`text_rules` ＋ `zh-TW`／`en`）。

## 三、⚠ 敘述不只走 `Message` 那一條路

第一版只記 `state.Message`，於是**遭遇選單的敘述一句都沒被檢查**——
`ENCOUNTER MENU`（`29h`）的三段敘述在 remake 走的是 `Prompt` 那一行
（`localizeECLPrompt`），不是 `Message`。

把 `Prompt` 也記進去之後，又抓到 6 句英文：瓦礫堆裡翻找的人、
「蟲群正盯著你們」、「巡邏隊正盯著你們」、「火蜥蜴靠了過來查看」，
以及兩句「你們要怎麼做？」。

⇒ **語系閘門要涵蓋每一條玩家看得到的字的路徑**，不是只有主敘述那一條。
少記一條路徑，那條路徑上的英文就永遠不會紅。

## 四、⚠ 一句話可能分成兩頁

紅羽衛巡邏隊那一句原本寫成**一條兩片段的規則**，結果一次都沒命中。
原因是那段文字在原作裡是**兩個分支**：

```
PRINTCLEAR "YOU ARE APPROACHED BY A RED PLUME PATROL."
COMPARE 4C5A, 1 / IF = / GOTO ...   → PRINT "'YOU ARE IN A WAR ZONE, BEWARE.'THEY LET YOU PASS."
                                     ↓ 否則 LOAD MONSTER / COMBAT
```

`MatchText` 拿到的是**一次執行累積的文字**，而放行與開打是兩條路徑，
所以「第一句 ＋ 戰區那句」永遠不會出現在同一份輸入裡。拆成兩條規則就對了。

⇒ **跨分支的 `all_contains` 在實機接不上**。寫規則前要先確認那兩段文字真的
會在同一次執行裡一起出現。

## 五、⚠ 廣義規則會蓋掉既有的具體規則

`MatchText` 回傳**清單裡第一個命中的規則**。只寫第一句的
`overland.red-plume-patrol` 一旦排在既有的 `yulash.red-plume-patrol`
（第一句 ＋ 刺青那句）前面，就會把後者整條蓋掉。

處置：廣義規則一律排在具體規則之後；哨卡那條也補上方向
（`TO THE NORTH`），免得蓋掉既有的「往東」。

## 六、明確不宣稱

- 沒有宣稱整個遊戲沒有英文：量的是**這條 session 走過的 260 句**。
  沒走到的支線不在範圍內。
- 沒有宣稱這 18 句的譯文與原作語氣完全對應；譯文是逐句依原文重寫的。
- 判準是啟發式的：一句全是專有名詞的中文譯名（例如只有人名）不會被判成原文，
  一句夾雜英文縮寫的中文也不會。
