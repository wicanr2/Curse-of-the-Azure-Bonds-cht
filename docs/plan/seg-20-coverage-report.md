# 驗證報告：主線分段的接線盤點

- 日期：2026-08-20
- 範圍：主線分段驗證計畫階段 2 的現況盤點（哪一段接到什麼程度）
- 結論：**25 段的入口都接上了**。入口文字與選項沒有一段落回原文；
  3 段的入口不出文字，而那是被帶進來的段落，不是缺漏。

## 一、量法

`cmd/segment-coverage` 對每一段直接進入（`-segment <id>` 的同一條路徑），
記下入口畫面出了什麼、入口文字與選項是中文還是原文、從入口再走一步會到哪裡。
輸出是 [`docs/audit/segment-coverage.md`](../audit/segment-coverage.md)。

「中文／原文」看的是**有沒有漢字**。原作文字整段是大寫英文，所以沒有漢字而有
英文字母就是落回原文。判準本身有正反對照（`TestLanguageOfSeparatesHanFromOriginalText`）。

## 二、結果

| 現況 | 段數 |
|---|---:|
| 入口有中文劇情 | 22 |
| 入口不出文字 | 3 |
| 入口落回原文 | 0 |

入口不出文字的三段是 `ECL2/0x02`（城區共用地圖）、`ECL3/0x12`（地下第二層）、
`ECL4/0x21`（神殿與牢房）。三段的共同點是**從別段被帶進來**：`0x21` 是從
`0x20` 被拖進神殿的，`0x12` 是從 `0x11` 往下走一層，`0x02` 與 `0x01` 共用地圖。
它們的劇情在前一段的轉移與每回合／搜尋生命週期裡，不在 `initial`。

## 三、⚠ 三個被推翻的舊斷言

計畫階段 2 原本按印象分成三類，量過之後三條都不成立：

- 「9 張 `original.geoN.block-NN` **地圖走得動、事件沒接**」——那 9 段的入口
  全部出中文劇情文字（猶拉什三段、哈普／熔岩洞／巫師塔／深層地城入口、
  外圍遺跡區）。
- 「ECL6 那三個**沒有出邊**」——只有 `0x43` 沒有。`0x40 → 0x42`／`0x50`、
  `0x42 → 0x40`／`0x43`。
- 「其餘 block **完全沒接**」——沒有任何一段的入口落回原文。

計畫正文已改寫成量出來的版本。

## 四、量的過程中修掉的一件事

第一版的盤點裡 `ECL2/0x02`、`ECL3/0x12`、`ECL4/0x21` 顯示的是**前一段的文字**
（「你們在一間小房間裡醒來…」）——`StartStorySegment` 沒有清掉上一段留下的
訊息與選單，於是不出文字的段看起來像有接。清掉之後這三段才現形。

**入口沿用前一段的字，比沒有字更難發現。** 盤點工具本身要先能區分「這一段
出了字」與「畫面上有字」。

## 五、明確不宣稱

- 沒有宣稱這 22 段的**整段**文字都接好了：量的是入口那一頁。段內的逐頁覆蓋
  看 `cmd/ecl-text-coverage`。
- 沒有宣稱「再走一步走得動」等於那一段玩得完；一步是一步。
- 沒有宣稱那三段在原作裡也不出文字——只宣稱它們的 `initial` 不出。
