# 驗證報告：段內支線與遭遇選單的旁白

- 日期：2026-08-21
- 範圍：主線 23 份段界快照上的逐格取樣、`29h ENCOUNTER MENU` 的旁白中文化
- 結論：**通過**。段內支線在主線進度下 9 段、123 格演得出來、落回原文 0 格；
  `29h` 的 20 句旁白原本有 **8 句玩家會看到整句英文**，補上規則與譯文後歸零。

## 一、段內支線量的是另一次取樣，不是同一件事的第二遍

`cmd/cell-sweep` 每一格都**重新進段**，用一支撐起來的盤點隊伍，答的是「這一格演
不演得出來、是不是中文」。這一輪加的 subtest 站上去的是**帶著主線進度、once-only
旗標已經被主線設過**的隊伍——同一格在不同旗標狀態下演的可能是別的東西。

所以「沒演出來」在這裡**不是缺口訊號**：段界那個時點，那張圖上多數事件已經被主線
自己觸發掉了。這一支擋的是兩件事：演出來的字落回原文，以及走訪整個塌掉。

## 二、兩個會讓這份數字整批失真的坑

**讀回來的狀態身上還掛著上一句話。** 存檔存的就是當時畫面上的字，不清掉就會被
當成「這一格演出來的」。第一版因此得到 **143／143 全部演得出來**，而且每一格演的
都是同一句「隊伍已建立。準備開始冒險。」清掉 `Message` 與 `Prompt` 之後才是真的。

**分派器與地圖必須取自同一個來源。** 段界記的 block 是**那一段結束時**的 block，
常常已經走進下一段而地圖還沒換。拿它去查分派器，就會用 A 段的地形碼表配 B 段的
地圖，得到一堆看起來像內容缺口的假紅（`0x22` 配 `GEO4/0x21` 那次是 4／21）。
改成一律取自「讀回來、推穩之後」的那個狀態。

⚠ 另外，段界快照不一定停在地城的行走畫面上。停在事件或選單上就先按繼續推回去，
推不回去才跳過並記原因——直接跳過會讓「這一段沒有段內支線」與「還沒把畫面推完」
長得一模一樣。

## 三、`29h ENCOUNTER MENU` 的旁白：一批沒有被數過的文字

`29h` 帶三句旁白（運算元 9、10、11），原作依距離挑一句。remake 目前只取**第一句
非空的**（`internal/ecl/runtime.go` 的 `0x29`）。

`cmd/ecl-text-coverage` 的分母裡**沒有這個 opcode**——它走的是「印字指令連成的
一頁」。所以那份報告寫著「未接上 0 群」的時候，這 48 句文字連被數到都沒有。
**查無與不存在長得一模一樣。**

新增 `cmd/ecl-encounter-text` 逐句比對 `all_contains`（不是把三句合起來比，合起來
比會讓第一句的規則把另外兩句蓋掉），結果：

| 項目 | 數 |
|---|---:|
| `29h` 的處數 | 20 |
| 旁白總句數 | 48 |
| remake 演得到的句數 | 20 |
| 演得到但沒接上譯文（**修正前**）| **8** |
| remake 演不到的句數 | 28 |

八句是玩家真的會看到的整句英文：猶拉什的髒袍人、教徒推人出門、散提爾堡的守軍
瞪視、法師與護衛、班恩的祭司、弗佐爾的傳喚、班恩的爪牙、密斯卓諾的巡邏隊。
規則與譯文都補上了，`TestShownEncounterPromptsAreLocalized` 釘住它不再回頭。

**同一句話有兩個來源。** `A DARK ELF PATROL ARRIVES` 其實早就有譯文，但走的是
`localizePrompt` 裡的硬編分支而不是 pack 規則——工具照 pack 判會把它報成缺口，
而改 pack 也改不動它。這一輪把它收斂到 pack，可見字串不變。

## 四、剩下的

1. **28 句 remake 演不到的旁白**是**還原度**缺口，不是中文化缺口：原作依距離在
   三句之間挑，remake 只演第一句。要補的是 `0x29` 的距離判斷，補完才輪到譯文。
2. `ECL2/0x03`（提爾佛頓下水道）沒有對應的段界快照——它在主線開場那一段之前，
   所以這一支取樣不到。
3. 四份段界快照停在世界地圖上推不回地城，這一支掃不到；那幾段的分支由
   `cmd/route-sweep` 負責。
