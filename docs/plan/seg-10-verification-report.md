# 驗證報告：`SEG-10`／`SEG-11` 後半／`SEG-13` 分段測試

- 日期：2026-08-20
- 範圍：把整條主線跑拆成每段一個測試，並在每段結束存下可重播的快照
- 結論：**通過**。12 段各自一個 subtest，覆蓋的步數一步都沒少；
  12 份段界快照全部存得下去、讀得回來。

## 一、拆法

`TestRealNewGameContinuesFromHapToBeholderCaveEntrance` 原本是一個 790 行的
函式。現在同一條 session 拆成 12 個 subtest：

| subtest | 段 |
|---|---|
| `ECL5/0x31 哈普村` | 世界路線進村 → 村內事件 → 東側外部出口 |
| `ECL5/0x32 古熔岩洞與 ECL5/0x33 巫師塔` | 守門戰、熔岩池、火蜥蜴、巫師塔往返 |
| `ECL1/0x50 世界路線：艾森布拉到希爾斯法` | 屋頂離開、Area5 道別、世界圖路由 |
| `希爾斯法城內` | 碼頭酒館挑釁、戰鬥、離城 |
| `ECL1/0x51 世界路線：希爾斯法到猶拉什` | 世界圖路由 |
| `ECL3/0x10 猶拉什：地面與指揮部` | 哨卡、間諜、指揮官、側門、坑洞入口 |
| `ECL3/0x11 猶拉什：地下第一層` | 艾莉亞絲與龍餌入隊、往下層 |
| `ECL3/0x12 猶拉什：地下第二層` | 莫吉安祭壇整段、祭壇搜尋、回上層 |
| `ECL3/0x11 返回與猶拉什邊界` | 最後一戰、離開猶拉什 |

段紅的時候直接看得出是哪一段；一段紅了就 `t.FailNow()`，不讓後面的段拿著壞掉
的狀態繼續跑出一串假故障。

## 二、覆蓋的步數一步都沒少

拆的方式是**純結構轉換**：同一條 session、同樣的敘述、同樣的順序。
把新舊兩份正規化之後逐行比對（去掉縮排、去掉 `t.Run` 包裝、把提前宣告的變數
還原成原本的 `:=`），差異只有三類：

- 開遊戲 image 的那一段從第一段的中間**搬到函式開頭**（開 zip 沒有遊戲狀態）；
- 跨段共用的四個變數改成先宣告後指派（宣告在 subtest 裡出不了那個閉包）；
- 12 個閉包各自多一個右大括號。

**沒有任何一個遊戲動作被加進來或拿掉。**

## 三、段界快照（`SEG-11` 後半）

每段結束時 `SavePartyFile` 存一份，最後一個 subtest 整批驗往返：讀回來的
block、模式、章節／地城、隊伍人數都要與存下去時一致。12 份全過。

這是 `SEG-11` 缺的那一半——先前只驗得到**段的入口**，現在段的**結束**狀態
也存得下去讀得回來，而那正是下一段真正該用的入口。

## 四、`SEG-13` 的處置

計畫原本寫「整條跑降級成 smoke，主要 gate 換成段測試」。現在主要 gate 已經是
段測試（12 個 subtest ＋ 段界快照往返），整條跑是它們共用的同一條 session。

**快照不進 repo。** 把 12 份存檔當成固定 fixture 收進版控，存檔格式一改整批
失效，而維護成本落在每一次格式演進上。目前的形狀已經拿到分段診斷與快照往返
兩項好處，不需要付那個代價。

## 五、明確不宣稱

- 沒有宣稱 12 段彼此獨立：它們共用一條 session，前一段紅了後面就不跑。
  真正的獨立要靠段界快照當入口，而快照不進 repo（見 §四）。
- 沒有宣稱這 12 段涵蓋 25 段裡的其餘 13 段——那是階段 2 的接線工作。
- 沒有宣稱段界快照保留了選單、待處理的 ECL 執行位置或戰鬥交易；比對的欄位
  列在 §三。
