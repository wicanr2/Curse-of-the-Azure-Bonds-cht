## 一、路線

散提爾堡的世界圖鄰居只有帖許瓦／猶拉什／費蘭，接不到立石群。實際可走的是

```

```

立石群到密斯卓諾這一段在 game pack 的世界圖裡本來就宣告好了
（`standing-stone → [ashabenford, essembra, hillsfar, myth-drannor]`），
缺的是路上那一場戲。

## 二、立石群的灰袍男子：一個變數插入頁

走到立石群跑生命週期，原作演的是灰袍男子那一場：

| 步驟 | 文字 |
|---|---|
| 1 | 你們來到立石群。一名灰袍男子靠著巨石而坐⋯ |
| 2 | 他開口說：「你們目前仍服侍**兩位**主人。再除掉其中**一位**後回來找我⋯」|
| 3 | 他繼續說：「往南方尋找紅色之人。」|

★ 第 2 句的數字是**執行期插進同一頁**的（原作字串是
`S. RETURN TO ME WHEN YOU HAVE SLAIN` ＋ 數字 ＋ ` MORE.`）。
game pack 原本只宣告了「四位主人／再除掉三位」那一種，所以這條路徑走到這裡
會直接把原文英文印給玩家。這一輪補上「兩位主人／再除掉一位」。

⚠ **其餘數字仍未宣告**。只補有執行期證據的那一種——沒有走到過的變體是猜測，
不寫進 pack。走到哪一種就補哪一種。

## 四、墓園裡往東要繞路

出生點是 `(2,15)`，而 `-burial-red-web` 直入的紅網格是 `(6,14)`。量過 `GEO6/0x40`
在 `y=12..15`、`x=0..8` 的通行性（N／E／S／W，`o` 通、`#` 牆、`X` 外部出口）：

```
(2,15)oo##  (3,15)o##o  (4,15)#o##[80] (5,15)###o[80]
(2,14)ooo#  (3,14)o#oo[01] (4,14)#o##[80] (5,14)#o#o[80] (6,14)#o#o[82]
(2,13)oooo  (3,13)oooo[01] (4,13)oo#o  (5,13)#o#o  (6,13)#o#o
```

★ **擋路的不是牆，是事件**：`x=3` 那一整欄（地形 `0x01`）是墓園的離場格，
`(3,13)` 與 `(3,14)` 踩上去隊伍都會被送回世界地圖。往東繞 `y=12` 那一列就通了：

```
(2,15) → (2,13) → (2,12) → (6,12) → (6,14)
```

⇒ 走到 `(6,14)` 拿到紅網那一場：「一張散發黯淡紅光的巨網橫亙在通道上。」
四個選項 `ENTER IT／SPEAK／HACK IT／RETREAT` 全部已中文化。

⚠ **`SPEAK` 不是解法**：說出通關語只會讓網更亮（`red-web.brighter`）。
原作的解法是 `HACK IT`——紅光消退、露出金屬套索、遠處有人咒罵跑走，
接著是蜘蛛，打完回到 `(6,14)` 的地城模式。

第一版判牆的自製規則（`wall == 0 || flags == 2 || flags == 3`）與引擎自己的
`CanMoveDungeon` 對不上，害我把「事件擋路」誤讀成「牆擋路」。
**判通不通要用引擎自己的判定式**，不要另外寫一套。
