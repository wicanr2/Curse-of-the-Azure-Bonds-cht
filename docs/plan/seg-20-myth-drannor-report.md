```

```

立石群到密斯卓諾這一段在 game pack 的世界圖裡本來就宣告好了
（`standing-stone → [ashabenford, essembra, hillsfar, myth-drannor]`），
缺的是路上那一場戲。

## 二、立石群的灰袍男子：一個變數插入頁

走到立石群跑生命週期，原作演的是灰袍男子那一場：

| 步驟 | 文字 |
|---|---|
| 1 | 你們來到立石群。一名灰袍男子靠著巨石而坐⋯ |
| 2 | 他開口說：「你們目前仍服侍**兩位**主人。再除掉其中**一位**後回來找我⋯」|
| 3 | 他繼續說：「往南方尋找紅色之人。」|

★ 第 2 句的數字是**執行期插進同一頁**的（原作字串是
`S. RETURN TO ME WHEN YOU HAVE SLAIN` ＋ 數字 ＋ ` MORE.`）。
game pack 原本只宣告了「四位主人／再除掉三位」那一種，所以這條路徑走到這裡
會直接把原文英文印給玩家。這一輪補上「兩位主人／再除掉一位」。

⚠ **其餘數字仍未宣告**。只補有執行期證據的那一種——沒有走到過的變體是猜測，
不寫進 pack。走到哪一種就補哪一種。
