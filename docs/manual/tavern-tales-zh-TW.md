# 酒館傳聞（目前已整理）

以下是 Adventure Journal `TAVERN TALES` 的前六則繁中整理，保留編號，讓後續 ECL／城市 script 可以用 tale ID 接回遊戲，而不是把傳聞文字散落在 renderer。

1. 有人低聲說：公主與國王都喬裝在城中。
2. 火焰巨人行走於精靈庭院，只害怕三件古老神器；其中一件可能在北方瀑布下。
3. 許多士兵覺得深坑不祥，有人寧可逃亡也不願去守衛。
4. 這座城市的下水道，是達倫地區最危險的地方之一。
5. 紅袍刺客正在森林小徑巡邏。
6. 商人冒險者 Akabar 已南下調查 Hap，另有一支女冒險者隊伍同行。

目前實作只把這六則作為可替換的預設 sequence；不代表已解出每座城市的實際觸發順序，也沒有把所有 62 則傳聞提前展示給玩家。
