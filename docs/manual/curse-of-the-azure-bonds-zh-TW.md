# 《青色枷的詛咒》繁體中文遊玩手冊

本文件是本 remake 的繁中整理版，提供遊戲內必要的背景與操作提示；它不是原版手冊的逐字重製。原始 DOS 手冊與 Adventurer's Journal 僅作本地研究素材，版權仍屬原權利人。

## 故事起點

冒險者為了尋找科米爾公主納卡西亞，前往提爾佛頓。途中遭到看不見的襲擊，醒來時已失去裝備，右臂皮膚下則留下五枚蔚藍色的魔法枷印。枷印會支配意志；隊伍必須查出製造者，逐一解除束縛。

第一篇冒險手札提醒隊伍：先在提爾佛頓補充武器與護甲，再向神殿、賢者、酒館等人查詢線索。後續旅程會穿越達倫地區的城鎮、荒野與遺跡。

## 基本操作

| 按鍵 | 用途 |
|---|---|
| Enter／Space | 確認選項、推進事件、執行戰鬥行動 |
| 方向鍵 | 移動游標、在荒野地圖移動、選擇戰鬥目標 |
| Esc | 離開地圖或關閉手札 |
| J | 隨時開啟冒險手札（戰鬥中停用） |
| F5 | 儲存已建立的隊伍至 `party.json` |
| F9 | 從 `party.json` 載入隊伍 |

手札共有八頁摘要；開啟後用左右／上下鍵翻頁，頁面內容包含序章、地理、勢力、神器、調查與戰鬥提示。

啟動時可用 `-font` 指定支援繁中文字形的 TTF／OTF 字型，例如：

```text
go run ./cmd/azure-bonds-game -font /path/to/cjk-font.ttf
```

可用 `-party-save PATH` 更換 F5／F9 使用的檔案；也可用 `-party-load PATH` 在啟動時載入 remake 的版本化 party JSON。這份檔案目前只保存角色描述，不是原版 DOS 存檔。

## 地點速覽

- **提爾佛頓**：故事開始的邊境城市，隊伍在此重新整裝並追查枷印。
- **暗影谷**：冒險者聚集的城鎮，也是前往荒野、客棧、商店與酒館的第一個已接入地點。
- **阿沙本福德**：迷霧谷的主要聚落。
- **匕首瀑布**：匕首谷的農業聚落。
- **精靈庭院／秘銀德拉諾**：古老精靈文明留下的森林與遺跡區域。

## 戰鬥提示

本 remake 已接入基本回合、先攻、AC、攻擊與傷害，以及繁中戰鬥畫面。左右鍵選擇敵人，Enter 攻擊。完整法術、物品效果、逃跑／談判、戰場格位與所有 AD&D 規則仍在還原中。
