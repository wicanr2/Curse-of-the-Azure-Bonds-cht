96／100（工程判斷，不是各分母平均）。**知識底盤、靜態劇情接線與第一人稱

封包尚未驗收。非第一人稱畫面、支線、音訊時機與中文人工校對改採代表性抽樣，
不再要求全量閉合。

## 評分與驗證口徑（2026-08-27 使用者決定）

- 目標是 **99／100**，不是宣稱逐 byte、逐像素或逐週期 100% 相同。
- 目前 **96／100** 是整體玩家體驗的風險評分，不由下表百分比相加或平均。
- 必過閘門：正常玩家可由開場到結局、主要戰鬥與替代路徑可玩、存讀檔可靠、
  繁中不落回原文、三平台交付物可啟動，以及沒有已知阻塞／資料毀損缺陷。
- 抽樣面：各主要 UI 類型、前中後期戰鬥、攻擊／法術／道具／逃跑、勝敗、
  城鎮／地城／世界地圖、存讀檔、音樂／語音／音效與主要支線各取代表樣本；
  高風險或曾出錯處提高密度。
- 未抽中範圍與硬體時序近似必須明列，不能寫成 `exact`；但不再為低風險尾端
  差異追求全量 oracle。

## 到「可對外交付」還差的工作

1. **Release 圖像獨立化**：既有 780 張 sprite PNG 已由 runtime 使用；補齊
   TILES、combat terrain、AREA/shared symbols、SKY 與 wall PNG＋WallDef JSON，
   詳見 `docs/audit/png-asset-independence-2026-08-27.md`。
2. **代表性玩家路徑抽樣**：主線、主要替代入口、前中後期高風險支線與曾出錯
   分支各至少一條；不再把 ECL 實跑覆蓋率推到全量當成完成條件。
3. **非第一人稱畫面抽樣 oracle**：選單／戰鬥／PIC／AREA／結局各取代表狀態；
   發現系統性差異才擴大同類樣本，不預設全量逐格比對。
4. **發行工程收尾**：Windows／macOS 真機啟動、macOS 簽署／公證、對外授權清單。
