## 到「可交付」還差的四步（依擋路程度排）

1. **連續按鍵通關**：從巫師塔往後把輸入層瓶頸逐個拆掉（歷史經驗：每個瓶頸
   拆掉後幀數翻倍前進）。這一條走完，「完整可玩」才成立。
2. **實跑覆蓋 59.6% → 目標值**（要先定停損線）：逐叢集鋪旗標路線；
   未蓋清單在 `docs/audit/ecl-run-coverage.md`。
3. **非第一人稱畫面的 oracle 比對**：把第一人稱那套（擷取→EGA 量化→逐格比）
   延伸到選單／戰鬥／PIC——工程已有全部零件，缺的是批次。
4. **發行工程**（gate 解除後）：三平台打包、資產授權界線、安裝說明。

音訊時機比對（PC-98 儀器）與整輪中文人工校對可與上述平行，
但都需要單獨的成本決定。
