# CoAB 四語 AI 翻譯與重要名詞表

更新日期：2026-08-29。

本檔是繁體中文（`zh-TW`）、簡體中文（`zh-CN`）、日文
（`ja`）與英文（`en`）的跨語系翻譯契約。繁中專名的完整權威表仍是
[`coab-glossary.md`](coab-glossary.md)；本檔只集中跨語系的重要詞與產生規則，
不複製全部繁中禁用譯名。

## 翻譯方式

- 使用者決定四語內容以 AI 翻譯，不建立人工校譯閥門。
- 英文劇情以原版 game pack `en` 文本為源，不把繁中回譯成英文。
- 簡中以繁中轉換為底，再套用本表的專名與用詞覆寫。
- 日文以原版英文為優先輸入；只有英文目錄沒有的 UI 字串才由繁中
  AI 翻譯。這能避免經過繁中的二次轉譯。
- 專案文本只能在離線容器內交給 AI 模型，不上傳外部翻譯 API。
- `printf` 佔位符、JSON key、控制碼、按鍵名、檔名、數值與換行結構先保護，
  翻譯後必須逐條比對簽章；簽章改變就失敗即關閉（fail-closed）。
- 交付文件必須說明簡中與日文是 AI 翻譯版本；不宣稱已經人工校譯。

## 不可自由翻譯的內容

- `F1`～`F10`、`Esc`、`Enter`、`Ctrl+S`、`Ctrl+O`與解析所需的按鍵名。
- `AC`、`HP`、`THAC0`、`AD&D`、`ECL`、`AREA`、`GEO`、`DAX`與檔案格式名。
- `%s`、`%d`、`%02d`等格式佔位符；`\n`可以依版面重排，但不可遺失。
- JSON key、事件 ID、地圖 key、檔名與存檔 schema 值。
