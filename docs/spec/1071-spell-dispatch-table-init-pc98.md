# 1071 — 法術分派表的初始化（PC-98）：101 筆全部指向同一個 overlay 段

- 證據等級：`exact`（PC-98 側 443 條逐條讀完）
- 作法見 spec 783

## `pc98 overlay-22:066EBh`（`retf`）

原本待解讀。整支就是一長串賦值，沒有任何分支。

```pascal
DS:0A38Ch ＋ i × 4 := 0117h:XXXXh;                 { i ＝ 0..100 }
DS:0A036h := 0;  DS:0A64Fh := 0;
DS:0A641h := 0;  DS:0A643h := 0;                   { 一個 32-bit 清 0 }
DS:0A038h := 1;
```

## ★★★ 表的形狀

| | |
|---|---|
| 基底 | **`DS:0A38Ch`** |
| 一筆 | 4 bytes（遠指標） |
| 本支填 | **索引 `0`..`100`，共 101 筆** |
| 段 | **全部是 `0117h`**（一個 overlay 的 entry stub 段） |
| offset 範圍 | `0034h`..`0241h` |
| 相異 handler | **81 個**（101 筆裡有 20 筆是重複指向） |

★ 相異 offset 之間的差是 `5`／`10`／`15`／`25`／`85`
——**`5` 就是 overlay entry stub 的長度**（`CD 3F` ＋ code_offset ＋ flags），
所以這 81 個 handler 是同一個 overlay 裡連號的 entry。

## ★★ 二十筆是共用的

| handler offset | 被幾個索引指到 |
|---|---|
| `00BBh` | **8** |
| `00B6h` | **6** |
| `00F2h` | 3 |
| `0110h`／`012Eh`／`014Ch`／`004Dh`／`015Bh`／`0165h` | 各 2 |

> ★★ **`00BBh` 一支被 8 個索引共用、`00B6h` 被 6 個共用。**
> ⇒ 這兩支是「一群效果共用同一個處理」的通用 handler
> ——與 spec 1005 在效果分派表看到的重複指向是同一種結構。

★ 索引 `0` 指向 `0034h`，**與其他 81 個 handler 的連號區（`00A2h` 起）分開**
——形狀上是「0 號 ＝ 無效／預設」。

## 中文化

## 明確不宣稱

- 沒有宣稱 `DS:0A38Ch` 是法術表還是效果表
  （spec 705／721 的 DOS 側是 `DS:72A0h`，spec 1005 是另一張）。
- 沒有宣稱索引 `101` 以後由誰填（本支只到 `100`）。
- 沒有宣稱 `0117h` 是哪一個 overlay 的 stub 段。
- 沒有宣稱 `DS:0A036h`／`0A038h`／`0A641h`／`0A64Fh` 四個旗標的語意。
- 沒有宣稱 81 個 handler 各自做什麼。
