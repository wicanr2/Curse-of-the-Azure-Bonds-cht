# 962 — `FExpand`：把相對路徑展開成完整路徑

- 證據等級：`exact`（逐條讀完，來源是 `PC98-GAME.EXE.asm`）
- 位置：`PC98-GAME.EXE` 的 `18D70h`
- 作法見 spec 783

## `18D70h`（156 行，far，`retf 4`）

```pascal
FExpand(來源路徑 arg_0, @結果 arg_4);

n := 來源[0];   si := 來源 ＋ 1;   結束 := si ＋ n;
di := 結果 ＋ 1;                                   { 留一格給長度前綴 }

{ ── 磁碟機 ── }
讀兩個 byte;
if (還沒到結尾) and (第二個 = ':') then begin
    if 第一個 in ['a'..'z'] then 第一個 := 第一個 − 20h;   { 轉大寫 }
end else begin
    si := si − 2;                                  { 退回去 }
    第一個 := <int 21h AH=19h>() ＋ 'A';           { 目前磁碟機 }
    第二個 := ':';
end;
寫入(第一個, 第二個);

{ ── 目錄 ── }
if (已到結尾) or (下一個 <> '\') then begin
    寫入('\');
    <int 21h AH=47h>(DL ＝ 磁碟機編號, DS:SI ＝ 結果 ＋ 目前位置);   { 取目前目錄 }
    if 成功 and (取回的不是空字串) then di := di ＋ strlen(取回的);
end;

{ ── 逐字元複製，順便正規化 ── }
while si < 結束 do begin
    c := 來源[si];  inc(si);
    if c in ['a'..'z'] then c := c − 20h;          { ★ 一律轉大寫 }
    if c <> '\' then 寫入(c)
    else begin
        if 前兩個 byte ＝ '\.'  then di := di − 2;         { 「\.」→ 去掉 }
        if 前兩個 byte ＝ '..' and 再前一個 ＝ '\' then begin
            di := di − 3;
            if 前一個 <> ':' then
                repeat dec(di) until 結果[di] = '\';       { ★「\..」→ 退一層 }
        end;
        寫入('\');
    end;
end;

if 結果[di − 1] = ':' then 寫入('\');              { 只剩 'C:' → 補成 'C:\' }
結果[0] := di − 結果 − 1;                          { 補長度前綴 }
```

## 三個正規化規則

| 輸入 | 結果 |
|---|---|
| 小寫字母 | **一律轉成大寫** |
| `\.` | 去掉（`.` 是目前目錄） |
| `\..` | **往回退一層**（掃到前一個 `\` 為止；已在根目錄就不退） |

★ **路徑全部轉大寫**——與 spec 937 的 64 個大寫字模、spec 941 的
輸入欄轉大寫是同一個世界觀：**這個引擎裡沒有小寫**。

## 與開檔的關係

spec 943（DOS）與 spec 958（PC-98）的開檔都要先組出完整檔名。
本支負責把「相對路徑 ＋ 目前磁碟機／目錄」展開，
所以那兩支拿到的路徑一定是絕對的、大寫的。

## 明確不宣稱

- 沒有宣稱本支由誰呼叫（IDA 只標出 `sub_1259Fh+12Ah` 一處，那支尚未讀）。
- 沒有宣稱 `int 21h AH=47h` 失敗時（進位）的後續行為是否正確
  ——程式碼直接往下走，等於忽略錯誤。
- 沒有宣稱結果緩衝的大小上限（本支不檢查）。
