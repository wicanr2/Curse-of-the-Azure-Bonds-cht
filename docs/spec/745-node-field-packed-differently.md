# 第七百四十五輪：同一個節點 byte，兩種打包方式

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-12` 的 `02CBh`、`212Ch`（兩支都沒有位元組缺口）。

## `02CBh`：魅惑（套用與解除共用一支）

```text
if arg_0 <> 0 then                                        ← 解除
    角色^[197h] := (節點^[3] and 40h) div 40h              ← 取 bit 6 當原陣營
    if 角色^[0F7h] = 0B3h then 角色^[0F7h] := 0
else                                                       ← 套用
    if (節點^[3] and 20h) = 0 then                         ← bit 5 ＝ 尚未套用
        節點^[3] := 節點^[3] + 20h + (角色^[197h] shl 6)   ← 立旗標並把原陣營存進 bit 6
        角色^[197h] := 節點^[3] div 80h                    ← 取 bit 7
        角色^[198h] := 1
        if 角色^[0F7h] <= 7Fh then 角色^[0F7h] := 0B3h
        角色^[18Dh]^[0Ah] := NIL                           ← 清掉鎖定的目標
        <overlay-24 entry#31>()                            ← 重算隊伍統計
    DS:6FA2h := 64h
```

## 節點 `+3` 沒有統一的版面

| 效果 | 打包方式 | 取回方式 |
|---|---|---|
| 操縱屍體（spec 734／744） | `(原陣營 shl 4) + 等級` | `節點^[3] div 16` |
| 魅惑（本輪） | `bit 5` ＝ 已套用旗標、`bit 6` ＝ 原陣營 | `(節點^[3] and 40h) div 40h` |

**同一個 byte，一個用高 4 位放陣營、一個用 bit 6 放陣營**，而且魅惑還多用了
bit 5 當「已套用」旗標。所以 `節點^[3]` 是每個效果自己解釋的欄位，
**沒有共通版面**——remake 若替它取一個名字並統一結構，兩邊都會壞。

`+20h` 那個旗標讓套用具有**冪等性**：重複套用不會再存一次原陣營（否則第二次會
把已經被改掉的陣營當成原值存進去）。這是刻意的。

## 改陣營之後要重算統計

`<overlay-24 entry#31>` 就是 spec 692 的 `25D4h`——依 `+197h` 統計人數的那支。
改完陣營立刻重算，兩處對得上。`1809h`（狂暴，spec 743）改陣營後**沒有**呼叫它，
兩支的處理不一致。

## `212Ch`：把瀕死的人拉回來

```text
n := 0
if 角色^[195h] = 5 且 角色^[18Dh]^[0Eh] < 6 then
    n := 6 − 角色^[18Dh]^[0Eh]
if 角色^[195h] = 4 then
    n := 6
if n > 0 且 <overlay-23 entry#23>(角色, n) then
    <overlay-23 entry#11>(角色, 5Fh, ROLLDICE(1, 4) + 1, 0FFh, 1)
    節點^[4] := 0
    <overlay-23 entry#3>(角色, 63h, 節點)
```

狀態 `5`（spec 698：`+18Dh^[0Eh]` 存著「低於 0 多少」）時補到剛好 0 為止
（`6 − 欠血`，而且欠血必須小於 6）；狀態 `4` 則固定補 6。

**兩個判斷是分開的 `if` 不是 `elif`**——但狀態不可能同時是 4 和 5，所以實際等價。
照抄成 `elif` 不會改變行為，寫成 `if/else` 也可以。

`6` 這個上限在兩條路徑都出現，而狀態 5 那條的算式讓結果落在 `1..6`。

## 明確不宣稱

- `DS:6FA2h := 64h` 的意義。
- 效果編號 `5Fh`／`63h`。
- `overlay-23 entry#23` 的行為（spec 734 用 `角色^[78h]` 當第二個參數，
  這裡用 `n`，看起來是「補多少 HP」）。
- `節點^[3]` 低 5 位在魅惑那條路徑上原本存什麼。
