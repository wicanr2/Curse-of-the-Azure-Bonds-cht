# 第六百三十七輪：`overlay-21` 小函式四支 —— `+188h` 的加減對，以及 70／30 的分支

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：PC-98 `overlay-21` 的 `001Bh`、`003Bh`、`0057h`、`10C4h`。

## `003Bh` 與 `0057h`：同一個欄位的減與加

```text
003Bh:  arg_2^[188h] := arg_2^[188h] − arg_0     (word)
0057h:  arg_2^[188h] := arg_2^[188h] + arg_0     (word)
```

兩支逐指令相同，只差 `sub` 與 `add`。`+188h` 是 word，兩支都**不做上下限檢查**
——減到負數會回捲成大正數（沒有任何比較指令）。

## `10C4h`：1d20 切成 70／30

```text
r := ROLLDICE(1, 14h)                 ← 1d20
if 1 <= r <= 0Eh then 回傳 1          ← 1..14，70%
if 0Fh <= r <= 14h then 回傳 2        ← 15..20，30%
```

兩個區間**剛好把 1..20 分完**，沒有縫隙也沒有重疊，所以雖然回傳值
（`[bp+var_1]`）沒有預設值，實際上不會讀到未初始化——與
[spec 629](629-spell-pack-idiom-and-uninit.md) 的 `2690h` 不同，那支的 case 是真的
有漏。

比較用的是**無號**（`jb`／`ja`）。
