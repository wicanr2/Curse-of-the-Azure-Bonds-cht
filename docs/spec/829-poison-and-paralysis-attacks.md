# 829 — 毒殺與麻痺兩種特殊攻擊；效果碼 `37h` 確定是中毒

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側**助憶碼完全相同**）
- 作法見 spec 783

## `overlay-12:1454h`（entry#59，兩平台各 59 條，實質差異 8 條）— 毒殺

| | DOS | PC-98 |
|---|---|---|
| 中毒 | `'is Poisoned'`（11，**大寫 P**） | `'は毒を受けた。'`（14 bytes） |
| 死亡 | `'is killed'`（9） | `'は死んだ。'`（10 bytes） |

`retf 6` ＝ 3 個 word。依宣告順序：`(角色, 參數6)`。

```pascal
目標 := 角色^[18Dh]^[0Ah];
DS:6FA3h := 目標;
if <far 1457h+1>(目標, 參數6, 0) then 離開;         { 已經中招就不重複 }
<far 1554h>(目標, 名字 ＋ 'is Poisoned', 0Ah, 0);
<far 0542h:0B33h>();
<far 1466h+1>(目標, 37h, 0, 0FFh, 0);
<far 1435h>(目標, 6, 名字 ＋ 'is killed');
```

### 效果碼 `37h` ＝ 中毒

spec 796 讀到 `Neutralize Poison` 移除的第一個碼就是 `37h`（另外連帶清 `16h` 與
`0Fh`）。這一支是**掛上去**的那一端，兩邊對得起來——**`37h`（55）確定是中毒**。

掛的值是 `0FFh`，旗標 0。訊息**分兩句**：先 `'is Poisoned'`（`1554h`，旗標 0），
中間插一次 `0542h:0B33h`，再 `'is killed'`（`1435h`，第二個參數 6）。
**中毒與死亡是同一支裡連續發生的**，沒有存活判定。

## `overlay-12:14F9h`（entry#60，兩平台各 43 條，實質差異 9 條）— 麻痺

| | DOS | PC-98 |
|---|---|---|
| 麻痺 | `'is Paralyzed'`（12，**大寫 P**） | `'は麻痺した。'`（12 bytes） |

`retf 8` ＝ 4 個 word。依宣告順序：`(角色, 參數8, 參數6)`。

```pascal
目標 := 角色^[18Dh]^[0Ah];
DS:6FA3h := 目標;
if <far 1457h+1>(目標, 0, 0) then 離開;
<far 1572h>(目標, 1, 名字 ＋ 'is Paralyzed');
<far 1466h+1>(目標, 34h, 參數8, 0Ch, 0);
```

效果碼 **`34h`（52）**，第三個參數由呼叫端給，第四個是 `0Ch`。

### 兩支共用的模子

| | 毒殺 | 麻痺 |
|---|---|---|
| 取目標 | `角色^[18Dh]^[0Ah]` → `DS:6FA3h` | 同左 |
| 守衛 | `1457h+1(目標, 參數6, 0)` | `1457h+1(目標, 0, 0)` |
| 顯示 | `1554h(…, 0Ah, 0)` ＋ `1435h(…, 6, …)` | `1572h(目標, 1, …)` |
| 掛效果 | `1466h+1(目標, 37h, 0, 0FFh, 0)` | `1466h+1(目標, 34h, 參數8, 0Ch, 0)` |

與 spec 819 的 `Spits Acid`、spec 826 的 `engulfs` 是同一族：**`overlay-12` 與
`overlay-13` 裡一個 entry 就是一種怪物特殊攻擊**，模子固定為
「取目標 → 查有沒有中過 → 印訊息 → 掛效果碼」。

`1466h+1` 的簽名到此累積為 `(對象, 效果碼, 參數, 值, 旗標)`：

| 出處 | 對象 | 碼 | 參數 | 值 | 旗標 |
|---|---|---|---|---|---|
| spec 826 | 目標 | `3Ah` | 0 | `1939h+1(目標)` | 0 |
| spec 826 | 目標 | `0Dh` | 0 | `145Ah+3(2,4)` | 0 |
| spec 826 | 角色 | `8Bh` | 0 | `1939h+1(目標)` | 1 |
| 本支（毒） | 目標 | `37h` | 0 | `0FFh` | 0 |
| 本支（麻痺） | 目標 | `34h` | 參數8 | `0Ch` | 0 |

## 中文化

`'is Poisoned'` 與 `'is Paralyzed'` 的 **`P` 都是大寫**，而 spec 796 的
`'is not poisoned.'` 是小寫 `p`——**同一個詞在不同字串裡大小寫不一致**，
是四個各自獨立的字串常數。

## 明確不宣稱

- 沒有宣稱 `far 1435h` / `1572h` / `0542h:0B33h` 各做什麼。
- 沒有宣稱效果碼 `34h` 的名稱。
- 沒有宣稱毒殺為什麼沒有存活判定。
