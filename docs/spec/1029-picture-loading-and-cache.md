# 1029 — 圖片載入：一格快取、`PIC`／`FINAL` 特例，以及 PC-98 的三平面尺寸

- 證據等級：`exact`（DOS 側 453 條、PC-98 側 340 條，兩邊各自逐條讀完）
- 作法見 spec 783

## `dos overlay-29:0010Bh` ↔ `pc98 overlay-29:0010Bh`（`retf 0Ch`）

兩側原本都是待解讀。

## ★★ 一格快取：圖名 ＋ 子索引

```pascal
if (圖名 = 字串(DS:7278h)) and (子索引 = DS:728Ah) then exit;   { 已經載好了 }
if 子索引 = 0FFh then exit;                                     { 哨兵 }
```

★★★ **spec 892 的未定項關掉了**：那份規格記過 `DS:728Ah`／`728Bh` 的初值是
`0FFh`，但沒說是什麼。現在確定
**`DS:7278h` 是目前載入的圖名（8 bytes）、`DS:728Ah` 是子索引，
`0FFh` ＝ 尚未載入的哨兵**（PC-98 對應 `DS:0A313h`／`DS:0A325h`）。

## 載入流程

```pascal
if DS:4FBFh <> 0 then begin                       { ⚠ PC-98 沒有這道判斷 }
    清一行(0, 28h, 18h, 0);
    印字(0, 18h, 0Ah, 0, 'Loading...Please Wait');
end;
…
DS:7278h := 圖名;  DS:728Ah := 子索引;
特例 := (圖名 = 'PIC') or (圖名 = 'FINAL');       { ★ 兩個特別的名字 }
檔名 := 圖名 ＋ Str(DS:5BEEh) ＋ '.dax';           { 資料片編號，spec 892 }
if <far 0636:08DEh>(檔名, 子索引, …) 失敗 then begin
    顯示 'PIC not found';  exit
end;
…逐張處理載進來的圖…
```

★ 檔名的組法與 spec 1024（怪物資料）同一套：**`名字 ＋ 資料片編號 ＋ '.dax'`**。
⚠ PC-98 的錯誤訊息是 `'PIC not found '`（14 字元，多一個空白）**後面還接子索引**。

## ★★ PC-98：三個平面 ＋ 可選的遮罩平面

DOS 每張圖前進 `var_11` 的量與 PC-98 不同。PC-98 那一段是

```pascal
var_11 += 高 × 寬 × 3;                             { ★ 三個平面 }
if 圖名 = 'SPRIT' then var_11 += 高 × 寬;          { ★ 再加一個遮罩平面 }
```

> ★★ **這是「PC-98 `+11h`（每張的 bytes）＝ 3 × 高 × 寬、遮罩平面 ＝ 高 × 寬」
> 那條既有結論的載入端確認**，而且指名了觸發遮罩的圖名：**`'SPRIT'`**。

★ PC-98 每張圖的表頭比 DOS 多一個 byte（`es:[di+2] := 1` 對 DOS 的 `es:[di+1] := 1`）。

★ 收尾的 `out 0A6h, al` 是**繪圖頁選擇器**（既有結論：IDA 標成 8259A 是錯的）。

## 中文化

| 字串 | DOS | PC-98 |
|---|---|---|
| 載入提示 | `'Loading...Please Wait'`（21） | 「読みこみ中です」（14 bytes ＝ 7 全形字） |
| 找不到 | `'PIC not found'`（13） | `'PIC not found '`（14，**沒翻**，後接數字） |
| `'PIC'`／`'FINAL'`／`'SPRIT'`／`'.dax'` | 3／5／—／4 | 相同 | **檔名，不可翻** |

⚠ **`'PIC'`、`'FINAL'`、`'SPRIT'` 同時是檔名前綴與程式裡的比較字串**，
翻了會同時弄壞載入與特例判斷。
⚠ PC-98 連 `'PIC not found '` 都沒翻——那是開發期訊息。

## 明確不宣稱

- 沒有宣稱 `DS:4FBFh`（DOS 才有的「要不要顯示載入提示」）由誰設定。
- 沒有宣稱 `far 0636:08DEh`（DOS）／`far 0723:0824h`（PC-98）的介面。
- 沒有宣稱圖表頭 `+11h` 之外的欄位。
- 沒有宣稱 `DS:7F2Ch`／`DS:7F54h`（PC-98 才有的兩個旗標）是什麼。
- 沒有宣稱 `'PIC'` 與 `'FINAL'` 這兩個特例在後面被怎麼用。
