# 1017 — 從範本建角色：AD&D 1e 的種族屬性上下限表，七個種族一格不差

- 證據等級：`exact`（DOS 側 910 條逐條讀完；PC-98 對側 923 條，
  差異是欄位偏移與幾處展開方式，資料表的值兩平台完全相同）
- 作法見 spec 783

## `dos overlay-16:01490h` ↔ `pc98 overlay-16:01C15h`（`retf 2`）

兩側原本都是待解讀。這是一支**巢狀程序**——唯一的參數是父函式的 `bp`：

```pascal
範本 := 遠指標(ss:[父bp − 1C0h]);      { PC-98 是 −1E8h }
角色 := 遠指標(ss:[父bp + 0Ah]);
```

它把範本裡的欄位一項一項搬進角色記錄，途中依種族與性別把六個屬性夾進合法區間。

## ★★★ 種族屬性上下限表 `DS:3F86h`（PC-98 `DS:701Bh`）

**每個種族 16 bytes**，以 `種族 × 16` 索引；力量那三組再加 `＋ 性別`。

| 表內位移 | 內容 |
|---|---|
| `+0`／`+1` | 力量下限（男／女） |
| `+2`／`+3` | 力量上限（男／女） |
| `+4`／`+5` | 力量百分位上限（男／女） |
| `+6`／`+7` | 智力下限／上限 |
| `+8`／`+9` | 智慧下限／上限 |
| `+0Ah`／`+0Bh` | 敏捷下限／上限 |
| `+0Ch`／`+0Dh` | 體質下限／上限 |
| `+0Eh`／`+0Fh` | 魅力下限／上限 |

> ★★★ **這七列與 AD&D 1e《Players Handbook》的種族屬性限制完全相同，
> 連「女性力量上限較低」與「例外力量百分位上限」都一格不差**：
> 人類男 100／女 50、矮人男 99／女 0、精靈 75／0、地精 50／0、
> 半精靈 90／0、半身人 0／0、半獸人 99／75。

種族 0 是 `Monster`（那一列的值不是屬性限制），性別 `2` 是 `Copper`
——⚠ 性別表被當成別的東西重用過，本規格不宣稱。

## ★ 角色記錄裡的屬性是筆距 2，範本是筆距 1

```pascal
for i := 0 to 5 do
    角色^[10h ＋ i × 2] := 範本^[10h ＋ i];
```

**範本一個屬性一個 byte，角色記錄一個屬性兩個 byte**——
第二個 byte 形狀上是「現值 vs 基準值」的另一半（spec 1000 那組
`+11Dh` 基準／`+19Dh` 現值是另一套）。

夾值的形狀，每個屬性各一段：

```pascal
if 角色^[10h ＋ i×2] < 下限 then 角色^[10h ＋ i×2] := 下限;
if 角色^[10h ＋ i×2] > 上限 then 角色^[10h ＋ i×2] := 上限;
```

⚠ **力量那一段多帶一個性別索引**，其餘五項不分性別——
與 AD&D 1e 只對力量分男女完全一致。

## 其餘欄位

除了屬性之外，本支還逐一搬 `+2Eh`（→ 角色 `+74h` 種族）、
`+9Eh`（→ `+119h` 性別）、15 bytes 的名字（`0A54:064Eh`）、
`+0BCh`..`+0C0h`（→ `+140h`..`+144h`）等數十個欄位，
並用 **`@Move$qm3Anyt14Word`**（`0A54:1ABDh`，Turbo Pascal 的 `Move`）
搬 6 段陣列。字串指定走 `@$basg$qm3Anyt14Word`（`0A54:025Dh`）。

## 兩平台差異

| | DOS | PC-98 |
|---|---|---|
| 種族限制表 | `DS:3F86h` | `DS:701Bh`（**值完全相同**） |
| 範本在父框架的位移 | `−1C0h` | `−1E8h` |
| 角色記錄欄位 | `+140h`.. | `+14Dh`..（部分欄位偏移不同） |

PC-98 多 13 條，是幾處把 `角色^[10h ＋ i×2]` 展開的方式不同，語意相同。

## 中文化

本支沒有字串。但**種族名表 `DS:0E9Ch`（筆距 10 ⇒ 中文 4 字）與
性別表 `DS:0F85h`（筆距 7 ⇒ 中文 3 字）**是角色卡上的兩欄，
既有結論已記過上限，這裡確認了它們的索引來源就是 `+74h` 與 `+119h`。

- 沒有宣稱角色屬性那第二個 byte 存什麼。

- 沒有宣稱性別表第 3 筆 `Copper` 為什麼在那裡。
