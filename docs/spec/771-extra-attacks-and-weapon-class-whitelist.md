# 771 — 額外攻擊次數的算法、物品類別白名單

- 證據等級：`exact`（以補洞後的匯出逐條讀完，見 spec 761）

## `overlay-13:1CE2h`（DOS）— 由門檻算出額外攻擊

`retf 0Ch`，第一個遠指標是輸出的累加器：

```pascal
n := <呼叫>(a, b, 角色);
if <呼叫>(角色) then
    m := (byte[5D02h + 角色^[151h]^[2Eh] * 10h] − 1) div 3   { 有號除法 }
else
    m := n;
if n − m > 0 then begin  n := n − m;  輸出^ := 輸出^ + 2;  end;
if n − m > 0 then begin  n := n − m;  輸出^ := 輸出^ + 3;  end;
```

- `+151h` 是裝備中的物品、`+2Eh` 是它的類別 ID，`DS:5CF6h` 起是每筆 16 bytes
  的物品屬性表（既有結論），`5D02h` 就是該表的 `+0Ch` 欄位。
- 門檻是 `(屬性 − 1) div 3`。
- **兩段判斷是先後、不是迴圈**：最多加兩次，值分別是 **2** 與 **3**。
- 判斷用的都是有號比較，`輸出^` 是 byte，沒有上限檢查。

2 與 3 這兩個加數配上「以半次為單位」的表示法（1 次 ＝ 2、1.5 次 ＝ 3），累加的
目的地就是 `BASEATTBLOWS`——消費端是 `ADJUSTBLOWS`，把半次值依**回合奇偶**換成
這一回合的整數次數（spec 1180）。

## `overlay-13:28C3h`（DOS）— 物品類別白名單

`retf 8`：

```pascal
可以 := false;
物品 := 角色^[151h];
if 物品 <> NIL then 類別 := 物品^[2Eh];
if (角色^[10Fh] > 0) or ((角色^[117h] > 0) and <呼叫>(角色)) then
    if (物品 = NIL)
       or (類別 = 61h) or (類別 = 7) or (類別 = 8)
       or ((類別 > 22h) and (類別 < 26h))          { 23h、24h、25h }
    then 可以 := true;

if 可以
   and (行動者^[18Dh]^[0Fh] > 1)
   and ((行動者^[0DEh] and 7Fh) <= 1) then
    結果 := (本模組 29A2h(行動者, 角色) = 行動者^[18Dh]^[09h])
else
    結果 := false;
```

白名單是 **`{NIL, 7, 8, 23h, 24h, 25h, 61h}`** ——沒有裝備也算通過。`類別` 的
比較是無號的（`jbe` / `jnb`），所以區間是開區間 `22h < 類別 < 26h`。

`+10Fh` 與 `+117h` 相差 8，正是既有結論裡「第一／第二職業區塊相差 8」的那組
配對。

## `overlay-10:0491h`（DOS）— 八組寫死的參數

`retf 2`，除了一個全域判斷之外整支都是寫死的呼叫：

```pascal
if DS:4A0Eh = 1 then begin
    本模組 0048h(3, 0, 05h);   本模組 0048h(4, 0, 05h);
    本模組 0048h(3, 1, 0Ah);   本模組 0048h(4, 1, 0Ah);
end else begin
    本模組 0048h(3, 0, 16h);   本模組 0048h(4, 0, 16h);
    本模組 0048h(3, 1, 16h);   本模組 0048h(4, 1, 16h);
end;
```

第一欄固定在 `{3, 4}`、第二欄固定在 `{0, 1}`，第三欄是 `5` / `0Ah` / `16h`。
**兩個分支的差別只在第三欄**：`DS:4A0Eh = 1` 時前兩組用 `5`、後兩組用 `0Ah`；
否則四組全用 `16h`。

原始碼是八行手寫呼叫、不是迴圈，所以這 24 個數字要當資料照抄，不能自己歸納
成公式（同 spec 559 記錄過的 `overlay-24:1AAAh` 那種寫法）。

## 明確不宣稱

- 沒有宣稱 `輸出^` 那個累加器的消費端怎麼解讀 2 與 3。
- 沒有宣稱物品類別 `7`／`8`／`23h`..`25h`／`61h` 各是什麼武器。
- 沒有宣稱 `本模組 0048h` 三個參數的意義，也沒有宣稱 `DS:4A0Eh` 代表什麼。
- 沒有宣稱 `行動者^[0DEh]` 的低 7 位是什麼。
- `dos overlay-15:0034h` 即使補洞後仍有誤解成 `in al, 0C4h`／`hlt` 的位元組，
  本輪**沒有**判讀。
