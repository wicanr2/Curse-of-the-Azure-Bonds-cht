## ★★★ 十個槽 ＝ 十個檔

```pascal

<overlay-26 entry#3>();                            { 十格初始化 }

可用 := 0;

        文字 := (字母 − 1) ＋ '  ';
        Move(文字, DS:0A338h ＋ (字母 − '@') × 7, 6);

    end;

```

> ★★★ **PC-98 版的存檔檔名是 `savgamA.dat` ..`savgamJ.dat`**
> ——十個槽對應 `A`..`J`，與 spec 1057 熱鍵塊 `'ABCDEFGHIJ'` 完全一致。
> ★★ **只有真的存在的槽才會被放進選單**（存檔側 spec 1057 是十個都列，
> 用「☆」標目前的那個）。
> ★ 兩張表的位址算式在這裡再確認一次：
> 文字 `DS:0A338h ＋ i × 7`、熱鍵 `DS:0A334h ＋ i`
> （組語寫成 `[di − 5CCCh]`，`di ＝ i`）。
