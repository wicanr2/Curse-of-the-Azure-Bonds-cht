# 1027 — 攻擊指令：`N`／`P` 換目標、方向鍵移游標，PC-98 全改成字母鍵

- 證據等級：`exact`（DOS 側 315 條、PC-98 側 303 條，兩邊各自逐條讀完）
- 作法見 spec 783

## `dos overlay-13:03B37h` ↔ `pc98 overlay-13:03A74h`（＝ `entry#21`）

兩側原本都是待解讀。這是 spec 1015 裡 **`A`（Attack）鍵**叫的那一支。

## ★ 攻擊次數從武器類別表拿

```pascal
次數 := arg_E;
if 次數 = 0FFh then                                { 呼叫端說「自己看著辦」}
    if 角色^[151h] <> NIL then                     { 第 0 個裝備槽有武器 }
        次數 := byte[5D02h ＋ 武器.itemptr × 16] − 1
    else
        次數 := 1;
if (次數 = 0) or (次數 = 0FFh) then 次數 := 1;
```

★ `5D02h − 5CF6h = 0Ch` ⇒ **物品類別表 `DS:5CF6h` 的 `+0Ch`**（新欄位），
值減 1 之後當攻擊次數用。類別表的欄位圖因此補到七格
（`+0` 槽位、`+1` 佔手數、`+2`／`+3` 對大型目標的骰、
**`+0Ch`**、`+0Dh` 可用性遮罩、`+0Eh` 旗標——spec 683／1000／1004／1011）。

## 主迴圈

```pascal
鍵 := ' ';
repeat
    …畫出目前鎖定的目標…
    鍵 := <sub_3040>(…, 次數, arg_8, arg_A, arg_C);
    if DS:7295h = 0 then case 鍵 of                { 一般模式 }
        'N': 換下一個目標;
        'P': 換上一個目標;
        47h,48h,49h,4Bh,4Dh,4Fh,50h,51h: …八方向移游標…;
        'C': 把游標拉回自己（`entry#13(x, y, 0, 8)`）;
    end
    else if 鍵 in [47h,48h,49h,4Bh,4Dh,4Fh,50h,51h] then
        <sub_33AC>(…)                              { ★ spec 1012 的目標游標畫面 }
until 鍵 in [#0, 'E'];
```

兩個集合常數（`@Set@MemberOf$q4Byte`，spec 1012 同一支）：

| 集合 | 內容 |
|---|---|
| `CS:3AF7h` | `[#0, 'E']`——離開條件 |
| `CS:3B17h` | `[47h, 48h, 49h, 4Bh, 4Dh, 4Fh, 50h, 51h]`——**八個方向掃描碼** |

★ `DS:7295h` 是 spec 1015 記過的「方向鍵直接操作」旗標，
在這裡決定方向鍵是**自己處理**還是**丟給 spec 1012 的游標畫面**。

## ★★★ PC-98 把方向鍵整組換成字母鍵

PC-98 的 `cmp al` 清單只有 **`C`、`M`、`N`、`P`、`T`** 五個，
**一個方向掃描碼都沒有**：

| 鍵 | DOS | PC-98 |
|---|---|---|
| 換目標 | `N`／`P` | `N`／`P`（相同） |
| 拉回自己 | `C` | `C`（相同） |
| 移游標 | **八個方向掃描碼** | **`M`**（叫 `sub_329F` ＝ spec 1012 的 PC-98 對側） |
| 指定目標 | — | **`T`**（叫 `sub_30D8`） |

> ★★★ **同一個功能，DOS 綁在 IBM PC 的擴充掃描碼上，PC-98 改成字母熱鍵。**
> 與 spec 1023（游標鍵 `Home/End/PgUp/PgDn` → `'2'/'3'/'8'/'9'`）
> 是同一類的鍵盤差異——**PC-98 版一律走得掉掃描碼**。

## 中文化

本支沒有字串。但**熱鍵 `N`／`P`／`C`／`M`／`T` 都是大寫字母**，
選項行由呼叫端（spec 1023 的清單選單）組出來，
中文化要跟 PC-98 的獨立熱鍵表（spec 1022／1023）。

## 明確不宣稱

- 沒有宣稱 `sub_3040`（畫目標並等鍵）與 `sub_394B`／`sub_38AA`／`sub_30D8` 做什麼。
- 沒有宣稱 `overlay-24 entry#23(0, 0, 0, 19h)` 畫的是什麼。
- 沒有宣稱物品類別表 `+0Ch` 減 1 之後的確切語意（形狀上是每回合攻擊次數）。
- 沒有宣稱 `arg_8`／`arg_A`／`arg_C` 三個參數是什麼。
