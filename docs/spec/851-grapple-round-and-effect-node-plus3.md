# 851 — 扭打的每回合結算，順便調和效果節點 `+3`

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼序列完全相同，21 條差異全是位址）
- 作法見 spec 783

## `overlay-13:045CFh` ↔ `overlay-13:0453Dh`（兩平台各 111 條）

`retf 0Ah` ＝ 5 個 word。依宣告順序：`(角色, 效果節點, 解除旗標)`。

```pascal
對手 := 遠指標(DS:6D35h + 節點^[3] * 4);
DS:6FA3h := 對手;

if (解除旗標 <> 0) or (角色^[196h] = 0) or (對手^[196h] = 0) then begin
    <far 143Dh+2>(對手, 3Ah, longint 0);
    <far 143Dh+2>(對手, 0Dh, longint 0);
    if 解除旗標 = 0 then begin
        節點^[4] := 0;
        <far 143Dh+2>(角色, 8Bh, 節點);
    end;
end else begin
    角色^[19Ch] := 2;
    角色^[19Dh] := 0;
    角色^[19Eh] := 2;
    角色^[1A0h] := 8;
    <本模組 19D8h>(角色, 對手, 1, longint 0, @結果);
    結果 := <far 159Ah>(角色);
    if 對手^[196h] = 0 then begin
        <far 143Dh+2>(角色, 8Bh, longint 0);
        <far 143Dh+2>(對手, 3Ah, longint 0);
        <far 143Dh+2>(對手, 0Dh, longint 0);
    end;
end;
```

## 三個效果碼的分工

| 碼 | 掛在誰身上 | 何時拿掉 |
|---|---|---|
| `8Bh`（139） | **抓人的那一方** | 解除、或對手不能行動 |
| `3Ah`（58）、`0Dh`（13） | **被抓的那一方** | 同上（兩個一起） |

只要**任一方 `+196h` ＝ 0**（不能行動，spec 806）就整組解開——這是「一方倒下扭打就結束」。
`解除旗標` ≠ 0 是外部強制解除，那條路**不清 `節點^[4]`、也不撤 `8Bh`**，
留給呼叫端自己處理。

## 扭打回合把攻擊資料寫死

```pascal
角色^[19Ch] := 2;   角色^[19Dh] := 0;
角色^[19Eh] := 2;   角色^[1A0h] := 8;
```

`+19Ch`／`+19Dh`／`+19Eh`／`+1A0h` 是 spec 808 每回合重算的那組攻擊欄位。
扭打期間**整組被覆寫成固定值**，然後才叫 `19D8h`（spec 817／833 認過的攻擊結算）。
所以**扭打時武器與平常的攻擊次數都不算數**。

## 效果節點 `+3`：依效果碼而異

spec 846（Teleport）把 `+3` 當戰鬥員索引，spec 847（龍息）拿它跟 `0FDh` 比再遞減，
兩者當時無法調和。本支給出第三個呼叫點，可以收斂了：

| 效果碼 | `+3` 的用法 | 出處 |
|---|---|---|
| `8Bh`／`90h` | **對手的戰鬥員索引**（查 `DS:6D35h`） | 846、本支 |
| `58h`（龍息） | **剩餘次數**（`0FFh` → `0FEh` → 用完） | 847 |

三個呼叫點只有一種讀法同時成立：**`+3` 是效果節點的通用欄位，語意由效果碼決定**。
所以它不該被定名成「施加者」或「計數器」——remake 要照效果碼分開處理。

spec 846／847 的保留段落已可據此更新，但**欄位本身仍不定名**。

本支另外動到 `節點^[4]`（解除時寫 0），那是 `+3` 之外的第二個欄位，用途未知。
