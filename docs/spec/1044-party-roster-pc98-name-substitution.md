# 1044 — 隊伍名單（PC-98 側）：三個劇情 NPC 的名字在畫面上才被換掉

- 證據等級：`exact`（PC-98 側 231 條逐條讀完）
- 作法見 spec 783；DOS 對側是 `overlay-24:0795h`（既有結論，見 spec 684）

## `pc98 overlay-24:00917h`（＝ `entry#2`，`retf 4`）

原本待解讀。參數是一個遠指標（＝選中的角色）。

```pascal
if DS:7F27h = 3 then exit;                    { 畫面模式 3 什麼都不畫 }
起始欄 := (DS:7F27h = 0) ? 1 : 11h;
印字(起始欄, 2, '名前');                       { 4 bytes }
印字(21h,   2, 'ＡＣ　　ＨＰ');                 { 12 bytes }
…走 DS:9598h 角色鏈（next 在 +18Ah）…
```

## ★★★ 三個劇情 NPC 的名字是**畫面上才替換**的

```pascal
名字 := 角色^.名字;
if 角色^[0F7h] <> 0 then begin                 { 劇情 NPC 旗標，spec 623／1028 }
    if 名字 = 'ALIAS'           then 名字 := 'エイリアス'
    else if 名字 = 'DRAGONBAIT' then 名字 := 'ドラゴンベイト'
    else if 名字 = 'AKABAR BEL AKAS' then 名字 := 'アーカバー・ベル・アーカッシュ';
end;
印字(起始欄, 列, 名字);
```

| 存檔／ECL 裡的名字 | bytes | PC-98 顯示 | bytes |
|---|---|---|---|
| `'ALIAS'` | 5 | 「エイリアス」 | 10 |
| `'DRAGONBAIT'` | 10 | 「ドラゴンベイト」 | 14 |
| `'AKABAR BEL AKAS'` | 15 | 「アーカバー・ベル・アーカッシュ」 | 30 |

> ★★★ **角色資料裡存的仍是英文名字，只有畫名單時才換成日文。**
> 三個名字正是《Curse of the Azure Bonds》的三個劇情同伴。
> ⚠ 注意第三個是 **`AKABAR BEL AKAS`（15 字元，末尾沒有 `H`）**——
> 手冊上的拼法是 Akabar Bel Akash，**程式裡少一個字母**，
> 比對是逐字元的，寫錯就替換不到。
>
> ⇒ **中文化要在同一個地方插替換**（艾莉亞絲／龍餌／阿卡巴·貝爾·阿卡什），
> 不要去改存檔或 ECL 裡的英文名字——那些名字還被別處拿來比對。
> ★ 替換只在 `+0F7h <> 0` 時發生；一般角色的名字原樣顯示。

## ★★ 右對齊補位：PC-98 側獨立確認 spec 684

```pascal
{ AC 欄 }
case 角色^[19Bh] of
    0..32h:   k := 1;      { 顯示值 60 − 儲存值 ⇒ 兩位數 }
    33h..3Ch: k := 2;      { 一位數 }
    3Dh..45h: k := 1;      { 負號 ＋ 一位數 }
    else      k := 0;
end;
畫在欄 20h ＋ k;

{ HP 欄 }
case 角色^[1A5h] of
    0..9:     k := 2;
    0Ah..63h: k := 1;
    else      k := 0;
end;
畫在欄 24h ＋ k;
```

> ★★ **欄基底 `20h`／`24h` 與 DOS 完全相同**，而分段值正好等於
> `k ＝ 3 − 顯示字元數`——spec 684 從 DOS 側推出的「右對齊補位」結論，
> 在 PC-98 側**用不同的分段寫法再驗證一次**。
> ★ 欄位 `+19Bh`（AC）／`+1A5h`（目前 HP）＝ DOS `+19Ah`／`+1A4h` 各 ＋1。
