# 1022 — 地城主選單：六個指令、四個沒寫出來的方向鍵，熱鍵機制的完整對照

- 證據等級：`exact`（DOS 側 248 條、PC-98 側 267 條，兩邊各自逐條讀完）
- 作法見 spec 783

## `dos overlay-14:0090Ah` ↔ `pc98 overlay-14:008E4h`

兩側原本都是待解讀。這是**在地城裡走動時的主迴圈**，
`DS:4FBAh`（畫面模式）＝ 4 才進來。

## ★★ 六個寫在選單上的指令

DOS 的選項是**資料段裡的一整條字串**：

```
DS:03D6h  33 字元：'Area Cast View Encamp Search Look'
```

**熱鍵就是那六個大寫字母**：`A`rea、`C`ast、`V`iew、`E`ncamp、`S`earch、`L`ook
——與程式裡的 `cmp al, 41h/43h/56h/45h/53h/4Ch` 一個不差。

| 鍵 | 動作 |
|---|---|
| `A` | **切換自動地圖**：`DS:720Eh := not DS:720Eh`，再重畫視野 |
| `C` | `DS:7294h := 1`；`overlay-15 entry#2` |
| `V` | `DS:7294h := 1`；`overlay-19 entry#5` |
| `E` | `DS:7294h := 1`；紮營 |
| `S` | 搜索 |
| `L` | 查看 |

> ★★★ **spec 1006 的未宣稱項關掉了**：那份規格說
> 「沒有宣稱 `DS:720Eh`（自動地圖旗標）由哪個按鍵設定」——**是 `A`（Area）**。

`A` 那一段還先檢查 `遠指標(DS:4F99h)^[1F6h]`，不為 0 時要過一道
`0A54:0724h` 的判斷，否則顯示 `'Not Here'`（8 字元）——**有些地方不能開地圖**。

## ★★★ 四個沒寫在選單上的方向鍵

```pascal
case 鍵 of
  48h {↑}: <sub_78E>();                                 { 前進 }
  50h {↓}: DS:7211h := (DS:7211h ＋ 4) mod 8;           { 180° 迴轉 }
  4Bh {←}: DS:7211h := (DS:7211h ＋ 6) mod 8;           { 左轉 90° }
  4Dh {→}: DS:7211h := (DS:7211h ＋ 2) mod 8;           { 右轉 90° }
end;
{ 轉完一律： }
DS:7212h := <overlay-30 entry#4>(DS:720Fh, DS:7210h, DS:7211h);
<overlay-30 entry#7>(DS:720Fh, DS:7210h, DS:7211h);      { ★ spec 1006 的視野重畫 }
```

★★★ 三件事一次對上：

1. **`48h`／`50h`／`4Bh`／`4Dh` 又是小鍵盤擴充掃描碼**——
   與 spec 1008（戰鬥移動）、spec 1012（目標游標）同一組。
   **這是方向編碼的第五個獨立確認。**
2. **`＋2` ＝ 右轉 90°、`＋6` ＝ 左轉 90°、`＋4` ＝ 180°**——
   與 spec 1006 從 `(方向 ＋ 6/4/2) mod 8` 推出的「左／後／右」**完全一致**。
3. `overlay-30 entry#7(欄, 列, 方向)` 的三個參數就是
   **`DS:720Fh`／`DS:7210h`／`DS:7211h`**，確認 spec 1006 的簽章，
   並定下 **`DS:7211h` ＝ 隊伍朝向**。

## ★★★ 熱鍵機制：兩平台的完整對照

PC-98 開頭多一段（DOS 完全沒有）：

```asm
call overlay-26 entry#3 @0858h        ; 十筆欄位初始化（spec 755）
rep movsb(DS:07CAh → DS:0A33Fh, 46h)  ; ★ 70 bytes ＝ 十筆 × 7 的「選項文字」
rep movsb(DS:0810h → DS:0A335h, 0Ah)  ; ★ 10 bytes ＝ 熱鍵表
call overlay-26 entry#2(…, 1, …)
```

兩張表的內容直接讀出來：

| # | 選項文字（`DS:07CAh`，每筆 7 bytes） | 熱鍵（`DS:0810h`） | DOS 對應 |
|---|---|---|---|
| 1 | 「マップ」 | `A` | Area |
| 2 | 「ｷｬﾗｸﾀｰ」 | `V` | View |
| 3 | 「 魔法 」 | `C` | Cast |
| 4 | 「 ｷｬﾝﾌﾟ」 | `E` | Encamp |
| 5 | （空） | `' '` | — |
| 6 | 「 捜索 」 | `S` | Search |
| 7 | 「 調査 」 | `L` | Look |
| 8–10 | （空） | `' '` | — |

熱鍵表整條就是 **`'AVCE SL   '`**。

> ★★★ **同一個選單，DOS 把六個熱鍵藏在 `'Area Cast View Encamp Search Look'`
> 的大寫字母裡，PC-98 把文字與熱鍵拆成兩張平行的表。
> 熱鍵字母完全相同（A V C E S L），只是標示方式不同。**

★ 空白熱鍵（第 5、8、9、10 格）＝**不可選**，與 spec 990 的規則一致。

**中文化跟 PC-98**：Big5 漢字的次位元組落在 `40h..7Eh`，
含 `41h`(A)、`43h`(C)、`45h`(E)、`4Ch`(L)、`53h`(S)、`56h`(V)——
照 DOS 的做法會把漢字後半誤判成熱鍵（spec 993）。

⚠ **每個選項只有 6 bytes ＝ 3 個全形字**。
日文用了「マップ」「ｷｬﾗｸﾀｰ」（半形カナ擠字），
中文兩個字就夠：地圖／角色／法術／紮營／搜索／查看。

## 兩平台位址

| DOS | PC-98 |
|---|---|
| `DS:720Eh`（自動地圖旗標） | `DS:0A2A8h` |
| `DS:720Fh`／`7210h`（隊伍欄／列） | `DS:0A2A9h`／`0A2AAh` |
| **`DS:7211h`（隊伍朝向）** | `DS:0A2ABh` |
| `DS:7212h` | `DS:0A2ACh` |
| `DS:7294h` | `DS:0A32Eh` |
| `DS:4FBAh`（畫面模式） | `DS:7F27h` |
| 選項 | 一條 33 字元字串 `DS:03D6h` | `DS:07CAh` ＋ `DS:0810h` 兩張表 |

## 明確不宣稱

- 沒有宣稱 `sub_78E`（前進）怎麼判斷撞牆。
- 沒有宣稱 `overlay-30 entry#4` 回什麼（結果存進 `DS:7212h`）。
- 沒有宣稱 `DS:7294h := 1` 的意義（`C`／`V`／`E` 三個鍵都會寫）。
- 沒有宣稱 `遠指標(DS:4F99h)^[1F6h]` 與 `0A54:0724h` 那道判斷是什麼，
  只知道不通過就顯示 `'Not Here'`。
- 沒有宣稱 `S`／`L` 兩個鍵呼叫的內容。
