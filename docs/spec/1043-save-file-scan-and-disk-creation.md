# 1043 — 存檔檔案掃描與建立存檔磁片：三張表分別是名字位移、旗標位移、預期長度

- 證據等級：`exact`（PC-98 `overlay-16:00614h` 205 條、`overlay-16:008E4h` 202 條，
  兩支各自逐條讀完）
- 作法見 spec 783

## `pc98 overlay-16:00614h`（`retf 8`）——依類別掃檔

```pascal
arg_0^ := NIL;  arg_4^ := NIL;                { 兩個輸出 }
case DS:0A816h of
  0: 樣式 := '*.guy';
  1: 樣式 := '*.cha';
  2: 樣式 := '*.sav';
  3: 樣式 := '*.hil';
end;
<overlay-16:00164h>(路徑, 樣式, 表A[類別], 表B[類別], 表C[類別], arg_4, arg_0);
```

★ `DS:0A816h` 選副檔名，同時決定三張平行表的索引：

| 表 | 基底 | 寬度 | 靜態內容（索引 0..3） |
|---|---|---|---|
| A | `DS:0BFCh` | byte | `00 00 04 F7` |
| B | `DS:0BFFh` | word | `00F7h`(247)、`0084h`(132)、`0013h`(19)、`01A7h`(**423**) |
| C | `DS:0C05h` | word | **`01A7h`(423)、`011Dh`(285)、`00BCh`(188)**、`0000h` |

> ★★★ **spec 1073 讀完被呼叫的那一支（就是 `overlay-16:00164h`）之後，
> 三張表的用途定案**——它們是接在「路徑、樣式」後面的三個參數：
>
> | 表 | 參數 | 靜態內容（`.guy`／`.cha`／`.sav`／`.hil`） |
> |---|---|---|
> | A | **名字欄位在檔案內的位移** | `0`／`0`／`4`／`0F7h` |
> | B | **旗標欄位在檔案內的位移** | `247`／`132`／`19`／`423` |
> | C | **預期的檔案長度** | `423`／`285`／`188`／`0` |
>
> ★★★ 表 B 的 `247` ＝ `0F7h` 正是 spec 1072／1076 拿來判圖示的
> **角色 `+0F7h`**，而 spec 1073 的拒收條件正是「那一格 ≥ `80h`」——
> **三處獨立對上**。表 A 的 `0` 也對得上：角色記錄開頭就是名字字串。
>
> ★★★ 表 C 的前三個值 423／285／188 是 spec 1038 的三種角色記錄長度，
> 但它們是**這條掃描路徑「預期讀到多長」**，不是「副檔名決定格式」。
> spec 1075／1076 在兩平台的存讀檔路徑都看到
> **隊伍成員存成 `.sav`、內容卻是現行長度**（DOS 422／PC-98 423），
> 因為那幾支一進門就先 `DS:7584h := 0`。
> ⇒ **決定格式的是 `DS:7584h`，不是副檔名。**
>
> ★★ 兩種 `.sav` 不會互相干擾：spec 1073 的長度檢查只收
> `預期 ± 1`，所以 422／423 的存檔角色**不會**出現在類別 2（預期 188）的清單裡。
>
> ⚠ 三張表的位址區間互相重疊（`0BFFh`..`0C0Ah` 與 `0C05h`..`0C0Ch`），
> 形狀上是同一排 7 個 word 的兩個取法；本規格不宣稱它們是不是同一筆記錄的欄位。

★ `.sav` 與 `.hil` 是 spec 1038 沒看到的兩個副檔名。

## `pc98 overlay-16:008E4h`（`retf`）——建立存檔磁片

```pascal
repeat
    Move(DS:0C0Ch, DS:0A335h, 0Ah);           { 熱鍵塊 }
    選項行 := '   はい                       いいえ    ';   { 40 bytes }
    DS:0A385h := 0Ah;  DS:0A386h := 0Ah;
    提示 := 'セーブディスクを作成しますか？ ';              { 31 }
    鍵 := <overlay-26 entry#5>(…);
until 鍵 in ['A', 'J', #0];
if 鍵 <> 'A' then exit;
顯示('セーブディスクを作成中です。');                       { 28 }
if <sub_5588h>() = 1 then begin
    顯示('セーブディスクの作成に失敗しました。リターン・キーを押してください。'); { 68 }
    exit
end;
…把檔案抄過去…
```

## ★★★ 第四組 Yes／No 熱鍵

```
DS:0C0Ch = 00 00 00 00 00 41 00 00 00 4A
```

⇒ 槽 6 ＝ **`'A'`（はい）**、槽 10 ＝ **`'J'`（いいえ）**，其餘槽 `00`。

| 出處 | 是／否熱鍵 | 空槽 |
|---|---|---|
| 營地（spec 1030） | `Y`／`B` | `06` ＋ 半形空白 |
| 商店（spec 1031） | `A`／`B` | `06` ＋ 全形空白 |
| 戰利品（spec 1032） | `A`／`B` | `00` |
| **本支** | **`A`／`J`** | `00` |

> ★★★ **四個 Yes／No 提示，三種不同的熱鍵配對。**
> 中文化只能**照抄各自的常數塊**，不能統一。

★ 選項行是 **40 bytes 的整列**（「はい」在第 3 byte、「いいえ」在第 30 byte），
與 spec 1030／1031 的 80 bytes 版本不同——**兩種寬度並存**。
★ `DS:0A385h`／`DS:0A386h` 這裡都寫 `0Ah`（spec 1032 看到的是 `0A385h := 1`），
兩者都落在 10 格陣列之後，用途仍不宣稱。
