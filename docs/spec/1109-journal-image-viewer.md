# 1109 — 手札的地圖與插圖在遊戲內彈窗顯示

- 狀態：`READY`
- 證據等級：`exact`（圖出自 Adventurer's Journal 掃描；彈窗以 `-screenshot` 實拍驗過）
- 前置：spec 1108（哪幾則手札玩家讀得到）、spec 556（手札分頁）

## 一、缺口

手札的地圖與插圖先前只存在於紙本手冊，條目本文還寫著「原始地圖圖像保存於
Adventurer's Journal 第 15 頁」——等於在遊戲裡叫玩家去翻紙本。這與 remake 的目標
相反，那幾句已隨本輪刪除。

## 三、資料落點

對應表在 `gamepack/rules/journal-images.json`（`message_id` → 檔名 ＋ 圖說 ID），
**不進共用 engine 的 Pack**：圖是本作手冊的掃描，檔名與裁切方式只對這一個標題有
意義，engine 沒有消費端。作法沿用 `rules/character-tables.json` 的先例。

★ 圖說的鍵刻意用 `journal-image.4` 而不是 `journal.image.4`：`journal.` 開頭的鍵
每一個都必須有 producer（`TestEveryJournalEntryHasAProducer`），而圖說沒有。

★ `TestJournalImagesMatchTheAssetDirectory` 要求清單與 `assets/journal/` **互為
子集**。單向檢查會讓兩種錯都變成靜默失敗：清單指向不存在的檔（執行時才發現），
以及圖放進目錄卻沒有人引用（永遠不會顯示）。

## 四、彈窗

在手札畫面按 `I` 開啟；只有目前這一頁真的有圖時，底部提示才會出現 `I：看圖`。

| 鍵 | 行為 |
|---|---|
| `Esc`／`I` | 關閉 |
| `Z` | 在「整張縮進視窗」與「原尺寸」之間切換 |
| 方向鍵 | 原尺寸時平移 |

★ **縮的時候不放大**（倍率上限 1）：216x194 的小插圖拉滿面板只會糊掉。
★ **縮的時候方向鍵不平移**：整張都看得見，沒有東西可移，方向鍵留給翻頁不會有歧義。
★ **平移量夾在「圖還看得到」的範圍**，比視窗小的那一軸直接歸零，否則玩家會把圖
推出畫面外再也找不回來。

缺圖時不讓遊戲停下來：記成「這一則沒有圖」並在 stderr 留一行，玩家照樣讀得到文字。

## 五、驗證

`-journal-image <訊息 ID>` 與 `-journal-image-zoom` 是 capture-only 直入點
（同既有 58 個分段驗收旗標）。實拍兩張：

- `journal.52` 縮放模式：圖說「尤拉什城區圖」與控制列都在面板內，整張城區圖可見。
- `journal.59` 原尺寸：`Animal Noises`、`Dexam's Shrine` 清楚可讀。

⚠ 容器裡沒有任何字型，`loadFace` 的候選路徑也都不存在，所以拍圖要帶 `-font`。
`uming.ttc` 不能用——`x/image/sfnt` 對它回 `invalid table offset` 而**靜默退回
7x13 點陣字**，中文會變成方框。這不是程式的問題，但沒帶字型就拍不出可判讀的圖。

倍率與平移夾限另有純函式測試（`journalImageScale`／`clampPan`），不需要顯示。

## 六、明確不宣稱

- 沒有宣稱圖的裁切邊界是原書的版面邊界；那是照內容目視裁的。
- 沒有處理手札 1 那張插圖（導言頁的 `CAB_AJ01.GIF`），也沒有處理手冊其他章節
  （地理、勢力、怪物圖鑑）的插圖。
- 沒有做圖的縮放記憶：關掉彈窗再開會回到「整張縮進視窗」。
