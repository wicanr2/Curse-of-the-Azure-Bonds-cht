# 900 — 法術選單入口：四種用途各一個標題，PC-98 逐格配熱鍵

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-22:00219h`（DOS 194 條）↔ `overlay-22:00227h`（PC-98 233 條）

`retf 6` ＝ 3 個 word：`(用途, ?, var 結果)`。

| 用途 | DOS | PC-98 標籤 | PC-98 熱鍵 |
|---|---|---|---|
| 1 | `'Cast'` | `'かける'` | `43h` `'C'` |
| 2 | `'Memorize'` | `'記憶ｽﾙ'` | `4Dh` `'M'` |
| 3 | `'Scribe'` | `' 書ｷｺﾑ'` | `53h` `'S'` |
| 4 | `'Learn'` | `' 学ぶ '` | `4Ch` `'L'` |
| 其他 | 空字串 | `'      '`（六個空白） | `20h` |

標題另有 `'Choose Spell: '`／`'呪文を選んでください'`。

```pascal
case 用途 of
  1: 選項 := 'Cast';       2: 選項 := 'Memorize';
  3: 選項 := 'Scribe';     4: 選項 := 'Learn';
  else 選項 := '';
end;

if <0A54h:08D4h>(某鍵表, 用途) then 標題 := 'Choose Spell: '
else                              標題 := '';

顏色 := (用途 = 2) ? 0Fh : 16h;
旗A  := (用途 = 4) ? 0 : 1;
旗B  := 0;
if 有號(結果^) < 0 then begin 旗B := 1;  結果^ := 0 end;
if 用途 in [1, 4] then 旗B := 1;

repeat
    鍵 := <far 16A9h>(var 選中, 結果, var 旗B, 旗A,
                      遠指標(DS:4B44h), 顏色, 26h, 5, 1, 0Fh, 0Ah, 0Dh,
                      選項, 標題);
until not <0A54h:08D4h>(離開鍵表, 鍵);

{ 算出選中的是第幾個法術行 }
p := 遠指標(DS:4B44h);   n := 0;
while p <> 選中 do begin
    if p^[29h] = 0 then inc(n);        { 標題行不算 }
    p := p^[2Ah];
end;

if <0A54h:08D4h>(取消鍵表, 鍵) then 結果碼 := 0
else 結果碼 := byte[4B9Ch ＋ n];        { 法術碼陣列 }

if 用途 = 3 then
    DS:729Ch := 遠指標(DS:4BF0h ＋ n * 4);

<本模組 16B8h>(@DS:4B44h);              { 釋放整條顯示行鏈 }
```

## 這是 spec 859 的呼叫端

`DS:4B44h` 是 spec 859 建立的**顯示行鏈**（`+29h` 標題行旗標、`+2Ah` next），
`DS:4B9Ch` 是它的**法術碼陣列**。本支把選中的節點換算成陣列索引：
**走鏈時只有 `+29h ＝ 0` 的行才推進計數**——與 spec 859 建鏈時的規則一致。

`用途 = 3`（Scribe）時另外從 `DS:4BF0h ＋ n × 4` 取一個遠指標寫進 `DS:729Ch`
——那是 spec 859 沒有讀到的**第三個平行陣列**（每筆 4 bytes 的遠指標），
形狀上是「這一行對應的卷軸物品」。

## PC-98：標籤與熱鍵寫在兩個不同的索引

PC-98 依 `var_32`（標題字串是不是空的）分兩條路：

| 條件 | 標籤位址 | 熱鍵位址 |
|---|---|---|
| 沒有標題 | `DS:0A33Fh`（索引 0） | `DS:0A335h`（索引 0） |
| 有標題 | `DS:0A362h`（索引 5） | `DS:0A33Ah`（索引 5） |

`0A362h − 0A33Fh = 35 = 5 × 7`、`0A33Ah − 0A335h = 5`——**索引一致**，
與 spec 899 定出的基底（標籤 `DS:0A33Fh` stride 7、熱鍵 `DS:0A335h` stride 1）
完全吻合。

四個標籤都是 6 bytes：`'かける'` 是三個全形字，
`'記憶ｽﾙ'`／`' 書ｷｺﾑ'`／`' 学ぶ '` 混用半形片假名與空白湊滿——
**日文版自己就已經被 6 bytes 逼到要用半形片假名**。
中文版三個字剛好，不必混用。

## 明確不宣稱

- 沒有宣稱 `far 16A9h` 那 14 個參數各是什麼。
- 沒有宣稱 `本模組 16B8h` 除了釋放之外還做什麼。
- 沒有宣稱 `DS:4BF0h` 那個遠指標陣列裝的是不是卷軸物品。
- 沒有宣稱 `DS:729Ch` 由誰讀。
- 沒有宣稱三張鍵表（`unk_1AAh`／`unk_1D9h`／`unk_1F9h`）的內容。
