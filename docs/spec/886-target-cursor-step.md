# 886 — 目標游標前後切換：接上 spec 852／860 的目標清單

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側 10 條差異全是位址）
- 作法見 spec 783

## `overlay-13:0394Bh` ↔ `overlay-13:03889h`（兩平台各 142 條）

`retf 6` ＝ 3 個 word。`arg_0` 是**父程序的框架指標**（巢狀程序），
`arg_2` 是「要不要動畫」，`arg_4` 是步進量（`+1`／`−1`）。
回傳被選中的戰鬥員遠指標。

```pascal
{ 父框架上的目標清單：每筆 3 bytes，第 0 筆當 header }
{   父[−0DBh] ＝ 目前索引（第 0 筆的 +0）  }
{   父[−0DAh] ＝ 筆數      （第 0 筆的 +1）  }
{   父[−0DEh]／[−0DFh] ＝ 現在高亮的座標    }
{   父[−0E0h]／[−0E1h] ＝ 新座標            }

if 要動畫 then begin
    k := 父[−0DBh ＋ 父[−0DBh] * 3];              { 目前那一筆的戰鬥員索引 }
    父[−0DEh] := byte[66A3h ＋ k * 4];
    父[−0DFh] := byte[66A4h ＋ k * 4];
end else
    <far 1901h+2>(父[−0DFh], 父[−0DEh]);          { 直接把游標畫掉 }

父[−0DBh] := 父[−0DBh] ＋ 步進;
if 父[−0DBh] = 0            then 父[−0DBh] := 父[−0DAh];   { 往前繞到最後 }
if 父[−0DBh] > 父[−0DAh]    then 父[−0DBh] := 1;           { 往後繞到第一 }

k := 父[−0DBh ＋ 父[−0DBh] * 3];
結果 := 遠指標(DS:6D35h ＋ k * 4);
父[−0E0h] := byte[66A3h ＋ k * 4];
父[−0E1h] := byte[66A4h ＋ k * 4];

if 要動畫 then begin
    <far 156Dh>(0, 1, 父[−0E1h], 父[−0E0h], 父[−0DFh], 父[−0DEh]);
    父[−0DEh] := 父[−0E0h];
    父[−0DFh] := 父[−0E1h];
end;
```

## 三張既有結構一次接上

| 這裡用的 | 出處 |
|---|---|
| `DS:66A3h ＋ k × 4` 的 `+0`／`+1` | spec 860 的**戰鬥員座標快取**（`+0` y、`+1` x、`+3` 體型） |
| `DS:6D35h ＋ k × 4` | spec 852 的**戰鬥員遠指標陣列** |
| 父框架上每筆 3 bytes、第 0 筆當 header 的清單 | spec 860 的**結果表**（`+0` 索引、`+1` 距離、`+2` 方向）版面 |

父程序把 `DS:6E94h` 那張結果表抄到自己的堆疊上（或用同一個版面自建），
本支只在上面走索引。**「第 0 筆當 header」的慣例第三次出現**
（前兩次是 `DS:66A3h` 與 `DS:6E94h`，spec 860）。

## 環狀走訪，兩個方向都繞

`步進` 是 `+1` 或 `−1`：減到 0 就跳到 `筆數`、加超過 `筆數` 就回到 1。
**索引從 1 起算**，與清單「第 0 筆是 header」一致。

## `arg_2` 分出兩條路

- **要動畫**：先取現在那一筆的座標當起點，走完之後叫
  `far 156Dh(0, 1, 新x, 新y, 舊x, 舊y)` 把游標從舊位置移到新位置。
- **不要動畫**：直接叫 `far 1901h+2(舊x, 舊y)` 把游標抹掉，
  新位置只算不畫。

## PC-98：10 條差異全是位址

`DS:66A3h`↔`0A2A0h − 3` 之類的段內位移、近呼叫目標，
以及回傳值取法（DOS 兩次 `mov`、PC-98 `les`）。**沒有邏輯差異。**

## 明確不宣稱

- 沒有宣稱 `far 156Dh` 的六個參數（形狀上是「把游標從舊格移到新格」）。
- 沒有宣稱 `far 1901h+2(x, y)` 做什麼（形狀上是抹掉游標）。
- 沒有宣稱父程序是誰、那張清單是抄的還是自建的。
