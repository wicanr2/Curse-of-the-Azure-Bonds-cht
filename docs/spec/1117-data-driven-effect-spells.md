# 1117 — 效果類法術改成資料驅動：11 支法術，0 段新的法術程式碼

- 證據等級：`exact`（效果碼、持續時間係數、豁免類別逐欄取自法術主表 spec 1111；
  施法收尾的形狀取自 spec 731）
- 對應工作項：`ENG-09` 的實作半邊

## 為什麼不是「再寫 67 個 handler」

原作的施法收尾是**同一個迴圈**（spec 731 的 `sub_F06h`）：對每個目標擲豁免、
依屬性表的 `+0Ah` 套效果、持續時間由 `+2h`／`+3h` 的係數算出來。
法術之間的差別幾乎全在資料裡。

量一下就看得出來：戰鬥可施放的 79 支裡，**46 支的 `+0Ah` 不是 0**——
它們要的是同一條路，不是 46 段程式碼。

## 三個容易寫錯的地方

**`Strength` 不是持續時間。** `0FFh` 是「永久」的標記（spec 441／758）——
拿它裝時間會讓效果永遠不會過期。時間寫 `Duration` 與 `Value` 兩格：
到期迴圈先看 `Duration`，為 0 時退回 `Value`。

**沒有豁免門檻的目標算失敗，不是自動成功。** 怪物記錄缺豁免值時該是弱點，
不是免疫；寫成「門檻 0 ⇒ 一定成功」會讓所有沒填豁免的怪物對控制類法術免疫。

**目標模式由 pack 手寫宣告，不從 `+0Bh` 推。** 屬性表的 `+0Bh` 只有 0／1／2
三個值，而 1 與 2 的差別原作沒讀出來（spec 827）。拿沒讀出來的欄位推
「敵方／友方」會得到一個自洽但沒有依據的規則。

## 豁免的語意來自觀察，不是定論

`+8h = 1` 判成「豁免就沒事」——spec 1111 只把它記成觀察（那一組全是
`Charm Person`／`Hold Person`／`Cause Blindness` 這一類），不是讀過
`overlay-23 entry#20` 的定論。所以判斷寫在 `saveNegatesKind` **一個常數**上，
日後讀出真正的語意時只改那一行。

## 還差什麼

- **`+0Ah` 是 0 的那 21 支**（傷害類為主）走不了這條路：它們的效果是傷害，
  由 spec 731 的 `entry#20` 結算，remake 那一側還沒有對應的資料驅動傷害路徑。
- **效果碼的語意**：46 支裡只有 11 支的碼 remake 解讀得了。其餘的碼記得上去、
  但沒有人判讀——`docs/audit/combat-spell-coverage-ledger.md` 的 `handler` 欄
  只代表「有 handler」，不代表玩家看得到效果。spec 1005 的效果分派表是下一步。
- **visual／sound**：新接的 11 支都沒有宣告視覺與音效，台帳照實列。
