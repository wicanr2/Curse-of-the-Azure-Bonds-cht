# 1079 — DOS 屬性重算：`+10h + i × 2` 是基準值、`+11h + i × 2` 是目前值，18/xx 只給戰士三職

- 證據等級：`exact`（DOS 側 594 條逐條讀完，無匯出破洞）
- 作法見 spec 783

## `dos overlay-23:018D8h`（`retf 6`）

原本待解讀。範圍 `18D8h`..`1F16h`。這是**「重算第 N 個屬性的目前值」**：
從基準值出發，把裝備中的物品加成與身上的法術效果疊上去，再寫回目前值。

```pascal
procedure 重算屬性(屬性: word; 角色: 遠指標);
```

⚠ **IDA 把本支當成 near 函式，所以 `arg_N` 的編號整體偏移 2**：
IDA 的 `arg_2` 其實是 `bp+6`（第一個參數）、`arg_4` 是 `bp+8`（角色遠指標）。
`retf 6` ＝ 2 ＋ 4，剛好兩個參數。
（判別法：同一支裡 `les di, [bp+8]` 與 `les di, [bp+arg_4]` 指向**同一個**
角色指標；若照 IDA 的編號讀，兩者會落在互相重疊的位置。）

## ★★★ 一、六個屬性的欄位是成對的

```pascal
基準 := 角色^[10h ＋ 屬性 × 2];      { var_1 }
百分比基準 := 角色^[1Dh];            { var_3 }
…算完之後…
角色^[11h ＋ 屬性 × 2] := 結果;
```

| 屬性 | 基準 | 目前 | AD&D |
|---|---|---|---|
| 0 | `+10h` | `+11h` | **力量**（另有百分比 `+1Ch`／基準 `+1Dh`） |
| 1 | `+12h` | `+13h` | 智力 |
| 2 | `+14h` | `+15h` | 睿智 |
| 3 | `+16h` | `+17h` | 敏捷 |
| 4 | `+18h` | `+19h` | **體質** |
| 5 | `+1Ah` | `+1Bh` | 魅力（spec 1040 已確認 `+1Bh` 是魅力） |

> ★★★ **既有結論只記了「屬性組 `+11h ＋ i × 2`」。這裡看到它是一對**：
> 偶數位移是**基準值**（建角時決定、不受裝備影響），
> 奇數位移是**目前值**（每次裝備／效果變動就由本支重算）。
> ⇒ remake 兩格都要存，只存一格會讓脫裝備後屬性回不去。

## ★★★ 二、物品迴圈：t ＝ 8 的「＋1 屬性」只在基準 < 18 時生效

```pascal
節點 := 角色^[14Dh];                                { 物品鏈，spec 1075 }
while 節點 <> NIL do begin
    if (節點^[3Eh] > 80h) and (節點^[34h] <> 0) then begin   { 已裝備且啟用 }
        t := 節點^[3Eh] and 7Fh;
        …依 屬性 分派，見下…
    end;
    節點 := 節點^[2Ah];                             { next，spec 1075 }
end;
```

| 屬性 | `t` | 效果 |
|---|---|---|
| 0 力量 | **5** | **把力量設成 `12h ＋ 節點^[3Dh]`**（`3Dh` ＝ 0..6 ⇒ **18..24**）；<br>`3Dh = 0` 時另外把百分比設成 **`64h` ＝ 100** ⇒ **18/00** |
| 0 力量 | 8 | 基準 < `12h` 且 `節點^[3Dh] = 0` ⇒ 力量 := 基準 ＋ 1、百分比 := 0 |
| 0 力量 | `0Dh` | 強制值 := 3 |
| 1 智力 | 8 | 基準 < `12h` 且 `節點^[3Dh] = 1` ⇒ ＋1 |
| 1 智力 | `0Ch` ／ `0Dh` | 強制值 := 7 ／ 3 |
| 2 睿智 | 8 | 基準 < `12h` 且 `節點^[3Dh] = 2` ⇒ ＋1 |
| 3 敏捷 | **2** | 依**基準敏捷**分段：`0`..`6` ⇒ **＋4**、`7`..`0Dh` ⇒ **＋2**、其餘 ⇒ **＋1** |
| 3 敏捷 | 8 | 基準 < `12h` 且 `節點^[3Dh] = 3` ⇒ ＋1 |
| 3 敏捷 | `0Ah` | **−2** |
| 4 體質 | 6 | **＋1** |
| 4 體質 | 8 | 基準 < `12h` 且 `節點^[3Dh] = 4` ⇒ ＋1 |
| 5 魅力 | 6 | **−1** |
| 5 魅力 | 8 | 基準 < `12h` 且 `節點^[3Dh] = 5` ⇒ ＋1 |

> ★★★ **`t = 8` 是「＋1 某個屬性」的通用物品，`節點^[3Dh]` 指定哪一個**
> （0 ＝ 力、1 ＝ 智、2 ＝ 睿、3 ＝ 敏、4 ＝ 體、5 ＝ 魅），
> 而且**只在該屬性的基準值 < 18 時生效**——這就是 AD&D
> 「屬性書（Tome）不能把已達 18 的屬性再往上推」的實作。
> ★★★ **`t = 5` 是巨人力量腰帶那一族**：`3Dh` 直接對到 18..24，
> 而 `3Dh = 0` 的那一件同時給 **18/00**（＝ 食人魔力量護手）。
> ★★ **`t = 6` 同時 ＋1 體質、−1 魅力**；**`t = 0Ah` −2 敏捷**。
> ⇒ 這兩個是「有代價」的裝備，remake 不能只實作正面加成。
> ⚠ 本規格不宣稱 `t` 這些編號各自對應哪一件具體物品。

## ★★★ 三、力量 18/xx 只給戰士、聖騎士、遊俠

只有 `屬性 = 0` 才走這一段（`arg_2 = 0`）：

```pascal
if <overlay-24 entry#27>(@效果, 26h, 角色) then begin
    <取效果的兩個值>(@百分比加值, @力量加值, 效果);
    if (基準 ≤ 12h) and (百分比基準 < 64h) then begin
        力量 := 力量加值 ＋ 基準;
        if 力量 > 12h then begin
            if (角色^[10Bh] > 0) or (角色^[113h] > 0)      { 戰士 }
            or (角色^[10Ch] > 0) or (角色^[114h] > 0)      { 聖騎士 }
            or (角色^[10Dh] > 0) or (角色^[115h] > 0) then { 遊俠 }
            begin
                百分比 := 角色^[1Ch] ＋ (力量 − 12h) × 0Ah;   { ★ 每點 10 個百分點 }
                if 百分比 > 64h then 百分比 := 64h;
            end;
            力量 := 12h;                                     { ★ 一律夾成 18 }
        end;
    end;
end;
```

> ★★★ **超過 18 的部分每 1 點換算成 10 個百分點，上限 100（＝ 18/00）**，
> 而且**只有職業槽 2／3／4（戰士／聖騎士／遊俠）有等級的角色**才拿得到百分比；
> 其他職業超過 18 就直接被砍成 18。
> ⇒ 這正是 AD&D 1e 的規則，**第四次獨立確認職業槽順序
> 牧師／德魯伊／戰士／聖騎士／遊俠／法師／盜賊／武僧**（spec 1055 等）。
> ★ `+109h ＋ j` 是等級、`+111h ＋ j` 是另一組平行陣列（本支只用來判「有沒有這個職業」）。

接著同一段還會再查兩個效果碼 `92h` 與 `0Ch`，各自把值疊上去。
最後：**強制值 ≠ `0FFh` 就直接寫強制值並把百分比清 0**，否則寫算出來的值。

## ★★★ 四、屬性 4（體質）會連帶重算最大 HP

```pascal
角色^[78h] := 角色^[12Ch];              { ★ 最大 HP 先回到基礎值 }
職業數 := 0;
for j := 0 to 7 do begin
    if 角色^[111h ＋ j] > 0 then <累加 HP>(角色^[111h ＋ j], j);
    if 角色^[109h ＋ j] > 0 then inc 職業數;
    等級 := 角色^[109h ＋ j];
    if DS:3EB9h[j] < 等級 then 等級 := DS:3EB9h[j];      { ★ 名望等級上限 }
    if 等級 > 角色^[0E6h] then <累加 HP>(等級 − 角色^[0E6h], j);
end;
加值 := 體質加值 div 職業數;                             { ★ 多職業平均 }
角色^[78h] := 角色^[78h] ＋ 加值;

{ 最大 HP 變動時同步調整目前 HP }
if 新最大 > 舊最大 then 角色^[1A4h] := 角色^[1A4h] ＋ (新 − 舊)
else if 角色^[1A4h] > (舊 − 新) then 角色^[1A4h] := 角色^[1A4h] − (舊 − 新)
else 角色^[1A4h] := 0;

角色^[19h] := 體質目前值;
if 角色^[19h] ≥ 14h then begin                          { ★ 體質 ≥ 20 }
    if not <overlay-24 entry#27>(@效果, 3Eh, 角色) then
        <加上效果>(1, 0FFh, 3Ch, 3Eh, 角色);
end else
    <移除效果>(0, 3Eh, 角色);
```

★ `DS:3EB9h` 就是 spec 1055 確認過的**八職業名望等級表**
（`10 15 10 10 11 12 11 19`），HP 到達上限之後改用固定加值——
**與 spec 1055 的 HP 公式是同一套**，這裡是「體質變了要補算」的路徑。
★ `+78h` ＝ 最大 HP、`+12Ch` ＝ 基礎最大 HP、`+1A4h` ＝ **目前 HP**、
`+0E6h` ＝ 名望等級的參考值。

> ★★★ **體質 ≥ 20 會自動掛上效果碼 `3Eh`、掉回 20 以下就自動移除**
> ——形狀上是**再生**（AD&D 的 CON 20 開始每回合回血）。
> ⚠ 本規格不宣稱 `3Eh` 是哪一個效果。
