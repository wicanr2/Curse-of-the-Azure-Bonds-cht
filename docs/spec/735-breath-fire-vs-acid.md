## 兩支並排

| | `5AA8h` 吐酸（spec 725） | `5C86h` 噴火（本輪） |
|---|---|---|
| 傷害旗標 `DS:6F95h` | `30h` | `21h` |
| `sub_175Bh` 最後兩個參數 | `1, 6` | `3, 9` |
| 檢查 `DS:7746h` 的時機 | 選完之後、走射線**之前**，且結果影響要不要走 | 選完之後直接返回或繼續 |
| **同類檢查迴圈** | **有**——目標陣列裡有一格 `+197h` 與自己不同就整次取消 | **沒有** |
| 走訪迴圈 | 兩個（前一個無 `NIL` 檢查） | 一個（有檢查） |
| 傷害參數 | `arg_6^[78h]`（攻擊者 HP 上限） | 同 |
| 次數欄位與遞減位置 | `arg_2^[3]`，最後才扣 | 同 |

**最實質的差別是同類檢查。** 吐酸只要範圍內混進一個不同陣營的單位就整次不發動
（spec 725），噴火沒有這道檢查——**火會燒到自己人**。

`sub_175Bh` 的 `(1, 6)` 對 `(3, 9)`：依 spec 729，那兩個參數走的是射線形狀與
射程相關的路徑，所以兩種吐息的覆蓋範圍不同。

## 明確不宣稱

- 傷害旗標 `21h`／`30h` 分別代表哪一種傷害。
- `sub_175Bh` 最後兩個參數的確切語意（spec 729 記為 `arg_0` 模式與 `arg_2` 射程，
  但沒有把每個值對上）。
- `DS:758Dh` 是什麼（兩支共用，為 0 時把次數重設成 3）。
