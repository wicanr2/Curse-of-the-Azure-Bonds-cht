# 970 — PC-98：名字顏色依陣營、以及與 DOS 同款的「沒有預設值」

- 證據等級：`exact`（兩支逐條讀完）
- 位置：`pc98 overlay-24:01AC2h`、`pc98 overlay-12:020E6h`
- 作法見 spec 783

## `overlay-24:01AC2h`（41 條，`retf 0Ah`）：印一個角色的名字

`(arg_0, 列 arg_2, 欄 arg_4, 角色 arg_6)`。
DOS 的對應是 `01AAAh`（spec 692），但**相似度只有 0.488——兩邊差很多**。

```pascal
if 角色^[197h] = 0 then      顏色 := 0Ch
else if 角色^[198h] = 1 then 顏色 := 0Eh
else                         顏色 := 0Bh;

<418h:1C96h>(角色, @名字);                        { 取名字 }
名字 := 限長(名字, 0FFh);
印字(0, 顏色, arg_2, arg_4, 名字);                { 418h:0D17h }
```

★ **名字的顏色由兩個既有欄位決定**：

| 條件 | 顏色 |
|---|---|
| `+197h` ＝ 0 | `0Ch` |
| `+198h` ＝ 1 | `0Eh` |
| 其他 | `0Bh` |

`+197h` 與 `+198h` 在既有規格裡分別是**陣營／隊伍側**與
**不能自由選擇**。所以這一支是**用顏色把敵我與「被控制的角色」分開**。

DOS 版（spec 692）在同一個位置做的是**三次 `sub_1975h` 呼叫**
（參數 `(arg_0, 1, 2, 1)`、`(arg_0, 1, 3, 0)` …），
**沒有這段顏色判斷**——PC-98 把它換成了單一的彩色名字。

## `overlay-12:020E6h`（48 條，`retf 0Ah`）：分段加成

DOS 的對應是 `02078h`（spec 741 的第三支）。

```pascal
if (DS:0A041h = 4) or (DS:0A041h = 2) then begin
    v := 角色^[19h];
    if v in [4..6]    then 加成 := 1
    else if v in [7..0Ah]  then 加成 := 2
    else if v in [0Bh..0Dh] then 加成 := 3
    else if v in [0Eh..11h] then 加成 := 4
    else if v in [12h..14h] then 加成 := 5;
    { ★ 沒有 else }
    DS:0A02Ch := DS:0A02Ch ＋ 加成;
end;
```

### ⚠ 同一個缺陷 PC-98 沒有修

`加成`（`bp−1`）在 `v < 4` 或 `v > 14h` 時**從頭到尾沒有被賦值**，
加進 `DS:0A02Ch` 的是堆疊殘值——與 spec 741 記的 DOS 版**完全相同**。

spec 741 列出本專案三處同型問題（`overlay-24:129Ah`／`overlay-22:23F2h`／
`overlay-12:2078h`），現在可以補一句：**PC-98 側至少這一處也一樣**。

### 編譯器碼型差異

11 個差異區塊全部是 spec 783 的**類別 (c)**：

```
DOS  ：mov al, …  /  xor ah, ah  /  cmp ax, 4  /  jl / jg      （有號）
PC-98：mov al, …  /              cmp al, 4  /  jb / ja        （無號）
```

`+19h` 的值域是 4..20，兩者在這個範圍內等價，**沒有行為差異**。

## 明確不宣稱

- 沒有宣稱 `<418h:1C96h>`（取名字）的內部。
- 沒有宣稱三個顏色碼 `0Ch`／`0Eh`／`0Bh` 在 PC-98 調色盤上是什麼顏色。
- 沒有宣稱 `DS:0A041h`（＝ DOS `DS:6FA7h`）與 `DS:0A02Ch`（＝ `DS:6F92h`）
  的語意（spec 741 也沒有宣稱）。
