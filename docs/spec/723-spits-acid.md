## 和龍息（spec 720）並排看

兩支的骨架幾乎一樣，四個數字不同：

| | 龍息 `5E11h` | 吐酸 `5974h` |
|---|---|---|
| 選目標模式碼 | `41h` | `41h`（相同） |
| 距離上限 | `>= 2` 就放棄 | `>= 7` 就放棄 |
| 命中判定 | `ROLLDICE(1,100) > 50` 直接不發動 | `> 30` 顯示 `and Misses` |
| 傳給 `entry#20` 的傷害參數 | 常數 `7` | `arg_6^[78h]`（攻擊者 HP 上限） |
| 未命中時 | 沒有任何訊息 | 有專屬訊息 |

**「打不中」的表現方式不同**：龍息是靜默返回，吐酸會告訴玩家。這種差異在把兩支
合併成一個共用函式時最容易被統一掉。

`+78h` 是 HP 上限（spec 689 已定），所以吐酸的強度隨攻擊者體質變化，龍息不會。

## 兩支共有的順序問題

`p` 都是先拿去呼叫 `entry#33`（算距離）才檢查 `NIL`。因為 `entry#33` 只讀不寫，
實務上不會當掉，但那次距離計算的輸入是中斷向量表的內容（spec 716）。
`6022h`（spec 722）是唯一一支呼叫前先把欄位清成 `NIL` 的。

## 明確不宣稱

- `entry#20` 第二個參數（這裡是 HP 上限、龍息是 `7`）到底是傷害還是別的東西。
- `overlay-24 entry#25` 最後兩個參數 `1`／`1Eh` 的意義。
- 命中率 `30`／`50` 是否會被別處修改（本輪看到的都是寫死的立即數）。
