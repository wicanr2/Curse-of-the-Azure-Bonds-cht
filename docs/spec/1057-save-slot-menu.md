# 1057 — 存檔槽選單：十個圈號、熱鍵 `A`..`J`、選中的槽前面標「☆」

- 證據等級：`exact`（PC-98 側 279 條逐條讀完）
- 作法見 spec 783

## `pc98 overlay-16:046CEh`（`retf`）

原本待解讀。

## ★★★ 十個槽的版面

| 東西 | 位址 | 內容 |
|---|---|---|
| 選項行 | `CS:4602h`（128 bytes） | `'      ① ② ③ ④ ⑤   ⑥ ⑦ ⑧ ⑨ ⑩ '` |
| 熱鍵塊 | `DS:0DB8h`（10 bytes） | **`'ABCDEFGHIJ'`** |
| 每槽的一行 | `DS:0A64Dh ＋ 槽 × 29h` | 前 2 bytes 是**標記** |
| 每槽的一個 byte | `DS:0A80Ah ＋ 槽` | 見下 |

★ 圈號是 Shift-JIS 的 `87 40`..`87 49`（①..⑩）。
★ 每筆 `29h` ＝ **41 bytes**，與 spec 1037 的選項行表同一種筆距。

## ★★★ 選中的槽前面標「☆」

```asm
46FF  mov  byte ptr [di-59B3h], 81h        ; di ＝ 目前槽 × 29h
4710  mov  byte ptr [di-59B2h], 99h
```

`81 99` ＝ Shift-JIS 的 **「☆」**；換槽時舊的那一格改寫成

```asm
487A  mov  byte ptr [di-59B3h], 81h
488B  mov  byte ptr [di-59B2h], 40h        ; ＝ 全形空白
```

> ★★★ **`81 99`（☆）與 `81 40`（全形空白）是就地覆蓋每一行的前兩個 byte。**
> ⚠ **中文化必須讓每一行的前兩個 byte 保持是一個完整的雙位元組字**，
> 否則覆蓋會切在 Big5 字的中間。
> ⚠ 也不能把標記換成單位元組符號（`*`／`>`）——寫的是**兩個 byte**。

## 流程

```pascal
if not <sub_B4Fh>(0) then exit;
…把目前槽標成 ☆…
選項行 := CS:4602h;                              { 上限 80 }
if 目前槽 <> 0 then DS:0A385h := 目前槽;         { ★ 游標停在目前槽 }
repeat
    印字(5, 14h, 0Dh, 0, 'どこにセーブしますか？');    { 22 bytes }
    Move(DS:0DB8h, DS:0A335h, 0Ah);              { 熱鍵 A..J }
    鍵 := <overlay-26 entry#5>(選項行, …);
until 鍵 in [#0, 'A'..'J'];                      { 集合常數 CS:466Bh }
if 鍵 = 0 then exit;
DS:0A816h := 0;                                  { ★ 檔案類別 0 ＝ '*.guy'，spec 1043 }
槽 := 鍵 − 40h;                                  { 'A' → 1 }
if byte[0A80Ah ＋ 槽] <> 5 then
    印字(2, 14h, …, ? ＋ Str(槽) ＋ '番は既に登録されています。');   { 26 bytes }
if <overlay-26 entry#8>('よろしいですか？', …) <> 'Y' then 重來;   { 16 bytes }
…舊槽的 ☆ 改回全形空白…
DS:0A670h := 槽;
byte[0A80Ah ＋ 槽] := DS:0BDF0h;
```

★ 離開條件的集合常數 `CS:466Bh` ＝ **`{#0, 'A'..'J'}`**
——按到別的鍵就整個重畫再問一次。
★ `DS:0A385h`（spec 1032／1043 一直沒宣稱用途的那一格）**在這裡被設成目前的槽號**
——形狀上是**選單的初始游標位置**。

## 中文化

| PC-98 | bytes | 建議中文 |
|---|---|---|
| 「どこにセーブしますか？」 | 22 | 「要存到哪一個？」 |
| ? ＋ 數字 ＋「番は既に登録されています。」 | 26 | 「號已經有存檔了。」 |
| 「よろしいですか？」 | 16 | 「確定嗎？」 |
| `'      ① ② ③ ④ ⑤   ⑥ ⑦ ⑧ ⑨ ⑩ '` | 128 | ⚠ **圈號可保留**，但每格前兩個 byte 會被覆蓋 |

⚠ **熱鍵 `A`..`J` 不要動**——它們是一整塊 `Move` 進去的（spec 1030 的機制）。

## 明確不宣稱

- 沒有宣稱 `sub_B4Fh(0)`（進門的前置檢查）在檢查什麼。
- 沒有宣稱 `byte[0A80Ah ＋ 槽]` 的 `5` 代表什麼（不等於 5 才顯示「已登記」）。
- 沒有宣稱 `DS:0BDF0h` 為什麼被寫進那一格（spec 1056 也看到這一格）。
- 沒有宣稱 `unk_468Bh`（1 byte，接在「號」前面）是什麼字元的一半。
- 沒有宣稱 `sub_4193h`／`sub_3FB7h`／`sub_424A`／`sub_402A` 做什麼。
