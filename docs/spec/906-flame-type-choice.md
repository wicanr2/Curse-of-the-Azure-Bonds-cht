# 906 — 選火焰種類：`+198h` 成立時改成隨機

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-22:04BECh`（DOS 194 條）↔ `overlay-22:04F5Fh`（PC-98 212 條）

`retf` ＝ 無參數。字串（spec 859 抽到的同一組）：
`'flame type: '`、`'Hot Cold'`、`'Abort spell? '`、`'Yes No'`。

```pascal
完成 := 0;
repeat
    if 遠指標(DS:6506h)^[198h] <> 0 then
        鍵 := (<far 145Dh>(0Ah, 1) > 5) ? 'H' : 'C'      { ★ 1d10 隨機 }
    else begin
        暫 := 'flame type: ';   暫2 := 'Hot Cold';
        鍵 := <far 169Fh>(var 有選中, 0, 0, 0Fh, 0Ah, 0Dh);
    end;

    if 鍵 = 'H' then begin
        <far 1499h>(訊息 ＋ <本模組 0E11h>(遠指標(DS:6506h), 55h, 32h), 0,0,0,0);
        <far 1499h>(訊息 ＋ <本模組 0E11h>(遠指標(DS:6506h), 55h, 8Fh), 0,0,0,0);
        完成 := 1;
    end
    else if 鍵 = 'C' then begin
        <far 1499h>(訊息 ＋ <本模組 0E11h>(遠指標(DS:6506h), 55h, 36h), 0,0,0,0);
        <far 1499h>(訊息 ＋ <本模組 0E11h>(遠指標(DS:6506h), 55h, 8Fh), 0,0,0,0);
        完成 := 1;
    end
    else begin
        暫 := 'Abort spell? ';   暫2 := 'Yes No';
        鍵 := <far 169Fh>(…);
        if 鍵 = 'Y' then 完成 := 1;
    end;
until 完成 <> 0;
```

## `+198h` ＝ 不能自己選

`遠指標(DS:6506h)^[198h]` ≠ 0 時，**整個選單被跳過，改用 1d10 決定**
（`> 5` 走 Hot、否則 Cold）。形狀上是「被控制／混亂，不能自主選擇」的狀態。
PC-98 是 `+199h`（角色記錄的 `+1` 位移，spec 849）。

## 三個效果碼

| 鍵 | 碼 |
|---|---|
| Hot | `32h` |
| Cold | `36h` |
| 兩者共用（第二次） | `8Fh` |

兩條路都是「先掛自己那一個、再掛共用的 `8Fh`」。
`本模組 0E11h(角色, 55h, 碼)` 與 spec 864 的訊息組法同一種形狀。

## 不選也走得掉

按到不是 `H`／`C` 的鍵就跳出第二個選單 `'Abort spell? '`／`'Yes No'`，
按 `'Y'` 才結束——**否則回到第一個選單重問**。所以這個選擇無法用
「亂按」跳過，只能明確放棄。

## PC-98：熱鍵字串又一次

PC-98 在兩個選單各前面多一段
`指派(DS:1589h+1 → DS:0A335h, 0Ah)` 與 `指派(DS:1594h → DS:0A335h, 0Ah)`
——**同一塊熱鍵緩衝，兩個選單各載入一份 10 bytes**。
與 spec 865／871／877／879／885 的模式相同。

- 沒有宣稱 `32h`／`36h`／`8Fh` 三個效果碼的名稱。
