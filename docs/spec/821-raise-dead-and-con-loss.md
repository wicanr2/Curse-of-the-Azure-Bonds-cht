# 821 — Raise Dead：體質 −1、最大 HP 依體質加成重算；PC-98 多一道「復活不了」的警告

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-04:063Eh`（entry#7，DOS 175 條／PC-98 192 條）

| | DOS | PC-98 |
|---|---|---|
| 「沒死」 | `'is not dead.'`（12，有句點） | `'は死んではいませんよ'`（20 bytes，無句點） |
| 「復活不了」 | **沒有** | `'は生き返りませんよ'`（18 bytes） |
| 法術名 | `'Raise Dead'`（10） | `'レイズ・デッド'`（14 bytes） |

`retf`（無參數）。

### 復活的代價是體質 −1

`p^[19h]` 是**體質**：三個門檻 `0Eh`（14）、`0Fh`（15）、`11h`（17）正好是 AD&D
體質對每級 HP 加成的分界（15 起 +1、16 起 +2、17 起戰士專屬 +3），而且 **`c = 2`
（戰士，spec 812）走的是與其他職業不同的式子**。

`+19h` 減 1 之後才重算，所以復活會**永久扣掉一點體質**與隨之而來的 HP。

### `+12Ch` 在這裡是「不含體質加成的 HP」

spec 809／810 已經確認 `+12Ch` 本身**從來不被法術可記憶數那張表寫到**（那張表
從 `+12Dh` 起）。這一支把它拿來與 `+78h`（最大 HP）相減得出「目前的體質加成
總量」，語意上就是**基礎 HP**。

### 幾個要照抄的邊界

- **狀態 `6` 與 `1` 都算死亡**（`+195h`，spec 772 的「The Gods intervene!」寫的
  就是 6）。
- **付了錢也可能什麼都不做**：`可 = 0`（沒死）時流程仍會走到問價那一步，答 `'Y'`
  之後才在 `if 可 = 0 then 離開` 被擋掉。
- `損` 與 `和` 都是 byte，`損 div 和` 是**有號**除法。
- 最後那個「不扣」的條件要三個同時成立（體質 ≥ 17、`+10Bh` ≤ 0、
  `+10Bh` ≤ `+0E6h`），任一不成立就扣。

### PC-98 多的那一道

DOS 只在「沒死」時多問一次；PC-98 在**已死**的情況下再檢查一次
`(p^[196h] = 8) or (p^[74h] = 2)`，成立就顯示「復活不了」並要求確認。

這是 PC-98 版**自己加的規則**（DOS 完全沒有這一段），中文版要決定跟哪一邊。

## 明確不宣稱

- 沒有宣稱效果碼 `20h` / `37h` 的名稱（`37h` 在 spec 796 是解毒清掉的那一個）。
- 沒有宣稱 `+10Bh` / `+0E6h` 是什麼。
- 沒有宣稱 PC-98 的 `+74h` ＝ 2 與 `+196h` ＝ 8 各代表什麼。
- 沒有宣稱 `損 div 和` 的量綱；只確定式子如上。
