# 977 — `SaveList.EST`、熱鍵字串切成欄位範圍、戰場圖示重畫

- 證據等級：`exact`（三支逐條讀完；字串、集合與被呼叫端的堆疊框都由原始 bytes 讀出）
- 作法見 spec 783

## `pc98 overlay-16:04193h`（77 條，`retf 4`）— 讀存檔清單

```pascal
路徑 := DS:8BF6h ＋ 'EST\' ＋ 'SaveList.EST';           { 磁碟前綴在 DS:8BF6h }
提示 := 'ドライブ２にセーブ・ディスクを入れてください' ＋ DS:8BF6h;
ok := <0723h:01EDh>(路徑, 提示, 1, f);                  { 開檔，見下 }
if ok <> 0 then begin
    BlockRead(f, 目的^, 0Ah, 實際讀到);                 { 0A65h:1983h }
    Close(f);                                           { 0A65h:1919h }
end
else
    三段指派(@DS:0DAEh, 目的^, 0Ah);                    { 預設值 }
for i := 1 to 0Ah do <本模組 402Ah>(@i);
```

★ **存檔清單是 10 個 byte**，檔案 `EST\SaveList.EST`，讀不到就用
`DS:0DAEh` 那十個 byte 當預設——**靜態值是 `05 05 05 05 05 05 05 05 05 05`**。

`0Ah` ＝ 10 這個數字與 spec 972／975 的**十格環狀選單**一致：
存檔槽有十個，選單也是十格。

### `0723h:01EDh` ＝ `PC98-GAME.EXE:1741Dh`，「請放入磁片」的開檔器

`0723h` 是相對段（載入基底 `1000h`，見 spec 973），線性位址 `1741Dh`。
`retf 0Eh` ＝ 7 個 word，堆疊框把簽章定死：

| 位置 | 型別 | 內容 |
|---|---|---|
| `[bp+10h]` | far ptr | **路徑**（進來第一件事就 `限長(…, 50h)`，上限 80 字） |
| `[bp+0Ch]` | far ptr | **提示訊息**（開不了時顯示） |
| `[bp+0Ah]` | byte | 模式，本呼叫端給 `1` |
| `[bp+6]` | far ptr | **檔案變數**（呼叫端的 `var_80`，128 bytes ＝ Turbo Pascal 的 `file`） |

回傳 `al`：非 0 ＝ 開成功。整支 279 行，本輪只定案簽章與參數角色。

### 中文化

提示訊息 `'ドライブ２にセーブ・ディスクを入れてください'`（44 bytes ＝ 22 個全形字）
是 overlay 內嵌常數，**不在任何字串表裡**。它後面還會串上 `DS:8BF6h` 的磁碟前綴，
所以譯文結尾要留得住那段路徑。

`'EST\'` 與 `'SaveList.EST'` 是**路徑與檔名，不能翻**。

## `dos overlay-26:000D5h`（92 條，`retf 6`）— 把熱鍵字串切成每一項的欄位範圍

`(表的 SS 偏移 arg_0, 熱鍵字串 arg_2)`。

```pascal
限長(字串^, s, 28h);                                   { 40 字 }
FillChar(表[1], 28h, 0);                               { 20 格 × 2 bytes }
n := 1;
for j := 1 to 長度(s) do
    if s[j] in ['0'..'9', 'A'..'Z'] then                { 集合在 CS:00B5h }
        if 表[n].起 = 0 then 表[n].起 := j
        else begin
            表[n].迄 := j − 2;
            inc(n);
            表[n].起 := j;
        end;
表[n].迄 := 長度(s);
表[0].迄 := n;                                          { 項數 }
```

集合 `CS:00B5h` 的 36 個成員逐 byte 讀出來是 **`'0'..'9'` 加 `'A'..'Z'`**。

輸入是**選項行本身**：DOS 把每一項的熱鍵字母寫成**大寫**、其餘寫成小寫
（`overlay-07:016D3h` 負責產生這種標記，見 spec 978），
所以**大寫英數字的位置就是該項的起點**，下一個大寫字前兩格是該項的終點，
最後一項的終點是字串長度。

- 表放在呼叫端堆疊框上，第 i 格在 `ss:[arg_0 − 8Fh ＋ 2i]`（起）與
  `ss:[arg_0 − 8Eh ＋ 2i]`（迄）。
- `FillChar` 從第 1 格清 40 bytes ⇒ **最多 20 項**。
- 第 0 格的「迄」欄位被拿來存**項數**。

這就是 spec 975 讀 `dos overlay-26:00A56h` 時看到的 `09C4h`（起）與 `0A10h`（迄）
的資料來源——那兩支是查表，本支是建表。

⚠ **相鄰的兩個大寫字會產生 `迄 < 起` 的空區間**（`迄 := j − 2`）。
正常的選項行不會發生（項與項之間有空白），但中文化改寫選項行時要留意：
**兩個熱鍵之間至少要隔兩格**。

⚠ 中文選項行沒有大小寫可用，這套標記在中文化之後會整個失效——
處置見 spec 978。

## `dos overlay-32:00320h`（87 條，`retf 4`）— 重畫戰場一格的戰鬥員圖示

```pascal
相對X := arg_2 − 遠指標(DS:6E92h)^[2];                  { 戰場原點，spec 750／825 }
相對Y := arg_0 − 遠指標(DS:6E92h)^[3];
<本模組 0578h>(相對X, 相對Y, 0);

<本模組 0509h>(arg_2, arg_0, @佔用者, @第二平面);        { 讀戰場兩平面 }
if 佔用者 > 0 then begin                                { 無號 }
    p := 遠指標[6D35h ＋ 佔用者 × 4];
    if <本模組 0763h>(p, 0) then
        <overlay-33 entry#6>(byte[67C6h ＋ 佔用者],      { 座標 B }
                             byte[680Eh ＋ 佔用者],      { 座標 A }
                             遠指標(p^[18Dh])^[9],       { 模式 }
                             0,                          { 編號 }
                             p^[143h]);                  { 組 ＝ 圖像編號 }
end;
```

### `overlay-33 entry#6` 的參數順序定案

被呼叫端 `dos overlay-33:00508h` 一開始就算
`di := arg_0 shl 3 ＋ arg_2 shl 2`、取 `[di ＋ 65D6h]`，
所以 **`arg_0`（`[bp+6]`）＝ 組、`arg_2`（`[bp+8]`）＝ 編號**。
`retf 0Ah` 的五個 word 由高到低是「座標B、座標A、模式、編號、組」，
而 Turbo Pascal **由左至右推疊**⇒ **宣告順序就是 `(座標B, 座標A, 模式, 編號, 組)`，
`組` 是最後一個**。

既有規格把它記成 `(組, 編號, 模式, 座標A, 座標B)`——那是 pop 順序。
兩種寫法指的是同一件事，但**照著推疊順序抄才不會弄反**。
這與 spec 973 對 `0418h:0D17h` 的處理是同一個做法：**簽章一律由被呼叫端的
堆疊框決定，不從呼叫端猜**。

### 三張以戰鬥員編號索引的表

| 位址 | 內容 |
|---|---|
| `DS:6D35h` | 戰鬥員遠指標表，**每格 4 bytes** |
| `DS:67C6h` | 每人一個 byte，傳給貼圖的座標 B |
| `DS:680Eh` | 每人一個 byte，傳給貼圖的座標 A |

`佔用者` 來自戰場地圖平面（`本模組 0509h`，既有結論），所以**戰場格上存的就是
這三張表的索引**。`0` ＝ 空格，本支直接跳過。

圖庫的「組」是角色記錄的 `+143h`（圖像編號，spec 873），「編號」固定 `0`，
「模式」取自戰鬥狀態記錄 `+18Dh` 的 `+9`——**同一個角色會依戰鬥狀態換圖**。

## 明確不宣稱

- 沒有宣稱 `本模組 0578h`（先叫的那一支）與 `本模組 0763h`（那道檢查）做什麼。
- 沒有宣稱 `+18Dh^[9]` 存的是什麼（形狀上是朝向或姿態）。
- 沒有宣稱 `DS:67C6h`／`DS:680Eh` 兩個座標各是 x 還是 y。
- 沒有宣稱 `SaveList.EST` 那十個 byte 的意義，也沒有宣稱預設值 `5` 代表什麼。
- 沒有宣稱 `pc98 overlay-16:0402Ah`（對十格各做一次的那一支）做什麼。
- 沒有宣稱 `0723h:01EDh` 開不了檔時的重試次數與取消方式（整支 279 行未讀）。
