# 1193 — 走訪未達成的三種成因

狀態：`READY`（分類已實作，數字由 `cmd/cell-reachability` 產生）

## 問題

走訪可達性報表說：250 個分派索引，實跑與冷走的聯集是 178。剩下的 72 個只是
一個數字——看不出**要補路線、要補劇情旗標、還是根本補不了**。這三種的處置
完全不同，混在一起就不知道下一步該做什麼。

## 三種成因

判準用的是**純幾何**（`CanMoveDungeon`），不跑 ECL：走過去又被劇情推回來那種
不算「走不到」——那是內容不是幾何，混進來會讓分類失去意義。

| 成因 | 判準 | 要做什麼 |
|---|---|---|
| 站得上去，但從段入口走不到 | 那個地形碼出現在**某個連通分量**的格子上，但不在入口那一塊 | 補路線：從那一塊自己的入口格另外走一趟 |
| 圖上有，但四面都不通 | 地形碼只出現在**沒有任何可通行邊**的格子上 | 走路永遠站不上去；要嘛靠事件傳送，要嘛它本來就不是玩家會站的格子 |
| 圖上根本沒有這個地形碼 | 分派表有這一格，整張地圖掃過去沒有 | 分母裡的死索引，補不了也不用補 |

目前：**71 / 1 / 0**。

★ **死索引是 0，所以未達成全部都是真的待辦**，不是分母灌水。這一點本來只能猜。

## 走路的上限

「站得上去」的索引有 **249**（250 減掉那個四面不通的）。

★ **那才是走訪這條路的天花板，不是 250。** 把分派索引總數當目標，會讓永遠差的
那一格看起來像還有事情可做。目前的 178 是天花板的 71%。

## 為什麼「站得上去」要另外算

一張圖常常不是一整片。巫師塔每一層在 GEO 上是**獨立的小房間**，層與層之間只靠
樓梯**事件**接（spec 1161）——從入口用走的永遠到不了別層。所以：

- 「從段入口走得到」是**下界**：它看不到那些要靠事件才進得去的房間。
- 「站得上去」是**上限**：只問幾何，不問怎麼進去那一塊。

兩個都要，差額就是「要靠事件才進得去」的那些房間。

## 這個數字證明不了什麼

- 「站得上去」**不表示玩家到得了**：進到那一塊要靠事件，而事件要不要觸發是內容。
  它是上限不是預測。
- 分類完全不看 ECL，所以「站得上去但從入口走不到」裡混著兩種：幾何上斷開的，
  和**門擋著**的。要再分下去得看門的旗標。
- 分母仍然直接取自 `cell-sweep -index-json`，**這一支不重算**——兩邊各自算一定會
  漂（第一版自己算得到 299 而實測是 250，兩個數都自洽，放在一起就是假的覆蓋率）。
