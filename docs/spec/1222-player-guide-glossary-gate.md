# 1222：玩家攻略納入地名詞彙稽核

狀態：`READY`（2026-08-27）

## 問題

詞彙稽核原本只掃三份繁中 JSON。玩家可直接閱讀的
`docs/guide/main-story-zh-TW.md` 不在分母內，因此測試全綠時，攻略仍同時使用：

- `Zhentil Keep` 的「散塔林堡」，而專案正規譯名是「散提爾堡」。
- `Myth Drannor` 的「神話卓諾」，而專案正規譯名是「迷斯卓諾」。
- `Bane` 的「貝恩」，而專案正規譯名是「班恩」。
- `Helm of Dragons` 的「龍之頭盔」，而專案正規譯名是「龍盔」。

這不是原版行為差異，而是玩家文件未受既有一致性閘門保護。

## 修正

1. 統一攻略中的上述四組譯名。
2. 詞彙表把「神話卓諾、密斯卓諾」加入 `Myth Drannor` 的禁用寫法；
   `Zhentil Keep`、`Bane`、`Helm of Dragons` 沿用既有禁用規則。
3. `internal/glossary` 逐行掃描繁中主線攻略；違規訊息保留檔名與行號。
4. 回歸測試明列四份玩家可見繁中來源，任何一份從掃描分母消失都會失敗。

## 驗證

Docker、無網路環境：

- `go test ./internal/glossary -count=1`：通過。
- `go run ./cmd/glossary-audit -check`：`terms=139 issues=0`。
- 攻略、UI locale、game-pack 與工具訊息目錄搜尋「散塔林堡／神話卓諾」：0 筆。

## 證據邊界

本閘門證明已列入詞彙表的正規譯名不再於四份掃描來源漂移；它不等於全文的
文學潤飾已完成，也不涵蓋歷史研究筆記、規格或英文文件。後者可以在勘誤與歷史
敘述中保留舊寫法，不應混入玩家內容的分母。
