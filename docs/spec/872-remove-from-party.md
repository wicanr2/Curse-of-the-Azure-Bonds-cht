# 872 — 把目前選中的角色移出隊伍並釋放

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側多兩處判斷）
- 作法見 spec 783

## `overlay-17:03A56h` ↔ `overlay-17:04122h`（DOS 104 條／PC-98 110 條）

`retf 4` ＝ 兩個 word：`(不減人數, 要釋放圖像)`。對象是 `遠指標(DS:6506h)`
（spec 864 的「現在在講誰」全域）。

```pascal
if 遠指標(DS:650Ah) = NIL then 離開;
p := 遠指標(DS:650Ah);

if p <> 遠指標(DS:6506h) then begin
    while (p^[189h] <> 遠指標(DS:6506h)) and (p^[189h] <> NIL) do
        p := p^[189h];                                  { 找前一個 }
    if p^[189h] <> NIL then begin
        if 要釋放圖像 <> 0 then <far 1994h>(遠指標(DS:6506h)^[143h]);
        p^[189h] := 遠指標(DS:6506h)^[189h];            { 從鏈上摘掉 }
        <overlay-17:0003Eh>(@DS:6506h);                 { 解構子，spec 849 }
        DS:6506h := p;
        if 不減人數 = 0 then dec(遠指標(DS:4F9Dh)^[67Ch]);
    end;
end else begin                                          { 要移除的就是鏈頭 }
    if 要釋放圖像 <> 0 then <far 1994h>(遠指標(DS:6506h)^[143h]);
    DS:650Ah := 遠指標(DS:6506h)^[189h];
    下一個 := 遠指標(DS:6506h)^[189h];
    <overlay-17:0003Eh>(@DS:6506h);
    DS:6506h := 下一個;
    if 不減人數 = 0 then dec(遠指標(DS:4F9Dh)^[67Ch]);
end;

if 遠指標(DS:6506h) = NIL then DS:6506h := 遠指標(DS:650Ah);
```

## 三件事一次做完

1. **從 `DS:650Ah` 那條鏈上摘掉**（頭與非頭兩條路徑）。
2. **叫 spec 849 的解構子** `overlay-17:0003Eh` 釋放整筆角色記錄
   （含戰鬥狀態 `16h`、物品鏈 `3Fh` 一節、效果鏈 9 bytes 一節），
   並把 `DS:6506h` 寫成 NIL。
3. **把 `DS:6506h` 移到一個還活著的節點**：非頭路徑指向前一個，
   頭路徑指向下一個，都失敗就退回鏈頭。所以呼叫端拿到的「現在選中的人」
   永遠有效——**這是刪除之後 UI 不會拿到懸空指標的原因**。

`遠指標(DS:4F9Dh)^[67Ch]` 是隊伍人數（spec 860／861 同一格）。
`不減人數 ≠ 0` 時不動它——形狀上是「換人不是離隊」的路徑。

## ⚠ PC-98 多一道 `+143h > 7` 的條件

兩處 `far 1994h(角色^[143h])` 的呼叫，PC-98 都多包一層
`if 角色^[143h] > 7`（無號）。所以 **`+143h ≤ 7` 的角色在 PC-98 不會走那一步**。

`+143h` 緊接在 spec 的外觀配色欄位 `+144h..+14Ah` 之前，形狀上是圖像編號；
`> 7` 讀作「編號 8 以上才是要另外釋放的自訂圖像」。
**本規格不宣稱這個門檻的由來**，但這是真的邏輯差異（spec 783 第 d 類），
不是碼型。

## 明確不宣稱

- 沒有宣稱 `far 1994h(圖像編號)` 做什麼（形狀上是釋放圖像資源）。
- 沒有宣稱 `+143h` 的名稱。
- 沒有宣稱兩個參數的呼叫端怎麼組合（四種組合都合法）。
