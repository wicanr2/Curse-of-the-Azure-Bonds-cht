# 1050 — 圖片搬運：三個平面**倒序**寫出，遮罩平面接在第四位

- 證據等級：`exact`（PC-98 常駐段 211 條逐條讀完，`objdump` 路線見 spec 1046／1048）
- 作法見 spec 783

## `pc98 PC98-GAME.EXE:12E3Dh`（`retf 0Eh`，580 bytes）

原本待解讀。呼叫端 `12BEEh`、`12E2Bh`。

```pascal
procedure 搬圖(圖:     遠指標;   { bp+06h，NIL 就直接離開 }
               目的偏移: word;   { bp+0Eh，會被就地累加 }
               目的:   遠指標);  { bp+10h }
```

## ★★ 圖片記錄的欄位，在這裡全部用上

| 位移 | 內容 | 佐證 |
|---|---|---|
| `+0`（word） | **高（列數）** | spec 1049 同一組 |
| `+2`（word） | **每列 bytes** | spec 1049 同一組 |
| `+8`（byte） | **張數** | 外圈是 `0 .. 圖^[8] − 1` |
| `+11h`（word） | **每張的 bytes** | ★★★ **spec 1029 記過的同一格** |
| `+13h`（遠指標） | **遮罩平面的位址**（可為 NIL） | ★★★ 對上 spec 1029 的 `'SPRIT'` 遮罩 |
| `+17h` 起 | 像素資料 | spec 1049 同一個表頭長度 |

> ★★★ **spec 1029 從載入端推出的兩件事，在這裡從使用端確認**：
> `+11h` 就是「每張的 bytes」、`'SPRIT'` 多出來的遮罩平面就掛在 `+13h`。

## ★★★ 三個平面是**倒序**寫出去的

```pascal
for 張 := 0 to 圖^[8] − 1 do begin
    for 平面 := 0 to 2 do begin
        來源 := 圖 ＋ 17h ＋ 平面 × (高 × 列寬) ＋ 張 × 圖^[11h];
        目的 := 目的緩衝 ＋ 目的偏移
                     ＋ (2 − 平面) × (高 × 列寬)     { ★★★ 倒序 }
                     ＋ 張 × 圖^[11h];
        Move(來源^, 目的^, 高 × 列寬);
    end;
    if 圖^[13h] <> NIL then begin
        目的 := 目的緩衝 ＋ 目的偏移
                     ＋ 3 × (高 × 列寬)              { ★ 第四位 }
                     ＋ 張 × 圖^[11h];
        來源 := 圖^[13h] ＋ 張 × (高 × 列寬);
        Move(來源^, 目的^, 高 × 列寬);
        目的偏移 := 目的偏移 ＋ 高 × 列寬;
    end;
end;
```

> ★★★ **`2 − 平面`：來源的平面 0／1／2 被寫到目的的 2／1／0。**
> 檔案裡的平面順序與畫面上的平面順序**相反**——
> ⇒ **remake 的素材管線如果照檔案順序直接送進 VRAM，顏色會整組錯掉。**
>
> ★ 遮罩平面（`+13h`）**接在三個平面之後的第四位**，
> 而且它的來源沒有 `+17h` 表頭、也沒有平面維度——是一條連續的單平面資料。

⚠ `目的偏移 := 目的偏移 ＋ 高 × 列寬` **只在有遮罩的分支裡執行**
（`je` 跳過整個遮罩區塊時不會走到）。本規格照組語記錄，不判斷這是不是原作的疏漏。
