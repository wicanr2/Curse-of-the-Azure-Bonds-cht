# 989 — 射線走訪與噴酸範圍的 PC-98 對側

- 證據等級：`exact`（兩支的差異區塊與全部運算元差異逐條比對）
- 作法見 spec 783

DOS 側已由 spec 729／725 判讀完，本規格只記 PC-98 側的差異。

## `pc98 overlay-22:019B4h` ＝ DOS `0175Bh`（spec 729，射線走訪與目標收集）

兩邊都是 `retf 0Ch`（6 個 word）、358／360 條，相似度 **0.994**。
它是範圍／射線類法術的共同底層——PC-98 側同樣被
`overlay-22:05E32h`（見下）等多支呼叫。

### 兩個結構差異，都不是邏輯差異

1. **分支方向相反**：PC-98 是 `jge short loc_1ACA`，
   DOS 是 `jl short loc_17FD` ＋ `jmp loc_187E`。
   DOS 因為目標太遠必須用「條件短跳 ＋ 無條件長跳」兩條指令表達，
   PC-98 一條短跳就夠——**同一個判斷的兩種編碼**。
2. **DOS 多一條 `xor ah, ah`**：DOS 把值零延伸後用 `cmp ax, N` 比，
   PC-98 直接 `cmp al, N`。八個常數（`0..7`）逐一對應，
   屬 spec 783 的 (c) 類碼型差異。

### ⚠ IDA 的 `arg_` 命名兩邊差 2

PC-98 印成 `arg_0`／`arg_4`／`arg_6`／`arg_8`／`arg_A`，
DOS 印成 `arg_2`／`arg_6`／`arg_8`／`arg_A`／`arg_C`。
**兩邊都是 `retf 0Ch`，參數個數與位置相同**——差的只是 IDA 的標籤起點。
這與 spec 980（`dos overlay-23:017B8h`）、spec 985（`dos overlay-17:02724h`）
遇到的是同一件事：**`arg_N` 這個名字不能當成 `bp+N`，要回去看原始 bytes。**

### 其餘 22 處運算元差異

全是位址，其中一張表值得記：**方向表 DOS `DS:2694h` ↔ PC-98 `DS:489Eh`**
（`mov al, [di + 表基底]`，索引來自方向序列）。

## `pc98 overlay-22:05E32h` ＝ DOS `05AA8h`（spec 725，噴酸範圍）

176／173 條，相似度 **0.991**，**只有一個結構差異**：
PC-98 多了 `xor ah,ah / mov cx,7 / imul cx`，把 DOS 的動畫常數換成
`DS:7F16h × 7`——spec 981 記的通例，這是第五個佐證。

24 處運算元差異全是位址，其中三處是既有結論的再確認：

| DOS | PC-98 | 出處 |
|---|---|---|
| `DS:7746h`（選目標的輸出） | `DS:0A9D8h` | spec 988 |
| `DS:758Dh`（回合計數） | `DS:0A81Fh` | spec 981／988 |
| `DS:72A0h`（分派表） | `DS:0A38Ch` | spec 980／988 |
| `DS:7559h`／`755Ah` | `DS:0A645h`／`0A646h` | spec 981 |
| `DS:7434h`（戰鬥員數） | `DS:0A520h` | spec 979 |
| `DS:7431h ＋ i×4`（戰鬥員表） | `DS:0A51Dh ＋ i×4` | spec 979 |
| 角色 `+197h`（陣營） | `+198h` | spec 806 的 `+1` 位移 |

`DS:6F95h ↔ DS:0A02Fh` 這一格是新的：本支寫 `30h`，
spec 980 的噴火那一支寫 `1`——**同一個全域被寫不同的值**，
形狀上是「這次用的是哪一種特殊攻擊」。本規格不宣稱。

## 這一輪之後，PC-98 側的怪物特攻只剩下沒配對的那幾支

`overlay-22` 的 PC-98 特攻（龍息 `061ADh`／`06019h`、吐酸 `05D17h`／`05E32h`、
電光 `062D7h`、凝視 `063D4h`、恐懼 `04DB9h`、群體解除 `03AE5h`、
反序效果迴圈 `01D0Bh`、射線底層 `019B4h`）**全部已解讀**。
剩下的 `01247h` 等是 `aligned_diff` 判為單邊的，要各自從頭讀。

## 明確不宣稱

- 沒有宣稱方向表 `DS:2694h`／`DS:489Eh` 的內容。
- 沒有宣稱 `DS:6F95h`／`DS:0A02Fh` 存的是什麼。
