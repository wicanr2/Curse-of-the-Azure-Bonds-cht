- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側同位址，唯一序列差異是一條 `cbw`）

## `overlay-05:00351h` ↔ `overlay-05:00351h`（DOS 166 條／PC-98 165 條）

`retf 4` ＝ 一個 longint（每人份的經驗值）。

```pascal
p := 遠指標(DS:650Ah);
while p <> NIL do begin
    if (p^[196h] <> 0) and (p^[195h] <> 1) then begin      { 能行動、非死亡 }
        xp := 每人份;
        case p^[75h] of
          0: if p^[15h] > 0Fh then xp := 每人份 + 每人份 div 10;
          2: if p^[11h] > 0Fh then xp := 每人份 + 每人份 div 10;
          3: if (p^[11h] > 0Fh) and (p^[15h] > 0Fh) then xp := 每人份 + 每人份 div 10;
          4: if (p^[11h] > 0Fh) and (p^[13h] > 0Fh)
                and (p^[15h] > 0Fh) then xp := 每人份 + 每人份 div 10;
          5: if p^[13h] > 0Fh then xp := 每人份 + 每人份 div 10;
          6: if p^[17h] > 0Fh then xp := 每人份 + 每人份 div 10;
          8, 0Ah..0Eh, 10h: xp := 每人份 div 2;
          9, 0Fh:           xp := 每人份 div 3;
        end;
        p^[127h] := p^[127h] + xp;                          { 經驗值，spec 845 }
    end;
    p := p^[189h];
end;
```

## `+75h` ＝ 職業組合碼，對上職業名稱表

`DS:0CB6h` 的職業名稱表有 19 筆：8 個單一職業、9 個多職業組合、
`'OK buddy, who are you?'`、`Monster`（見 `resident-data-tables.md`）。
`+75h` 的分支正好落在同一組編號上：

| `+75h` | 處置 |
|---|---|
| 0（Cleric）／2（Fighter）／3（Paladin）／4（Ranger）／5（Magic-User）／6（Thief） | prime requisite ≥ 16 就 **＋10%** |
| 1（Druid）／7（Monk） | 沒有加成分支 |
| **8、0Ah..0Eh、10h** | 經驗值 **÷ 2**（雙職業） |
| **9、0Fh** | 經驗值 **÷ 3**（三職業） |

所以那 9 個多職業組合裡，**編號 9 與 15 是三職業，其餘七個是雙職業**。

`0Fh` ＝ 15，`> 0Fh` 就是 **≥ 16**——AD&D 的 prime requisite ＋10% 門檻。

## 屬性欄位版面定案：stride 2、AD&D 順序

各職業檢查的欄位反推出整組屬性的位置：

| 職業 | AD&D prime requisite | 本支檢查 |
|---|---|---|
| Cleric | 睿智 | `+15h` |
| Fighter | 力量 | `+11h` |
| Ranger | **力量、智力、睿智** | `+11h`、`+13h`、`+15h` |
| Magic-User | 智力 | `+13h` |
| Thief | 敏捷 | `+17h` |

遊俠那一列有三個屬性、順序又與 AD&D 的列法相同，是決定性的證據：

| 位移 | 屬性 |
|---|---|
| `+11h` | 力量 |
| `+13h` | 智力 |
| `+15h` | 睿智 |
| `+17h` | 敏捷 |
| `+19h` | 體質 |

**stride 是 2**，與先前只知道的 `+15h` 睿智、`+19h` 體質一致。

每個屬性實際上**佔兩個 byte，兩格存同一個值**：`+10h ＋ j×2` 與 `+11h ＋ j×2`。
spec 925 的套模板下限每次都把相鄰兩格寫成同一個值，本支讀到的是每一對的後半格。
第七對 `+1Ch`／`+1Dh` 在模板上緊跟著力量（模板 `+14h` 力量、`+15h` 對應它），
**就是 AD&D 的 18/xx 百分位力量**——`overlay-24:0129Ah`（DOS）／`01498h`（PC-98）
在力量等於 18 時拿 `+1Ch` 照 50／75／90／99／100 五道界線分成六階，
與規則書逐格相同（spec 974）。
spec 853 的種族等級上限用 `+11h` 的 17／18 當門檻——**那確實是力量**，
與 AD&D「高力量放寬戰士的種族上限」相符，該規格已回頭改成定名。

⚠ 聖騎士（`+75h` ＝ 3）在這個引擎裡的 prime requisite 是**力量 ＋ 睿智**，
AD&D 原版是力量 ＋ 魅力。這是引擎自己的改動，不是判讀錯誤。
