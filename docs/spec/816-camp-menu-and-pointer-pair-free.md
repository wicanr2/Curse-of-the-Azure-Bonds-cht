# 816 — 紮營選單（`Cast Memorize Scribe Display Rest Exit`）、成對遠指標的釋放

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的差異已逐條列出）
- 作法見 spec 783

## `overlay-15:14D2h`（entry#16，DOS 82 條／PC-98 95 條）— 紮營選單迴圈

選單字串放在**常駐資料段**（不是 overlay 內）：

| | 位址 | 內容 |
|---|---|---|
| DOS | `DS:0451h` | `'Cast Memorize Scribe Display Rest Exit'`（38） |
| PC-98 | `DS:086Bh` | `'    かける　記憶　書込む　休息　 影響　      …      抜ける　　'`（80 bytes） |

```pascal
repeat
    if not <0A54h:08D4h>(20h, @空字串) then 離開;
    暫存 := '';                                        { 0A54h:0634h }
    選 := <far 169Dh+2>(暫存, @DS:0451h, 0Dh, 0Ah, 0Fh, 1, 1, @旗標);
    if 旗標 <> 0 then begin
        <far 1022h>(選);
        <far 14F8h+2>(DS:6506h);
    end
    else case 選 of
        'C'(43h): <本模組 04CBh>();       { spec 797：選法術的外迴圈 }
        'M'(4Dh): <本模組 0942h>();
        'S'(53h): <本模組 0B9Bh>();
        'D'(44h): <本模組 1016h>();
        'R'(52h): <本模組 07B2h>(輸出);   { spec 814：休息主流程 }
    end;
until 輸出^ <> 0;
```

`retf 4` ＝ 2 個 word；迴圈條件是**呼叫端傳進來的那個 byte 變成非 0**。

### 六個項目、五個處理常式

| 鍵 | DOS 標籤 | 處理 | 已知的是 |
|---|---|---|---|
| `C` | `Cast` | `04CBh` | spec 797 的選法術外迴圈 |
| `M` | `Memorize` | `0942h` | — |
| `S` | `Scribe` | `0B9Bh` | — |
| `D` | `Display` | `1016h` | — |
| `R` | `Rest` | `07B2h` | spec 814 的休息主流程 |
| `E` | `Exit` | — | 由 `旗標 ≠ 0` 或輸出 byte 收掉 |

`C` / `M` / `S` / `R` 四個處理常式分別對得上先前讀過的施法（797）、記憶（792）、
抄寫（803）、休息（813／814）四條線——**這一支就是那四條線的入口**。

### 中文化：熱鍵是 ASCII，標籤是排版

**兩平台的比較字元完全相同**（`43h` / `4Dh` / `53h` / `44h` / `52h`），PC-98 只換
了選單字串。這是本專案第三次看到同一種手法（spec 794 的角色切換鍵是**例外**——
那裡連鍵都換了）。

PC-98 的字串有兩個要照抄的性質：

- **固定 80 bytes、用空白排版**，每個項目落在特定欄位；長度不同的譯文會讓整排
  跑掉。
- **顯示順序與 DOS 不同**：DOS 是 `Cast Memorize Scribe Display Rest Exit`，
  PC-98 是 `かける 記憶 書込む 休息 影響 … 抜ける`——**`Rest` 與 `Display` 對調**，
  但**鍵沒有換**。所以中文版可以自由排版，只要別動那五個 ASCII 鍵。

第一個參數是一個**空字串**（`0A54h:0634h` 從 `loc_14B2+1` 抄過來，長度位元組是 0），
形狀上是提示詞的前綴。

### PC-98 多的兩段

- 開頭多一次 `Move(loc_954, DS:0A335h, 0Ah)`——先把 10 bytes 搬到常駐資料段。
- `旗標 ≠ 0` 那條路多一組 `<far sub_14CA>(DS:9594h)` ＋ `<far loc_157D+1>()`。

兩段都是 PC-98 版自己加的，DOS 沒有對應。

## `overlay-33:015Ah`（entry#4，DOS 40 條／PC-98 48 條）— 釋放一組兩個遠指標

```pascal
if 遠指標@(65D6h + 索引 * 8) <> NIL then <0297h:1D19h>(@(65D6h + 索引 * 8));
if 遠指標@(65DAh + 索引 * 8) <> NIL then <0297h:1D19h>(@(65DAh + 索引 * 8));
```

`retf 2` ＝ 一個 word（索引）。

- `DS:65D6h` 起是**每筆 8 bytes 的陣列，`+0` 與 `+4` 各是一個遠指標**。
- `0297h:1D19h` 收的是**指標變數的位址**（不是指標值），是 Dispose／FreeMem 那一
  家的形狀。
- 兩個欄位各自判 NIL，**判完不清成 NIL**——釋放後那兩格留著舊值。

### PC-98 兩處不同

- **開頭多一道守衛**：`<0A65h:08E4h>(索引, @loc_2C8)` 回 0 就整支跳過。DOS 沒有。
- **兩個欄位的相對位置相反**：DOS 是 `65D6h`（第一）與 `65D6h + 4`（第二）；
  PC-98 是 `9670h`（第一）與 `9670h − 4`（第二）。**陣列版面兩平台不同**，
  remake 不能假設一致。
