# 1174 — 換武器之後傷害怎麼算：**槽 0 的武器無條件蓋掉記錄的骰子**

- 證據等級：`exact`（`overlay-24:0C28h` 的重算主體、`0025h` 的武器投影、
  `021Dh` 的護甲移動懲罰逐條讀完；大／小體型的切換點在 `overlay-13:1608h`）
- 關掉的未定項：spec 1120「怪物換上另一把武器之後，傷害怎麼算」
- 上游：spec 1000（同一支的 AC 那一半）、spec 1120（自動換裝）、spec 795

## 重算主體 `overlay-24:0C28h`

```pascal
for 槽 := 0 to 12 do 角色^[151h ＋ 槽×4] := NIL;   { 依槽的裝備中物品表 }
角色^[14Ch] := 0;                                   { 物品件數 }
角色^[185h] := 0;  角色^[187h] := 0;                { 佔用手數、總重 }

節點 := 角色^[14Dh];                                { 物品鏈 }
while 節點 <> NIL do begin
    inc(角色^[14Ch]);
    重 := 節點^[37h];  if 節點^[39h] > 0 then 重 := 重 × 節點^[39h];
    角色^[187h] += 重;
    if 節點^[34h] <> 0 then begin                   { 裝備中 }
        槽 := byte[5CF6h ＋ 節點^[2Eh] × 16];        { 類別表 +0 ＝ 裝備槽 }
        if 槽 in [0..8] then 角色^[151h ＋ 槽×4] := 節點
        else if 槽 = 9 then …                        { 雙持的第二格 }
        角色^[185h] += byte[5CF7h ＋ 節點^[2Eh] × 16]; { 類別表 +1 ＝ 佔用手數 }
    end;
    節點 := 節點^[2Ah];
end;

{ 基準 → 現值，整組抄過去 }
for i := 1 to 2 do begin
    角色^[19Dh ＋ i] := 角色^[11Dh ＋ i];   { 攻擊骰數 }
    角色^[19Fh ＋ i] := 角色^[11Fh ＋ i];   { 攻擊面數 }
    角色^[1A1h ＋ i] := 角色^[121h ＋ i];   { 傷害加值 }
end;
角色^[19Ah] := 角色^[124h];   角色^[1A5h] := 角色^[0E4h];   角色^[199h] := 角色^[73h];

<sub_25>(角色);                                    { ★ 武器投影，見下 }
{ 再走一次鏈，對每件裝備中的呼叫 <sub_21D>（護甲移動懲罰）與 <sub_2A7>（AC）}
```

## ★★ `overlay-24:0025h`：武器投影

```pascal
武器 := 角色^[151h];              { ← 槽 0 }
if 武器 = NIL then 離開;           { ★★ 沒有槽 0 的武器就整支不做 }

類別 := 武器^[2Eh];
角色^[199h] := 角色^[73h];
if byte[5D04h ＋ 類別×16] and 2 <> 0 then 角色^[199h] += <sub_120Ah>(角色);
角色^[1A2h] := byte[5D01h ＋ 類別×16];      { 傷害加值 := 類別表 +0Bh }
…
角色^[19Eh] := byte[5CFFh ＋ 類別×16];      { 攻擊骰數 := 類別表 +09h }
角色^[1A0h] := byte[5D00h ＋ 類別×16];      { 攻擊面數 := 類別表 +0Ah }
```

`+09h`／`+0Ah`／`+0Bh` 是類別表的**小型目標**傷害三連（`SmallDamageDice`／
`Sides`／`Bonus`），三格連號。

⇒ **答案是「武器蓋掉記錄的骰子」，而且沒有任何條件**——不看記錄的骰子是不是 0、
也不看類別表給的骰數是不是 0。記錄自己的基準骰只有在**槽 0 沒有裝備中的武器**
時才是實際傷害，因為那時 `sub_25` 第一行就返回，重算前面抄過去的基準值原封不動。

⇒ spec 1120 量到的「兩者都非 0 但不一樣」那 13 隻不是矛盾：`BUGBEAR` 的記錄
`2d4` 是**放下武器時**的天生攻擊，拿著 `1d6` 的武器時用武器的。

## ★ 大／小體型在戰鬥當下才切

`overlay-13:1608h`（攻擊結算）在目標體型 `and 7 > 1` 時，把槽 0 武器的**整筆
16 bytes 類別記錄**複製出來，改用 `+02h`／`+03h`／`+04h`（大型三連）：

```pascal
角色^[19Eh] := 類別記錄[2];                 { 大型骰數 }
角色^[1A0h] := 類別記錄[3];                 { 大型面數 }
角色^[1A2h] := 角色^[1A2h] − 小加值 ＋ 大加值;
```

所以重算裝的是小型那組，戰鬥遇到大型目標才換。**兩處都要有**，只做一邊會讓
所有攻擊都用小型骰。

## remake 這一輪改了什麼

`FighterWithEquipment` 先前挑的是「第一件有傷害骰的裝備中物品」。那條規則會被
**弓或彈藥**搶走——它們排在鏈的前面而槽不是 0（spec 1120 量測時多報過兩隻）。
現在先找槽 0 的裝備中物品，找到就由它無條件供給骰子。

⚠ **沒有槽 0 的武器時沿用舊規則**（第一件有骰的）。原作在那個情況下什麼都不做，
但 remake 還沒有「徒手」的完整模型，照抄會讓只帶弓的角色變成沒有攻擊。
這是**寫成可以拿掉的條件**：補上徒手攻擊之後就能移除。

## 明確不宣稱

- 沒有宣稱類別表 `+0Eh`（`and 2`／`and 4` 兩個位元）各代表什麼，只知道它們
  決定要不要加 `<sub_120Ah>`／`<sub_1345h>` 的命中修正。
- 沒有宣稱 `+73h`（命中基準）與 `+74h`（`= 2` 時對某幾種武器 `+1`）的完整語意。
- 沒有宣稱槽 9（雙持第二格）那一路怎麼選第二把武器。
- 大／小體型的切換**還沒接進 remake**：`ItemRecord.Effect` 已經有 `large` 參數，
  但呼叫端一律傳 `false`。要接的是「攻擊結算當下依目標體型選三連」，
  不是重算那一側。
