# 第七百一十六輪：目標陣列裡的 `NIL`，一半的走訪沒有檢查

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-22` 的 `4791h`、`20E1h`、`3EE2h`、`2F5Eh`；掃描範圍為整個
`overlay-22`。

## 問題

spec 709 已經確定：`1C39h` 之類的 opcode 會把不合格的目標**寫成 `NIL` 而不動
筆數**。所以走訪 `[7431h + k×4]` 的函式必須自己檢查 `NIL`。

`overlay-22` 裡有 16 支會走這個陣列。以「`mov ax, [di+7431h]` ＋
`or ax, [di+7433h]` ＋ `jz`」這個形狀去掃：

| 有檢查（6 支） | 沒有這個形狀（10 支） |
|---|---|
| `0F06h`、`1ABFh`、`4672h`、`4822h`、`56C4h`、`5AA8h`、`5C86h` | `10D2h`、`175Bh`、`1C39h`、`22B4h`、`2580h`、`370Eh`、`3804h`、`4791h`、`4A8Fh` |

（表格左欄 7 支、右欄 9 支，合計 16。）

其中 `1C39h`、`22B4h`、`4791h` 三支我逐條讀過，確認**真的沒有任何形式的檢查**：
它們直接 `les di, [di+7431h]` 之後就取欄位。其餘幾支沒有這個形狀，但可能用別的
寫法檢查，需要逐一確認才能下結論——**本節的「沒有」是「沒有這個形狀」，不是
「一定沒檢查」**。

## 後果

`NIL` 是 `0000:0000`。`les di, [di+7431h]` 之後取 `es:[di+0E5h]` 會讀到
**中斷向量表**的內容（實模式下 `0000:00E5h`）。讀是不會當掉的，但拿到的是
當時的向量值——**同一段腳本每次跑的結果可能不同，而且不會有任何錯誤徵兆**。

寫入更嚴重：spec 656 已經記過另一支在同樣情況下會**寫進中斷向量表**。

## 已知會留下 `NIL` 的來源

| 出處 | 動作 |
|---|---|
| `1C39h`（spec 709） | 篩掉不符合的目標 |
| `24CDh`（spec 709） | 狀態 1 時清第 1 格 |
| `4194h`（spec 714） | 同上 |
| `22B4h`（本輪確認，spec 715） | Sleep 扣不起 HD 的目標 |
| `4822h`（spec 711） | 把筆數夾小（不是寫 `NIL`，但同樣讓陣列與筆數不同步） |

## 四支本輪讀完的 opcode

```text
4791h：<sub_1ABFh>(0, 'is charmed'（CS:4786h）)
       for k := 1 to DS:7434h do            ← ⚠ 沒有 NIL 檢查
           p := far [7431h + k×4]
           if <overlay-24 entry#27>(p, 0Bh, @node) then
               <overlay-23 entry#2>(0Bh, p, node, 0)

20E1h：p := DS:7435h
       if p = NIL 或 DS:7434h = 0 then 返回   ← 這支有檢查
       if <overlay-23 entry#8>(p, 4, 0) <> 0 then 返回
       if not <overlay-24 entry#27>(p, 0Ch, @node) then 返回
       <overlay-23 entry#3>(p, 0Ch, 0)
       <overlay-23 entry#24>(p, 0)
       <overlay-24 entry#20>(p, 'has been reduced'（CS:20D0h）, 0Ah, 1)

3EE2h：if not <overlay-23 entry#16>(目標, 2Ah) then
           <sub_F06h>(DS:6F97h, 0, 0, 0, 0, 'is Speedy'（CS:3ED8h）)

2F5Eh：if <overlay-23 entry#16>(目標, 21h) then
           <overlay-24 entry#26>(目標, 1, 'can see'（CS:2F56h）)
```

`3EE2h` 與 `2F5Eh` 的判斷方向**相反**：前者是「沒有 `2Ah` 才顯示」，後者是
「有 `21h` 才顯示」。兩支的結構長得幾乎一樣，只差一個 `jnz`／`jz`。

`4791h` 的訊息在迴圈**外面而且在最前面**——先講「`is charmed`」，再去逐個處理。
所以訊息與實際生效與否無關。
