## `+0E5h` ＝ 0 就是「零級」

spec 811 定下 `+0E5h` 是**最高職業等級**（八個職業槽裡最大的那個）。這一支要求
**目標的 `+0E5h` ＝ 0** 才橫掃，而且統計「可打幾個」時也只數 `+0E5h` ＝ 0 的。

AD&D 的戰士橫掃規則正是「對**零級**生物每回合可攻擊等於自己等級的次數」——
兩邊對得起來。

## 上限來自 `+18Dh^[5]`

spec 806 讀到回合初始化時 `c^[5] := 角色^[0DDh]`，當時不知道用途。這裡它是
**這一回合最多橫掃幾個**：

- 進場先擋 `+19Ch >= +18Dh^[5]`（打夠了就不做）。
- 算出 `可打` 之後再夾一次 `可打 := min(可打, +18Dh^[5])`。

`+19Ch` 是 spec 808 每回合重算的那個欄位；這一支在每打一個之後把它**設成 1**
（不是遞增），所以它在這裡的語意是「已經動用過攻擊」而不是計次。

## 打之前先把清單順序調一下

```pascal
if 遠指標(DS:6D35h + DS:758Fh * 4) <> 目標 then begin
    byte[758Eh + 位置] := DS:758Fh;
    DS:758Fh := <far 1939h+1>(目標);
end;
```

`DS:758Fh` 是「目前選中的戰鬥員索引」，`DS:758Eh + k` 是目標清單（spec 802／815）。
這一段把**原本選中的那一個換到目標所在的格子**，再讓 `DS:758Fh` 指向目標。
形狀上是「把玩家點的那個換到前面」。

⚠ `位置` 只有在第一個迴圈裡找到目標時才會被賦值。目標不在清單裡時它是**未初始化
的區域變數**，而這一段仍然會拿它當索引寫入 `DS:758Eh + 位置`。
進場的 `1593h+2` 檢查應該保證目標在清單裡，但**這一支自己沒有防護**。

## 每一下攻擊的形狀

`194Ah(q, 角色)` ＋ `19D8h(q, 角色, 0, longint 0, @DS:75DBh)` ——與 spec 817 的
機會攻擊一模一樣（第一個參數是被打的、第二個是攻擊者），差別只在最後一個參數
指向 `DS:75DBh` 這個全域而不是區域變數。

## 明確不宣稱

- 沒有宣稱 `角色^[0DDh]` 是哪一個等級（形狀上是橫掃次數的來源）。
- 沒有宣稱 `far 1593h+2` 判的是什麼。
- 沒有宣稱 `DS:75DBh` 那塊全域裝什麼。
- 沒有宣稱 `19D8h` 第三、四個參數（`0` 與 `longint 0`）的意義。
