# 856 — 合併同款物品：三個效果槽的比對寫成自己比自己

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼序列完全相同，差異全是位址）
- 作法見 spec 783

## `overlay-19:022A3h` ↔ `overlay-19:02275h`（兩平台各 154 條）

`retf 4` ＝ 一個物品遠指標。

```pascal
目標 := arg_0;
數量 := 目標^[39h];
p := 遠指標(DS:6506h)^[14Dh];

while p <> NIL do begin
    next := p^[2Ah];
    if (p <> 目標) and (p^[39h] > 0)
       and (p^[2Fh] = 目標^[2Fh]) and (p^[30h] = 目標^[30h])
       and (p^[31h] = 目標^[31h]) and (p^[2Eh] = 目標^[2Eh])
       and (p^[32h] = 目標^[32h]) and (p^[33h] = 目標^[33h])
       and (p^[36h] = 目標^[36h])
       and (word(p^[37h]) = word(目標^[37h]))
       and (p^[3Ch] = p^[3Ch])              { ⚠ 自己比自己 }
       and (p^[3Ch] < 2)                    { 無號 }
       and (p^[3Dh] = p^[3Dh])              { ⚠ 自己比自己 }
       and (p^[3Eh] = p^[3Eh])              { ⚠ 自己比自己 }
    then begin
        if 有號(數量 + p^[39h]) <= 0FFh then begin
            數量 := 數量 + p^[39h];
            <far 1545h>(p, 遠指標(DS:6506h));    { 把 p 從鏈上移除 }
        end else begin
            目標^[39h] := 0FFh;                  { 這一堆填滿 }
            p^[39h] := p^[39h] − (0FFh − 數量);  { 剩下的留在 p }
            數量 := p^[39h];
            目標 := p;                           { 換成 p 繼續往後合 }
        end;
    end;
    p := next;
end;
目標^[39h] := 數量;
```

## ⚠ 三個效果槽的比對是壞的

比對欄位時，其他每一格都是「載入 `p`、取值、載入 `目標`、比較」：

```asm
les di, [bp+var_4]        ; p
mov al, es:[di+2Fh]
les di, [bp+var_C]        ; 目標
cmp al, es:[di+2Fh]
```

但 `+3Ch`／`+3Dh`／`+3Eh` 這三格**兩次都載入 `var_4`**：

```asm
les di, [bp+var_4]        ; p
mov al, es:[di+3Ch]
les di, [bp+var_4]        ; p ← 應該是 var_C
cmp al, es:[di+3Ch]
```

所以這三個比較**恆為真**，等於沒有比。`+3Ch`..`+3Eh` 是物品的三個效果槽
（spec 803／841：法術編號 ＋ 最高位「已排入抄寫」旗標）。

**後果**：效果不同的同型物品會被合併成同一堆——例如兩張法術不同的卷軸，
只要類型、加值、價格、詛咒旗標都相同就會疊在一起，其中一張的法術直接消失。

`p^[3Ch] < 2` 那道還是有作用的，它把效果槽 0 的值限制在 0／1，
所以真正會撞在一起的是「第一個效果槽同為 0 或 1」的那一類物品。

兩平台完全一致，**不是反組譯錯位**，是原版的複製貼上錯誤。

## 溢位時換一堆繼續

數量是 byte，合併會超過 `0FFh` 時的處理相當完整：把目標填滿到 255、
把差額留在 `p`，然後**把 `目標` 換成 `p`** 再往後掃。所以一次呼叫可以把
整條鏈上的同款物品整理成「幾堆滿的 ＋ 一堆零頭」。

## 比對用到的欄位

| 位移 | 先前出處 |
|---|---|
| `+2Eh` 類型 | 804 |
| `+2Fh`／`+30h`／`+31h` 三個屬性槽 | 832 |
| `+32h`／`+33h` 兩個數值 | 804 |
| `+36h` 被詛咒 | 794 |
| `+37h`（word） | **本支新增** |
| `+39h` 數量 | 789 |
| `+3Ch`..`+3Eh` 效果槽 | 803／841（但這裡沒真的比） |

`+34h`（裝備中）與 `+3Ah`（定價）**沒有列入比對**。

## 明確不宣稱

- 沒有宣稱 `+37h` 那個 word 是什麼。
- 沒有宣稱 `far 1545h(p, 角色)` 除了「從鏈上移除」之外還做什麼。
- 沒有宣稱 `p^[3Ch] < 2` 這道限制的用意。
