# 1233 一般強度路線：延遲法術失效收尾與可見安全選項

狀態：`READY`（2026-08-27）

## 結論

- QUICK 延遲法術的原目標若在結算前死亡、逃跑或離場，remake 現在會取消
  施法 UI、消耗已承諾的記憶槽並推進戰鬥，不再永久重試失效目標。這沿用
  spec 733 已證實的原版 CAST abort 契約；屬 `strong inference`，不冒稱逐指令
  相同。
- 鍵盤重放只有在目前無活動角色，或活動角色就是待決法術施法者時，才以
  Enter 推進 scheduler。另一名手動隊員先完成自己的正常回合，避免場上只要
  有待決法術便鎖死所有其他角色。
- 一般強度路線不再故意走艾森布拉往哈普的「小徑」撞三條黑龍；玩家可見的
  「荒野」是合法替代路徑。火刀據點明示旋轉刀刃時選「等待」，不選會讓滿血
  六人當場全滅的「闖入刀刃」。兩項都只改測試玩家決策，不改怪物、傷害或
  隊伍數值。
- 武器店有兩個實際 continuation。除既有 `(3,12)` 外，由西側入口進店會回
  `(5,11)`；GEO2/0x01 遮罩量得 `(5,11)→(5,12)→(6,12)→(6,13)→(7,13)`，
  即南、東、南、東，已接回安全紮營格。

## 驗證

- 戰鬥層回歸：失效治療目標、火球術延遲區域中心、詛咒術敵方目標三項通過。
- 3000 幀正常鍵盤路線：373 格、4 個 ECL 段、413 次快速戰鬥動作、0 次全滅、
  0 句原文 fallback。上一版在第 1649 幀選「闖入刀刃」全滅；改選「等待」後
  不再發生。
