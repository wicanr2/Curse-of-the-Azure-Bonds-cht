# 825 — 回合結束：瀕死者每回合流血，第 10 回合死亡

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的差異已逐條列出）
- 作法見 spec 783

## `overlay-08:0997h`（entry#8，兩平台各 112 條）

| | DOS | PC-98 |
|---|---|---|
| 有人瀕死 | `'Your Teammate is Dying'`（22） | — |
| 續戰確認 | `'Continue Battle:'`（16） | `'戦闘を続けますか？'` |

`retf 4` ＝ 一個遠指標（輸出一個 byte）。

```pascal
<far 10A7h+3>(1, 1);
inc(DS:758Dh);                                       { 回合計數 }
<far 0CACh+1>();

p := DS:650Ah;
while p <> NIL do begin
    <0141h:0034h>(13h, p);
    <0141h:0039h>(0, p);
    if p^[195h] = 5 then begin                       { 瀕死 }
        inc(p^[18Dh]^[0Eh]);
        if p^[18Dh]^[0Eh] > 9 then p^[195h] := 6;    { 死亡 }
    end;
    p := p^[189h];
end;

if <far 014Dh:010Bh>(0) then begin
    顯示('Your Teammate is Dying');
    <far 014Dh:007Fh>();
end;
<far 014Dh:00BBh>();
<far 018Ch:0061h>(DS:6E92h^[2] + 3, DS:6E92h^[3] + 3, 0FFh, 8);

if (DS:6F90h = 0) or (DS:6F91h = 0) or (DS:758Dh >= DS:758Eh) then
    輸出^ := 1;

if (DS:6F90h > 0) and (DS:6F91h = 0) and (DS:4FBCh = 0) then begin
    顯示('Continue Battle:');
    if <far 0167h:003Eh>(0Dh, 0Ah, 0Fh) = 'Y' then 輸出^ := 0;
end;
```

### 戰鬥狀態 `+0Eh` ＝ 瀕死回合計數

狀態 `5` 是**瀕死**：每回合把 `+18Dh^[0Eh]` 加 1，**超過 9 就變成狀態 6（死亡）**。
所以倒下之後有 **10 個回合**可以救。與 AD&D「−1 到 −10 每回合流失 1 點」的規則
對得起來。

這是 spec 806 版面表裡 `+0Eh` 的第一個用途。狀態欄位 `+195h` 到此累積：

| 值 | 意義 | 出處 |
|---|---|---|
| 1 | 死亡（Raise Dead 認得） | 821 |
| 5 | **瀕死** | 本支 |
| 6 | 死亡（`The Gods intervene!` 也寫這個值） | 772／821／本支 |
| 7 | 石化 | 763 |

### 座標是螢幕格緩衝的表頭 `+2` / `+3` 各加 3

`DS:6E92h^[2]` / `^[3]` 是 spec 750 定的戰場原點（隊伍位置 −3），這裡各加回 3
——**加回去正好是隊伍自己的位置**。

### 兩個輸出條件是分開判斷的

先算 `輸出^ := 1`（三個條件任一成立），再獨立判斷要不要問「Continue Battle:」，
**答 `'Y'` 會把剛才寫的 1 蓋回 0**。兩段之間沒有 `else`，所以「已經決定結束」與
「玩家選擇繼續」可以同時發生，後者贏。

### PC-98 的兩處不同

- 續戰的條件**少一個**：PC-98 沒有 `DS:6F91h = 0` 那一項，只判
  `DS:0A02Ah > 0` 與 `DS:7F1Ch = 0`。
- 問話之前多設兩個 byte：`DS:0A385h := 0Ah` 與 `DS:0A386h := 0Ah`。DOS 沒有。

## 明確不宣稱

- 沒有宣稱 `DS:758Dh`（回合計數）與 `DS:758Eh` 的關係；只確定前者每回合 ＋1、
  兩者相比決定一個輸出條件。
- 沒有宣稱 `DS:6F90h` / `DS:6F91h` / `DS:4FBCh` 各代表什麼。
- 沒有宣稱 `0141h:0034h(13h, p)` 與 `0141h:0039h(0, p)` 做什麼。
- 沒有宣稱 `014Dh:010Bh` 怎麼判斷「有人瀕死」。
- 沒有宣稱 PC-98 那兩個 `0Ah` 是什麼。
