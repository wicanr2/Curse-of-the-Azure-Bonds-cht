# 794 — Remove Curse（物品 `+36h` ＝ 詛咒旗標）、上下一位角色的按鍵

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-04:097Bh`（entry#10，72 條，差異 20 條）— Remove Curse

| | DOS | PC-98 |
|---|---|---|
| 「沒被詛咒」 | `'is not cursed.'`（14） | `'は呪われてはいませんよ'`（22 bytes） |
| 法術名 | `'Remove Curse'`（12） | `'リムーブ・カース'`（16 bytes） |

```pascal
答 := 'Y';  有 := 0;
p := DS:6506h^[14Dh];                        { 角色的物品鏈 }
while (p <> NIL) and (有 = 0) do begin
    if p^[36h] <> 0 then 有 := 1;
    p := p^[2Ah];
end;
if 有 = 0 then
    if not <014Dh:00A7h>(@暫存, 24h, DS:6506h) then begin
        顯示(名字 ＋ 'is not cursed.');
        答 := <本模組 0047h>();
    end;
if 答 = 'Y' then begin
    顯示('Remove Curse');
    答 := <本模組 00F3h>(0DACh);             { 3500 }
    if 答 = 'Y' then begin
        DS:7435h := DS:6506h;                { 遠指標 }
        <011Ah:004Dh>();
    end;
end;
```

`retf`（無參數）。

### 物品節點 `+36h` ＝ 被詛咒

「有沒有被詛咒」有**兩個獨立來源**，任一成立就不問：

- 角色物品鏈（`+14Dh` 起頭、`+2Ah` 接下一個，spec 789）裡有任何一件
  `+36h` ≠ 0 的物品；
- 角色身上掛著效果碼 `24h`（36）。

兩者都不成立才顯示 `'is not cursed.'` 並再確認一次。這是本專案第一次看到物品
節點的 `+36h`（PC-98 `+5Eh`）。

### 與其他神殿服務同一個模子

| 法術 | spec | 效果碼 | 價 |
|---|---|---|---|
| 石化解除 | 763 | — | `7D0h`（2000） |
| Cure Blindness | 785 | `21h`（33） | `3E8h`（1000） |
| Remove Curse | 本支 | `24h`（36） | `0DACh`（3500） |

三支都是「先問狀態 → 不符再確認 → 帶價錢問一次 → 動手」，且**本支同樣沒有
扣款動作**。不同的是這一支動手前先把角色遠指標寫進 `DS:7435h`
（PC-98 `DS:0A521h`），再呼叫 `011Ah:004Dh`。

## `overlay-19:32DCh`（entry#10，71 條，差異 20 條）— 切換目前角色

| | DOS | PC-98 |
|---|---|---|
| 「上一位」 | `'G'`（47h） | `'8'`（38h） |
| 「下一位」 | `'O'`（4Fh） | `'2'`（32h） |

```pascal
p := DS:650Ah;                               { 隊伍串列頭 }
if p <> NIL then
    if 鍵 = 'G' then begin
        if p = DS:6506h then                 { 目前就是第一位 }
            while p^[189h] <> NIL do p := p^[189h]    { 跳到最後一位 }
        else
            while (p <> NIL) and (p^[189h] <> DS:6506h) do p := p^[189h];
    end
    else if 鍵 = 'O' then begin
        if DS:6506h^[189h] <> NIL then p := DS:6506h^[189h];
    end
    else p := DS:650Ah;                      { 其他鍵：回到第一位 }
DS:6506h := p;
```

`retf 2` ＝ 一個 word（按鍵）。

三件要照抄的事：

- **兩個方向不對稱**：`'G'`（上一位）在第一位時**環繞到最後一位**；`'O'`
  （下一位）在最後一位時**原地不動**。
- **任何其他按鍵都會把選擇重設到第一位**——不是「忽略」。
- 隊伍是空的（`DS:650Ah` ＝ NIL）時，`DS:6506h` 被寫成 NIL。

### 中文化的既有前例

這是 spec 已記錄過的 PC-98 移植手法再一次出現：**DOS 的字母鍵（`'G'` / `'O'`
是 Home / End 的掃描碼位置）在 PC-98 版換成數字鍵盤的 `'8'` / `'2'`**，
而比較字元的程式碼結構一字未改。中文版沿用哪一組要跟著目標平台走，不是跟著
翻譯走。

## 明確不宣稱

- 沒有宣稱效果碼 `24h` 的名稱。
- 沒有宣稱 `0DACh` 就是金幣價格；本支沒有扣款動作。
- 沒有宣稱 `011Ah:004Dh` 做什麼，也沒有宣稱 `DS:7435h` 由誰讀。
- 沒有宣稱物品 `+36h` 的非零值有幾種。
