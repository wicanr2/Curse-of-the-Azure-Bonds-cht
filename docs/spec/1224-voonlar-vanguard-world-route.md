# 1224：暗影谷至溫拉爾的軍隊分支

狀態：`READY`（2026-08-27）

## 問題

動態覆蓋的最大未走叢集是 `ECL1/0x51:0x0DFD` 起 189 條。原始查表證明
`4C9D=7`（暗影谷的第四條有向邊）會由旅途場景表選到這支處理常式；game-pack
的第四個目的地是溫拉爾。因此這是正常玩家可走的 `JOURNEY ON → VOONLAR → TRAIL`
事件，不是靜態走訪誤收的死碼。

舊測試只驗世界點位圖可達，沒有真的走這條邊。

## 修正

1. 從暗影谷的原版抵達 entry 起跑，經玩家選單前往溫拉爾；不直接寫 `4C9D`
   或 `ON GOTO` 索引。
2. 分別驗證四種結果：躲藏、會面後通過、會面後主動攻擊、已被定罪後強制戰鬥。
3. 戰鬥使用原版 `MON1CHA` 資料；強化單人只負責讓內容盤點不因難度中止，
   不冒稱一般強度證據。
4. 後續勘誤（2026-08-27）：`THE ARMY CONTINUES ON PAST YOU.` 後面沒有
   玩家停留點，會在同一次執行被抵達訊息蓋過。為它加單句
   `all_contains` 規則反而會污染後續世界 run，已移除規則與未使用的
   locale ID；該句保留為原版控制流證據，不冒稱是玩家可停留的畫面。

## 結果

- 原本 `0x8DFD` 起 189 條的最大叢集已消失；下一個叢集改從 `0x9004` 起，
  是後續特什維夫支線，不再是溫拉爾軍隊事件。
- `ECL1/0x51`：255／726（35.1%）→ **289／726（39.8%）**。
- 全作實跑：9,095／14,177（64.2%）→ **9,132／14,177（64.4%）**。
- 圖外執行：0。
- 文字分母仍為 1,022 頁、unmatched 0；`0x0F7C` 的短暫字串不再
  用寬規則誤收後續 run。
