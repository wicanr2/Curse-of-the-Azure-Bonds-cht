# 888 — 走一格並重畫：地圖範圍 50 × 25，PC-98 多一整套髒區重繪

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側多出來的 437 條逐塊讀過形狀）
- 作法見 spec 783

## `overlay-32:009DFh`（DOS 142 條）↔ `overlay-32:00CCBh`（PC-98 579 條）

`retf 8` ＝ 4 個 word：`(方向, 參數, 座標y, 座標x)`。

```pascal
新x := byte[2694h ＋ 方向] ＋ 座標x;            { dx 表，spec 854 }
新y := byte[269Dh ＋ 方向] ＋ 座標y;            { dy 表 }

if <本模組 081Dh>(參數, 新y, 新x) then
    for i := 1 to DS:66A6h do begin             { 戰鬥員清單 }
        p := 遠指標(DS:6D35h ＋ i * 4);
        if (p^[196h] <> 0)
           and (byte[66A6h ＋ i * 4] > 0)        { 體型 ≠ 0 }
           and <本模組 0763h>(0, p) then
            <far 0196h:003Eh>(p^[143h], 0, p^[18Dh]^[9],
                              byte[680Eh ＋ i], byte[67C6h ＋ i]);
    end;

<本模組 0320h>(座標y, 座標x);

if not <本模組 0732h>(新y − 遠指標(DS:6E92h)^[3],
                      新x − 遠指標(DS:6E92h)^[2]) then begin
    if 有號(新x) > 31h then 新x := 31h;          { 49 }
    if 有號(新x) < 0   then 新x := 0;
    if 有號(新y) > 18h then 新y := 18h;          { 24 }
    if 有號(新y) < 0   then 新y := 0;
end;

<本模組 0174h>(新y, 新x);
<far 0297h:1316h>();
```

## 地圖範圍是 **50 × 25**

夾限用的 `31h` 與 `18h` 是**含端點的上界**，所以合法座標是
`x ∈ 0..49`、`y ∈ 0..24`。夾限只在 `本模組 0732h` 回假時才做——
形狀上是「捲動不成立就把游標留在畫面內」。

`DS:2694h`／`DS:269Dh` 是 spec 854 定案的方向位移表（0 ＝ 上、順時針到 7、8 ＝ 原地）。
`DS:6D35h`（戰鬥員遠指標陣列，spec 852）與 `DS:66A3h`（座標快取，spec 860）
在這裡再次一起出現。

## PC-98：多一整套「依效果碼決定重畫哪些格子」

PC-98 那 437 條全部是同一種東西：先確認 `DS:0BE2Ch` 與 `DS:8BEEh` 都成立，
再依 `DS:0BE2Dh` 的值選一種**髒區形狀**，對每一格叫 `本模組 02DAh(x, y)`。

| `DS:0BE2Dh` | 重畫的範圍（以新座標為中心） |
|---|---|
| `15h`、`19h`、`5Bh` | x ±1、y ±1（3 × 3） |
| `22h` | 只有 (x＋1, y)、(x, y＋1)、(x＋1, y＋1) 三格 |
| `52h`、`2Fh` | 依 `DS:0BDF0h` 是 `50h`／`51h` 分兩種：x ±2 × y ±1 ＋ 邊，或 x ±3 × y ±1 ＋ 邊 |
| `29h`、`2Eh`、`32h`、`34h`、`35h`、`45h` | x ±1、y ±1（3 × 3） |
| `57h` | x ±2 × y ±1，再補上下各兩排 |

DOS 完全沒有這一段——**DOS 把文字畫在圖形畫面上，整塊重畫；
PC-98 是硬體文字層 ＋ 圖形層，必須自己算哪些格子髒了**
（與 spec 876 讀到的 PC-98 清 GDC 文字畫面是同一個成因）。

remake 用單一畫布時不需要這一層；要重現 PC-98 的畫面時序才需要。

## 明確不宣稱

- 沒有宣稱 `本模組 081Dh`／`0763h`／`0320h`／`0732h`／`0174h` 各做什麼。
- 沒有宣稱 `far 0196h:003Eh` 的五個參數。
- 沒有宣稱 `DS:67C6h`／`DS:680Eh` 兩個陣列裝什麼
  （靜態 dump 全是 `0FFh`，是執行期才填的）。
- 沒有宣稱 `DS:0BE2Ch`／`DS:0BE2Dh`／`DS:0BDF0h` 是什麼
  （形狀上是「剛剛畫了什麼」的記錄）。
- 沒有宣稱 `p^[18Dh]^[9]` 是戰鬥狀態的哪一格。
