# 第六百七十九輪：兩支降到下限就改施加效果 `1Fh`

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：PC-98 `overlay-12` 的 `1091h`、`111Bh`。

## 相同骨架、不同標的

```text
1091h:
    if <sub_3C>(3Ch, arg_2^[3], 2Bh, arg_6) = 0 then return
    if arg_6^[11h] > 3 then                       ← 下限 3
        備妥 'は弱まった。'，顯示
        arg_6^[11h] := arg_6^[11h] − 1
    else
        if <far 014Ah:0547h>(arg_6, 1Fh, @var) = 0 then
            <sub_1437>(arg_6, 1Fh, 0, 0FFh, 0)     ← 改施加效果 1Fh

111Bh:
    if <sub_3C>(0Ah, arg_2^[3], 2Ch, arg_6) = 0 then return
    if arg_6^[1A5h] > 1 then                       ← 下限 1（目前 HP）
        DS:0A02Fh := 0
        <far 014Ah:0464h>(arg_6, 0, 0, 1)
        if DS:7F27h <> 5 then <far 014Ah:04CAh>(DS:9594h)
    else
        （與 1091h 的 else 完全相同）
```

兩支的**下半段一字不差**：查目標身上有沒有效果 `1Fh`，沒有才施加。差別在上半段：

| | `1091h` | `111Bh` |
|---|---|---|
| `sub_3C` 的第一個常數 | `3Ch`（60） | `0Ah`（10） |
| 效果 id | `2Bh` | `2Ch` |
| 遞減的欄位 | `+11h` | `+1A5h`（目前 HP） |
| 下限 | **3** | **1** |
| 訊息 | 'は弱まった。' | 無 |

`2Bh` 與 `2Ch` 是相鄰的兩個 id——與 [spec 633](633-alignment-encoding-and-effect-callbacks.md)
的 `09B9h`「同一組參數連續套用 `2Bh` 與 `2Ch`」對得上：那支同時掛上兩個效果，這兩支
分別是它們的處理常式。

## 「降到底就換一種」的寫法

兩支都不是「減到 0 就結束」，而是**減到下限就改施加另一個效果**。下限不是 0：
`+11h` 停在 3、HP 停在 1——**這兩支自己不會把角色降到死亡**，死亡由效果 `1Fh` 那邊
處理。

施加前先查有沒有（`014Ah:0547h` 回傳非 0 表示已有），所以**不會重複掛**。

`111Bh` 的遞減路徑沒有訊息，但多了 `DS:0A02Fh := 0` 與一個依 `DS:7F27h` 決定的
額外呼叫；`1091h` 則相反——有訊息但沒有那些副作用。同一種骨架，兩邊各自加料。

## 明確不宣稱

- `+11h` 是哪一項屬性。
- `sub_3C` 第一個參數（`3Ch`／`0Ah`）的意義。
- 效果 `1Fh` 做什麼（只知道是「降到底之後」才掛的那一個）。
