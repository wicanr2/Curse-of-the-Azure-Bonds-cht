# 1124 — 傷害／治療類法術的骰子：分派表 → handler → 兩支擲骰入口

- 證據等級：`exact`（法術分派表由 `overlay-22` 的初始化函式逐條讀出；
  骰子由 `scripts/spell_damage_table.py` 從各 handler 本體機械抽出）
- 對應工作項：`ENG-09` 的「`+0Ah = 0` 的傷害類」
- 上游 spec 1071（分派表的 PC-98 對側）、spec 731（施法收尾）、spec 1111（屬性表）

## 骰子為什麼不在屬性表裡

屬性表（spec 1111）每支法術 16 bytes，裡面有持續時間係數、豁免類別、目標形狀，
但**沒有傷害**。`+0Ah`（效果碼）為 0 的那 31 支就是靠 handler 自己算的那一批。

handler 的位址在**法術分派表**：`DS:72A0h` 起 101 筆遠指標，由 `overlay-22` 的
一支初始化函式一條一條填進去（PC-98 對側是 `DS:0A38Ch`，spec 1071）。

```
段固定 011Ah  →  ＋7Bh 段落 ＝ overlay-22 的控制記錄
位移           →  (位移 − 20h) ÷ 5 ＝ entry 編號
```

101 筆指到 **81 個相異 handler**——20 筆是共用的（解除魔法的牧師版與法師版指到
同一支，移除詛咒也是）。

## 兩支擲骰入口

```pascal
<overlay-23 entry#9> (目標, 骰數, 面數)
<overlay-23 entry#10>(來源, 0, 0, 骰數, 面數)
```

兩支都是 `(骰數, 面數)` 依序推入。**用途不是「治療 vs 傷害」**：`entry#9` 既被
治療輕傷用，也被解除魔法拿去擲 `1d100`。所以表裡的形狀欄位照 entry 編號記，
用途要看該支法術自己。

`entry#10` 那條路的收尾是 spec 731 的 `sub_F06h`，中間還推了一個**傷害屬性旗標**
與一句訊息字串。`sub_F06h` 的第一件事就是 `mov ds:6F95h, al`——把那個旗標寫進
抗性效果會讀的那一格（spec 1123）。

| 法術 | 旗標 | 位元 |
|---|---|---|
| 致傷那一族 | `08h` | bit 3 |
| 火焰打擊 | `09h` | bit 0（火）＋ bit 3 |
| 冰風暴、寒冰錐 | `0Ah` | bit 1（冷）＋ bit 3 |
| 電擊觸手 | `0Ch` | bit 2（電）＋ bit 3 |

所以抗寒（守衛 `and al, 2`）只會對冰風暴那一類生效——**兩個獨立的證人指向同一組
位元語意**，也補上了 spec 573 當時「bit 1 尚未有對應效果證據」的那一格。

## ★ 骰數 0 ＝ 用施法者等級

魔法飛彈是 `0d4`、寒冰錐是 `0d4`。那個 0 不是「不擲」，是「骰數從施法者等級來」。
把它當成 0 會讓那幾支法術完全不造成傷害。

## ★ 不能只取第一次擲骰

火球的 handler 裡擲了兩次（`1d3` 與 `等級d6`），第一次不是傷害。腳本因此收集
**每一次**擲骰；只有一次的才給數字，多次的標 `ambiguous`。
只取第一次會產生「看起來有答案但是錯的」那一列——那比空白更糟。

## 量到的

| 類別 | 支數 |
|---|---:|
| `+0Ah = 0` 且不是占位 | 31 |
| 唯一一次擲骰（數字可用）| 15 |
| 多次擲骰（`ambiguous`）| 1 |
| 沒有可辨識的擲骰 | 15 |

同族法術的差別確實只有骰數：治療輕傷 `1d8`、中傷 `2d8`、重傷 `3d8`；
致傷那三支一樣。火焰打擊 `6d8`、冰風暴 `3d10`——都與 AD&D 的數字對得上。

完整逐支見 [`spell-damage-table.md`](../audit/spell-damage-table.md)。
