# 第五百六十五輪：ECL 記憶體讀取路徑與讀寫不對稱

狀態：`READY`（限讀取路徑的 bank 路由、具名特例與 round-trip 結論）。
日期：2026-08-14

## 結論先行

`ADDRESSVALUE` 對 operand code `01h/03h/80h` 呼叫的記憶體讀取 routine
（PC-98 `overlay-07:0FFCh`）與 `STOREVALUE` **共用同一個位址分類器**，
bank 0–3 的指標、位移與寬度完全對稱：

| bank | 讀取 | 寫入（spec 563） |
|---:|---|---|
| 0 | `es:[di + 2×addr + 6A00h]`，`DS:7F05h` | 同左 |
| 1 | 先算，算不出來才讀陣列（見下）；`DS:7F09h` | `es:[di + 2×addr + 0800h]` |
| 2 | `es:[di + 2×addr + 0C00h]`，`DS:7F0Dh` | 同左 |
| 3 | `es:[di + addr − 8000h]`，**byte**，`DS:7F12h` | 同左 |

**bank 1 不是單純的儲存區**：讀取時先呼叫一個計算 routine（PC-98
`overlay-07:08BDh`）並帶一個「是否有效」的旗標，只有旗標為 0 才回退去讀
陣列。也就是說 `7C00h..7FFFh` 之中有一部分是**動態計算出來的虛擬值**，
不是寫進去的值。哪些位址屬於計算值尚未逐一解出。

## bank 4 的讀寫不對稱（重要）

bank 4 的具名特例在讀與寫兩側**不是同一組位址**：

| ECL 位址 | 讀 | 寫 |
|---|---|---|
| `00B1h` | `DS:A880h` | **明確忽略** |
| `00FBh` | `DS:A87Ch` | **明確忽略** |
| `00FCh` | `DS:A87Eh` | **明確忽略** |
| `033Dh` | `DS:A2ABh` | — |
| `035Fh` | no-op | — |
| `03DEh` | — | `DS:BDDEh` |
| `00B8h` | — | `DS:BDE0h` |
| `00B9h` | — | `DS:BDE2h` |
| `5208h` | — | `DS:7F11h` |

所以 `00B1h`／`00FBh`／`00FCh` 是**唯讀**的計算值，`03DEh`／`00B8h`／`00B9h`／
`5208h` 是**唯寫**的設定值。remake 若把它們當成一般可讀寫的 work address，
會在其中一個方向產生原版沒有的行為。

## `C04Bh` 以上的虛擬地圖暫存器（round-trip 閉合）

讀取端以 `C04Bh` 為基底（寫入端是 `BF68h + E3h`，等值）：

| ECL 位址 | 偏移 | 讀 | 寫 |
|---|---:|---|---|
| `C04Bh` | 0 | `DS:A2A9h`，**符號延伸** | `DS:A2A9h` |
| `C04Ch` | 1 | `DS:A2AAh`，符號延伸 | `DS:A2AAh` |
| `C04Dh` | 2 | `DS:A2ABh` **÷ 2** | `DS:A2ABh`，值 **× 2** |
| `C04Eh` | 3 | `DS:A2ACh`，零延伸 | — |
| `C04Fh` | 4 | `DS:A2ADh`，零延伸 | — |
| `C059h` | 0Eh | no-op | `DS:A87Ah` |

**`C04Dh` 的 round-trip 是一致的**：寫 `3` 存成 `6`，讀回來 `6 ÷ 2 = 3`。
所以第 563 輪「remake 與原版內部表示差一個係數」的說法要收窄：對 ECL 而言
沒有差異，`×2` 只有直接讀 `DS:A2ABh` 的繪圖端看得到。**remake 直接保存 ECL
原值不會產生 ECL 可見的偏差。**

`C04Eh`／`C04Fh` 只可讀不可寫，與第 548 輪「getter 讀回 wall／terrain cache」
一致（DOS 側為 `DS:7212h`／`7213h`）。

`C04Bh`／`C04Ch` 讀取用 `cbw` **符號延伸**：值超過 `7Fh` 會讀成負數。目前的
地圖座標都在 `0..15`，不受影響，但這是資料型別事實，不是可忽略的細節。

## 這份規格明確不宣稱

- **bank 1 計算 routine（`08BDh`）算的是什麼**、哪些位址走計算路徑。
- **各具名特例的語意**。本輪確定的是方向性（唯讀／唯寫）與目的位址。
- ~~**DOS 側的讀取路徑**。本輪只讀 PC-98；DOS 的分類器與 `STOREVALUE` 已在
  spec 563 對照過，讀取端尚未逐條核對。~~ → spec 986：DOS `overlay-07:00F3Ah`
  已逐條核對，**bank 0–4 的位移、寬度、延伸方式、`÷2` 與 no-op 全部對稱**。
  同時補上一點：`033Dh` 這個 ECL 位址也讀 `DS:7211h`／`DS:0A2ABh` 但**不除以 2**，
  所以「`×2` 只有繪圖端看得到」要改成「`033Dh` 這條 ECL 路徑也看得到」。
