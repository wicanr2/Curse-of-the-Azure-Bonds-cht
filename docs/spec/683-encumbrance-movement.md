# 第六百八十三輪：負重決定移動力 —— `9`／`6`／`3` 的階梯

狀態：`READY`。日期：2026-08-14
位置：DOS `overlay-24` 的 `021Dh`、`03C5h`。

## 兩支各自的門檻

```text
021Dh:
    if byte[arg_0^[2Eh] × 16 + 5CF6h] <> 2 then return      ← 只對某一類生效
    w := arg_0^[37h]                                         ← 有號 word
    if 0 <= w <= 96h        then arg_4^[1A5h] := arg_4^[0E4h]  ← 用基準值
    else if 97h <= w <= 18Fh then arg_4^[1A5h] := 9
    else                          arg_4^[1A5h] := 6
    if arg_0^[32h] <> 0 and arg_4^[1A5h] <= 9 then
        arg_4^[1A5h] := arg_4^[1A5h] + 3                      ← 加回 3

03C5h:
    w := arg_0^[187h] − <sub_148F>(arg_0)                     ← 32-bit 相減
    if w < 0 then w := 0                                       ← 夾到 0
    if 0 <= w <= 200h        then v := arg_0^[1A5h]           ← 維持原值
    else if 201h <= w <= 300h then v := 9
    else if 301h <= w <= 400h then v := 6
    else                           v := 3
    if v < arg_0^[1A5h] then arg_0^[1A5h] := v                 ← 只降不升
```

| 十六進位 | 十進位 |
|---|---|
| `96h` | 150 |
| `18Fh` | 399 |
| `200h` | 512 |
| `300h` | 768 |
| `400h` | 1024 |

兩支的階梯值都是 **`9`／`6`／`3`**——AD&D 的負重等級（未負重／輕／中／重）正是
`12`／`9`／`6`／`3`。`021Dh` 的第一段不寫死而是取 `+0E4h`（基準移動力），對應
「未負重時用角色自己的值」。

## 兩支的差別

| | `021Dh` | `03C5h` |
|---|---|---|
| 負重來源 | `arg_0^[37h]` 直接讀 | `arg_0^[187h] − <sub_148F>()` |
| 負值處理 | 落到最後一段（`6`） | **夾到 0**，走第一段 |
| 門檻 | 150／399 | 512／768／1024 |
| 寫回方式 | **無條件覆寫** | **只在更小時覆寫** |
| 額外調整 | `+32h` 非 0 且 `<= 9` 時 `+3` | 無 |

**`03C5h` 只降不升**（`jnb` 跳過寫回），所以它可以在 `021Dh` 之後再跑一次而不會把
值加回去；`021Dh` 則是直接覆寫。兩支的先後順序會影響結果。

`021Dh` 的 `+3` 補償有上限檢查（`<= 9`），所以最多補到 `12`——正好是 AD&D 未負重的
移動力。

## `+1A5h` 是移動力（DOS）

DOS 的 `+1A5h` 對應 PC-98 的 `+1A6h`
（[spec 641](641-dos-field-offset-shift.md) 的對照表）。這兩支把 `9`／`6`／`3` 寫進
它，而 `+0E4h` 是它的基準值——所以 `+1A5h` 是**目前移動力**、`+0E4h` 是**基準移動
力**。等級 `strong inference`：數值階梯與 AD&D 吻合，但沒有訊息字串或型別表直接
指名。

注意這**不是** HP：DOS 的目前 HP 在 `+1A4h`（[spec 641](641-dos-field-offset-shift.md)
的 `20FAh` 加血夾在 `+78h`），兩者相鄰但不同。
