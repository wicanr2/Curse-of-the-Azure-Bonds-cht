# 第四百六十九輪：散提爾堡 stable-ID 與實戰玩家路徑

狀態：`READY`

## 問題

散提爾堡、幽暗神殿與眼魔洞窟的產品文字早已由 game-pack 驅動，但回歸測試仍
直接複製目前繁中片段；德克薩姆與散提爾堡部隊兩戰更使用 `forceEnemyDefeat`
把敵方 HP 設為零。前者會使翻譯改稿破壞行為測試，後者只能證明戰後
continuation，不能證明目前 combat runtime 能完成兩戰。

## 本輪變更

- 世界 trail、Zhentil edge、城門盤查、警告、內城與手札 32 改由 stable ID
  取得期望。
- 奧莉芙、幽暗神殿、手札 50／51、迪姆斯沃特、手札 12 與同行選擇全部改讀
  正式 game-pack。
- 兜帽女子、弗佐爾、德克薩姆、手札 30／7、護符、戰後離場及 Shadowdale edge
  同樣不再複製譯文。
- 移除 `forceEnemyDefeat`；兩場戰鬥各以 `CombatAct` 真正推進，設 500 回合
  有界上限，未結束即失敗。

## 驗證範圍

1. Pit 離場後正常 world path 抵達 Zhentil Keep、進城並解鎖手札 32。
2. GEO4 `20h` 奧莉芙事件進入 `21h` 幽暗神殿，解鎖手札 50／51。
3. Dimswart cell 解鎖六頁手札 12，接受後保持 story escort，不占 fighter slot，
   且事件不重播。
4. 兜帽女子與弗佐爾事件進入 ECL `22h`／GEO `25h` 眼魔洞窟。
5. 德克薩姆／梅杜莎／十牛頭人第一戰與散提爾堡 `11+4+3+1` 第二戰均由實際
   回合完成；護符、離場四段、`4CE2h／7F12h=1` 與 Shadowdale 返回仍成立。

這些是數條 focused path 共用原始 ECL／GEO 串接的證據，尚不是從新遊戲一路
不中斷走到此處的單一長回歸。戰鬥使用高能力測試隊伍，但不直接修改敵人 HP；
完整原版 AI、法術、眼魔射線、梅杜莎能力、動畫與音效仍未完成。

本輪沒有產品 Go 中文可再移除，Go 漢字 baseline 維持 603；成果是消除測試的
第二份文字真相來源與強制勝利假證據。
