# 1059 — 從公用池取錢：七種貨幣的名稱表，以及只列出「有東西」的幣種

- 證據等級：`exact`（DOS 側 243 條逐條讀完）
- 作法見 spec 783

## `dos overlay-21:00CF0h`（`retf`）

原本待解讀。這是 spec 1030／1031 營地／商店選單 **`T`（Take）** 鍵叫的那一支。

## ★★★ 七種貨幣的名稱表 `DS:0F93h`（筆距 `0Bh` ＝ 11）

| 索引 | 名稱 | 長度 |
|---|---|---|
| 0 | `'Copper'` | 6 |
| 1 | `'Silver'` | 6 |
| 2 | `'Electrum'` | 8 |
| 3 | `'Gold'` | 4 |
| 4 | `'Platinum'` | 8 |
| 5 | `'Gems'` | 4 |
| 6 | `'Jewelry'` | 7 |

> ★★★ **spec 773／798／858／1000 一路提到的「七種貨幣」，名字在這裡。**
> 前五個正是 AD&D 的 cp／sp／ep／gp／pp，第六、七個是寶石與珠寶。
> ⚠ 名稱欄位**上限 10 bytes**（筆距 11 減掉長度 byte）
> ——中文最多 **5 個全形字**。

## ★★ 只把「池裡有東西」的幣種做成選項

```pascal
鏈頭 := NIL;
for i := 6 downto 0 do begin
    if longint(DS:6F70h ＋ i × 4) <= 0 then continue;   { ★ 空的就跳過 }
    節點 := GetMem(2Eh);                                { ★ 46 bytes }
    節點^[2Ah] := 舊鏈頭;                                { 串到前面 }
    節點^.文字 := 幣種名[i] ＋ ' ' ＋ Str(數量);          { 上限 40 }
    節點^[29h] := 0;
    鏈頭 := 節點;
end;
```

★ **`GetMem(2Eh)` ＝ 46 bytes** ——與 spec 1030 記過的
「`overlay-25` 選單節點 DOS 46／PC-98 86 bytes」是同一種節點。
★ `+2Ah` ＝ next、`+29h` ＝ 一個旗標（spec 1013 的「可選數」數到第一個 `+29h ＝ 0` 為止）。
★ **由 6 數到 0** ⇒ 串出來的鏈是 **Copper 在最前面**。

## 兩段對話

```pascal
選項 := <overlay-26 entry#5>(…, 'Select type of coin ', 'Select', …, 鏈頭, …);
if (鏈頭 ＝ NIL) or (選項 ＝ 0) then exit;
提示 := 'How much ' ＋ 幣種名 ＋ 'will you take? ';
數量 := <sub_2ADh>(提示, …, 0Ah);                  { 讀一個十進位數 }
<sub_A8Ah>(…);  <overlay-26 entry#8>(鏈頭);        { 收尾／釋放 }
DS:7564h := 0;                                     { ★ 公用池標記清掉 }
```

★ `'Select type of coin '`（20，結尾有空白）與 `'Select'`（6）是**兩個參數**
——前者是標題、後者是提示。
★ `'How much '`（9）＋ 幣種名 ＋ `'will you take? '`（15）是**三段接起來的**。

## 中文化

| DOS | 長度 | 建議中文 |
|---|---|---|
| `'Select type of coin '` | 20 | 「選擇貨幣種類 」 |
| `'Select'` | 6 | 「選擇」 |
| `'How much '` ＋ 幣種 ＋ `'will you take? '` | 9 ＋ 15 | 「要拿多少」＋幣種＋「？」 |
| 七個幣種名 | ≤ 10 | 銅幣／銀幣／琥珀金／金幣／白金／寶石／珠寶 |

⚠ **`'How much X will you take? '` 的語序**：中文要把幣種挪到前面
（「要拿多少金幣？」），三段的組法本身得改。
⚠ 幣種名欄位上限 10 bytes ＝ **5 個全形字**。

## 明確不宣稱

- 沒有宣稱 `sub_B91h`（把選中的節點文字取出來）與 `sub_2ADh`（讀數字）的介面。
- 沒有宣稱 `sub_A8Ah` 與 `overlay-26 entry#8` 收尾時各自做什麼。
- 沒有宣稱錢實際被加到角色身上的哪一步（本支只讀到數量）。
- 沒有宣稱 PC-98 對側（`overlay-21:00DE8h`）的細節，
  只知道它的字串是「貨幣の種類を選んでください」「決定」「どれだけ」「持っていきますか？」。
