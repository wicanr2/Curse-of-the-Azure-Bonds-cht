# 1170 — 充能物品的 `USE` 接進 remake：15 件全部活過來

- 證據等級：`exact`（分派與扣除順序取自 spec 921，九支 handler 取自 spec 1169，
  目標模式取自 spec 1009／1111）＋ `derived`（戰鬥裡的敵我判別借用 `+7`，見下）
- 上游：spec 921、spec 1009、spec 1111、spec 1117、spec 1124、spec 1168、spec 1169
- 產物：`internal/combat/item_use.go`、`internal/game/combat_use_item.go`、
  [`docs/audit/combat-item-use.md`](../audit/combat-item-use.md)

## 這一輪之前的狀態

戰鬥選單有 `使用`，但按下去沒有動作。六章 15 件充能物品——治療藥水、極效治療、
速度、隱形、巨人力量、粉塵、飛彈項鍊、魔法飛彈魔杖、比克魔杖、火球／閃電／
冰風暴魔杖——在戰鬥裡全部是死的。

現在 15 件全部走得通（`cmd/item-use-audit` 的 `已接` 欄 15/15）。

## 分類用欄位，不用類別

```pascal
if 卷軸(物品) then …
else if (物品^[3Dh] > 0) and (物品^[3Eh] < 80h) then
    效果 := 物品^[3Dh] and 7Fh;
```

⚠ 用**物品類別**去判會漏掉粉塵與飛彈項鍊——它們的類別是 `46h`，不是魔杖
（`4Eh`／`4Fh`）也不是藥水（`47h`／`54h`）。`internal/monster` 的
`DecodeConsumable` 就是照類別分的，所以 USE 這條路不走它。

## 等級一律 6

原作在 `DS:7563h` 非 0（效果來自物品）時施法者等級一律當 **6**，不查使用者
（spec 733／1016）。所以火球魔杖永遠 6d6，不會因為誰拿著而變強；
持續時間也用同一個等級算。

## 目標怎麼取

形狀來自主表的 `+6`（spec 1009），敵我來自 `+7`：

| `+6` 形狀 | `+7` | remake 取的目標 | 用到的物品 |
|---|---:|---|---|
| `self`（0）| 1 | 使用者自己 | 速度、巨人力量、隱形、治療 |
| `fixed` N | 4 | 我方，最多 N 個 | 粉塵（4 個）|
| `fixed` N | 0 | 目前瞄準的敵人 | 麻痺魔杖、魔法飛彈魔杖 |
| `area` r | 0 | 圓心半徑 r 內的所有人 | 飛彈項鍊、比克魔杖、三支法術魔杖 |

⚠ **`+7` 拿來當戰鬥裡的敵我判別是推論。** spec 719 把 `+7` 記成**戰鬥外**那條
選目標路徑的欄位（1 ＝ 施法者自己、2 ＝ 點一個、4 ＝ 全隊）。九個物品效果的
兩欄組合完全一致，所以借用它；但這不是讀出來的，因此
`chargedItemTargets` **遇到沒見過的組合一律回錯誤**——猜一個會得到自洽但沒有
依據的規則。

⚠ 固定數量目前一律收斂成 **1 個**（敵方那一路）。這與既有的效果類法術一致
（`effectSpellTargets` 的 `enemy` 也只回一個），不是這一輪新加的落差：remake
還沒有「連點 N 個目標」的操作。

## 圓心有兩種

飛彈項鍊（`40h`）用玩家瞄的那一點；比克魔杖（`62h`）的 handler **自己從使用者
算圓心**（spec 1169）。所以行為表有 `CenterOnUser` 這一格，不是統一取一種。

## 扣除順序

```pascal
if 結果 <> 0 then
    if 物品^[39h] > 1 then dec(物品^[39h])       { 數量 }
    else begin
        dec(物品^[3Ch]);                          { 充能 }
        if 物品^[3Ch] = 0 then 丟掉(物品);
    end;
```

⚠ **一疊物品的最後一個才會消耗充能**。三瓶極效治療藥水（`+39h = 3`、
`+3Ch = 3`）要喝掉前兩瓶之後，第三瓶才開始扣充能。

⚠ `結果 = 0` 時**整段跳過**。目前唯一會回 0 的是速度藥水對已經被緩速的目標
（`39h` 先查 `2Ah`，有就連 `sub_F06` 都不呼叫）——那一次不扣充能。

## 沒接的東西，以及為什麼

- **卷軸那 15 件**：`sub_3474h`（從卷軸上的三個法術挑一支）沒有讀出來。
  按下去回錯誤，**不會**默默把卷軸消耗掉。
- **巨人力量到期把力量換回去**：藥水掛的是效果記錄 `92h`，舊力量存在記錄的
  `Strength` 那一格（原作 `entry#11` 的第三個參數）。`92h` 的到期處理還沒讀，
  所以現在只上不下——資料在，之後接得上。
- **選單裡的物品清單**：`U` 用掉目前選中的那一件、`Alt+U` 換下一件。
  原作是列出背包讓玩家點，remake 還沒有那個清單控制項。

## 中文化

新增十個訊息鍵，四句直接對應 handler 裡的字串
（`is Speedy`／`is stronger`／`is paralyzed`／`is invisible`）。
`combat_item_no_effect` 對應原作「什麼都沒發生」那一路——**不要**自行補上
「因為已經被緩速」之類的解釋，原作就是不說（同 spec 921 的 `'oops!'`）。

## 明確不宣稱

- 沒有宣稱 `+7` 在戰鬥裡就是敵我旗標（見上，是借用）。
- 沒有宣稱效果記錄 `92h` 到期時做什麼。
- 沒有宣稱固定數量那一路在原作要怎麼連點 N 個目標。
