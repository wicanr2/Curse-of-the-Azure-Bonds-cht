## 一半的機率直接不吐

```pascal
if (DS:758Dh <> 0) and (1d100 <= 50) then 離開;
```

`DS:758Dh`（PC-98 `DS:0A81Fh`）是一個開關；開著的時候**每次噴吐有 50% 機率整支
直接跳過**，連訊息都不印。關掉時則每次必吐。

## 落點：把目標座標往自己的方向拉

```pascal
DS:7559h := x + f(DS:7559h − x);
DS:755Ah := y + f(DS:755Ah − y);
```

`DS:7559h`／`DS:755Ah`（PC-98 `DS:0A645h`／`0A646h`）進來時是目標座標，
`far 1894h+1` 拿「目標減自己」的差值算出一個新差值，再加回自己的座標。
形狀上是**把噴吐的落點限制在自己周圍的某個範圍內**（`1894h+1` 大概是符號保留的
夾限或縮放，本規格不宣稱其算式）。

之後那兩道修正很特別：

```pascal
if DS:7559h = x + 1 then inc(DS:7559h);
if DS:755Ah = y + 1 then inc(DS:755Ah);
```

**落點剛好落在自己的正右／正下一格時，再往外推一格**——避免噴到貼著自己的位置。
兩軸各判一次，所以斜角相鄰的那一格不受這條保護。

## 傷害用最大 HP

```pascal
<本模組 3947h>(…, 角色^[78h], 3, 0, @結果);
<本模組 3A03h>(0Ah, 角色^[78h], 3, 0);
```

`+78h` 是最大 HP（spec 845 那三格之一）。**AD&D 的龍息傷害就是等於龍的當前 HP**，
這裡取的是最大 HP——remake 若照抄，受傷的龍噴吐威力不會下降。

`DS:6F95h := 24h` 是傷害型別（spec 731 讀到同一格：傷害量為 0 時清 0、否則設成型別）。

## `節點^[3]`：大於 `0FDh` 就減 1，否則移除效果 `58h`

```pascal
if 節點^[3] > 0FDh then dec(節點^[3])
else <far 143Dh+2>(角色, 58h, 節點);
```

形狀上是「噴吐次數用完就把噴吐能力（效果 `58h`）拿掉」，`0FEh`／`0FFh` 是還有次數
的編碼。

⚠ 這跟 spec 846 對同一個結構 `+3` 的用法（拿去索引 `DS:6D35h` 戰鬥員陣列、
與施法者比對）**互相矛盾**，目前無法調和。spec 846 已加註，兩邊都只宣稱
「在這一支裡它被這樣用」，不對欄位定名。

## PC-98 的唯一差異

多一段 `xor ah, ah` ＋ `mov cx, 0Ch` ＋ `imul cx`（**乘 12**）。與 spec 837 之後
反覆出現的「DOS 用常數、PC-98 改成算式」是同一類。其餘 26 條全是位址：
`DS:758Dh↔0A81Fh`、`DS:6F95h↔0A02Fh`、`DS:7559h/755Ah↔0A645h/0A646h`、
`DS:7746h↔0A9D8h`、`DS:72A0h↔0A38Ch`。
