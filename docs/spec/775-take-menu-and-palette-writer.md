# 775 — 「Take:」戰利品選單、PC-98 調色盤寫入子程序

- 證據等級：`exact`（以補洞後的匯出逐條讀完，見 spec 761）

## `overlay-05:0ED7h`（DOS）— 戰利品的「Take:」選單

補洞之前這一支的匯出位移不可靠（spec 756 列在「沒有判讀」裡），補完之後是完整
的 98 條。`retf 8`，兩個遠指標（`[bp+0Ah]` 與 `[bp+06h]`，都指向計數 byte）：

```pascal
if 甲^ = 0 then begin <呼叫 DB1h>();  離開 end;
if 乙^ = 0 then begin <呼叫>();  <呼叫>();  離開 end;
repeat
    組字串('Take: ');                        { CS:0EBFh，6 字元含尾隨空白 }
    組字串('Money Items Exit');               { CS:0EC6h，16 字元 }
    k := <選單>(@旗標, 1, 1, 0Fh, 0Ah, 0Dh);
    case k of
        'M': begin <呼叫>();  <呼叫>();  end;
        'I': <呼叫 DB1h>();
        'E', #0: 結束 := true;
        'G': <呼叫 1022h>(k);
        'O': <呼叫 1022h>(k);
    end;
    <呼叫>(DS:6506h);
    <呼叫>(乙, 甲);
    if (甲^ = 0) or (乙^ = 0) then 結束 := true;
until 結束;
```

**中文化的重點在這裡**：

- `'Take: '` 的**尾隨空白是常數的一部分**（長度 byte 是 6），後面要接選項字串。
- `'Money Items Exit'` 是**一條 16 字元的字串**，三個選項用空白分隔，不是三條
  獨立的字串。
- 熱鍵是 `'M'`／`'I'`／`'E'` 三個**寫死的 ASCII 大寫字母**，直接跟按鍵比對。
  換成中文之後選項字面上不再有 M／I／E，熱鍵與顯示會脫節——要嘛在譯文裡保留
  英文字母提示，要嘛改比對。
- `#0` 與 `'E'` 走同一條路（擴充鍵的前導 0 被當成離開）。
- `'G'`（`47h`）與 `'O'`（`4Fh`）呼叫同一支且都把按鍵值傳下去；這兩個值正好是
  Home 與 End 的掃描碼，但本輪沒有讀 `1022h`，不宣稱。

離開條件有兩個：使用者選 Exit，或兩個計數任一歸零（拿光了）。

## PC-98 `overlay-11:0800h` — 寫入 16 組調色盤

近呼叫 `retn`，入口 `SI` 指向 48 bytes 的調色盤資料：

```
for i := 0Fh downto 0 do begin
    out 0A8h, i          { 索引 }
    out 0AAh, [si]       { 綠 }   inc(si)
    out 0ACh, [si]       { 紅 }   inc(si)
    out 0AEh, [si]       { 藍 }   inc(si)
end
```

這支是 spec 755 的 `overlay-11:07CDh` 呼叫的那一段——當時已經逐條讀過並寫進
該筆的說明，這裡只是把它自己的台帳條目補上。索引由 `0Fh` 遞減到 `0`，而資料
指標 `SI` 往前遞增，所以**資料的第一組對應的是索引 15，不是 0**。

`0A8h`..`0AEh` 是 PC-98 的類比調色盤埠。進出時 `DS`／`CX`／`BX`／`AX` 都有
存回，`SI` 沒有——離開時 `SI` 停在資料尾端。

## 明確不宣稱

- 沒有宣稱 `overlay-05` 那兩個計數指標各自數的是什麼（形狀上是「錢」與
  「物品」兩堆的剩餘量）。
- 沒有宣稱 `1022h`、`DB1h`、`1146h`、`15A9h` 各做什麼。
- 沒有宣稱 `'G'` / `'O'` 就是 Home / End。
