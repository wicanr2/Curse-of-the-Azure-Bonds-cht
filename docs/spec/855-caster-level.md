# 855 — 施法者等級：聖騎士 −8、遊俠 −7／−8，全部照 AD&D

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼序列完全相同，13 條差異全是位址）
- 作法見 spec 783

## `overlay-24:028B3h` ↔ `overlay-24:02AEAh`（兩平台各 149 條）

`retf 2` ＝ 一個 word（法術編號）。回傳施法者等級。

```pascal
p := 遠指標(DS:6506h);

if (p^[109h] = 0) and (p^[10Eh] = 0)
   and (有號(p^[10Ch]) < 9) and (有號(p^[10Dh]) < 8) then begin
    結果 := 6;  goto 收尾;
end;

m := <far 1652h>(p);                                  { 多職業的乘數 }
case byte[37DAh + 法術 * 10h] of                      { 法術屬性 +0 ＝ 類別 }
  0: 結果 := max( p^[109h] + p^[111h] * m,            { Cleric }
                  p^[10Ch] + p^[114h] * m − 8 );      { Paladin − 8 }
  1: begin
        a := p^[10Dh] + p^[115h] * m − 7;             { Ranger − 7 }
        結果 := if 有號(a) > 0 then a else 0;
     end;
  2: 結果 := max( p^[10Eh] + p^[116h] * m,            { Magic-User }
                  p^[10Dh] + p^[115h] * m − 8 );      { Ranger − 8 }
  3: 結果 := 0Ch;                                     { 固定 12 }
end;

收尾:
if (DS:7563h <> 0) and (byte[37DAh + 法術 * 10h] <> 3) then 結果 := 6;
```

所有 `max` 都用有號比較。

## 四個類別對上 AD&D

法術屬性表 `DS:37DAh` 的 `+0` 欄（spec 788：`00` cleric、`01` druid、`02` mage、
`03` 未定名）在這裡各自取不同的職業等級：

| 類別 | 取誰的等級 | AD&D 依據 |
|---|---|---|
| 0 牧師法術 | **Cleric**，或 **Paladin − 8** 取大者 | 聖騎士 9 級才會第 1 級牧師法術 → 等效施法者等級 ＝ 等級 − 8 |
| 1 德魯伊法術 | **Ranger − 7**（負值夾成 0） | 遊俠 8 級才會第 1 級德魯伊法術 |
| 2 法師法術 | **Magic-User**，或 **Ranger − 8** 取大者 | 遊俠 9 級才會第 1 級法師法術 |
| 3 | **固定 12** | — |

**三條扣減全部一格不差**。類別 `3` 固定 12 級且不受 `DS:7563h` 影響——形狀上是
「物品／裝置發動的法術」，本規格不宣稱。

## 兩個職業等級陣列的用法定案

角色記錄有兩個 8 bytes 的職業等級陣列（`+109h`..`+110h` 與 `+111h`..`+118h`）。
本支把它們成對使用：

```
實際等級 := 第一陣列[c] + 第二陣列[c] × <far 1652h>(角色)
```

`1652h` 在 spec 834（Turn Undead）也是同一個用法（`+109h` ＋ `+111h` × `1652h`）。
所以**第二陣列是要乘上某個係數才加進去的**，`1652h` 回傳什麼仍未定名。

## 零級的預設是 6

Cleric 與 Magic-User 都是 0、Paladin < 9、Ranger < 8 的角色（也就是完全不會施法的）
拿到的施法者等級是 **6**。同樣地，`DS:7563h` ≠ 0 時除了類別 3 以外一律壓成 6。
形狀上是「這一次的施法來自卷軸或物品，用固定等級」。

## 明確不宣稱

- 沒有宣稱 `far 1652h(角色)` 回傳什麼。
- 沒有宣稱法術類別 `3` 是什麼。
- 沒有宣稱 `DS:7563h` 是什麼開關。
- 沒有宣稱為什麼零級與 `DS:7563h` 兩條路都選 6。
