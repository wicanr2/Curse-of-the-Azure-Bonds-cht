# 第七百四十一輪：命中附加效果，與第三處未初始化回傳

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-12` 的 `2782h`、`22A3h`、`2078h`（三支都沒有位元組缺口）。

## `2782h`：麻痺觸碰

```text
p := 角色^[18Dh]^[0Ah]                             ← 目前鎖定的目標
DS:6FA3h := p
if <overlay-23 entry#8>(p, 0, 0) = 0 then          ← 豁免失敗
    <overlay-23 entry#11>(p, 34h, 0, 0FFh, 0)
    <overlay-24 entry#20>(p, '<名字> is paralyzed'（CS:2775h）, 0Ah, 1)
```

效果編號 `34h` 與訊息都和 spec 722 的凝視（`overlay-22:6022h`）相同，但參數不同：
凝視是 `entry#11(p, 34h, 3Ch, 0FFh, 0)`，這裡第三個是 `0`。所以**同一個麻痺效果
有兩種持續時間來源**。

`entry#8` 的第二個參數這裡是 `0`（凝視是 `1`），豁免類別也不一樣。

## `22A3h`：三個效果都沒有才加傷害

```text
p := 角色^[18Dh]^[0Ah]
if 沒有 14h 且 沒有 36h 且 沒有 3Dh then          ← 三次 <overlay-24 entry#27>
    DS:6F94h := DS:6F94h + ROLLDICE(1, 6)
```

三個編號**任何一個成立就完全不加**。三次查詢是短路的（前一個找到就跳到結尾），
所以平均只查一次多一點。

`3Dh` 在 spec 712 的持續時間表裡也出現過（`5d4`），兩處是同一個編號域。

## `2078h`：分段加成，而且**沒有預設值**

```text
if DS:6FA7h = 4 或 DS:6FA7h = 2 then
    v := 角色^[19h]
    v ∈ 4..6    → bonus := 1
    v ∈ 7..10   → bonus := 2
    v ∈ 0Bh..0Dh → bonus := 3
    v ∈ 0Eh..11h → bonus := 4
    v ∈ 12h..14h → bonus := 5
    （其他值：bonus **不會被寫入**）
    DS:6F92h := DS:6F92h + bonus
```

> ⚠ `bonus`（`bp−1`）在 `v < 4` 或 `v > 20` 時**從頭到尾沒有被賦值**，
> 加進 `DS:6F92h` 的是堆疊殘值。

這是本專案第三處同型的問題：

| 位置 | 情況 |
|---|---|
| `overlay-24:129Ah`（spec 694） | 力量落在 0..25 之外，或 18 但百分位 > 100 |
| `overlay-22:23F2h`（spec 702） | `DS:7434h` 不在 1..4 |
| 本輪 `overlay-12:2078h` | `角色^[19h]` 不在 4..20 |

三處的共同形狀是「一串 `if 範圍 then 賦值`，**沒有 `else`**，而區域變數在函式
開頭也沒有初始化」。Turbo Pascal 不會替區域變數清零，所以拿到的是上一個呼叫留在
那個堆疊位置的東西。

**remake 要補預設值**，但補什麼要另外決定——原作的行為隨堆疊內容而定，沒有
「正確答案」可抄。

分段本身是 `4..6 / 7..10 / 11..13 / 14..17 / 18..20 → 1 / 2 / 3 / 4 / 5`，
每段長度 3／4／3／4／3，不是等距。

## 明確不宣稱

- `DS:6FA7h`（只有等於 2 或 4 才做事）、`DS:6F92h`、`角色^[19h]` 的語意。
- 效果編號 `14h`／`36h`／`3Dh` 各代表什麼。
- `entry#11` 第三個參數（`0` 對 `3Ch`）的意義。
