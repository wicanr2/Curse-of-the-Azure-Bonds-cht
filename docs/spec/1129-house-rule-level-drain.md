# 1129 — 偏離規則：龍巫妖的等級吸取

- 證據等級：**不適用**——這一份不是還原，是**刻意加上去的規則**
- 決定者：使用者，2026-08-17
- 上游 spec 1127（原作沒有等級吸取的證明）、spec 1125（復原術）

## 這一份為什麼長得跟其他規格不一樣

其他規格都在回答「原作怎麼做的」。這一份回答的是「我們決定怎麼做」。
兩者混在一起是最貴的錯誤——過幾輪之後沒有人分得出哪一條是量到的、哪一條是
自己加的，而**假的還原比沒有還原更糟**。所以：

- 檔案放在 `gamepack/rules/house-rules.json`，**不進共用 engine 的 pack schema**。
  house rule 應該待在它屬於的那一款遊戲裡，不要邀請別的作品也長出同一個欄位。
- 每一條都要寫「為什麼偏離」與「誰決定的」。
- 程式與資料的註解一律以 ★★ 標出「這是偏離不是還原」。

## 原作的事實（spec 1127）

CoAB **沒有**等級吸取：`+0E7h`／`+0E8h` 只有兩個消費者（訓練升級、復原術）、
零個生產者；職業等級陣列連一個 `dec` 都沒有；68 種怪物裡沒有屍妖／幽魂／
幽靈／吸血鬼／暗影。復原術因此永遠回「沒有可恢復的等級」。

## 加了什麼

| 項目 | 值 | 為什麼 |
|---|---|---|
| 怪物 | 龍巫妖（`DRACOLICH`）| 名單裡唯一的不死生物，位置最貼近 |
| 載體 | 天生效果碼 `7Eh` | **龍巫妖獨有**（`7Dh` 與 ALIAS／DRAGONBAIT 共用，會誤傷）|
| 一次吸 | 1 級 | AD&D 龍巫妖等級的常見值 |

命中且目標還活著才吸；打死了不吸——復原術是還給活人的。

## ★ 資料形狀沿用原作，所以還原那一側一行都沒改

吸下去記的就是復原術會讀的那兩格：

```
被吸的職業 := 等級最高的那一個;   { AD&D 吸最高的 }
每級HP := 最大HP div 職業等級總和;
職業等級 -= 1;
最大HP／基準最大HP／目前HP 各 -= 每級HP;
+0E7h += 1;  +0E8h += 每級HP;
```

`restoreDrainedLevel`（復原術）與訓練升級那條路**完全沒有為了這條規則改過**，
照樣把它還回去——測試 `TestHouseRuleLevelDrainRoundTripsWithRestoration` 就是
釘住這件事的：吸 6 級戰士一級 ⇒ 記 1 級／8 HP（`48 ÷ 6`），復原術還完歸零。

⚠ 掉的 HP 用「平均每級」估：原作沒有逐級 HP 紀錄，而復原術還的量是
`+0E8h ÷ +0E7h`，所以只要吸的時候按同一個尺度記，一來一回就對得上。

⚠ 只剩一級的職業不再往下吸——等級陣列沒有 0 級的合法狀態。

## 明確不宣稱

- 沒有宣稱原作的龍巫妖有這個能力。**它沒有。**
- 沒有宣稱效果碼 `7Eh` 在原作是「等級吸取」。它在原作的語意還沒讀，
  這裡只是借它當**載體**，因為它剛好只有龍巫妖帶。
- 沒有宣稱掉的 HP 與 AD&D 的規則一致（AD&D 吸的是該級擲到的 HP）。
- 沒有宣稱豁免、抗性或不死免疫會不會擋——目前是命中就吸。
