# 785 — 兩平台同形配對（第三批三組）：治療失明、戰鬥員螢幕座標

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-04:0280h`（entry#5，53 條，差異 15 條）— Cure Blindness

四條訊息把它定死：

| | DOS | PC-98 |
|---|---|---|
| 「不是失明」 | `'is not blind.'`（13） | `'は盲目ではありませんよ。'`（24 bytes） |
| 法術名 | `'Cure Blindness'`（14） | `'キュア・ブラインドネス'`（22 bytes） |

```pascal
答 := 'Y';
if not <014Dh:00A7h>(@暫存, 21h, DS:6506h) then begin
    顯示(角色 ＋ 'is not blind.');
    答 := 本模組 0047h;                       { 「それでもかけますか」型的 Y/N }
end;
if 答 = 'Y' then begin
    顯示('Cure Blindness');
    答 := 本模組 00F3h(3E8h);                 { 1000 }
    if 答 = 'Y' then <0141h:002Fh>(0, 0, 21h, DS:6506h);
end;
```

與 spec 763 的石化解除（`overlay-04:0B31h`）是同一個模子：**先問狀態、不符就
再確認一次、然後帶一個數字去收費、最後動手**。這一支用的效果碼是 **`21h`
（33）**，價錢是 **`3E8h`（1000）**；石化那支用的是 `7D0h`（2000）。

`014Dh:00A7h` 是「角色身上有沒有效果 `21h`」的查詢，`0141h:002Fh` 是「移除
效果 `21h`」。

**中文化的直接參考**：法術名稱與狀態句都是 overlay 內嵌的字串常數，PC-98 版
整條換成日文而**呼叫結構完全沒改**（差異的 15 條全是位址與近呼叫目標）。

## `overlay-32:0079h`（entry#3，51 條，差異 7 條）— 重算所有戰鬥員的螢幕座標

```pascal
n := DS:66A6h;                                  { 戰鬥員數 }
for i := 1 to n do begin
    byte[67C6h + i] := byte[66A3h + i * 4] − 地圖^[2];
    byte[680Eh + i] := byte[66A4h + i * 4] − 地圖^[3];
end;
```

一次補上四件事：

- **戰鬥員記錄是每筆 4 bytes、基底 `DS:66A3h`、1 起算**：`+0` 是世界 x、
  `+1` 是世界 y。`+3`（＝ `66A6h + 4i`）就是 spec 772 的 `overlay-13:48DCh`
  歸零的那個 byte。
- **計數 `DS:66A6h` 與記錄 0 的 `+3` 是同一個位址**——1 起算的陣列把第 0 格讓給
  計數，這是本專案第三次遇到同一種擺法（spec 772、spec 784 的 `DS:6E96h`）。
- 螢幕座標放在 **`DS:67C6h + i`** 與 **`DS:680Eh + i`** 兩個 byte 陣列
  （相距 `48h` ＝ 72，所以上限至少 72 筆）。
- 換算方式是**世界座標減掉地圖表頭的 `+2` / `+3`**——那正是 spec 750 寫進去的
  戰場原點。整條線（原點 ＝ 隊伍位置 −3 → 螢幕座標 ＝ 世界座標 − 原點）到此
  閉合。

減法是 byte 相減沒有夾制，戰鬥員在原點左上方時會得到迴繞的大值。

## `overlay-29:000Ch`（entry#1，51 條，差異 10 條）

```pascal
if 遠指標 = NIL then 離開;
if (DS:4F99h^[3FEh] > 0) or (第三個參數 <> 0) then begin
    if DS:4F99h^[3FEh] > 0 then
        <0297h:1626h>(遠指標, 1, 0, @DS:0AA8h, @DS:0A98h);
    <0297h:09E4h>(遠指標@DS:4FE8h, 遠指標, 0, 0, 參數6 − 1, 參數8 − 1);
    <0297h:1316h>();
end else
    <0297h:1110h>(遠指標, 參數6, 參數8);
```

`DS:0A98h` 與 `DS:0AA8h` 是兩塊相距 `10h` 的靜態緩衝區。兩條路都以
`0297h:1110h` 或 `0297h:09E4h` 收尾——後者多帶四個參數且座標**各減 1**。

`DS:4F99h^[3FEh]`（PC-98 `DS:7F05h^[3FEh]`）是決定走哪一條的旗標。
