# 874 — 角色頭像與身體圖的兩格快取：編號沒變就不重載

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-29:005DDh`（DOS 110 條）↔ `overlay-29:004E0h`（PC-98 120 條）

`retf 4` ＝ 兩個 byte：`(頭部編號, 身體編號)`，`0FFh` ＝ 這一格不動。
三個字串**兩平台完全相同**（檔名前綴不能翻）：`'HEAD'`、`'BODY'`、
`'head not found'`。

```pascal
Str(DS:5BEEh, 寬度 1, var 數字);                 { 0A54h:12ABh }

{ 頭部：DS:726Eh 記編號、DS:726Fh 記遠指標，前綴 'HEAD' }
if (編號A <> 0FFh)
   and ((DS:726Eh = 0FFh) or (DS:726Eh <> 編號A)) then begin
    暫 := 常數A ＋ 數字;                          { DOS 才串接 }
    <far 297h:011Bh>(暫, 編號A, 0, 0, @DS:726Fh);  { 載入，參數順序見 spec 971 }
    if 遠指標(DS:726Fh) = NIL then begin
        暫 := 失敗訊息;
        <far 0542h:0946h>(0, 0Eh);
    end;
    DS:726Eh := 編號A;
end;

{ 身體：DS:7273h ／ DS:7274h，前綴 'BODY'，其餘完全一樣 }
...

<far 06EAh:024Ch>();
```

**兩格各自記住「現在裝的是幾號」，編號一樣就整段跳過**——
這是資源快取，不是每次都重載。`0FFh` 是「這一格這次不處理」的哨兵，
與另一格的哨兵互不影響。

這接上 spec 873：角色外觀是 `+143h` 圖像編號 ＋ `+144h..+14Ah` 七個配色，
而實際的圖檔分成**頭與身體兩份**，由呼叫端各給一個編號。

載入用的 `far 297h:011Bh` 與 `overlay-33:0002Eh` 是同一支載入器。

## ⚠ 三處兩平台真的不同

| | DOS | PC-98 |
|---|---|---|
| 載入前 | 直接覆蓋 `DS:726Fh` | **先檢查舊指標非 NIL 就叫 `2A8h:10D5h` 釋放** |
| 檔名 | 常數 ＋ `Str(DS:5BEEh)` 的一位數字 | **只有常數，沒有串接數字** |
| 載入呼叫 | `297h:011Bh`，4 個參數 | `2A8h:025Bh`，**多一個 0** |
| 區域緩衝 | `102h` ＝ 258 bytes | `12h` ＝ 18 bytes |

DOS 把 `DS:5BEEh` 轉成一位數接在檔名後面（`DS:5BF0h` 是 spec 868 的路徑前綴，
相鄰），PC-98 不接——**PC-98 的檔案位置是固定的，DOS 要拼出磁碟編號**。
緩衝大小差 240 bytes 正是這個差別的連帶。

**PC-98 先釋放再載入、DOS 不釋放**是行為差異，不是碼型：
DOS 這條路徑上，重載時舊的那塊沒有被釋放。
本規格不宣稱 DOS 是不是漏了（`297h:011Bh` 內部有沒有處理沒有讀到），
但 remake 要照 PC-98 的寫法才安全。

## ⚠ 原版訊息 bug：身體載入失敗也印 `'head not found'`

兩格的失敗分支指向**同一個字串常數**（DOS `loc_5C9`、PC-98 `loc_4CC`）。
所以 `'BODY'` 那一格載入失敗時，畫面上印的是 `'head not found'`。
**兩平台都一樣**，PC-98 也沒有修。中文化照原樣重現即可，
但 remake 若要修，這是一個明確的點。

## 中文化

`'HEAD'` 與 `'BODY'` 是檔名前綴，**不能翻**。
`'head not found'` 是給玩家看的錯誤訊息，可以翻——但要記得它會在
身體載入失敗時也出現（見上）。

## 明確不宣稱

- 沒有宣稱頭／身體圖檔的格式。
- 沒有宣稱 `DS:5BEEh` 是什麼（形狀上是磁碟／資料片編號）。
- `far 297h:011Bh` 的簽章已由 spec 971 定案為
  `(檔名: string; 編號: byte; a, b: byte; var 目的: pointer)`；仍沒有宣稱中間
  那兩個 `0` 是什麼。第三格快取（`DS:728Ch`／`DS:7290h`，`'bigpic'`）也在
  spec 971 補齊。
- 沒有宣稱 `far 0542h:0946h`／`418h:12EFh` 的兩個參數（`0`／`0Eh`）。
- 沒有宣稱結尾 `far 06EAh:024Ch` 做什麼。
