# 第六百九十六輪：物品節點的完整版面，與「包紮」

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-24` 的 `32A9h`、`3387h`。

## `32A9h`：物品節點的建構子，15 個參數

```text
GetMem(node, 3Fh)
FillChar(node^, 3Fh, 0)                  ← 0A54:1AE0h
node^[2Eh] := 參數1   （byte）
node^[2Fh] := 參數2   … node^[36h] := 參數9
node^[37h] := 參數10  （word）
node^[39h] := 參數11  （byte）
node^[3Ah] := 參數12  （word）
node^[3Ch] := 參數13  node^[3Dh] := 參數14  node^[3Eh] := 參數15
回傳 node（DX:AX）
retf 1Eh                                 ← 30 bytes ＝ 15 個 word
```

參數順序與欄位順序**一一對應**：第一個參數進 `+2Eh`，最後一個進 `+3Eh`。
15 個裡有 2 個是 word（`+37h`、`+3Ah`），其餘 13 個是 byte。

## 節點版面因此完全定下來

把本輪與 spec 695、spec 686 的結果拼起來，63 bytes 沒有空隙：

| 位移 | 大小 | 內容 | 來源 |
|---|---|---|---|
| `+00h` | 41 | Pascal 字串（長度位元組 ＋ 最多 40 字元） | spec 686 |
| `+29h` | 1 | 旗標，建立時 0 | spec 686 |
| `+2Ah` | 4 | far 指標，下一個節點 | spec 695 |
| `+2Eh` … `+36h` | 各 1 | 參數 1..9 | 本輪 |
| `+37h` | 2 | 參數 10 | 本輪 |
| `+39h` | 1 | 參數 11 | 本輪 |
| `+3Ah` | 2 | 參數 12 | 本輪 |
| `+3Ch` … `+3Eh` | 各 1 | 參數 13..15 | 本輪 |

`+00h`..`+2Dh` 這段（名字 ＋ 旗標 ＋ next）**與 spec 686 選單節點的版面完全
相同**——選單就是直接拿物品節點來顯示的，不是另外配置一種結構。這也解釋了
spec 686 裡「複製 40 bytes 當項目文字」為什麼上限正好是 40。

`+2Eh` 就是 `3018h`／`305Bh` 拿去查 `DS:5D02h` 那張 16 bytes 一格的表的索引
（spec 691）——所以 `+2Eh` 是物品類別編號。

`FillChar` 把整個 63 bytes 清成 0，所以名字欄的長度位元組是 0（空字串），
建構子不填名字。

## `3387h`：包紮

```text
found := 0
p := DS:650Ah                                    ← 隊伍鏈
while p <> NIL do
    if p^[18Dh]^[13h] = 0 且 p^[197h] = 0 且 p^[195h] = 5 then
        found := 1
        if arg_0 <> 0 then
            p^[195h] := 4                        ← 狀態 5 降為 4
            p^[18Dh]^[0Eh] := 0
            顯示「<名字> is bandaged」（CS:337Bh）
            arg_0 := 0                           ← ⚠ 只有第一個會被處理
    p := p^[189h]
回傳 found
retf 2
```

`arg_0` 同時是「要不要真的做」與「還沒做過」兩件事：進來時為 0 就只查不改，
非 0 時**只處理第一個符合的成員**，之後的成員只讓回傳值變成 1。所以

> 「回傳 1」不等於「已經包紮了」，只表示**還有人符合條件**。

狀態 `5 → 4` 與既有台帳裡「`+197h = 0` 時狀態 5 降為 4」是同一條規則的兩個
出處。`+195h` 是狀態欄。

訊息 `is bandaged` 走的是 spec 693 的同一條路（呼叫端補主詞 ＋ 常數述部
＋ `17D6h`）。

## 明確不宣稱

- 15 個參數各自的意義，只確定了寬度與落點。
- `+18Dh^[13h]`、`+18Dh^[0Eh]` 是什麼。
- 狀態值 4 與 5 的名稱。
