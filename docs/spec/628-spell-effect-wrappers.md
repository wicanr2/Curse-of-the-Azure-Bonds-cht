# 第六百二十八輪：法術薄包裝六支 —— 效果 id `2Ah`／`21h` 與「有沒有中」的判斷方向

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：PC-98 `overlay-22` 的 `1F53h`、`3223h`、`3804h`、`3BCBh`、`41AFh`、`42C4h`。

## `013Eh:0070h` 是「目標身上有沒有這個效果」

兩支用同一個呼叫、方向相反：

| 函式 | 效果 id | 印訊息的條件 | 訊息 |
|---|---|---|---|
| `3223h` | `21h` | 回傳**非 0** | 「の視力は戻った。」 |
| `41AFh` | `2Ah` | 回傳 **0** | 「はすばやくなった。」 |

「視力回復了」只在**已經有** `21h` 時才說得通，「變快了」只在**還沒有** `2Ah`
時才說得通。兩邊的分支方向剛好相反，所以回傳值就是「目標身上有沒有這個效果」。
`21h` 因此是失明、`2Ah` 是加速。

`2Ah` 另外出現在 `3BCBh`——它把 `2Ah` 連同「は加速された。」一起交給 `sub_3AE5`，
與 `41AFh` 指同一個效果。

## 六支的內容

```text
1F53h:  <sub_1E8D>(DS:9594h^[198h], 'は祝福を受けた。')

3BCBh:  <sub_3AE5>(2Ah, DS:9594h^[198h], 'は加速された。')

3223h:  if <far 013Eh:0070h>(t, 21h) <> 0 then          ← t 是 DS:0A521h
            <far 014Ah:00A2h>(t, 1, 'の視力は戻った。')

41AFh:  if <far 013Eh:0070h>(t, 2Ah) = 0 then
            推入 DS:0A031h 與四個 0，備妥 'はすばやくなった。'，呼叫 <sub_F62>

3804h:  x := <far 014Ah:00D4h>(DS:0A031h, DS:0A031h)
        n := (signext(DS:9594h^[198h]) shl 4) + x        ← 高位元組放 [198h]
        推入 n 與三個 0，備妥 'は祈っている。'，呼叫 <sub_F62>

42C4h:  n := ROLLDICE(1, 6) + 14h                        ← 1d6+20
        <sub_3BF5>(n, 4, 0, …)
        <sub_3CB1>(0, 4, 14h, 3)
```

`3804h` 的 `shl 4` 把 `[198h]` 放進高 4 bit、`014Ah:00D4h` 的回傳值放低位——是把
兩個值**打包成一個 word**，不是相加。

`42C4h` 的 `1d6+20` 出現在一支不印任何訊息的函式裡，兩個後續呼叫都帶常數 `4`
與 `14h`（20）。

## `0A65h:62Fh` 不是訊息呼叫的參數

多支的形狀是「推入數值 → `lea di, [bp+var_N]` ＋ `mov di, offset 常數` ＋
`call 0A65h:62Fh` → 呼叫訊息 routine」。`62Fh` 是 Turbo Pascal 的字串串接起始
（同 [spec 623](623-killthedude-damage-message.md)），它把常數**複製進區域變數**，
那兩組 push 是給 `62Fh` 用掉的，不是訊息 routine 的參數。

因此本輪只宣稱「推入了哪些數值、備妥了哪一個字串」，不宣稱訊息 routine 的完整
參數表。

## 參數順序：先推的是第一個參數

Turbo Pascal 由左而右推參數，所以**最先推入的是第一個參數**。要注意巢狀呼叫：
`f(t, g(a, b), c)` 會編成「推 `t` → 推 `a`、`b` → 呼叫 `g` → 推結果 → 推 `c` →
呼叫 `f`」，`a`／`b` 夾在 `f` 的參數中間。把呼叫前最靠近的 push 全算給那一個呼叫
會得到錯誤的參數表。

## 明確不宣稱

- `sub_1E8D`／`sub_3AE5`／`sub_F62`／`sub_3BF5`／`sub_3CB1` 的內部行為。
- `DS:0A521h:0A523h`（far pointer）與 `DS:0A031h`、`DS:9594h^[198h]` 的身分。
- `42C4h` 的 `1d6+20` 是傷害、持續時間還是別的。
- 這六支各自對應哪一個法術名稱。
