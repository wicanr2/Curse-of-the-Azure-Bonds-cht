# 1167 — 驅散不死接進 remake

- 證據等級：`exact`（矩陣逐 byte 取自資料段 dump，演算法照 spec 834）
- 前置：spec 834（演算法與矩陣）、spec 905（選單顯示條件）、spec 815（目標挑選）

## 為什麼這一支值得單獨做

牧師的驅散不死是 AD&D 一版的核心能力，而 remake 的戰鬥選單一直沒有它——
`移動　查看　瞄準　使用　施法　快速　結束` 七項，少了 `退散`。規格
（spec 834／905）早就 `READY`，缺的只是接線。

## 矩陣

`internal/combat/turnUndeadMatrix` 是 `DS:0367h` 那 100 個 byte，逐 byte 取自
`workplace/re-sweep/dos/dseg` 的資料段 dump，與 spec 834 的表一致。

⚠ **`0` 與 `−1` 不能統一。** 兩者的驅離／摧毀行為相同（`abs` 之後都必過、
`v ≤ 0` 都走摧毀），但額外配額那一條寫的是 `if 有號(v) < 0`——`0` 那幾格摧毀
之後**不會**把配額加回來。測試把這一點兩面釘住：同樣是自動摧毀、同樣三個目標、
同樣配額 1，欄 8（`−1`）做得到三個、欄 6（`0`）只做得到一個。

## 四條規則

- 1d20 只擲一次，整批共用；1d12 決定這一次最多影響幾個。
- 第一個沒過就整批停。
- 摧毀最多可以再多做 6 個（配額歸零時若這次是 `v < 0` 就加回 1）。
- 目標從最弱的開始（`+0E9h` 最小的）。

⚠ 「整批停」這一條**在目前的挑選順序下看不出差別**：矩陣每一欄由上往下不遞減，
而目標又是由弱到強，所以第一個沒過的後面一定也不會過。程式照原作寫 `break`，
但這是照抄不是被測試釘住的——換掉挑選器的話要重新想。

## 選單

`CombatMainMenuText()` 改成動態的（spec 905）：牧師槽等級 > 0 而且這一場還沒
驅散過（`TRIEDTOTURN` ＝ 0）才接上 `退散`，用過就消失。兩種排列各一條文字規則。

⚠ 條件裡**沒有**「場上要有不死生物」——原作照樣讓你按下去，然後印
`Nothing Happens...`。remake 跟著這樣做。

## 資料接線

| 欄位 | 來源 |
|---|---|
| `Fighter.UndeadType` | 怪物記錄 `+0E9h`（`UNDEADLEVEL`）|
| `Fighter.ClericLevel` | 隊員的職業與等級（牧師才有值）|
| `Fighter.TriedToTurn` | 22 bytes 戰鬥狀態的 `+11h` |
| 被驅離 | 目標的 `+18Dh^[10h]` ＝ `TURNED` ＝ 1（`RawCombatState10`）|
| 被摧毀 | HP 歸零、不留屍體（原作 `+195h := 8` Gone、`+196h := 0`）|

## 這一作幾乎用不到

`MON*CHA.DAX` 六章裡唯一的不死生物是 **DRACOLICH**。所以這個選項在《青色枷的
詛咒》裡幾乎沒有出場機會——但它是玩家預期會在選單上看到的東西，而且缺了它，
牧師的選單就與原作不同。

## 明確不宣稱

- 沒有宣稱聖騎士能不能驅散。原作的顯示條件是牧師槽的等級（spec 905），聖騎士
  的牧師槽在原版存檔裡是 0，所以這裡只認牧師。多職角色那條
  （`+111h > 0` 且 `far 0160h:0052h`）沒有接。
- 沒有宣稱十個種類各對應哪一種不死生物（同 spec 834）。
- 沒有接原作那四個未解讀的呼叫（`1944h`／`194Dh+1`／`1505h+4`／`1570h+2`）。
