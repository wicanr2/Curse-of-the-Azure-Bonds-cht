# 1077 — PC-98 選單核心：底部十格就是機能鍵列，每格 7 欄、第 24 列

- 證據等級：`exact`（PC-98 側 581 條逐條讀完，無匯出破洞）
- 作法見 spec 783；DOS 對側見 spec 1060

## `pc98 overlay-26:00133h`（`retf 16h`）

原本待解讀。範圍 `133h`..`81Bh`。這是 spec 1030／1031／1032／1043／1057／1069
一路呼叫的那支「選項列選單本體」的 **PC-98 版**，
與 DOS 的 `overlay-26:003D4h`（spec 1060）**`retf` 值相同（`16h` ＝ 22 bytes）**。

| 位移 | 用途 |
|---|---|
| `bp+18h`（`arg_12`） | 提示字串（上限 `28h` ＝ 40） |
| `bp+14h`（`arg_E`） | 第二行字串（上限 `50h` ＝ 80） |
| `bp+12h`（`arg_C`） | 印字用的一個 byte |
| `bp+10h`（`arg_A`） | 顏色索引 1 |
| `bp+0Eh`（`arg_8`） | 顏色索引 2 |
| `bp+0Ch`（`arg_6`） | ≠ 0 時數字鍵走方向換算表 |
| `bp+0Ah`（`arg_4`） | ≠ 0 時允許換頁動畫 |
| `bp+6`（`arg_0`） | `@輸出旗標`（byte） |

回傳 `al` ＝ 選到的字元。收尾另外把輸出旗標抄進 `DS:0A32Fh`。

## ★★★ 一、底部選單列的實體版面

`DS:15C0h` 起是一張 **10 筆 × 6 bytes** 的表，本支進門就把它填好：

| 欄位 | 內容 |
|---|---|
| `+0`..`+3` | 該格屬性 VRAM 的**遠指標**，段一律 `A200h` |
| `+4` | **上一格**的索引 |
| `+5` | **下一格**的索引 |

十個位移（`A200h:`）：`0F08h`、`0F16h`、`0F24h`、`0F32h`、`0F40h`、
`0F54h`、`0F62h`、`0F70h`、`0F7Eh`、`0F8Ch`。

`A200h` 是 PC-98 的**屬性平面**，一列 `0A0h` ＝ 160 bytes ⇒ `0F00h` ＝ **第 24 列**
（最下面一列）；一欄 2 bytes ⇒ 十格的欄號是

```
第 1..5 格：欄  4  11  18  25  32
第 6..10 格：欄 42  49  56  63  70
```

> ★★★ **每格 7 欄、兩組各 5 格、全部在第 24 列。**
> 「7 欄」正好對上 spec 1030 的 `DS:0A338h ＋ i × 7`
> ——那張表**一筆 7 bytes 就是一格 7 個半形欄位**，
> 而屬性字串是 `Chr(屬性) ＋ #0` 重複 7 次 ＝ `0Eh` ＝ 14 bytes。
> ⇒ **中文全形字一個佔 2 欄 ⇒ 一格最多 3 個全形字（第 7 欄只能留空白）。**
> ⚠ spec 1030 的「6 bytes 內容 ＋ 1 bytes 長度」不是排版寬度，
> 排版寬度是這裡的 **7 欄**。

## ★★★ 二、有提示字串時只用右邊五格

```pascal
if 提示字串 <> '' then begin
    if DS:0A385h < 6 then begin DS:0A385h := 6; DS:0A386h := 6 end;
    DS:0A335h := DS:0A33Ah;
    第6格.上一格 := 10;   第10格.下一格 := 6;      { 6..10 自成一圈 }
    起始格 := 6;
end else begin
    第6格.上一格 := 5;    第10格.下一格 := 1;      { 1..10 一整圈 }
    起始格 := 1;
end;
for i := 起始格 to 10 do 把 14 bytes 屬性字串寫進 第i格.屬性指標^;
```

> ★★★ **提示字串會佔掉左邊五格（欄 4..38），選項只剩右邊五格。**
> 環狀鏈也跟著改接，所以游標不會跑到被提示佔用的格子上。
> ⇒ 中文化時「提示 ＋ 選項」同時出現的畫面，**選項最多五個**。

## ★★ 三、游標與熱鍵陣列

```pascal
while byte[DS:0A334h ＋ DS:0A385h] = ' ' do          { 熱鍵是空白 ＝ 空格 }
    DS:0A385h := 第(DS:0A385h)格.上一格;
DS:0A386h := DS:0A385h;
<near 00B4h>(bp);                                     { 重畫游標 }
```

★ `DS:0A334h ＋ i` 是 spec 1030／1032 的**熱鍵陣列**，`DS:0A385h`／`0A386h`
是游標位置（spec 1057 已確認 `0A385h` 是初始游標）。
★ **熱鍵為空白的格會被自動跳過**——spec 1032 記的「PC-98 `T` 熱鍵留在空格上」
那個瑕疵，就是因為那一格熱鍵不是空白，這道跳過機制擋不住。

## ★★★ 四、按鍵分派表

取鍵用 `07E3:0206h`（是否有鍵用 `08EE:03B3h`）。

| 鍵 | 行為 |
|---|---|
| `'1'`..`'4'`、`'6'`..`'9'` | `arg_6 ≠ 0` → 查 `DS:49D8h ＋ (鍵 − '1')` 換成方向碼；<br>`arg_6 = 0` → 若鍵 **在集合 `CS:113h` ＝ `['1','3','7','9']`** 就回 0，否則原樣回傳 |
| `1Bh`（ESC） | 回 0 |
| `0Dh`（Enter）／`20h`（Space） | 取目前游標格的熱鍵；**是空白就不算數，繼續等** |
| `'a'`／`'A'` | 回 `10h`，並把輸出旗標設 1 |
| `'m'`／`'M'` | 回 `11h`，並把輸出旗標設 1 |
| `#0` ＋ `'b'`..`'k'`（`62h`..`6Bh`） | **直接選第 1..10 格**（取該格熱鍵；空白就不算數） |
| `#0` ＋ `3Ah` | 回 `'8'` |
| `#0` ＋ `3Bh` | 游標 := 上一格，重畫，繼續等 |
| `#0` ＋ `3Ch` | 游標 := 下一格，重畫，繼續等 |
| `#0` ＋ `3Dh` | 回 `'2'`，輸出旗標設 1 |
| `#0` ＋ `36h` | 回 `'9'`，輸出旗標設 1 |
| `#0` ＋ `37h` | 回 `'3'`，輸出旗標設 1 |
| 其他 | 回 0 |

> ★★★ **十個連號的擴充碼直接對到十格**，而那十格的版面正是
> 「第 24 列、每格 7 欄、分左右兩組五個」——**形狀上就是 PC-98 的機能鍵標籤列**。
> ⇒ **PC-98 版的熱鍵不必出現在選項文字裡**（DOS 靠掃字元，見 spec 1060），
> 所以**中文化必須跟 PC-98 這一套**：全形字放進 7 欄的格子，
> 熱鍵另外寫在 `DS:0A334h ＋ i`。
>
> ★★ `'8'`／`'2'`／`'9'`／`'3'` 這四個回傳值與數字鍵的方向碼同一組
> ——形狀上是方向鍵被翻成數字鍵盤的方向。
> ⚠ 本規格不宣稱 `#0` 後面那些碼各自對應哪個實體鍵。
>
> ★ `arg_6 = 0` 時被吃掉的正好是 `'1'`／`'3'`／`'7'`／`'9'` 四個**斜角**
> ——形狀上是「這個畫面不接受斜向」。

## 五、閒置動畫與逾時（與 DOS spec 1060 對照）

```pascal
起點 := GetTicks;  下次A := GetTicks ＋ 64h;  下次B := 下次A ＋ 96h;
{ 進入迴圈前與迴圈中，滿足下列條件才跑閒置動畫 }
if (DS:7F27h = 3) and (DS:0A32Bh = 'y') and (DS:0A325h <> 'P') then begin
    <overlay-27 entry#3/#4/#5>;                    { 進門一次 }
    …每過 64h tick 叫 entry#4、每過 96h tick 叫 entry#5…
end;

if (bank0^[3FEh] <> 0) or (arg_4 <> 0) then
    if DS:0A2C8h > 0 then begin
        <overlay-29 entry#1>(word[DS:0A2C5h ＋ 索引 × 8],
                             word[DS:0A2C7h ＋ 索引 × 8], arg_4, 3, 3);
        if 已過 28h tick 或 bank0^[3FEh] <> 0 then begin
            inc DS:0A2C8h;
            if DS:0A2C8h > DS:0A2C6h then DS:0A2C8h := 1;
        end;
    end;

if (DS:0A330h/0A332h 這個 32-bit 逾時 > 0) and 已過那麼久 then begin
    結果 := DS:0A334h;  結束;                       { ★ 逾時自動送鍵 }
end;
…
離開前：bank0^[3FEh] := 0;
```

| | DOS（spec 1060） | PC-98 |
|---|---|---|
| 閒置條件 | `DS:4FBAh = 3`、`DS:7290h = 'y'`、`DS:728Ah <> 50h` | `DS:7F27h = 3`、`DS:0A32Bh = 'y'`、`DS:0A325h <> 'P'` |
| 動畫間隔 | `1Eh` tick | `64h` ／ `96h` tick |
| 換頁計數／上限 | `DS:722Dh` ／ `DS:722Ch` | `DS:0A2C8h` ／ `DS:0A2C6h` |
| 換頁間隔 | `0Ah` tick | `28h` tick |
| 逾時／逾時送出的鍵 | `DS:7296h/7298h` ／ `DS:729Ah` | `DS:0A330h/0A332h` ／ `DS:0A334h` |
| 觸發旗標 | `bank0^[3FEh]` | **同一格** |

★ `'P'` ＝ `50h`：**兩平台是同一個判斷**（DOS 寫成數值、PC-98 寫成字元），
即 spec 1029 的圖片子索引。
★ 逾時送出的鍵取自 `DS:0A334h` ＝ 熱鍵陣列的**第 0 格**（十格是 1..10，
第 0 格不是選項）。

## 中文化

本支沒有字串常數，但**它決定了整個 PC-98 選單的排版上限**：

- 一格 **7 個半形欄** ⇒ **全形最多 3 個字**，第 7 欄要留空白。
- 有提示字串時**只剩右邊五格**（提示自己上限 40 bytes ＝ 全形 20 字）。
- 熱鍵寫在 `DS:0A334h ＋ i`，**不必出現在文字裡** ⇒ 中文選項可以完全不含英文字母。
- 第二行字串上限 `50h` ＝ 80 bytes ＝ 全形 40 字。

## 明確不宣稱

- 沒有宣稱 `near 00B4h`（重畫游標那一支）怎麼畫。
- 沒有宣稱 `DS:49D8h` 那張 8 筆方向換算表的內容。
- 沒有宣稱 `'a'`／`'A'` → `10h` 與 `'m'`／`'M'` → `11h` 兩個特例代表什麼。
- 沒有宣稱 `#0` 後面那些擴充碼對應哪些實體鍵。
- 沒有宣稱 `DS:0A2C5h`／`0A2C7h` 那張 8 bytes 一筆的換頁表的內容。
- 沒有宣稱 `DS:0A32Fh`（收尾抄進去的輸出旗標）由誰讀。
- 沒有宣稱 `DS:0A335h := DS:0A33Ah` 這一行（有提示字串時才做）的用意。
- 沒有宣稱 `0893:0177h`、`0418:044Ah`、`0418:0DA5h`、`07E3:02C7h` 四支
  resident helper 的介面。
