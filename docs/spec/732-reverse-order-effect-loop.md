## 和 `sub_F06h`（spec 731）的差別

| | `sub_F06h` | `1ABFh` |
|---|---|---|
| 走訪順序 | 第 1 格 → 最後一格 | **最後一格 → 第 1 格** |
| 傷害 | 有（`entry#20`） | 完全沒有 |
| 表格索引 | `arg_C`（＝`DS:6F97h`） | 一律 `DS:6F97h` |
| 特例 | `表.+2 = 0FFh` 那一段 | 兩處強制豁免 |
| 等級 | 可由參數覆寫 | 一律 `entry#36` |

**順序相反這件事會影響結果**：spec 711 的「最多影響 N 個」是由前往後扣預算，
而這一支由後往前處理。兩支對同一個目標陣列的「誰先被處理」剛好相反。

## 兩處強制豁免

**第一個處理到的目標（`k = DS:7434h`）遇上法術 `4Fh`／`51h` 時直接算豁免成功**，
連骰都不擲。也就是那兩個法術對「陣列最後一格」的單位無效——由於順序是倒著走，
那是**最先被處理**的那一個。

**`p^[11Ah] > 1` 或 `p^[0DEh] > 1` 的目標一律豁免成功**，除非法術是 `5Eh`。
這是免疫規則，`5Eh` 是唯一能穿透的。

`+11Ah` 在 spec 710 的 `56C4h` 也被讀（`= 12h` 時旗標 0），所以它是同一個欄位的
兩種用法。

## 動畫只從第二個目標開始播

`if k < DS:7434h` 把第一次迭代排除掉。所以連鎖型法術的第一段動畫是由呼叫端負責，
這一支只補後面幾段。

## 明確不宣稱

- 法術編號 `4Fh`／`51h`／`5Eh` 是哪三個法術。
- `+11Ah`、`+0DEh` 是什麼欄位。
- `word [25B0h]`、`0713:0020h` 的意義（spec 687 也看過同一支）。
