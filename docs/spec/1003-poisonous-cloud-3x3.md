# 1003 — 毒雲是 3×3，與毒霧共用同一套機制

- 證據等級：`exact`（DOS 側 546 條逐條讀完；PC-98 對側 559 條相似度 0.999）
- 作法見 spec 783

## `dos overlay-22:04F3Eh` ↔ `pc98 overlay-22:052E0h`

兩側原本都是待解讀。字串 `CS:4F24h` ＝ `'Creates a poisonous cloud'`（25 字元）。

**流程與 spec 999 的毒霧（`02799h`）逐段相同**，只有六個地方不一樣：

| | 毒霧 `02799h`（spec 999） | 毒雲 `04F3Eh`（本規格） |
|---|---|---|
| 訊息 | `'Creates a noxious cloud'` | `'Creates a poisonous cloud'` |
| 鏈頭 | `DS:755Bh` | **`DS:755Fh`** |
| 效果碼 | `28h`（40） | **`5Bh`（91）** |
| 格子序列表 | `DS:27D7h` | **`DS:27DBh`** |
| 格數 | **4** | **9** |
| 地圖值 | `1Eh`（30） | **`1Ch`（28）** |

其餘完全一致：節點 30 bytes（`GetMem 1Eh`）、`+0` 施法者、`+4` next、
`+1Ah`／`+1Bh` 中心座標、`+1Ch` 實例編號、
`overlay-23 entry#11(角色, 效果碼, 等級, 等級 ＋ (n shl 4), 1)`、
`overlay-32 entry#9` 讀兩平面、`DS:26A2h` 地磚查表的 `0FFh` 哨兵、
收尾的訊息／`overlay-32 entry#13`／`0542h:0B33h`／`entry#21`／`entry#5`。

## ★★ 兩張格子序列表在記憶體裡是連續的

`DS:27D7h` 起的 bytes：

```
27D7h:  00 08 02 03 04   08 00 01 02 03 04 05 06 07   00 05
        └── 毒霧用 ──┘   └────────── 毒雲用 ──────────┘
           索引 1..4          （27DBh 的索引 1..9）
```

- **毒霧**（`27D7h`，索引 1..4）＝ `8, 2, 3, 4` ＝ **原地、右、右下、下** ⇒ **2×2**
- **毒雲**（`27DBh`，索引 1..9）＝ `8, 0, 1, 2, 3, 4, 5, 6, 7`
  ＝ **原地 ＋ 八個方向** ⇒ **3×3**

兩張表**共用同一段位元組**：毒雲表的起點就是毒霧表的第 5 個 byte。
索引 0 兩張都用不到（迴圈從 1 開始）。

九個方向碼直接對上 spec 999 的九格位移表（`DS:2694h`／`DS:269Dh`），
所以毒雲蓋滿中心格的八個鄰居——**標準的 3×3 方塊**。

## ★ 節點的 `+11h`..`+19h` 是九格旗標

毒雲寫 `p^[10h ＋ i] := …`，`i = 1..9` ⇒ `+11h`..`+19h`。
spec 999 讀毒霧時只看到 `+11h`..`+14h` 被寫，當時記成「四個格子各一個 byte」，
其餘留 `FillChar` 的 0。

> **30 bytes 的雲節點裡，`+11h`..`+19h` 是一個九格的旗標陣列，
> 毒霧只用前四格。**

節點版面因此補完：

| 位移 | 內容 |
|---|---|
| `+0`（dword） | 施法者遠指標 |
| `+4`（dword） | next |
| `+8`..`+10h` | 未寫入（`FillChar` 後為 0） |
| **`+11h`..`+19h`** | **九格旗標**（1 ＝ 這一格算數） |
| `+1Ah` | 中心 x |
| `+1Bh` | 中心 y |
| `+1Ch` | 實例編號 |
| `+1Dh` | 未寫入 |

## ★ 兩種雲各自一條鏈

鏈頭 `DS:755Bh`（毒霧）與 `DS:755Fh`（毒雲）**相差 4 bytes**——
形狀上是一個「每種雲一個鏈頭」的遠指標陣列。
本規格不宣稱那個陣列有幾格。

## 中文化

`'Creates a poisonous cloud'`（25 字元）接在名字後面，語序與中文相同，
可以直接換字串。但它走的是 `overlay-24 entry#20` 的**戰鬥訊息框**
（spec 982），**一行只有 8 個漢字**——「◯◯◯製造了一團毒雲。」要折兩行。

⚠ 兩句訊息只差 `noxious`／`poisonous` 一個形容詞。中文若都翻成「毒雲」
就分不出來——`1Eh` 與 `1Ch` 是兩種不同的地圖格、效果碼也不同
（`28h` 對 `5Bh`），**遊戲機制上是兩種東西**，譯名要能區分。

## 明確不宣稱

- 沒有宣稱效果碼 `28h`／`5Bh` 各對應哪個法術。
- 沒有宣稱「該格已經有雲」時的合併規則細節（兩支都有這一段）。
- 沒有宣稱鏈頭陣列的長度。
- 沒有宣稱節點 `+8`..`+10h` 與 `+1Dh` 的用途。
