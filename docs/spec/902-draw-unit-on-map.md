# 902 — 把一格畫出來：地圖記錄的版面就此定案

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼完全相同，19 條差異全是位址）
- 作法見 spec 783

## `overlay-32:00174h` ↔ `overlay-32:0012Eh`（兩平台各 190 條）

`retf 4` ＝ 兩個 byte：`(座標x, 座標y)`。

```pascal
地圖 := 遠指標(DS:6E92h);
基x := 座標x − 地圖^[2];                        { 換算成視窗內座標 }
基y := 座標y − 地圖^[3];

for i := 0 to 3 do begin                        { 一個單位最多四格 }
    if not <本模組 0011h>(var dy, var dx, i, 地圖^[5]) then continue;
    if not <本模組 0732h>(基y ＋ dy, 基x ＋ dx) then continue;   { 在視窗內？ }

    地形 := 地圖^[7 ＋ (座標y ＋ dy) * 32h ＋ (座標x ＋ dx)];
    <far 0196h:002Fh>(0, byte[26A5h ＋ 地形 * 4],
                      (基y ＋ dy) * 3, (基x ＋ dx) * 3);

    if 地圖^[4] <> 0 then
        <far 0196h:003Eh>(19h, 0, 0, 基x ＋ dx, 基y ＋ dy);
end;

<本模組 0509h>(var 佔用者, var 未用, 座標y, 座標x);

if (佔用者 > 0) and <本模組 0763h>(0, 遠指標(DS:6D35h ＋ 佔用者 * 4)) then begin
    p := 遠指標(DS:6D35h ＋ 佔用者 * 4);
    <far 0196h:003Eh>(p^[143h], 0, p^[18Dh]^[9],
                      byte[680Eh ＋ 佔用者], byte[67C6h ＋ 佔用者]);
end;
```

## `遠指標(DS:6E92h)` ＝ 地圖記錄，版面定案

spec 852 讀到 `DS:6E92h..6E95h` 是一個遠指標，spec 860 讀到它被當成
「地圖」原樣轉給 `overlay-31:03EAh`。**本支給出它指向的東西長什麼樣**：

| 位移 | 內容 |
|---|---|
| `+2` | 視窗左上角的 **x** |
| `+3` | 視窗左上角的 **y** |
| `+4` | 旗標（≠ 0 時每格多畫一層 `19h`） |
| `+5` | 傳給 `本模組 0011h` 的**體型參數** |
| `+7` 起 | **地形碼陣列，每列 `32h` ＝ 50 欄** |

`32h ＝ 50` 與 spec 888 讀到的地圖夾限 `x ∈ 0..49`**完全一致**，
兩支互相定界。

## `DS:26A5h` ＝ 地形表的圖磚欄

`26A5h ＝ 26A2h ＋ 3`，也就是地形表（每筆 4 bytes）的 `+3`
——`resident-data-tables.md` 早就記著「`+0` 移動成本、`+1`／`+2` 視線、
`+3` 圖磚」。**本支是 `+3` 第一次被實際使用**，證實它就是圖磚編號。

spec 896 用的是同一張表的 `+0`（移動成本），兩支各取一欄。

## 座標乘 3

貼圖前 `(基y ＋ dy) × 3`、`(基x ＋ dx) × 3`——與 spec 880（sprite 貼上）
與 spec 890（戰鬥動畫）同一個換算：**格子座標 × 3 ＝ 貼圖座標**。

`DS:67C6h`／`DS:680Eh` 是 spec 890 定的戰鬥員畫面座標，
`DS:6D35h` 是 spec 852 的戰鬥員遠指標陣列，`+143h` 是 spec 873 的圖像編號。
**這一支把五張既有結構一次接起來。**

## PC-98：19 條差異全是位址

`DS:6E92h`↔`9F2Ch`、`DS:26A5h`↔`48AFh`、`DS:6D35h`↔`−6231h`、
`+18Dh`↔`+18Eh`。**助憶碼序列完全相同，沒有邏輯差異。**

## 明確不宣稱

- 沒有宣稱地圖記錄 `+0`／`+1`／`+6` 三格是什麼。
- 沒有宣稱 `本模組 0732h(y, x)` 的判斷（形狀上是「在不在視窗內」）。
- 沒有宣稱 `far 0196h:002Fh` 與 `003Eh` 的完整簽章。
- 沒有宣稱 `19h` 那一層畫的是什麼。
