# 974 — 力量的第三張表：AD&D 1e 負重加值，並把 `+1Ch` 定名為百分位力量

- 證據等級：`exact`（三支逐條讀完；表格值與 AD&D 1e 逐格對照）
- 作法見 spec 783

## `dos overlay-24:0148Fh`（90 條，`retf 4`）— 未曾判讀的第三張力量表

```pascal
i := <本模組 129Ah>(角色);                 { 0..30 的力量索引，spec 694 }
case i of
  1..3   : 結果 := −350;
  4..5   : 結果 := −250;
  6..7   : 結果 := −150;
  0Ch,0Dh: 結果 := 100;
  0Eh,0Fh: 結果 := 200;
  10h    : 結果 := 350;
  11h..15h: 結果 := (i − 11h) × 250 + 500;
  16h..1Ah: 結果 := (i − 16h) × 1000 + 2000;
  1Bh    : 結果 := 7500;
  1Ch..1Eh: 結果 := (i − 1Ch) × 3000 + 9000;
else       結果 := 0;
end;
```

**二十一格全中**，而且**力量 1 這一格沒有被併掉**（傷害表與命中表都把 1 併進 2，
見 spec 694／697；這一張三格 1..3 本來就同值，所以看不出併不併）。

### 這關掉了 spec 683 的一個未宣稱項

spec 683 的 `03C5h` 寫成

```text
w := 角色^[187h] − <sub_148F>(角色)
```

並在「明確不宣稱」留了「`sub_148F` 算的是什麼（從用法看像是可承重）」。
現在確定：**`+187h` 是背負總重，`148Fh` 是力量給的負重加值**，
相減後的超重量再去比 `200h`／`300h`／`400h` 三道門檻決定移動力階梯。
「像是可承重」這個推測是對的，該項可以關閉。

⚠ 注意這三張表**不共用閘門**：傷害（`13FDh`）與命中（`1345h`）都先看
`角色^[125h] = 0` 就回 0，**負重這一張沒有這道閘門**——任何角色都吃得到。

## `pc98 overlay-24:01498h`（62 條）＝ DOS `0129Ah` 的對應

逐條同構，14 個差異區塊全部是 **碼型差異（spec 783 的 (c) 類）**：
DOS 用 `xor ah,ah` ＋ 有號 `jl`／`jg`，PC-98 直接 `cmp al` ＋ 無號 `jb`／`ja`。
對 byte 值而言結果相同。

★ **`+1Ch` 就是百分位力量，這一支是決定性證據。** `+11h`（力量，spec 857）
等於 `12h`（18）時，才會去讀 `+1Ch` 並照

```
0 → 18        1..50 → 18/01–50      51..75 → 18/51–75
76..90 → 18/76–90    91..99 → 18/91–99    100 → 18/00
```

分成六階。**這正是 AD&D 的 18/xx 例外力量分段**，而且五個界線
（50／75／90／99／100）與規則書完全一致。spec 857 當時只寫「形狀上是
AD&D 的 18/xx 百分位力量」，現在可以定名，該處已改。

⚠ **spec 694 記的「兩條路徑不會寫入回傳變數」PC-98 也一模一樣**：
`+11h` 落在 0..25 之外（且不等於 18）、以及 `+11h = 18` 但 `+1Ch > 100` 時，
`var_1` 從未被指派，回傳的是堆疊殘值。**兩平台同一個缺陷**，不是反組譯誤差。

## `pc98 overlay-24:01530h`（67 條）＝ DOS `01345h` 的對應（命中調整）

閘門、索引來源、二十一個區間的值與 spec 697 的 DOS 版**逐格相同**：

```
i = 1..3 → −3   4..5 → −2   6..7 → −1   8..16 → 0
i = 17..19 → +1   20..22 → +2   23..25 → +3   26..27 → +4   28..30 → i − 23
```

18 個差異區塊同樣全是有號／無號碼型與位址。閘門 `角色^[125h] = 0 → 回 0`
兩平台都有。

## 中文化

三張表都是純數值，沒有字串。但**負重加值的單位是 gp／coin**，
數字會出現在角色狀態畫面上（`+187h` 的總重旁邊），中文化時單位詞
要跟遊戲內既有的重量單位一致。

## 明確不宣稱

- 沒有宣稱 `角色^[125h]` 是什麼（傷害與命中兩張表的閘門，負重這張沒有）。
- 沒有宣稱 `+187h` 的單位與累加來源。
- 沒有宣稱 `pc98 overlay-24:01659h`（DOS `148Fh` 的對側，目前標為邊界碎片）
  的內容是否也是這張表。
