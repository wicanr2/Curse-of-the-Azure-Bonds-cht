# 1025 — 粒子動畫的一幀：3 × 40 顆、8.5 定點座標、每 6 幀一次重力

- 證據等級：`exact`（DOS 側 234 條、PC-98 側 235 條，兩邊各自逐條讀完）
- 作法見 spec 783

## `dos overlay-18:004DFh` ↔ `pc98 overlay-18:003DCh`（`retf 8`）

兩側原本都是待解讀。整支沒有字串。這是一支**巢狀程序**——
`bp+06h` 收的是父函式的 `bp`（本體讀 `ss:[父bp − 6]` 當幀計數）。

```pascal
procedure 走一幀(色階上限: byte;    { bp+0Ch }
                 粒子陣列: 遠指標;  { bp+08h..0Bh }
                 父bp:     word);   { bp+06h }
```

## ★★ 陣列版面：3 列 × 40 行，每顆 23 bytes

```pascal
粒子 := 陣列 ＋ 列 × 398h ＋ 行 × 17h − 3AFh;   { 0FC51h ＝ −3AFh }
for 列 := 1 to 3 do for 行 := 1 to 40 do …
```

`398h ＝ 920 ＝ 40 × 23`、`17h ＝ 23` ⇒ **每列 40 顆、每顆 23 bytes、共 120 顆**。
索引從 1 起算，所以基底要先減 `3AFh`（＝ `398h ＋ 17h`）。

| 位移 | 內容 |
|---|---|
| `+2`（word） | 顯示用的橫座標（畫之前檢查範圍） |
| `+4`／`+6`（word） | **顯示座標 ＝ 累加器 ÷ 32** |
| `+8`／`+0Ah`（word） | x／y 累加器（8.5 定點） |
| `+0Ch`／`+0Eh`（word） | x／y 速度 |
| `+10h`（byte） | 目前色階（0..5） |
| `+11h`（byte） | 目標色階 |

## ★★ 物理：定點座標、重力、水平阻力

```pascal
粒子.x累加 += 粒子.x速度;
粒子.y累加 += 粒子.y速度;
粒子.顯示x := 粒子.x累加 div 32;        { ★ 8.5 定點 }
粒子.顯示y := 粒子.y累加 div 32;

if (幀 mod 6) = 0 then inc(粒子.y速度);  { ★ 每 6 幀加一次重力 }

if 粒子.x速度 > 0 then dec(粒子.x速度)   { ★ 水平阻力：往 0 收斂 }
else if 粒子.x速度 < 0 then inc(粒子.x速度);

if (粒子.目標色階 > 色階上限) 之類的條件成立 then …;
if (粒子.目前色階 < 粒子.目標色階) and (粒子.目前色階 < 5) then
    inc(粒子.目前色階);                   { ★ 色階逐幀 +1，上限 5 }
```

★ **座標用 `div 32` 的 8.5 定點**——速度可以小於一個像素，
所以水平阻力（每幀 ±1）是很細的減速。

★ **重力不是每幀加，是每 6 幀加一次**（`幀 mod 6`），
所以拋物線比較平緩。

## 三趟迴圈

同一組 3 × 40 走三次：

1. **物理**：更新累加器、顯示座標、重力、阻力、色階。
2. **畫**：`8 < 粒子.顯示x < 65`（PC-98 是 `< 66`）才叫 `sub_0(粒子.目標色階, …)`。
3. **再畫一次**：條件相同，但顏色改成
   `byte[4ACDh ＋ 列 × 5 ＋ 目前色階]`——**每一列自己一條 5 階的顏色斜坡**。
   最後 `粒子.目前色階 = 2` 時另外叫 `sub_6A`。

⚠ 那張顏色斜坡表在靜態映像裡是 `0FFh`，**執行期才填**（PC-98 在 `DS:7BA3h`）。

## 兩平台差異

只有兩處：

| | DOS | PC-98 |
|---|---|---|
| 右邊界 | `< 41h`（65） | **`< 42h`（66）** |
| 顏色斜坡表 | `DS:4ACDh` | `DS:7BA3h` |

陣列版面（`17h`／`398h`／`−3AFh`）與物理常數（`6`、`32`、`5`）**兩平台完全相同**。
