# 第三百五十輪：散塔林堡迪姆斯沃特同行

Status: `READY`

## 目標

延續規格 349 的奧莉芙密道：在貝恩幽暗神殿中找到賢者迪姆斯沃特，完整閱讀
手札 12 的五道枷印與三件神器說明，接受他同行，再回到可操作的神殿地圖。

## 原版證據

- `ECL4.DAX` block `0x21`、`GEO4.DAX` block `0x21`：
  - `(6,13)` terrain `0x84`、PICTURE 42：奧莉芙再次現身，指示迪姆斯沃特
    在南邊牢房，並再次觸發手札 51 說明。
  - `(2,14)` terrain `0x85`、PICTURE 35：牢房老人自我介紹，解鎖手札 12。
  - 後續選單是 `WILL YOU TAKE DIMSWART ALONG?`、`YES/NO`。
- 選 `YES` 後回到同一 `GEO4/0x21` 地城；再次進入 `(2,14)` 不會重播事件，
  證實 ECL 保存一次性同行狀態。
- 接受前後正式 fighter roster 人數不變。這與攻略「迪姆斯沃特不占正式隊員
  欄」一致；不得臆造 `ADD NPC` 或塞入戰鬥隊伍。
- 手札 12 原文取自隨附 *Adventure Journal* TXT，內容涵蓋五個枷印勢力、
  摩安德／散塔林會／德拉坎德羅斯／提朗瑟克斯，以及洛山達護符、龍之頭盔、
  摩安德護手。

## 資料與引擎邊界

- 人名、敘事、手札六頁與 text matching rules 屬 CoAB JSON game pack。
- 通用引擎只保留 ECL choice、work memory 與一次性事件執行能力，不認識
  Dimswart 或任何 CoAB 神器。
- 迪姆斯沃特是 story escort flag；在找到 ADD NPC 或戰鬥 participation 的
  原版證據前，不投影為 `combat.Fighter`。

## 繁中與長文

- 手札 12 拆成六頁，保留賢者逐層分析的小說式節奏，不縮成任務摘要。
- 術語統一使用：散塔林會、火焰匕首、摩安德、摩貢、德拉坎德羅斯、
  提朗瑟克斯、光芒之池、洛山達護符、龍之頭盔、摩安德護手。
- 顯示沿用 640×480 與倚天 16×15 粗體正文。

## 驗收

1. 真實 `(6,13)` 顯示 PICTURE 42 與繁中南方牢房提示。
2. continuation 的手札 51 提示仍為繁中，且不重複加入既有頁面。
3. 真實 `(2,14)` 顯示 PICTURE 35、繁中會面文字並加入手札 12 六頁。
4. `YES/NO` 顯示「是／否」，問句顯示「要讓迪姆斯沃特同行嗎？」。
5. 選「是」後回到 `ModeDungeon`、`GEO4/0x21`。
6. fighter roster 不新增假 NPC；重訪牢房不重播會面。
7. focused real-image test 與完整 Docker/Xvfb regression 通過。
