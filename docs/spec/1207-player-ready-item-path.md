# Spec 1207：玩家整備／卸下物品路徑

狀態：**READY**（2026-08-26）

## 玩家可見缺口

商店會依原版把新購物品存成 `Readied=false`，戰鬥投影也只計入已整備物品；但
remake 原先沒有任何玩家選單可切換此旗標。因此玩家即使買了盔甲與盾牌，進入
戰鬥仍是 AC 10。這不是平衡問題，而是「商店資料 → 角色裝備規則 → 戰鬥」垂直鏈
少了一段正式 UI。

未撐隊伍的按鍵診斷在皇家衛兵戰記錄到六名角色全為 AC 10；五名皇家衛兵為
AC 4、21 HP。既有宣稱通過該戰的測試則把單一測試角色改成 20,000 HP、AC -10、
攻擊與傷害 +100，不能作為一般玩家路徑證據。

## 原版契約

直接沿用 READY spec 907 的 DOS／PC-98 `READYITEM` 精確證據：

- 選取未整備物品時，先檢查職業遮罩、裝備槽、雙手／副手衝突與戒指上限，再設
  `Readied=true`。
- 選取已整備物品時嘗試卸下；詛咒物品拒絕卸下。
- 商店購買本身不自動整備。

本輪沒有改動上述規則，也沒有新增自動穿裝。

## Remake 實作

營地「查看」現在形成正式玩家路徑：

1. 選擇角色。
2. 顯示每件背包物品的「裝備中／未裝備」狀態。
3. 選取物品時呼叫既有 `party.Character.EquipItem`／`UnequipItem`。
4. 成功後立即用原版 ITEMS 目錄重算該角色的戰鬥投影；失敗時保留原狀並顯示
   本地化拒絕訊息。
5. 可返回角色清單與原營地選單。

## 驗證

- `TestCampViewReadiesEquipmentAndReprojectsArmorClass`：以未整備板甲與盾牌進入營地，
  兩次玩家選擇後旗標皆為 true，戰鬥 AC 由 10 變為 3；再把板甲標成詛咒並嘗試
  卸下，確認仍維持整備且顯示拒絕訊息。
- `TestCampMenuViewCharacterAndReturn`：無裝備角色仍可查看摘要，並可由物品頁返回
  角色清單與營地。
- 一般強度皇家衛兵長跑尚未成為此功能的完成證據：目前自動策略會在戰前商店
  啟發式流程中把裝備賣掉。這是驗證器待辦，不能反向解讀成整備 UI 失敗或一般
  隊伍已能通關。
