
## 追加紀律：參數順序一律「先推的先宣告」

Turbo Pascal 由左至右推參數，所以**堆疊上最先被推的那個，就是原始碼裡宣告的第
一個參數**（位址最高）。實務上很容易寫反，因為閱讀反組譯時看到的順序與宣告順序
相反。

2026-08-14 的一次自我稽核抓到四處寫反（spec 807 的 `16ABh+3`、spec 819 的
`145Dh` / `1457h+1` / `1462h`、spec 822 的 `0167h:003Eh`），正文與台帳條目都已
更正。

**寫進 spec 之前，把呼叫點的 `push` 由上往下抄一次，第一個 `push` 就是第一個
參數**——不要憑印象排。遠指標推兩個 word（節區在前、位移在後），算**一個**參數。
