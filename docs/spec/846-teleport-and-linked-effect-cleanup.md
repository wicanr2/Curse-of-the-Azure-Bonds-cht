## 效果節點的 `+3` 在這裡被當成戰鬥員索引

```pascal
if 遠指標(DS:6D35h + 節點^[3] * 4) = p then …撤掉…
```

`DS:6D35h` 是戰鬥員遠指標陣列（spec 833／838），`節點^[3]` 拿去當索引，
結果跟施法者比對——**在這一支裡它的作用是「這個效果是誰放的」**。

⚠ 不能就此把 `+3` 定名。spec 847（龍息）拿同一個結構的 `+3` 跟 `0FDh` 比、
大於就減 1，那是計數器的用法。兩種用法目前**還沒有調和**，在讀到更多呼叫點之前
本規格只宣稱「這一支把它當索引用」。

傳送時把場上每一個帶有效果 `90h`（144）或 `8Bh`（139）、而且**施加者是自己**的
目標，兩個效果一起撤掉。形狀上是「維持型法術的施法者離場，效果跟著斷」。

⚠ 判斷式是 `有 90h 或 有 8Bh`，但撤除是**兩個都撤**——只帶其中一個的目標，
另一個會被多撤一次（`143Dh+2` 對沒有的效果是不是無害，本規格不宣稱）。

## `DS:6E92h` 那塊緩衝的版面

| 位移 | 內容 |
|---|---|
| `DS:6E92h`..`6E95h` | 遠指標（傳給 `18ABh+3` 用） |
| `DS:6E96h` | **筆數** |
| `DS:6E97h` 起 | 每筆 3 bytes，`+0` 是戰鬥員索引 |

索引式寫成 `byte[6E94h + i × 3]`，`i` 從 1 起算，所以第一筆落在 `6E97h`。

spec 838 讀到同一塊緩衝時只知道呼叫前要清 `^[6]`——那正好是 `6E92h + 6` ＝ `6E98h`，
在第一筆記錄的中間。**兩處對得起來但語意還沒閉合**，本規格不下結論。

## 明確不宣稱

- 沒有宣稱效果碼 `3Ah`／`8Bh`／`90h` 各是什麼法術。
- 沒有宣稱 `far 18ABh+3` 那六個參數的意義（形狀上是「把附近的戰鬥員收進緩衝」，
  `0FFh` 落在半徑的位置）。
- 沒有宣稱 `far 1912h`／`193Ah`／`1947h+2`／`191Fh+2` 各做什麼。
- 沒有宣稱 `DS:7559h`／`DS:755Ah` 裝什麼（形狀上是傳送目的地座標）。
- 沒有宣稱效果節點 `+3` 之外的欄位。
