# 877 — 休息時間設定：天／時／分三欄，加減與方向鍵

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側差異逐條列出）
- 作法見 spec 783

## `overlay-20:00712h`（DOS 131 條）↔ `overlay-20:0073Ah`（PC-98 140 條）

`overlay-20` ＝ CLOCK。`retf` ＝ 無參數，回 `al`。
DOS 的選單字串是一整條：**`'Rest Days Hours Mins Add Subtract Exit'`**
——七個選項的字首正好是下面用到的七個熱鍵。

```pascal
確定 := 0;  欄 := 2;
repeat
    <本模組 05D4h>(欄);                               { 反白目前欄位 }
    鍵 := <far 0167h:002Fh>(var 有選中, 0, 1, 0Fh, 0Ah, 0Dh);

    if 有選中 <> 0 then
        case 鍵 of                                     { 方向鍵轉成字母 }
          48h (↑): 鍵 := 'A';
          50h (↓): 鍵 := 'S';
          4Bh (←): begin inc(欄); if 欄 > 4 then 欄 := 2; 鍵 := 'X' end;
          4Dh (→): begin dec(欄); if 欄 < 2 then 欄 := 4; 鍵 := 'X' end;
        else       鍵 := 'X';
        end;

    if 鍵 = 0Dh then 鍵 := 'R';                        { Enter ＝ Rest }

    case 鍵 of
      'R': 確定 := 1;
      'D': 欄 := 4;                                    { Days }
      'H': 欄 := 3;                                    { Hours }
      'M': 欄 := 2;                                    { Mins }
      'A': begin                                       { Add }
              if 欄 = 2 then DS:7568h := DS:7568h + 5
              else           inc(word[7566h + 欄 * 2]);
              <本模組 0385h>();
           end;
      'S': begin                                       { Subtract }
              if 欄 = 2 then <本模組 045Eh>(1, 5)
              else           <本模組 045Eh>(欄, 1);
              <本模組 0385h>();
           end;
    end;
until not <0A54h:08D4h>(離開鍵表, 鍵);
結果 := 確定;
```

## 三欄對上時鐘的三個單位

`DS:7566h` 是時鐘各單位的陣列（word），索引與 `DS:3E2Ah` 的進位表
（10／10／6／24／30／12／256，spec 793／802）同一套：

| 索引 | 進位上限 | 單位 | 本支的欄位 |
|---|---|---|---|
| 1 | 10 | **分** | 欄 2（`Mins`），位址 `DS:7568h`，每次 ±**5** |
| 2 | 6 | 10 分 | — |
| 3 | 24 | **小時** | 欄 3（`Hours`），每次 ±1 |
| 4 | 30 | **天** | 欄 4（`Days`），每次 ±1 |

索引 3 的進位上限 24 是「小時 → 天」、索引 4 的 30 是「天 → 月」，
所以三欄的單位由進位表反推就定下來了，不必靠字串猜。
分那一欄步進 5，與 `045Eh(1, 5)` 的減法參數對稱。

⚠ 加法直接 `inc`／`+5`，**沒有做進位**；進位由 `本模組 0385h` 或別處處理，
本支沒有讀到上限檢查。

## PC-98：方向鍵碼不同，熱鍵字串再一次獨立

| | DOS | PC-98 |
|---|---|---|
| ↑ ↓ ← → | `48h` `50h` `4Bh` `4Dh` | `38h` `32h` `34h` `36h` |
| 迴圈開頭 | — | 多叫一次 `本模組 05D2h`，並把 `DS:136Ah` 的 10 bytes 指派到 `DS:0A335h` |
| 堆疊框 | `2Ch` | `56h` |

`DS:0A335h` 就是 spec 865／871 那個熱鍵緩衝——**這是該模式的第六個出現點**。

**字母熱鍵 `R`／`D`／`H`／`M`／`A`／`S` 兩平台完全相同**
（對齊區段沒有任何 `cmp al, 44h` 之類的差異）。所以 PC-98 的作法是
「畫面標籤換成日文、熱鍵字母原封不動、另外存一份 ASCII 給提示用」。
中文版照這個作法即可。

堆疊框 `2Ch`↔`56h` 是字串緩衝 40→80 的連帶（spec 859）。

## 明確不宣稱

- 沒有宣稱 `far 0167h:002Fh` 的六個參數（形狀上是「畫選單收一個鍵」）。
- 沒有宣稱 `本模組 0385h`（每次加減後都叫）與 `05D4h`／`05D2h` 做什麼。
- 沒有宣稱 `'X'`（`58h`）這個「什麼都不做」的哨兵有沒有別的用途。
- 沒有宣稱回傳 1 之後由誰真的推進時間（形狀上是交給 `overlay-20:00020h`，spec 849）。
