# 791 — 依 `+18Dh^[3]` 挑人（隨機決勝）、`DS:7573h` 那條倒數的另一半

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-08:01ABh`（entry#3，68 條，差異 6 條）— 挑出優先度最高的角色

```pascal
最佳值 := 0;  最佳骰 := 0;
p := DS:650Ah;
while p <> NIL do begin
    骰 := <0141h:004Dh>(1, 64h);                  { 1..100 }
    v := 有號(p^[18Dh]^[3]);
    if v > 最佳值 then 最佳骰 := 骰;              { 有號比較 }
    if (v >= 最佳值) and (骰 >= 最佳骰) then begin { 骰是無號比較 }
        最佳骰 := 骰;
        最佳值 := p^[18Dh]^[3];
        輸出^ := p;                               { arg_0 是遠指標輸出參數 }
    end;
    p := p^[189h];
end;
if 最佳值 = 0 then 輸出^ := NIL;
```

`retf 4` ＝ 一個遠指標輸出參數。

- **選的是 `+18Dh^[3]` 最大的那個角色，同值時比隨機骰**（1..100）。這是戰鬥狀態
  記錄的新欄位（既有的欄位見 spec 782：`+09h` 面向、`+0Ah` 目標、`+0Fh` 動作
  計數、`+12h` 累計轉向、`+14h` 本回合已撤退）。
- `v > 最佳值` 時**先把最佳骰換成這次的骰**，於是下一個 `if` 必定成立——所以
  「值更大」永遠贏，骰只在**同值**時才決勝。
- **`+18Dh^[3]` ＝ 0 的角色不可能被選中**：迴圈跑完若最佳值仍是 0，輸出寫 NIL。
  注意輸出參數在迴圈中可能已被寫過（`v = 0` 且骰夠大時也會寫），最後那一步
  是把它清掉。
- 每個角色**各擲一次骰**，就算它不可能勝出也照擲——remake 若要對齊原版的亂數
  序列，這些空擲不能省。

## `overlay-20:0B05h`（entry#15，67 條，差異 8 條）— `DS:7573h` 的每拍遞減

```pascal
i := 1;  p := DS:650Ah;
while p <> NIL do begin
    if byte[7573h + i] > 0 then dec(byte[7573h + i]);   { 無號 }
    if (byte[7573h + i] = 0) and (p^[72h] = 0) then begin
        旗標 := 0;
        r := <本模組 09DFh>(p, @旗標);
        if r = 0 then r := <本模組 091Dh>(p, @旗標);
        byte[7573h + i] := r * 3;
    end;
    p := p^[189h];
    inc(i);
end;
```

`retf`（無參數）。

與 spec 789 的 `overlay-20:0BB6h` 是同一組的兩半：

| | `0BB6h` | 這一支 |
|---|---|---|
| 誰遞減 | 角色 `+72h` | `DS:7573h + i` |
| 多久一次 | 每 12 次呼叫 | 每次呼叫 |
| 重算的條件 | `+72h` 剛好減到 0 | `DS:7573h+i` ＝ 0 **且** `+72h` ＝ 0 |
| 傳給 `09DFh` 的旗標初值 | **1** | **0** |
| 重算結果 | 都寫成 `r * 3` 進 `DS:7573h + i` | 同左 |

所以 `DS:7573h + i` 是**每拍遞減、歸零就重填 `r × 3`** 的短週期計數，而 `+72h`
是十二拍才動一次的長週期計數；長的那個歸零時會**強制**重算一次（不管短的還剩
多少），短的那個則要等**兩個都是 0** 才重算。

傳進 `09DFh` 的旗標初值不同（1 對 0），是兩邊唯一的語意差別——remake 不能把這
兩支合併成一支。

索引 `i` 由 1 起算，跟著 `DS:650Ah` 的鏈結順序走；**沒有上限檢查**。

PC-98 的陣列在 `DS:0A65Fh`。

## 明確不宣稱

- 沒有宣稱 `+18Dh^[3]` 是什麼（形狀上是「越大越優先」的一個 byte）。
- 沒有宣稱 `0141h:004Dh` 的兩個參數哪個是次數哪個是面數；只確定是 `(1, 64h)`。
- 沒有宣稱 `overlay-20:09DFh` / `091Dh` 算什麼，也沒有宣稱那個旗標的意義。
- 沒有宣稱 `× 3` 這個倍數的來由。
