# 第七百零五輪：持續時間公式，與會回捲的擲骰門檻

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-22` 的 `0D67h`、`30C0h`。

## `DS:37DAh` 是另一張 16 bytes 一格的表

`0D67h` 與 `overlay-24:28B3h` 都用 `[37DAh + 索引 × 16]`。目前已知被讀的格內
欄位：`+0`（`28B3h`）、`+2`、`+3`、`+6`（本輪）。

這張表和 spec 700 的 `DS:5CF6h`（物品屬性）是**兩張不同的表**，格寬同樣是 16，
索引來源不同：`5CF6h` 用物品節點的 `+2Eh`，`37DAh` 用傳進來的編號。

## `0D67h`：持續時間

```text
if DS:7563h = 0 then
    lvl := <overlay-24 entry#36>(arg_0)
    v := 表[arg_0].+3 × lvl + 表[arg_0].+2
else
    v := 表[arg_0].+3 × 6 + 表[arg_0].+2          ← 等級固定當 6
if v = 0 且 表[arg_0].+6 <> 0 then v := 1
if v = 0FFh                     then v := 1
回傳 v（byte）
retf 2
```

`DS:7563h` 非 0 時**等級寫死 6**——不查 `entry#36`。這是「不是由角色施放」時
的替代路徑（卷軸／物品之類），remake 不能只實作前一條。

兩個「補成 1」的修正方向不同：`v = 0` 且表上 `+6` 非零時補 1（表示這個效果至少
撐一回合），而 `v = 0FFh` 也補 1（`0FFh` 應該是表上的哨兵值）。

乘法是 `imul`（**有號**），但兩個運算元都用 `xor ah, ah` 零延伸載入，所以實際上
是無號值走有號乘法。結果只取低 byte 存進 `v`——`+3 × lvl` 超過 255 就會回捲。

## `30C0h`：成功率是一個 byte，兩邊都會回捲

```text
lvl  := <overlay-25 entry#10>(DS:6506h)
base := 目標^[10Eh] + 目標^[116h] × lvl          ← 兩個欄位都 cbw，有號
v    := ss:[arg_0 − 2]                            ← arg_0 是 SS 上的位移

if v > base then  門檻 := (v − base) × 5 + 50
elif v < base then 門檻 := 50 − (base − v) × 2
else               門檻 := 50

回傳 ROLLDICE(1, 100) <= 門檻
retf 6
```

門檻存在 **一個 byte** 的全域（`4CB5h`，`base` 存在相鄰的 `4CB6h`）。兩個公式
都會溢出這個 byte，而且方向相反：

| 情況 | 算式結果 | 存進 byte 之後 | 後果 |
|---|---|---|---|
| `v − base >= 42` | `>= 260` | `260 − 256 = 4` | 幾乎**必定失敗** |
| `base − v > 25` | `< 0` | 例如 `−10 → 246` | 幾乎**必定成功** |

也就是說，優勢或劣勢一旦拉大到某個程度，結果會**翻轉**。50 ± 這兩個係數
（`×5` 與 `×2`）在正常範圍內是合理的機率調整，但沒有夾限。

> remake 必須先決定要不要重現這個回捲。夾限成 `0..100` 會讓極端情況的行為和
> 原作相反，而不是「修好一個 bug」——原作的存檔與攻略都是在有回捲的版本上
> 累積的。

`ROLLDICE(1, 100)` 依 PC-98 側的判讀是 `Random(100) + 1`，也就是 1..100；
`<=` 門檻，所以門檻 0 時必定失敗、門檻 100 時必定成功。

`v` 從 `ss:[arg_0 − 2]` 取——`arg_0` 是 SS 上的位移，讀的是**它前面那個 byte**。
`overlay-23:1756h` 也有同樣的「用負位移讀區域結構」寫法。

## 明確不宣稱

（`DS:7563h` 已由 spec 733 解出：**非 0 代表這次施放來自物品**，所以「等級寫死 6」就是「物品施放一律當 6 級」。）

- `overlay-25 entry#10`、`overlay-24 entry#36` 的內部行為。
- `DS:37DAh` 表的長度與其餘欄位。
