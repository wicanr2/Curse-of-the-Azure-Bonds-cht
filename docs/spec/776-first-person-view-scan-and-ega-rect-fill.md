# 776 — 第一人稱視野的 13 × 5 掃描、EGA 矩形填色

- 證據等級：`exact`（以補洞後的匯出逐條讀完，見 spec 761）

## `overlay-10:08C9h`（DOS）— 掃過party 周圍 13 × 5 格

`retf`，不收參數。兩層迴圈用的是**兩個全域 byte**當計數器：

```pascal
DS:4A0Dh := 0FEh;                          { −2 }
repeat
    DS:4A0Ch := 0FAh;                      { −6 }
    repeat
        x := DS:720Fh + 有號(DS:4A0Ch);
        y := DS:7210h + 有號(DS:4A0Dh);
        DS:4A0Fh := 本模組 0378h(x, y, 6);   { 西 }
        DS:4A0Eh := 本模組 0378h(x, y, 0);   { 北 }
        DS:4A10h := 本模組 0378h(x, y, 2);   { 東 }
        DS:4A11h := 本模組 0378h(x, y, 4);   { 南 }
        本模組 03ECh(bp);  0491h(bp);  050Eh(bp);  06ECh(bp);
        DS:4A15h := <呼叫>(x, y) and 40h;
        本模組 00CCh();
        if DS:4A0Ch = 6 then break else inc(DS:4A0Ch);
    until false;
    if DS:4A0Dh = 2 then break else inc(DS:4A0Dh);
until false;
```

一次接起好幾條線：

- `DS:720Fh` / `DS:7210h` 是隊伍在迷宮裡的 x／y（spec 770）。
- 掃描範圍是 **dx ∈ −6..+6、dy ∈ −2..+2**，共 **13 × 5 ＝ 65 格**——這是第一
  人稱視野一次要考慮的格子數。
- 每格對**四個方向（6 西、0 北、2 東、4 南）**各查一次牆，用的是 spec 765 的
  `overlay-10:0378h`（同一道牆從兩側各查一次再取聯集）。結果放進四個相鄰的
  全域：`DS:4A0Eh` 北、`4A0Fh` 西、`4A10h` 東、`4A11h` 南。
- 接著四個繪圖子程序都用 `push bp` 傳靜態鏈——**它們是巢狀程序**，讀的就是上面
  那四個全域。其中 `0491h` 正是 spec 771 那支「八組寫死參數」的函式，它判斷的
  `DS:4A0Eh` 就是北面的牆旗標。
- **兩個迴圈計數器是全域而不是 local**，所以這支不可重入；`DS:4A0Ch` / `4A0Dh`
  離開時停在 `6` / `2`。

## `START.EXE:154DDh`（DOS）— EGA 矩形填色

`retf 0Ch`（6 個 word）：

```
存下 unk_211A2h
位移 := 上列 * 28h * 8 + 左欄
列數 := (下列 − 上列 + 1) * 8 − 1
<設色>(顏色索引);  <呼叫 15420h>();
out 3CEh, 5 ; out 3CFh, 2                 { Graphics Mode := 2 → Write Mode 2 }
for i := 0 to 列數 do begin
    FillChar(unk_211A0h:位移, 右欄 − 左欄 + 1, 填充值);
    位移 := 位移 + 28h;
end
out 3CEh, 5 ; out 3CFh, 0                 { Mode 歸零 }
還原 unk_211A2h 並再 <設色> 一次
```

`28h`（40）是每列的位元組數，與 spec 762 的字元繪製一致（320 像素寬）。上下界
以**字元列**為單位（乘 8 換成掃描線），左右界以**位元組**為單位。

`unk_211A0h` 是畫面段值、`unk_211A2h` 是目前顏色（存了又還原）。

## 明確不宣稱

- 沒有宣稱 `03ECh`／`050Eh`／`06ECh` 三支巢狀繪圖程序各畫什麼。
- 沒有宣稱 `DS:4A15h` 那個 `and 40h` 取出來的位元代表什麼。
- 沒有宣稱 `154C4h` / `15420h` 兩支的內容；只知道前者收一個顏色索引。
- 沒有宣稱 13 × 5 這個範圍與畫面上實際看得到的格數的關係。
