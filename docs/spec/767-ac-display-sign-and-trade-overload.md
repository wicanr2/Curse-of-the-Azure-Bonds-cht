# 767 — AC 顯示連負號一起確認、交易的超重訊息

- 證據等級：`exact`（以補洞後的匯出逐條讀完，見 spec 761）

## AC 的顯示規則（含負值）

PC-98 `overlay-24:0B41h`（`retf 8`）把既有的「顯示值 ＝ 60 − 儲存值」補完了
負數那一半：

```pascal
v := p^[19Bh] − 3Ch;                     { 3Ch = 60 }
if v < 0 then v := −v;                   { 取絕對值 }
s := 數值轉字串(v);
s := s + CS:0B3Ch;                       { 長度 2，內容是兩個半形空白 }
if p^[19Bh] > 3Ch then                   { 無號比較 }
    s := CS:0B3Fh + s;                   { 長度 1，內容是 '-' }
印字(欄 arg_2, 列 arg_0, 顏色 0Ah, 0, @s);   { 0418h:0D17h，簽章見 spec 973 }
```

所以畫出來的字串是：

| 儲存值 | 顯示 |
|---|---|
| `< 3Ch` | `<60 − 儲存值>` ＋ 兩個空白 |
| `= 3Ch` | `0` ＋ 兩個空白 |
| `> 3Ch` | `-` ＋ `<儲存值 − 60>` ＋ 兩個空白 |

**兩個尾隨空白是字串常數的一部分**（`CS:0B3Ch` 長度就是 2），用途是蓋掉上一次
畫的較長數字。中文化改這個欄位時**不能把尾隨空白刪掉**，否則 AC 從兩位數變一位
數時會留下殘影。負號也是獨立的一個字元常數。

## 交易與超重

`overlay-19:213Ch`（DOS）／`2102h`（PC-98），`retf 4`：

```pascal
對象 := DS:4AF8h;                        { PC-98：DS:7BD6h，記住上次選的人 }
<呼叫>();
選人(對象 ← 'Trade with Whom?', 1);
if 對象 = NIL then 離開;                 { 取消 }
DS:4AF8h := 對象;                        { 記住這次選的 }
if 本模組 3258h(物品, 對象) then          { spec 762：拿不拿得下 }
    顯示('Overloaded')
else begin
    <呼叫>(物品, 對象);
    <呼叫>(物品, DS:6506h);
    <呼叫>(對象);
end;
```

| 位址 | DOS | PC-98 |
|---|---|---|
| 提示 | `Trade with Whom?`（16） | `誰に渡しますか？`（16 bytes） |
| 拒絕 | `Overloaded`（10） | `持ちすぎです`（12 bytes） |

`DS:4AF8h`（PC-98 `DS:7BD6h`）**跨呼叫保留**：進來時先讀舊值當預設、選完再寫
回去。與 spec 719 記錄的 `DS:7555h` 是同一種「上次選的人」快取。

## PC-98 `PC98-GAME.EXE:14E97h` — 一段有欄位上限的繪字

`retf 0Ch`（6 個 word）：

```pascal
StoreString(字串, 緩衝, 0FFh);
if (參數F > 27h) or (參數E > 27h) then 離開;      { 27h = 39 }
本模組 145CAh(0, @緩衝, @暫存);                   { 就地改寫 }
StoreString(→ 緩衝, 0FFh);
長度 := 緩衝[0];
屬性 := byte[1928h + 屬性];                       { 查表換算 }
本模組 1692Dh(@緩衝[1], 長度, 參數C, 屬性, 參數E, 參數F * 2);
```

`27h`（39）是兩個座標各自的上限，超過就整支不畫——**沒有裁切，直接放棄**。
最後一個座標傳進去之前先乘 2。屬性經過 `DS:1928h` 這張表換算。

  整體比 DOS 多 1，兩個欄位相鄰，本輪沒有分辨。確定的是 60 為基準的顯示規則。
- 沒有宣稱 `overlay-19:213Ch` 那三個後續呼叫各自做什麼（形狀上是「從甲身上拿掉、
  加到乙身上、更新乙」）。
- 沒有宣稱 `DS:1928h` 那張屬性表的內容。
