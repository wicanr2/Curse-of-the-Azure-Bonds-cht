# 1153 — `37h LOAD PIECES` 寫進存檔的那三組牆面參數

- 證據等級：`exact`（`LOADWALLSET` 的收尾與 `37h` 的 `0FFh` 分支逐條讀出；
  23 處 corpus 運算元全數列出）
- handler 本體見 [spec 1087](1087-ecl-handlers-six.md)（DOS）與
  [spec 587](587-ecl-handler-21-37-shared.md)（PC-98，兩個 opcode 共用一支）
- 存檔版面見 [spec 1076](1076-original-save-layout.md) 第 9..14 欄

## 誰寫那三組參數

`37h` 的三個運算元是三個**牆面組槽位**的片號。載得進去的槽走
`LOADWALLSET(槽, 片)`（DOS `overlay-30:104Ch`，PC-98 側同名符號），
而那一支的**最後六條指令**就是寫入端（DOS `overlay-30:12DEh`）：

```pascal
word[DS:7210h ＋ 槽 × 4] := 片;      { 12F0h }
word[DS:7212h ＋ 槽 × 4] := 槽;      { 1306h ★ 兩個運算元都取 arg_0 }
```

★ **第二個 word 存的是槽號本身**，不是第二個片號——`12F4h` 與 `12FBh` 讀的都是
`[bp+arg_0]`（`46 06`），不是 `arg_2`（`46 08`）。所以一筆記錄是自我標示的
`{片, 槽}`，正好對上 remake `SAVGAMSetBlock` 既有的 `{BlockID, SetID}` 欄位名。

運算元是 `0FFh` 的槽不呼叫 `LOADWALLSET`，改由 handler 自己寫哨兵
（DOS `overlay-02:0D44h`／`0D55h`）：

```pascal
word[DS:7210h ＋ 槽 × 4] := 0FFFFh;
word[DS:7212h ＋ 槽 × 4] := 0FFFFh;
```

⇒ **`0FFFFh` ＝ 這一槽沒有牆面組**，與 spec 1072／1074 記的初值和 `> 0` 判斷
一致，三份規格互相印證。

- **`7Fh` 一次都沒出現**，所以 `o[1] = 7Fh ⇒ LOADWALLSET(1, 0)` 那一支
  在本作走不到。
- **`0FFh` 出現 6 次**，一律在槽 2／3；槽 1 從來不是 `0FFh`。
- 槽 2 每一處都帶著真實片號（`02`／`06`／`0Ah`／`0Fh`／`10h`／`12h`）。
  ⇒ 兩槽分支（`bank0^[1CEh]` 與 `[1D0h]` 都非零時只載槽 1／3）**若是常態，
  這些片號會全部是死資料**——所以逐槽迴圈才是正常路徑。這是推論不是觀測，
  因為 `1CEh`／`1D0h` 的語意還沒解出來。

## ★ 順帶：`21h LOAD FILES` 的第一個運算元是要載的地圖 block

- 第一個運算元是 **block 編號**，也就是 `LOAD3DMAP(o[1])` 要載的地圖。
  ★ 通常等於所在 block 自己的編號，但**不一定**——`ECL2/0x02` 載 `01`、
  `ECL4/0x22` 載 `21`、`ECL5/0x31` 載 `32`。那三處正好證明它是「要載哪一張」
  而不是「我是誰」。
- 第二個一律 `02`，第三個一律 `0FFh` ⇒ bigpic 那一支全遊戲不執行。
- `ECL1` 三個 block（開場）全部是 `7F 7F 7F`，落在
  `o[1] <> 7Fh` 的排除條件裡，所以開場不載地圖。

⚠ 這張表同時是判斷 spec 1087 舊版轉錄有誤的第二個證人：把運算元順序反過來讀，
`LOAD3DMAP` 的守衛會變成 `0FFh <> 0FFh`，全遊戲一次都不會載地圖。

## remake

- 三個槽的資產載入本來就接上了（`loadMapPieceSets` 依 `selectors[i]` 對到
  槽 `i+1`，與原作逐槽迴圈同號），`0FFh` 也已經跳過不載。
- **這一輪補的是存檔那一半**：`applyWallSetParams` 依上面的規則維護
  `SAVGAMContainer.SetBlocks`——載得進去的槽記 `{片, 槽}`、`0FFh` 的槽記
  `{0FFFFh, 0FFFFh}`。先前 remake 從來沒有寫過這三格，存出來的檔一律是零，
  而拿原版當 oracle 時那是對不上的。
- 沒跑過任何 `LOAD PIECES` 時保留匯入來的那一份，不用零蓋掉。

## 明確不宣稱

- 沒有宣稱 `bank0^[1CCh]`／`[1CEh]`／`[1D0h]` 是什麼（spec 1030 也留白）。
- 沒有宣稱 `LOADWALLSET` 前 276 條做什麼——只讀了它的收尾六條。
- 沒有宣稱 `o[1] = 7Fh` 那一支的用途（本作走不到）。
- 沒有宣稱 `DS:8B6Eh` 是什麼（spec 1087 同樣留白）。
- 沒有宣稱片號 `01h`..`12h` 各自對到哪一組牆面美術。
