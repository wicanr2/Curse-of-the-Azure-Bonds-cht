# 784 — 兩平台同形配對（第二批三組）：戰場的第二個平面、隊伍血量百分比

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-32:0509h`（entry#9，43 條，差異 2 條）— 戰場還有第二個平面

```pascal
if (0 <= x <= 31h) and (0 <= y <= 18h) then begin      { 49 / 24，有號 }
    輸出A^ := 地圖^[y * 32h + x + 7];                   { DS:6E92h 指向的堆積 }
    輸出B^ := byte[6857h + y * 32h + x];                { 靜態陣列 }
end else begin
    輸出B^ := 0;  輸出A^ := 0;
end;
```

範圍 `0..49` × `0..24` 就是既有的 **50 × 25 戰場格陣**（spec 749／756／759 三次
獨立確認過）。新的是第二個平面：

**`DS:6857h` 起是一塊與地圖同尺寸（1250 bytes）的靜態陣列**，索引式一模一樣
（`y * 50 + x`），只是沒有那 7 bytes 的表頭。`6857h + 1250 = 6D29h`，正好落在
`DS:6D35h`（戰鬥員指標表）之前，不重疊。

所以戰場每一格有兩個 byte：一個在堆積上的地圖緩衝區裡（`DS:6E92h^`，spec 748
在畫圖時寫的那個），一個在常駐資料段的 `DS:6857h`。

PC-98 對應 `DS:9F2Ch`（地圖）與 `[di − 670Fh]`（＝ `98F1h`）。

## `overlay-10:02F6h`（entry#6，49 條，差異 3 條）— 巢狀的牆面查詢

這就是 spec 765 的 `overlay-10:0378h` 用 `push bp` 呼叫的那支巢狀程序。
`retf 8` ＝ 4 個 word：`(x, y, 方向)` 再加**最低位的一個 word 是靜態鏈**
——本體從來不讀它，這正好把「多推的那個 `bp` 是靜態鏈而不是參數」坐實。

```pascal
if (0 <= x <= 0Fh) and (0 <= y <= 0Fh) then begin
    if      not <呼叫A>(x, y, 方向) then 結果 := 1
    else if not <呼叫B>(x, y, 方向) then 結果 := 0
    else                                 結果 := 3;
end else begin
    if (y = DS:7210h) and (方向 in {2, 6}) then 結果 := 0    { 隊伍所在的那一列 }
    else                                       結果 := 1;
end;
```

- 回傳值只有 **0、1、3** 三種。
- **超出地圖範圍時不是一律當牆**：如果查的是隊伍所在那一列（`DS:7210h` 是隊伍
  的 y）而且方向是東或西，回 `0`（等同沒牆），否則回 `1`。這是地圖邊界的特例
  處理，remake 照抄時不能簡化成「界外＝有牆」。

## `overlay-13:2E22h`（entry#25，49 條，差異 6 條）— 隊伍血量百分比

```pascal
最大 := 0;  目前 := 0;
角色 := DS:650Ah;
while 角色 <> NIL do begin
    if 角色^[197h] = 1 then begin              { 陣營 1 }
        if 角色^[196h] <> 0 then 目前 := 目前 + 角色^[1A4h];   { 目前 HP }
        最大 := 最大 + 角色^[78h];                              { 最大 HP }
    end;
    角色 := 角色^[189h];
end;
if 最大 > 0 then
    DS:75D9h := ((目前 * 14h) div 最大) * 5;   { 全部無號 }
```

`(目前 × 20 ÷ 最大) × 5` ——結果是 **0 到 100、以 5 為級距**的百分比，存進
一個 byte（`DS:75D9h`，PC-98 `DS:0A86Bh`）。

兩個細節要照抄：

- **`+196h` 為 0 的成員，目前 HP 不計入，但最大 HP 照計**。所以那種狀態的成員
  會把整隊的百分比往下拉。
- `最大 = 0` 時**整個不寫**，`DS:75D9h` 保留上一次的值。

PC-98 的欄位全部 ＋1（`+198h` 陣營、`+197h`、`+1A5h` 目前 HP、`+18Ah` next）。

`DS:0A86Bh` 這個位址在 spec 758 的士氣判定裡出現過（`DS:0A03Ch := DS:0A86Bh`）
——士氣判定拿的就是這個隊伍血量百分比。
