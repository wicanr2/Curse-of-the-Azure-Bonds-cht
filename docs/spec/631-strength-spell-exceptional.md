# 第六百三十一輪：`222Ah` —— AD&D 的 18/xx 特例力量表

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：PC-98 `overlay-22:222Ah`（308 bytes）。

## 兩個全域是「力量值」與「百分比」

```text
DS:7D93h := 12h                          ← 預設
DS:7D94h := 0
case <far 014Ah:00D4h>(DS:0A031h) of
    1:      DS:7D94h := 0
    2:      DS:7D94h := 1
    3:      DS:7D94h := 33h
    4:      DS:7D94h := 4Ch
    5:      DS:7D94h := 5Bh
    6:      DS:7D94h := 64h
    7:      DS:7D93h := 13h
    8:      DS:7D93h := 14h
    9:      DS:7D93h := 15h
    0Ah, 0Bh: DS:7D93h := 16h
end
```

把常數換成十進位就認得出來：

| `DS:7D93h` | `12h` | `13h` | `14h` | `15h` | `16h` |
|---|---|---|---|---|---|
| 十進位 | **18** | **19** | **20** | **21** | **22** |

| `DS:7D94h` | `0` | `1` | `33h` | `4Ch` | `5Bh` | `64h` |
|---|---|---|---|---|---|---|
| 十進位 | **0** | **1** | **51** | **76** | **91** | **100** |

這是 AD&D 的**特例力量（exceptional Strength）**：戰士的 18 點力量再擲百分比，
級距切在 **01／51／76／91／00**。程式用 `100` 表示 `18/00`（最高段），另外一個
`0` 是「沒有百分比」。訊息是「は強くなった。」。

前六個 case 動的是**百分比**（力量值留在 `18`），後五個 case 動的是**力量值**
（`19`..`22`，百分比留在預設 `0`）——兩組互斥，一次只會改其中一個。

`case` 有預設值（進 `case` 前先設 `12h` 與 `0`），所以**沒有
[spec 629](629-spell-pack-idiom-and-uninit.md) `2690h` 那種未初始化問題**。
輸入超出 `1..0Bh` 時得到的是 `18`／`0`。

## 明確不宣稱

- `014Ah:00D4h` 的回傳值代表什麼（職業、等級、還是擲骰結果）。它在
  [spec 628](628-spell-effect-wrappers.md) 的 `3804h` 推兩個參數、這裡推一個，
  呼叫形狀不同。
- `013Eh:007Fh`／`013Eh:0057h`／`013Eh:0098h`／`sub_E75` 的內部行為。
- 力量值與百分比實際存進角色紀錄的哪個欄位（本輪只看到寫進兩個全域）。
