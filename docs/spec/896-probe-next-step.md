# 896 — 探一步：這個單位往某方向走會踩到什麼

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側只差一條 `xor ah, ah`）
- 作法見 spec 783

## `overlay-32:00D06h` ↔ `overlay-32:013BBh`（DOS 147 條／PC-98 146 條）

`retf 16h` ＝ 11 個 word，五個是 var 參數。

```pascal
撞到誰^ := 0;
最貴地形^ := 17h;
最高成本 := 1;
有1Eh^ := 0;
有1Ch^ := 0;

我 := <本模組 0CAEh>(arg_12, arg_14);
基y := byte[66A3h ＋ 我 * 4];        { 座標快取，spec 860 }
基x := byte[66A4h ＋ 我 * 4];

for i := 0 to 3 do begin                                   { 最多佔 4 格 }
    if not <本模組 0011h>(var dy, var dx, i, byte[66A6h ＋ 我 * 4]) then continue;

    ny := byte[2694h ＋ 方向] ＋ dy ＋ 基y;                 { 方向位移，spec 854 }
    nx := byte[269Dh ＋ 方向] ＋ dx ＋ 基x;

    <本模組 0509h>(var 地形, var 佔用者, nx, ny);

    if 佔用者 = 我 then 佔用者 := 0;
    if 佔用者 > 0 then 撞到誰^ := 佔用者;                  { 無號 }

    if (地形 = 0) or (最貴地形^ = 0) then begin
        最貴地形^ := 0;  continue;                          { 0 ＝ 不能走 }
    end;

    if      地形 = 1Eh then 有1Eh^ := 1
    else if 地形 = 1Ch then 有1Ch^ := 1
    else if byte[26A2h ＋ 地形 * 4] >= 最高成本 then begin   { 無號 }
        最高成本 := byte[26A2h ＋ 地形 * 4];
        最貴地形^ := 地形;
    end;
end;
```

## 三張既有結構同時出現

| 用到的 | 出處 |
|---|---|
| `DS:66A3h ＋ 我 × 4` 的 `+0`／`+1`／`+3` | spec 860 的戰鬥員座標快取（y、x、體型） |
| `DS:2694h`／`DS:269Dh` | spec 854 的方向位移表 |
| `DS:26A2h ＋ 地形 × 4` 的 `+0` | 地形表的**移動成本**（`resident-data-tables.md`） |

`本模組 0011h` 與 spec 860 的 `far 18Ch:002Ah` 是同一種東西：
「這個體型有沒有第 i 格、相對偏移是多少」。**大型單位一次踩四格**，
所以要取四格裡**最貴的**地形當代價。

## `1Ch` 與 `1Eh` 就是 spec 862 的兩種雲

那兩個格類在 spec 862 是「腳下有雲」的判斷值
（`1Ch` 配效果碼 `5Bh`、`1Eh` 配 `28h`）。
本支把它們從一般地形裡挑出來、各自回填一個旗標——
**走進去之前先知道會不會踩到雲**。

其餘地形走「取成本最大值」那條路；`地形 = 0` 是**不能通行**，
一格不能走整步就不能走（`最貴地形^ := 0` 之後每一圈都會再撞到同一個條件）。

`最貴地形^` 的初值 `17h`（23）不是成本而是**地形編號**，
與回填的值同一個空間。

## PC-98：只差一條 `xor ah, ah`

DOS 把地形碼零擴充成 `ax` 再 `cmp ax, 1Eh`／`1Ch`，PC-98 直接 `cmp al`。
spec 783 第 c 類。其餘 11 條是表基底位址。

## 明確不宣稱

- 沒有宣稱 `本模組 0CAEh(arg_12, arg_14)` 怎麼算出「我是誰」。
- 沒有宣稱 `本模組 0509h` 怎麼查地形與佔用者。
- 沒有宣稱初值 `17h` 為什麼選這一個地形編號。
- 沒有宣稱五個 var 參數的呼叫端怎麼使用。
