# 第七百二十八輪：能不能施放這個法術——兩組相差 8 的平行欄位

狀態：`READY`。等級：`exact`（流程）／`strong inference`（第二組欄位是第二職業）。
日期：2026-08-14
位置：DOS `overlay-22:0020h`（`retf 6`：法術編號、角色 far 指標）。

## 分派

```text
id    := arg_0 and 7Fh                      ← 先去掉最高位
class := byte [37DAh + id × 16]             ← DS:37DAh 表格內 +0
```

`and 7Fh` 和 spec 703 物品效果槽的處理一樣：**最高位是旗標，不是編號的一部分**。
`[37DAh + id × 16]` 的 `+0` 欄位在 `overlay-24:28B3h` 也被讀過，本輪確定它是
**法術分類**。

## 四類各自的條件

```text
class = 0：
    if 角色^[15h] <= 8                            then 0
    elif 角色^[109h] > 0                          then 1
    elif 雙職業 且 角色^[111h] > 0                 then 1
    elif 角色^[10Ch] > 8                          then 1
    elif 角色^[114h] > 8 且 雙職業                 then 1
    else 0

class = 1：
    if 角色^[15h] <= 8                            then 0
    elif 角色^[10Dh] > 6                          then 1
    elif 雙職業 且 角色^[115h] > 6                 then 1
    else 0

class = 2：
    if 角色^[13h] <= 8                            then 0
    elif 角色^[74h] <> 7                          then 1
    elif 角色^[159h] = NIL                        then 1
    elif DS:4FBAh <> 5                            then 1
    elif 角色^[10Dh] > 8                          then 1
    elif 非雙職業                                  then 0
    elif 角色^[115h] <= 8                         then 0
    elif 角色^[10Eh] > 0                          then 1
    elif 非雙職業                                  then 0
    elif 角色^[116h] > 0                          then 1
    else 0

class = 3：0
其他：0（`var_1` 初始化就是 0）
```

「雙職業」指 `<overlay-25 entry#10>(角色)` 回非 0。它在 `class = 2` 那一段被
**呼叫兩次**（`0134h`、`015Fh`），中間沒有快取。

## 兩組相差 8 的平行欄位

把用到的欄位排開：

| 第一組 | 第二組 | 差 |
|---|---|---|
| `+109h` | `+111h` | 8 |
| `+10Ch` | `+114h` | 8 |
| `+10Dh` | `+115h` | 8 |
| `+10Eh` | `+116h` | 8 |

**每一次都是「先看第一組；若是雙職業，再看第二組的同一欄」。** 所以
`+109h..+110h` 與 `+111h..+118h` 是兩個 8 bytes 的平行區塊，分別對應角色的
第一與第二職業。

這也解釋了 spec 705 `30C0h` 用 `角色^[10Eh] + 角色^[116h] × 等級` 算門檻——
那是把兩個職業的同一欄加起來。

## 門檻值

`class = 0` 用 `> 8`（`+109h` 那條是 `> 0`），`class = 1` 用 `> 6`，
`class = 2` 用 `> 8`。三類的門檻不同，不能共用一個常數。

## 明確不宣稱

- `+13h`、`+15h`、`+74h`、`+159h` 是什麼。
- `class` 值 `0`／`1`／`2`／`3` 對應哪些法術系統。
- `overlay-25 entry#10` 到底判斷什麼（本輪只確定它決定要不要看第二組欄位）。
- `DS:4FBAh <> 5` 為何會直接放行。
