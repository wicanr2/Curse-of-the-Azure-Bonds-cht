# 922 — 交易錢幣給隊友：與 spec 920 同骨架，但外層多一圈選人

- 證據等級：`exact`（兩平台都逐條讀完；相似度 0.978）
- 作法見 spec 783

## `overlay-19:02C57h`（DOS 327 條）↔ `overlay-19:02C69h`（PC-98 335 條）

`retf` ＝ 無參數。

| | DOS | PC-98 |
|---|---|---|
| 選對象 | `'Trade to?'` | `'誰にわたしますか？'` |
| 補齊空白 | `' '` | `'　'`（全形） |
| 選單提示 | `'Select type of coin '` | `'貨幣の種類を選んでください'` |
| 按鍵列 | `' Select'` | `'決定'` |
| 數量（前） | `'How much '` | `'どれだけ'` |
| 數量（後） | `'will you trade? '` | `'わたしますか？'` |
| 熱鍵字串 | — | `' 決定 '` → `DS:0A362h`，限長 6 |

```pascal
repeat                                              { 外圈：選收款人 }
    對象 := 遠指標(DS:4AF8h);                       { 上次選的當預設 }
    <sub_15A9h>();
    選角色('Trade to?', @對象, 1);                  { sub_15B8h }
    if 對象 = NIL then begin 外圈結束 := 1;  goto 收尾 end;
    <sub_83h>();
    DS:4AF8h := 對象;

    repeat                                          { 內圈：選幣別 }
        <sub_597h>();
        { …建幣別鏈，與 spec 920 逐條相同：
          七格 角色^[0FBh + i×2]、GetMem 2Eh、往回接、
          補 := 8 − byte[0F93h + i×0Bh]、限長 28h、+29h := 0 … }

        選單('Select type of coin ', ' Select', …, 鏈, 1, …, @選中);

        if 選中 = NIL then 內圈結束 := 1            { ⚠ 見下 }
        else begin
            幣別 := <loc_1151h+1>(@名稱, 選中);
            問句 := 限長('How much ' ＋ 名稱 ＋ 'will you trade? ', 0FFh);
            數量 := <loc_1156h+1>(0Ah, @問句, 角色^[0FBh ＋ 幣別 × 2]);
            <loc_115Bh+1>(@角色, @對象, 數量, 幣別);       { ★ 轉帳 }
            內圈結束 := 1;   外圈結束 := 1;
            for i := 0 to 6 do
                if 有號(角色^[0FBh ＋ i × 2]) > 0 then begin
                    外圈結束 := 0;   內圈結束 := 0;
                end;
        end;
        if 尾 <> NIL then 釋放鏈(@尾);
    until 內圈結束 <> 0;
until 外圈結束 <> 0;
```

## 與 spec 920 的差別只有三處

1. **外層多一圈**：先用 `'Trade to?'` 選收款人，選到的存進 `DS:4AF8h`
   當下一次的預設值。
2. **結尾動作是轉帳不是丟棄**：`<loc_115Bh+1>(@來源角色, @目標角色, 數量, 幣別)`，
   兩個參數都是**指向角色遠指標的遠指標**（來源直接傳 `@DS:6506h`）。
3. 句尾字串是 `'will you trade? '` 而不是 `'will you drop? '`。

**幣別鏈的建構、節點版面、`8 − 名稱長度` 的補齊、`28h` 限長、往回接造成的
反向順序，全部與 spec 920 逐條相同**，不重複列。

## ⚠ 取消幣別選單時，靠一個沒賦值過的變數決定去向

```
2E7F  jnz  loc_2E89            ← 選中 ≠ NIL 才往下
2E81  mov  [bp+var_132], 1     ← 只設內圈旗標
2E86  jmp  loc_2F46            ← 跳過重掃錢包那一段
…
2F62  cmp  [bp+var_131], 0     ← 外圈旗標
2F67  jnz  loc_2F6C            ← ≠ 0 → 離開
2F69  jmp  loc_2C5E            ← ＝ 0 → 重新選收款人
```

`var_131`（外圈旗標）在整支函式裡只被寫過三次：`2C94`（選人時取消）、
`2F14`（轉帳成功後）、`2F36`（錢包還有錢）。
**「選好人之後取消幣別選單」這條路徑一次都沒經過那三處**，
所以判斷用的是 `sub sp, 234h` 之後的堆疊殘值。

實際表現：取消幣別選單有時直接離開、有時退回選人畫面，取決於上一個函式
在那一格留下什麼。**兩平台完全相同**，不是反組譯錯位。

remake 要照原樣重現的話這一格不可能重現（殘值不可預期）；
建議實作成「退回選人畫面」——那是這個 UI 唯一合理的行為。

## ⚠ PC-98 的全形空白補齊

與 spec 920 同一處：`補 := (8 − 名稱長度) div 2`。
兩支函式各有一份獨立的程式碼，**不是共用的**，所以中文化要各改一次。

## 明確不宣稱

- 沒有宣稱 `sub_15A9h`／`sub_15B8h`／`sub_83h`／`sub_597h` 各做什麼。
