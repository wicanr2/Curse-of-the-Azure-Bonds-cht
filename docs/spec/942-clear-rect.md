# 942 — 清一個矩形：三種顯示模式各一條路

- 證據等級：`exact`（逐條讀完）
- 位置：DOS `START.EXE` 的 `15F6Ah`
- 作法見 spec 783

## `15F6Ah`（207 條）—— `retf 8`

`(下 arg_0, 右 arg_2, 上 arg_4, 左 arg_6)`，四個都是**有號 byte**（`cbw`），
座標是 spec 937／940 那個「一列 ＝ 8 條掃描線」的格線系。

### `byte_211A6h = 0`：CGA

```pascal
起線 := 上 shl 2;   迄線 := (下 shl 2) ＋ 3;      { 每格 4 條，兩個半頁共 8 條 }
寬   := (右 − 左 ＋ 1) shl 1;                     { 每像素 2 bits → 每格 2 bytes }
for y := 起線 to 迄線 do begin
    位移 := y × 50h ＋ 左 × 2;
    FillChar(0B800h:位移, 寬, 0);
    FillChar(0BA00h:位移, 寬, 0);
end;
```

`50h` ＝ 80 bytes／掃描線 ＝ 320 像素 × 2 bits。

### `byte_211A6h = 1`：委派

```pascal
<sub_154DDh>(0, 0, 下, 右, 上, 左);
<sub_154DDh>(0, 1, 下, 右, 上, 左);
```

**同一支呼叫兩次、只有第二個參數不同（0 與 1）**——形狀上是兩個位元平面。

### `byte_211A6h = 2`：Tandy 16 色

```pascal
起線 := 上 shl 1;   迄線 := (下 shl 1) ＋ 1;      { 每格 2 條，四個半頁共 8 條 }
左位移 := 左 shl 2;
寬     := (右 − 左 ＋ 1) shl 2;                   { 每像素 4 bits → 每格 4 bytes }
for y := 起線 to 迄線 do begin
    位移 := y × 0A0h ＋ 左位移;
    FillChar(0B800h:位移, 寬, 0);
    FillChar(0BA00h:位移, 寬, 0);
    FillChar(0BC00h:位移, 寬, 0);
    FillChar(0BE00h:位移, 寬, 0);
end;
```

`0A0h` ＝ 160 bytes／掃描線 ＝ 320 像素 × 4 bits。

## 兩種模式都是「每格 8 條掃描線」

| | 半頁數 | 每格佔的掃描線 | 每格 bytes | 每列 bytes |
|---|---|---|---|---|
| 模式 0 | 2 | 4 × 2 ＝ **8** | 2 | `50h` |
| 模式 2 | 4 | 2 × 4 ＝ **8** | 4 | `0A0h` |

與 spec 935（CGA 字模）、spec 938（Tandy 字模）、spec 940（裁切以 8 線為單位）
完全一致——**整個繪圖層的縱向單位就是 8 條掃描線**。

## ⚠ 兩個迴圈的邊界判斷不一樣

```
模式 0：cmp 起線, 迄線 ; ja  → 起線 > 迄線 就整個跳過
模式 2：cmp 起線, 迄線 ; jbe → 起線 <= 迄線 才做
```

兩者等價，但**都是無號比較**，而 `上`／`下` 是有號的。
`上` 為負時 `shl` 之後會變成極大的無號數 → 整個跳過（不畫）。
所以負座標會被靜默忽略，**不會越界寫入**。
