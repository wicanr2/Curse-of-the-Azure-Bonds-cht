# 904 — 3D 視圖的另一層牆面：三個全域是三個距離層

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側只差一條 `xor ah, ah`）
- 作法見 spec 783

## `overlay-10:0050Eh` ↔ `overlay-10:0050Eh`（DOS 197 條／PC-98 196 條，同位址）

`overlay-10` ＝ COMPREP。`retf 2` ＝ 一個父框架指標（巢狀程序），
與 spec 898 是同一組的另一支。

```pascal
左 := <本模組 0378h>(6, 父[−2] − 1, 父[−1]);
右 := <本模組 0378h>(0, 父[−2],     父[−1] − 1);
兩邊都空 := (左 = 0) and (右 = 0);

for i := 1 to 4 do
    case i of
      1: 依 DS:4A0Eh（0／3／1）與 DS:4A0Fh（0／3／1）與 兩邊都空
             → A ∈ {16h, 0Dh, 0, 0Fh, 5, 12h, 2}
      2: 依 DS:4A0Eh 單獨決定 → B ∈ {16h, 11h, 5}
      3: 依 DS:4A0Fh（0／3／1）與 DS:4A0Eh 與 兩邊都空
             → C ∈ {16h, 10h, 0Ah, 14h, 7, 1, 3}
      4: 依 DS:4A0Fh（0／3 一組、1 另一組）與 DS:4A0Eh
             → D ∈ {16h, 17h, 0Ah, 0Dh, 15h, 6}
    end;

<本模組 0048h>(A, 0, 1);
<本模組 0048h>(B, 0, 2);
<本模組 0048h>(C, 1, 1);
<本模組 0048h>(D, 1, 2);
```

## 與 spec 898 的關係：三個全域是三個距離層

| | 用到的全域 | 畫在 |
|---|---|---|
| spec 898（`006ECh`） | `DS:4A0Eh` ＋ `DS:4A10h` | `(0,5)` `(0,6)` `(1,5)` `(1,6)` |
| **本支（`0050Eh`）** | `DS:4A0Eh` ＋ **`DS:4A0Fh`** | `(0,1)` `(0,2)` `(1,1)` `(1,2)` |

兩支都以 `DS:4A0Eh` 為主軸，各自再配一個相鄰的全域
（`DS:4A0Fh` 與 `DS:4A10h`）。三個位址連續，形狀上是
**由近到遠三個距離層的牆面狀態**，值域都是 `{0, 1, 3}`。

`本模組 0378h` 的第一個參數兩支不同（本支用 `6` 與 `0`，
spec 898 用 `2` 與 `0`），而且取樣座標也不同
（本支 `父[−1] − 1`，spec 898 `父[−1] ＋ 1`）——
**兩支看的是同一格的不同側**。

`16h`（22）在兩支的四個位置都當「什麼都沒有」的預設值。

## PC-98：只差一條 `xor ah, ah`

DOS 把迴圈變數零擴充後 `cmp ax, n`，PC-98 直接 `cmp al, n`。
其餘 13 條是 `DS:4A0Eh`↔`7AC4h`、`DS:4A0Fh`↔`7AC5h` 的位址。
**沒有邏輯差異。**

## 明確不宣稱

- 沒有宣稱那些圖磚編號各是什麼圖。
- 沒有宣稱 `DS:4A0Eh`／`4A0Fh`／`4A10h` 的名稱與由誰設定。
- 沒有宣稱 `本模組 0378h` 第一個參數（`0`／`2`／`6`）的意義。
- 沒有宣稱畫面位置 `(列, 欄)` 的座標系。
