# 1056 — 效果的影響範圍：以效果碼查半徑，逐格重畫站在裡面的人

- 證據等級：`exact`（PC-98 側 255 條逐條讀完）
- 作法見 spec 783

## `pc98 overlay-32:00473h`（`retf 4`）

原本待解讀。兩個 byte 參數：`arg_2` ＝ 欄、`arg_0` ＝ 列。

```pascal
x1 := 欄;  x2 := 欄;  y1 := 列;  y2 := 列;          { 預設只有自己這一格 }
if (DS:0BE2Ch <> 0) or (DS:8BEEh = 0) then …跳過半徑計算…
else case DS:0BE2Dh of                              { ★ 效果碼 }
    …見下表…
end;
for 欄 := x1 to x2 do
  for 列 := y1 to y2 do begin
      <sub_864h>(欄 − 視窗^[2], 列 − 視窗^[3], 0);
      <sub_7F5h>(欄, 列, @槽, @?);
      if 槽 > 0 then
          if <sub_A4Fh>(槽, …, 0) then
              <overlay-33 entry#6>(…, 表A[槽], 表B[槽],
                                   角色[槽]^[18Eh]^[9], 0, 角色[槽]^[143h]);
  end;
```

## ★★★ 半徑表（以 `DS:0BE2Dh` ＝ 效果碼為索引）

| 效果碼 | 範圍 |
|---|---|
| `15h`(21)、`19h`(25)、**`5Bh`(91)** | `±1` ⇒ **3 × 3** |
| `22h`(34) | `＋1` 只往一邊 ⇒ **2 × 2** |
| `52h`(82)、`2Fh`(47) | `DS:0BDF0h` ＝ `50h` 或 `51h` → `±2`（5 × 5）；**否則 `±3`（7 × 7）** |
| `29h`(41)、`2Eh`(46)、`32h`(50)、`34h`(52)、`35h`(53)、`45h`(69) | `±1` ⇒ 3 × 3 |
| `57h`(87) | `±2` ⇒ 5 × 5 |
| 其他 | `±0` ⇒ **只有一格** |

> ★★★ **`DS:0BE2Dh` 就是 spec 1005 效果分派表的效果碼**
> ——`5Bh` ＝ 91 正是那份規格裡認出來的**毒雲**（同一個編號、同樣是 3 × 3）。
> ⇒ 這張表補上了**每個效果佔多大的地面範圍**，是效果分派表之外的第二個維度。
>
> ★ `52h`／`2Fh` 兩個效果的半徑**還會再看 `DS:0BDF0h`**（`50h`／`51h` 時縮小）
> ——同一個效果有兩種大小。

★ **`DS:0BE2Ch <> 0` 或 `DS:8BEEh ＝ 0` 時整張表都不查**，範圍退成單格。

## 逐格做什麼

★ `視窗^[2]`／`[3]`（`DS:9F2Ch` 指的記錄）是**畫面左上角的地圖座標**，
相減得到螢幕上的相對格。
★ `sub_7F5h(欄, 列, …)` 回傳**站在那一格的隊伍槽號**（0 表示沒人）。
★ 有人且 `sub_A4Fh` 成立才叫 `overlay-33 entry#6`
——參數裡有 `角色^[143h]`（spec 1037 的**圖示顏色**）與
`角色^[18Eh]^[9]`（走一層遠指標再取第 9 個 byte）。

⇒ 形狀上是：**把效果範圍內每一個角色的圖示重畫一次**（換色／蓋效果）。
