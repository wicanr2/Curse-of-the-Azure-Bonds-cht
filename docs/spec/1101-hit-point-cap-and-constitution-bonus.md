# 1101 — HP 上限的計算：多職取平均，體質加成有各職業的等級上限

- 狀態：`READY`
- 證據等級：`exact`（DOS `overlay-17:046ECh` 與 `overlay-17:045E9h` 逐條讀完；
  兩張資料表以 AD&D 1e 的 HD 上限與體質加成指紋比對）
- spec 1086 §四 用到的 `near 46ECh` 就是這一支
- 產物：[`../audit/resident-data-tables.md`](../audit/resident-data-tables.md)

## 一、`overlay-17:046ECh`：掃八個職業槽再取平均

```pascal
function HP上限(角色): byte;                    { retf 4 }
begin
    職業數 := 0;  總和 := 0;
    for i := 0 to 7 do
        if 角色^[109h + i] > 0 then begin        { 這個職業槽有等級 }
            總和 := 總和 + 角色^[109h + i];
            inc(職業數);
            if i = 4 then inc(總和);             { ★ 遊俠 ＋1 }
            if i = 7 then inc(總和);             { ★ 武僧 ＋1 }
        end;
    修正 := <sub_45E9>(角色);                    { 有號，見 §二 }
    if 修正 < 0 then begin
        if 總和 > 職業數 ＋ abs(修正) then 總和 := (總和 ＋ 修正) div 職業數
        else                                     總和 := 1;   { ★ 至少 1 }
    end else
        總和 := (總和 ＋ 修正) div 職業數;
    結果 := 總和;
end;
```

> ★★ **多職就是除以職業數**——AD&D 的多職 HP 平均。
> ★ 遊俠（槽 4）與武僧（槽 7）各多 ＋1。
> ★ 修正為負且總和不夠時，下限是 **1**，不會變成 0 或負數。

⚠ **一個未解的衝突**：本支累加的是 `角色^[109h + i]`，而 spec 1084／1055 說
那八格是**職業槽等級**。等級總和除以職業數得到的是平均等級，不是 HP；
但 spec 1086 §四 拿本支的回傳值與 `角色^[78h]`（最大 HP）比較並回寫。
⇒ **`+109h + i` 在這個 context 的語意本規格不宣稱**，兩種讀法必須另外查清楚，
否則照抄會得到錯的 HP。

## ★★★ 二、`overlay-17:045E9h`：體質加成，每個職業各有等級上限

```pascal
function 體質HP修正(角色): shortint;
begin
    修正 := 0;
    for i := 0 to 7 do begin
        if 角色^[109h + i] <= 0 then continue;
        上限 := byte[DS:3EB9h + i];                    { 該職業槽的等級上限 }
        if 角色^[109h + i] >= 上限 then continue;      { ★ 到頂就不再加 }
        修正 := 修正 + byte[DS:427Fh + 角色^[19h]];    { 體質目前值查表 }
        …角色^[75h] = 2 或 3 時另有分支…
    end;
end;
```

★ `角色^[19h]` 是**體質的目前值**（spec 1079 的奇數位移）。

### `DS:3EB9h` 各職業槽的體質加成等級上限（8 bytes）

| 槽 | 職業 | 值 | 實際可加的等級 | AD&D 1e 的 HD 上限 |
|---|---|---|---|---|
| 0 | 牧師 | 10 | 1..9 | 9 ✓ |
| 1 | 德魯伊 | 15 | 1..14 | 14 ✓ |
| 2 | 戰士 | 10 | 1..9 | 9 ✓ |
| 3 | 聖騎士 | 10 | 1..9 | 9 ✓ |
| 4 | 遊俠 | 11 | 1..10 | 10 ✓ |
| 5 | 法師 | 12 | 1..11 | 11 ✓ |
| 6 | 盜賊 | 11 | 1..10 | 10 ✓ |
| 7 | 武僧 | 19 | 1..18 | 18 ✓ |

> ★★★ **八個全部命中 AD&D 1e 的 HD 上限**（判定是 `等級 >= 上限 就不加`，
> 所以「上限 − 1」才是最後一個仍加體質的等級）。這一組指紋確認了
> 表的基底、筆距與職業槽順序（spec 1084 的牧師／德魯伊／戰士／聖騎士／
> 遊俠／法師／盜賊／武僧）三者都對。

### `DS:427Fh` 體質 → HP 加成（依 `角色^[19h]` 索引）

| 體質 | 3 | 4–6 | 7–14 | 15 | 16 | 17..25 |
|---|---|---|---|---|---|---|
| 加成 | **−2** | **−1** | 0 | **+1** | **+2** | +2 |

> ★★ 與 AD&D 1e 的一般職業體質加成一致。
> ★ AD&D 的戰士系在 17／18 另有 ＋3／＋4——本表統一給 ＋2，
> 而 `045E9h` 裡正好有 `角色^[75h] = 2`（戰士）或 `= 3`（聖騎士）的分支。
> ⚠ 該分支的內容本規格未讀完，戰士系的額外加成怎麼算尚未宣稱。
> ⚠ 索引 0 那格是 `+8`，形狀上不是體質 0 的加成（體質最低是 3）；
> 與 spec 1099 的表一樣，索引 0 很可能屬於相鄰的資料。

## 對 remake 的意義

- 多職角色的 HP 目前是 0（建角只設了職業槽等級與經驗值），要接上本支才會有值。
- 接之前必須先解掉 §一 的衝突：`+109h + i` 到底是等級還是各職累積 HP。
- 戰士系的體質加成分支也要讀完，否則戰士的 HP 會少算。

## 明確不宣稱

- 沒有宣稱 `角色^[109h + i]` 在 `046ECh` 的語意（等級 vs 各職 HP）。
- 沒有宣稱 `045E9h` 裡 `角色^[75h] = 2/3` 分支的內容。
- 沒有宣稱 `DS:427Fh` 索引 0 那格（`+8`）的用途。
- 沒有宣稱本支由誰呼叫（只知道 spec 1086 §四 的數值調整會用）。
- 沒有宣稱 PC-98 側的對應位址。
