# 854 — 視線的逐格推進，與方向編碼 0..8 的定案

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側**只差一條表基底**；三張表由原始
  bytes 解出，兩平台逐 byte 相同）
- 作法見 spec 783

## `overlay-31:00246h` ↔ `overlay-31:00246h`（兩平台各 132 條，同位址）

`overlay-31` ＝ LOS。`retf 4` ＝ 一個狀態記錄的遠指標。回傳 1 ＝ 還沒到終點。

```pascal
xs := 1;  ys := 1;  結果 := 0;

if 有號(s^[0Ah]) >= 有號(s^[0Ch]) then begin        { x 是主軸 }
    if s^[0Eh] = s^[04h] then 離開;                { 已到終點 }
    s^[0Eh] := s^[0Eh] + s^[12h];                  { 主軸走一格 }
    xs := s^[12h] + 1;
    s^[08h] := s^[08h] + s^[0Ch] * 2;              { 誤差累加（寫成加兩次） }
    s^[16h] := s^[16h] + 2;                        { 步數 ＋2 }
    if 有號(s^[08h]) >= 有號(s^[0Ah]) then begin
        s^[08h] := s^[08h] − s^[0Ah] * 2;
        s^[10h] := s^[10h] + s^[14h];              { 次軸也走一格 }
        ys := s^[14h] + 1;
        inc(s^[16h]);                              { 斜走再 ＋1 }
    end;
    結果 := 1;
end else begin
    { y 是主軸，整段對稱：0Ch↔0Ah、0Eh↔10h、12h↔14h }
end;

s^[17h] := byte[2558h + ys * 3 + xs];              { 查 3×3 表得方向碼 }
```

這是標準的 Bresenham，只是誤差項用「加兩次／減兩次」代替乘 2。

### 狀態記錄的版面

| 位移 | 內容 |
|---|---|
| `+04h` | 終點 x |
| `+06h` | 終點 y |
| `+08h` | 誤差累加器 |
| `+0Ah` | x 方向的長度（主軸判斷用） |
| `+0Ch` | y 方向的長度 |
| `+0Eh` | 目前 x |
| `+10h` | 目前 y |
| `+12h` | x 每步的增量（−1／0／＋1） |
| `+14h` | y 每步的增量 |
| `+16h` | **累計步數**（直走 ＋2、斜走 ＋3） |
| `+17h` | 這一步的方向碼 |

**`+16h` 的計法就是 spec 837 的移動花費**：正向 `地形成本 × 2`、斜向 `× 3`。
視線距離與移動力用的是**同一套半格度量**，spec 838 的 `距離 div 2` 也對得起來。

## 方向編碼 0..8 定案

`DS:2558h`（PC-98 `DS:47E6h`）是一張 3×3 表，索引 `(y增量+1) × 3 + (x增量+1)`，
兩平台逐 byte 相同：

| | x −1 | x 0 | x ＋1 |
|---|---|---|---|
| **y −1** | 7 | 0 | 1 |
| **y 0** | 6 | **8** | 2 |
| **y ＋1** | 5 | 4 | 3 |

拿去對 spec 837 提過的兩張 9 bytes 位移表（`DS:2694h` ＝ dx、`DS:269Dh` ＝ dy）：

| 方向 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| dx | 0 | ＋1 | ＋1 | ＋1 | 0 | −1 | −1 | −1 | 0 |
| dy | −1 | −1 | 0 | ＋1 | ＋1 | ＋1 | 0 | −1 | 0 |

**兩張獨立的表完全一致**，方向編碼就此定案：

```
      7  0  1
      6  8  2      0 ＝ 上，順時針到 7 ＝ 左上，8 ＝ 原地
      5  4  3
```

這同時驗證了 spec 837 對 AI 方向偏移表的換算——偏移 `1` ＝ 順時針 45°、
`7` ＝ 逆時針 45°、`2` ＝ 90°、`4` ＝ 180°，全部成立。

## 明確不宣稱

- 沒有宣稱 `+0Ah`／`+0Ch` 進來時是 `|dx|` 還是 `2|dx|`（程式只比大小、只用來選主軸）。
- 沒有宣稱這個狀態記錄由誰初始化。
- 沒有宣稱 `+16h` 的上限或誰會讀它。
