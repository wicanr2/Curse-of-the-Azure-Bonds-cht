# 1217 — 一般強度火刀連戰的資源控制組

狀態：`READY`（限目前五／六級快捷隊伍、`route-clean-716` 與 1,800 幀控制組；
不宣稱一般強度已通關）

## 固定條件

- `COAB_KEY_BOOST=0`，不修改隊伍 HP、AC、命中、傷害或攻擊次數。
- 使用 `workplace/campaign-frames/route-clean-716.json`。
- 敵人數、敵人資料、骰子、戰場投影與戰鬥規則均不變。
- 隊伍是 spec 1210 的五級戰士／牧師／法師／遊俠／聖武士與六級盜賊，走正式
  訓練、購買、整備、記憶與休息 UI。

## 基線

皇家衛兵戰開場總 HP 182，勝利後剩 119；法師四發燃燒之手已耗盡。緊接的八名
火刀遭遇最後擊倒三名，六名隊員全倒、敵方剩五名。這證明 spec 1215 修正後第二戰
確實逐幀接受玩家輸入；失敗已不是「新遭遇在玩家按鍵前同步結算」。

## 兩個已還原的控制實驗

### 五格治療輕傷

把牧師五個一環槽全部透過正常 MEMORIZE 選成治療輕傷。QUICK 確實會找傷員並
施法，第二戰由剩五敵改善為剩兩敵，但仍全滅。這只證明資源配置有影響，不足以
支持把測試 loadout 永久改成單一法術，實驗已還原。

### 保留燃燒之手到第二戰

第一戰不開 QUICK magic，也不手動施放燃燒之手；第二戰看見「火刀」敵名後才開。
法師只來得及施放一次便倒下，最後仍剩五敵，與基線相同。實驗已還原。

## 結論與下一步

現有一環資源與 QUICK 戰術不足以證明一般強度連戰可過；不能藉此降低原版敵人數
或屬性。五級法師本應具有逐級法術選擇與更高環資源，但 guided／quick 建角要如何
呈現該選擇會改變玩家體驗，仍依共同決策閘門等待使用者選擇：原版逐級選法術，或
quick 固定 loadout、guided 逐級選擇。決策落地後，應以同一條一般強度控制組重跑。

spec 1241 已補完 CAMP 的一至五環候選、逐環容量與準備時間；3000 幀控制組確認
完整容量已到正式 UI，但歷史 route 仍只選一環法術，因此本節的快捷法師 loadout
決策仍然存在，不能把「能選」誤寫成「正常重放已選」。
