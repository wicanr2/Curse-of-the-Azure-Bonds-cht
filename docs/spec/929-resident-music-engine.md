# 929 — 常駐音樂引擎：命令式資料流、12 平均律、PC speaker 與 Tandy 雙輸出

- 證據等級：`exact`（四支函式逐條讀完）
- 位置：DOS `START.EXE` 的 `1941Bh`、`19490h`、`1951Eh`、`195AFh`
- 作法見 spec 783

## 全貌

常駐裡有一個**四聲道的音樂播放器**，與遊戲自己的音效呼叫
（`0713h:0020h` 等）分屬兩層。它有兩套硬體輸出：

| 函式 | 輸出裝置 | 聲道狀態基底 | 頻率表基底 |
|---|---|---|---|
| `1941Bh` | **PC speaker**（`out 42h` 設分頻、`out 61h` 開關閘門） | `DS:0176h` | `DS:02F6h` |
| `19490h` | **Tandy／PCjr SN76496**（`out 0C0h`） | `DS:0310h` | `DS:0490h` |

兩支都以 `byte_1C2E2 = 4` 當計數器、每個聲道 **`30h` ＝ 48 bytes**，
並把當次的基底寫進 `word_1C30C`（聲道）與 `word_1C30E`（頻率表）。

`word_1C308 = 0` 時兩支都直接跳到收尾（PC speaker 關閘門／SN76496 四個
聲道各送一個靜音命令 `9Fh`／`0BFh`／`0DFh`／`0FFh`）——**那是總開關**。

## `1951Eh`：每一格的聲道更新

```pascal
[si+0Ah] := [si+0Ah] ＋ [si+0Ch];          { 頻率滑音 }
[si+4]   := [si+4]   ＋ [si+6];            { 音量包絡 }

dx := 0;
相位 := [si+1Eh] ＋ [si+20h];              { 顫音 LFO }
if 相位 <> 0 then begin
    if 相位 >= [si+24h] then 相位 := 相位 − [si+24h];   { 週期回繞 }
    [si+1Eh] := 相位;
    ah := byte[[si+1Ch] ＋ (相位 sar 4)];  { 波形表 }
    dx := (ah shl 8) × [si+22h];           { 深度 }
end;
[si+8] := dx ＋ [si+4];                    { 實際輸出頻率 }

if [si+14h] <> 0 then begin                { 滑音剩餘格數 }
    dec([si+14h]);
    if [si+14h] = 0 then begin [si+18h] := 10h;  [si+1Ah] := 1 end;
end;

dec([si]);                                 { 音長倒數 }
if [si] = 0 then <195AFh>();               { 取下一個音符／命令 }

if [si+1Ah] <> 0 then begin                { 包絡表倒數 }
    dec([si+1Ah]);
    if [si+1Ah] = 0 then
        repeat                             { 走 4 bytes 一筆的包絡表 }
            bx := [si+16h] ＋ [si+18h];
            if word[bx+2] = 0FFFFh then begin
                [si+0Ah] := word[bx];
                if word[bx] = 0 then [si+0Ch] := 0;
                [si+18h] := [si+18h] ＋ 4;
            end else begin
                [si+0Ch] := word[bx];
                [si+1Ah] := word[bx+2];
                [si+18h] := [si+18h] ＋ 4;
                break;
            end;
        until false;
end;
```

### 聲道狀態版面（`30h` bytes）

| 位移 | 內容 |
|---|---|
| `+0` | 音長剩餘格數 |
| `+2` | 資料流指標 |
| `+4` | 音量／基礎值（每格加 `+6`） |
| `+6` | 音量包絡增量 |
| `+8` | 本格實際輸出值 |
| `+0Ah` | 頻率（每格加 `+0Ch`） |
| `+0Ch` | 頻率滑音增量 |
| `+0Eh` | 速度（音長倍率，0 視為 1） |
| `+10h` | 前一個目標頻率 |
| `+12h` | 移調量 |
| `+14h` | 滑音剩餘格數 |
| `+16h` | 包絡表基底 |
| `+18h` | 包絡表位移 |
| `+1Ah` | 包絡下一筆的倒數 |
| `+1Ch` | 顫音波形表基底 |
| `+1Eh` | 顫音相位 |
| `+20h` | 顫音相位增量 |
| `+22h` | 顫音深度 |
| `+24h` | 顫音週期 |

## `195AFh`：命令式資料流直譯器

```pascal
di := [si+2];
if di = NIL then 離開;
word_1C30A := si;
repeat
    b := byte[di];  inc(di);
    if b >= 0FAh then
        跳表 word[16Ah ＋ (b − 0FAh) × 2]        { 六個命令 }
    else
        音符(b);
until 結束;
```

### 六個命令（`0FAh`..`0FFh`，跳表在 `DS:016Ah`）

| 目標 | 行為 |
|---|---|
| `195D2h` | **迴圈**：讀索引 byte、讀位址 word；`[si＋索引]` 是計數器，非 0 就遞減，歸零才往下走，否則跳到該位址 |
| `195E9h` | **切換聲道**：讀 word，`si := word ＋ word_1C30C`，把 `+4`..`+24h` 共 15 個 word 全部清 0 |
| `19623h` | **設參數**：讀索引 byte、讀值 word，`[si＋索引] := 值`；索引為 0 時直接收尾 |
| `19650h` | **返回**：`di := word_1C310` |
| `19657h` | **呼叫**：讀位址 word，把目前 `di` 存進 `word_1C310`，跳過去 |
| `19665h` | 再讀一個 byte 當音符 |

收尾（`19633h`）：`[si] = 0` 時把 `byte[152h ＋ (4 − byte_1C2E2)]` 清 0 並讓
`di := 0`，最後 `[si+2] := di`。

### 音符：兩個 byte

```
第一個 byte：  高 3 bits ＝ 聲道編號        低 5 bits ＝ 音長索引
第二個 byte：  bit 7 ＝ 這是最後一個音符    低 7 bits ＝ 音高（7Fh ＝ 休止符）
```

- 聲道位址 ＝ `(b shr 5) × byte_1C2E3 ＋ word_1C30C`。
- 音長 ＝ `byte[157h ＋ 低5bits] × [si+0Eh]`（速度，0 視為 1），寫進 `[si]`。
- 休止符（低 7 bits ＝ `7Fh`）**只設音長，不動頻率**。

### ★ 音高換算就是 12 平均律

```pascal
n := 音高 ＋ [di+12h];          { 移調 }
八度 := 0;
while n >= 0Ch do begin n := n − 0Ch;  inc(八度) end;
頻率 := word[word_1C30E ＋ n × 2] shr 八度;
[di+4] := 頻率;   [di+8] := 頻率;
```

**`word_1C30E` 指向一張 12 筆的頻率表**（一個八度十二個半音），
更高的八度用**右移**得到——分頻值減半 ＝ 頻率加倍。
PC speaker 用 `DS:02F6h` 那張、Tandy 用 `DS:0490h` 那張。

同時 `[di+14h] := 目標頻率 − [di+10h]`（滑音增量的種子）、
`[di+18h] := 0`、`[di+1Ah] := 1`（重啟包絡）。

## ⚠ 噪音聲道的特例被停用

```
196BF  cmp di, 3A0h            ← 3A0h ＝ Tandy 聲道基底 310h ＋ 90h ＝ 第 3 聲道
196C3  jnz short $+2           ← 75 00：跳到下一條指令，兩條路一樣
196C5  add bx, word_1C30E      ← 一定會執行
```

`jnz short $+2` 的位移是 0，**跳到緊接的下一條指令**，
所以那個 `cmp` 的結果不影響任何事，`add bx, word_1C30E` 無條件執行。

SN76496 的第 3 聲道是**噪音聲道**，本來應該用不同的方式算暫存器值。
這條特例現在等於不存在——形狀上是被停用或改寫時留下的殘骸。

## 對 remake 的價值

音高換算（12 平均律 ＋ 右移八度）與音符編碼（3 bits 聲道 ＋ 5 bits 音長 ／
1 bit 結束 ＋ 7 bits 音高）是**可以直接照做的規格**。
資料流的六個命令構成一個小型 VM，重寫時要照樣支援迴圈與子序列呼叫，
否則長曲子會展不開。
