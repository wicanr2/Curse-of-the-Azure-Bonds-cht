# 第七百三十一輪：法術結算的共同迴圈（`sub_F06h`）

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-22:0F06h`（`retf 0Eh` ＝ 7 個 word）。

`overlay-22` 十幾條 opcode 的收尾都是它。

## 參數

依 Pascal 順序（先推的在高位址，spec 700）：

```text
sub_F06h(法術編號, 等級覆寫, arg_8, 傷害量, 傷害型別, 訊息 far)
```

所有已讀的呼叫點第一個參數都推 `DS:6F97h`（法術編號，spec 721）。

## 流程

```text
複製 訊息 → 區域緩衝（上限 28h）

if 傷害量 = 0 then DS:6F95h := 0 else DS:6F95h := 傷害型別
if DS:7434h = 0 then 返回
lvl := (等級覆寫 = 0) ? <overlay-24 entry#36>(法術編號) : 等級覆寫

for k := 1 to DS:7434h do
    p := far [7431h + k×4]
    if p = NIL then 跳過                                   ← 有檢查

    if 表[法術編號].+8 = 0 then 豁免 := 0
    else 豁免 := <overlay-23 entry#8>(p, 表[法術編號].+9, 0)

    if 表[DS:6F97h].+2 = 0FFh then                         ← ⚠ 這裡用 DS:6F97h
        <overlay-24 entry#7>(p)
        <overlay-23 entry#4>(p, 0Bh)
        if <overlay-23 entry#7>(p^[19Ah], p, DS:6506h) = 0 then
            傷害量 := 0；豁免 := 1

    if 傷害量 > 0 then
        <overlay-23 entry#20>(p, 傷害量, 表[法術編號].+8, 豁免)

    if 表[法術編號].+0Ah > 0 then
        <overlay-23 entry#21（PUTEFFECT）>(p, 表[法術編號].+0Ah,
            <sub_E11h>(法術編號), lvl, arg_8, 表[法術編號].+8, 豁免, 緩衝)

DS:6F95h := 0
```

## `DS:37DAh` 表格再解出四個欄位

| 格內位移 | 用途 | 出處 |
|---|---|---|
| `+0` | 法術分類（0/1/2/3） | spec 728 |
| `+2`、`+3` | 持續時間係數（第一組）；`+2 = 0FFh` 是特例標記 | spec 705、本輪 |
| `+4`、`+5` | 持續時間係數（第二組） | spec 712 |
| `+6` | 「至少撐 1」旗標 | spec 705 |
| `+7` | 選目標模式（1／2／4） | spec 719 |
| `+8` | 豁免旗標（0 ＝ 不用擲） | 本輪 |
| `+9` | 豁免類別 | 本輪 |
| `+0Ah` | 要套用的效果編號（0 ＝ 不套） | 本輪 |

16 bytes 一格裡已經解出 9 個欄位。

## 這解掉了 spec 730 的未定項

spec 730 記錄 `4DA0h` 在尾端**無條件**用 `is clumsy` 呼叫 `sub_F06h`，即使剛才
走的是 `is slowed` 那條，看起來像複製時忘了改。

現在可以判斷：**訊息只在 `表[法術編號].+0Ah > 0` 時才會被用到**（傳給
`PUTEFFECT`），而 `4DA0h` 傳進來的傷害量是 0。所以那條法術的表格項目若
`+0Ah = 0`，那句 `is clumsy` 根本不會顯示，「忘了改」也不會有可見後果。

要確定得看 `DS:37DAh` 表的實際內容——它在 resident 資料段，不在 overlay 裡。
**本輪把問題從「是不是 bug」縮小成「查表格 `+0Ah` 那一欄」。**

## 一處латent 的不一致

第 12 行用的是 `表[DS:6F97h]`，其餘全部用 `表[法術編號]`（`arg_C`）。
已讀過的每一個呼叫點都是 `arg_C := DS:6F97h`，所以兩者永遠相等——**目前不會出
事，但兩個來源混用是真的**。如果 remake 把法術編號改成參數傳遞而不再用全域，
這一行會變成讀到別的東西。
