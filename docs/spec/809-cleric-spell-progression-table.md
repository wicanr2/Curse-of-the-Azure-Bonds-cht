# 809 — 牧師系可記憶法術數：進階表在 `DS:42BAh`，智慧加成寫死在程式碼

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側**只有 2 條運算元差異**；進階表取自
  常駐資料段 dump，兩平台逐位元組相同）
- 作法見 spec 783

## `overlay-25:0671h`（entry#2，121 條，差異 2 條）

`retf 6` ＝ 3 個 word。依宣告順序：`(角色, 要不要重算)`。

```pascal
等級 := 角色^[109h] + 角色^[111h] * <本模組 13BCh>(角色);
if 有號(等級) <= 0 then 離開;

if 要不要重算 <> 0 then begin
    for j := 2 to 5 do 角色^[12Ch + j] := 0;
    角色^[12Dh] := 1;
    for L := 2 to 等級 do                              { 有號 }
        for j := 1 to 5 do
            角色^[12Ch + j] := 角色^[12Ch + j] + byte[42BAh + L * 5 + j];
end;

if (角色^[15h] > 0Ch) and (角色^[12Dh] > 0) then inc(角色^[12Dh]);   { 智慧 13 }
if (角色^[15h] > 0Dh) and (角色^[12Dh] > 0) then inc(角色^[12Dh]);   { 智慧 14 }
if (角色^[15h] > 0Eh) and (角色^[12Eh] > 0) then inc(角色^[12Eh]);   { 智慧 15 }
if (角色^[15h] > 0Fh) and (角色^[12Eh] > 0) then inc(角色^[12Eh]);   { 智慧 16 }
if (角色^[15h] > 10h) and (角色^[12Fh] > 0) then inc(角色^[12Fh]);   { 智慧 17 }
if (角色^[15h] > 11h) and (角色^[130h] > 0) then inc(角色^[130h]);   { 智慧 18 }
```

## 進階表 `DS:42BAh`（PC-98 `DS:734Fh`）：每等級 5 bytes 的**增量**

索引式是 `42BAh + L * 5 + j`（`j` ＝ 法術等級 1..5），所以每一列的起點是
`42BBh + L * 5`。兩平台逐位元組相同：

| 角色等級 | 1 級 | 2 級 | 3 級 | 4 級 | 5 級 | 累計後（含基底 1/0/0/0/0） |
|---|---|---|---|---|---|---|
| 1 | — | — | — | — | — | 1 |
| 2 | +1 | | | | | 2 |
| 3 | | +1 | | | | 2 / 1 |
| 4 | +1 | +1 | | | | 3 / 2 |
| 5 | | +1 | +1 | | | 3 / 3 / 1 |
| 6 | | | +1 | | | 3 / 3 / 2 |
| 7 | | | | +1 | | 3 / 3 / 2 / 1 |
| 8 | | | +1 | +1 | | 3 / 3 / 3 / 2 |
| 9 | +1 | +1 | | | +1 | 4 / 4 / 3 / 2 / 1 |
| 10 | | | | +1 | +1 | 4 / 4 / 3 / 3 / 2 |
| 11 | +1 | | +1 | | | 5 / 4 / 4 / 3 / 2 |
| 12 | +1 | +1 | +1 | | | 6 / 5 / 5 / 3 / 2 |

累計後那一欄**與 AD&D 一版的牧師法術進階表完全相同**。

### 表只有到等級 12

`L = 13` 之後整列都是 `FFh`（等級 0 那一列是 `06 00 FF FF FF`，不屬於這張表）。
迴圈 `for L := 2 to 等級` **沒有上界檢查**，所以角色等級超過 12 時每一級會各加
`0FFh`（255）。這是資料與程式碼的落差，remake 必須自己決定要不要補上界。

## 智慧加成寫死在程式碼裡，不是資料

六個門檻 `> 0Ch`..`> 11h` ＝ 智慧 **13 / 14 / 15 / 16 / 17 / 18**，加的位置是
1 級 ×2、2 級 ×2、3 級 ×1、4 級 ×1——**AD&D 牧師的智慧額外法術表**。

- **`角色^[15h]` 是智慧。**
- 每一條都附帶 `該等級目前 > 0` 的條件：**還不能施放那個等級的角色拿不到加成**。
- 這六條**與進階表分開**，改一個不會動到另一個。

### `+12Ch` 那張表的第 0 格再次讓出

清零從 `j = 2` 開始、基底寫在 `+12Dh`，累加從 `j = 1` 起——**`+12Ch` 本身從頭到尾
沒被碰過**。配合 spec 788 的索引式 `+12Ch + 職業 * 5 + 等級`（等級 1 起算），
職業 0 的區塊就是 `+12Dh`..`+131h`。本專案第五次遇到這個擺法。

由此也定下：**職業碼 0 ＝ 牧師系**（spec 773 的法術屬性表 `+0` 欄只出現
`00` / `02` / `03`）。

### 參數為 0 時只加成、不重算（會累積）

`要不要重算 ＝ 0` 那條路**跳過清零與重算，但六條智慧加成照跑**。連續呼叫兩次
就會多加一次。呼叫端必須保證這條路只在剛重算過之後走。

## 明確不宣稱

- 沒有宣稱 `13BCh` 回傳什麼（形狀上是「要不要把第二職業的等級算進來」的 0/1）。
- 沒有宣稱 `+109h` / `+111h` 哪一個是第一職業。
- 沒有宣稱職業碼 `02` / `03` 是什麼，也沒有宣稱它們用哪一張進階表。
- 沒有宣稱 `DS:42BBh` 那個 `06 00` 屬於什麼。
