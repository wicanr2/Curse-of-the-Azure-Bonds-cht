# 800 — 隊列調序（與下一位對調）、戰鬥員佔地的逐格檢查

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-15:16CBh`（entry#19，84 條，差異 34 條）— 把目前角色往後移一位

```pascal
前 := DS:650Ah;
if 前 <> DS:6506h then
    while 前^[189h] <> DS:6506h do 前 := 前^[189h];
後 := DS:6506h^[189h];
if 後 = NIL then begin                       { 已在隊尾 → 繞到隊首 }
    DS:6506h^[189h] := DS:650Ah;
    DS:650Ah := DS:6506h;
    前^[189h] := NIL;
end else begin                               { 與下一位對調 }
    DS:6506h^[189h] := 後^[189h];
    if DS:650Ah = DS:6506h then DS:650Ah := 後;
    if 前 <> DS:6506h then 前^[189h] := 後;
    後^[189h] := DS:6506h;
end;
```

`retf`（無參數）。

- 找前一位用的是**從頭走一遍**（單向串列沒有前向指標）。若目前角色就是隊首，
  `前` 會停在它自己，後面兩處判斷都靠 `前 <> DS:6506h` 擋掉。
- **隊尾會繞回隊首**，不是原地不動——與 spec 794 的 `'O'`（下一位到底不動）
  剛好相反，所以「調序」與「選人」是兩套邊界規則。
- 對調之後 `DS:6506h` 沒有改變，**目前選的還是同一個角色**，只是它在串列裡的
  位置換了。

## `overlay-32:0763h`（entry#12，79 條，差異 6 條）— 佔地的四格檢查

```pascal
可 := 1;
i := <本模組 0CAEh>(參數2, 參數4);
if byte[66A6h + i * 4] = 0 then 結果 := 0
else
    for k := 0 to 3 do
        if <本模組 0011h>(byte[66A6h + i * 4], k, @dx, @dy) then begin
            r := <本模組 0732h>(byte[67C6h + i] + dx, byte[680Eh + i] + dy);
            if r = 0 then begin
                可 := 0;
                if 參數0 <> 0 then 結束;
            end else begin
                可 := 1;
                if 參數0 = 0 then 結束;
            end;
        end;
結果 := 可;
```

`retf 6` ＝ 3 個 word，回傳 `al`。

### 戰鬥員記錄的 `+3` 是「佔幾格」

`DS:66A3h + i * 4` 的 `+3`（＝ `66A6h + 4i`，spec 785）在這裡被當成
`0011h` 的第一個參數，用來把 `k = 0..3` 展開成一組 `(dx, dy)` 位移；`0` 表示
**沒有佔地**，整個檢查直接回 0。

配合 spec 785 已知的：`DS:67C6h + i` / `DS:680Eh + i` 是該戰鬥員的螢幕座標
（世界座標減地圖原點）。所以這一支是**把佔地的每一格換算成螢幕座標後逐格問
`0732h`**。

### 參數 0 是 AND / OR 的開關

| `參數0` | 語意 |
|---|---|
| ≠ 0 | **每一格都要成立**（遇到 0 立刻回 0） |
| ＝ 0 | **任一格成立就夠**（遇到非 0 立刻回 1） |

兩種模式共用同一段程式碼，只差提前離開的條件。remake 不能只實作其中一種。

迴圈跑滿 `k = 0..3`（四格），但 `0011h` 回傳假的那些 `k` 會被跳過——所以實際
檢查幾格由 `+3` 決定。

## 明確不宣稱

- 沒有宣稱 `+3` 的數值與格數的對應關係（只確定 0 ＝ 不檢查）。
- 沒有宣稱 `0011h` 展開出來的四組位移是什麼形狀。
- 沒有宣稱 `0732h` 判的是什麼（形狀上是「這一格可不可以」）。
- 沒有宣稱 `0CAEh` 如何從兩個參數算出戰鬥員索引。
