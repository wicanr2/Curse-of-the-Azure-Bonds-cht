# 1015 — 戰鬥回合的按鍵分派：九個指令鍵、兩個 DOS 專屬的後門

- 證據等級：`exact`（DOS 側 302 條逐條讀完；PC-98 對側 288 條，
  差異已逐條比對）
- 作法見 spec 783

## `dos overlay-08:003D5h` ↔ `pc98 overlay-08:00414h`（`retf 4`）

兩側原本都是待解讀。唯一的參數是角色遠指標。
這是**玩家操作的那一個戰鬥員的回合主迴圈**——spec 1008 的移動指令就是它叫的。

## 骨架

```pascal
procedure 玩家回合(角色: 遠指標);
if 角色^[196h] = 0 then begin                        { 不能行動 }
    <overlay-24 entry#34>(角色);  exit
end;

if 角色^[18Dh]^[0] > 0 then begin                    { ★ 這一格非 0 就直接施法 }
    n := 角色^[18Dh]^[0];  角色^[18Dh]^[0] := 0;
    <overlay-22 entry#5>(@結束, 1, 0, n);            { 施法主流程，spec 705／既有 }
    結束 := <overlay-24 entry#34>(角色);
    exit;
end;

結束 := 0;
repeat
    <sub_76C>(@鍵, 角色);                            { 戰鬥行動選單，依狀態串選項 }
    …按鍵分派（見下）…
    if 結束 = 0 then begin
        <overlay-32 entry#22>(1, 2, 角色);
        DS:75E5h := 1;
        <overlay-24 entry#5>(角色);
    end;
until 結束 <> 0;
```

★ `角色^[18Dh]^[0]`（戰鬥狀態的第一格）非 0 就**跳過整個選單直接施法**——
形狀上是「上一回合排隊的法術這回合結算」。

## ★★ 兩套按鍵表，由 `DS:7295h` 切換

`DS:7295h = 0` 時是**指令模式**：

| 鍵 | 做什麼 | 呼叫 |
|---|---|---|
| `Q` | 交給 AI 打完這一回合 | `overlay-09 entry#1`（既有：一個戰鬥員的一回合） |
| `M` | 移動 | `sub_B06`（＝ spec 1008 的移動指令，帶 `' '` 進去開選單） |
| `V` | 檢視 | `overlay-19 entry#5` ＋ `overlay-13 entry#8` |
| `A` | 攻擊 | `overlay-13 entry#21`（10 word） |
| `U` | 使用物品 | `DS:7294h := 2`；`overlay-19 entry#6`（`Ready/Use/Trade/Drop/Halve/Join` 選單） |
| `C` | 施法 | `overlay-13 entry#19`（既有：開始施法） |
| `T` | 轉化不死 | `overlay-13 entry#12`（既有：**Turn Undead**，AD&D 轉化矩陣在 `DS:0367h`） |
| `D` | — | `sub_FE8` |
| 空白 | 全隊掃一遍，`+0F7h < 80h` 的人 `+198h := 0` | — |

`DS:7295h ≠ 0` 時是**方向鍵直接移動模式**：
`48h`／`50h`／`4Dh`／`4Bh`／`47h`／`4Fh`／`51h`／`49h` 直接把掃描碼餵給
`sub_B06`（spec 1008 的八方向表），**不經過選單**。

★ 兩種模式共用後面那三個鍵（`2`、`10h`、`-`），所以它們在兩種模式下都能按。

## ★★ 兩個 DOS 專屬的後門，PC-98 拿掉了

| 鍵 | DOS | PC-98 |
|---|---|---|
| `'2'`（`32h`） | 切換 `DS:75DAh`，顯示 **`'Magic On'`／`'Magic Off'`** | **沒有** |
| `'-'`（`2Dh`） | `overlay-13 entry#33` ＝ **神明介入**（`'The Gods intervene!'`，把陣營 1 的成員救回來） | **沒有** |
| `10h` | 全隊叫一次 `sub_1314`、`角色^[18Dh]^[3] := 14h`、直接結束回合 | 有 |
| `11h` | 沒有 | **有**（PC-98 才加的） |

★ `'2'` 是**魔法動畫開關**（`Magic On`／`Magic Off`），
`'-'` 是**救場用的作弊鍵**——兩個都只在 DOS 版留著。
PC-98 另外多了一個 `11h`，本規格不宣稱它做什麼。

不認得的鍵一律顯示 `"That doesn't work"`（`CS:03C3h`，17 字元）。

## ⚠ PC-98 的延遲改成 `DS:7F16h × 50`

DOS 在「AI 代打」與「`10h`」兩處各寫死一個 `0C8h`（200）的延遲：

```asm
mov ax, 0C8h  / push ax / call far ptr 9ABh:29Eh
```

PC-98 兩處都改成

```asm
mov al, ds:7F16h / xor ah, ah / mov cx, 32h / imul cx / push ax / call far ptr 8EEh:379h
```

——**`DS:7F16h × 50`**。這是既有那條「PC-98 用 `DS:7F16h × n` 取代 DOS 的固定動畫常數、
比例逐處重調」的又一個實例（`DS:7F16h = 4` 才會等於 DOS 的 200）。

## ⚠ 兩筆被誤標「邊界碎片」的其實是正式進入點

`sub_FE8`（`overlay-08:0FE8h`，`D` 鍵）與 `overlay-19:1588h`（`U` 鍵的物品選單）
台帳都標「邊界碎片」，但前者是同模組的 `call` 目標、後者是 overlay entry stub 的目標
——**起點都不是 IDA 猜的**。與 spec 1005 那七筆同一類，另行修正。

## 兩平台位址

| DOS | PC-98 |
|---|---|
| `DS:7295h`（方向鍵模式） | （對應位址未列） |
| `DS:75DAh`（魔法動畫） | — |
| `DS:7294h` | — |
| `DS:75E5h` | `DS:0A877h`（spec 1010／1012 同一格） |
| `resident 09AB:029Eh`（延遲） | `resident 08EE:0379h` |

## 中文化

三個字串都在 overlay code 段：

| 字串 | 長度 |
|---|---|
| `'Magic On'` | 8 |
| `'Magic Off'` | 9 |
| `"That doesn't work"` | 17 |

前兩個 PC-98 沒有用到（那個鍵被拿掉了），**中文版跟 PC-98 就不必翻**。
`"That doesn't work"` 走 `overlay-24 entry#19` 的訊息框。

⚠ 指令鍵 `Q`／`M`／`V`／`A`／`U`／`C`／`T`／`D` 是**選項字串裡的大寫字母**
（選單由 `sub_76C` 動態串接），與 spec 1012／1013 是同一套機制——
**中文化要跟 PC-98 的獨立熱鍵表**。

## 明確不宣稱

- 沒有宣稱 `DS:7295h`（方向鍵模式）與 `DS:7294h` 由誰設定。
- 沒有宣稱 `D` 鍵的 `sub_FE8`、`A` 鍵的 `overlay-13 entry#21` 做什麼。
- 沒有宣稱 `10h`／PC-98 的 `11h` 是什麼指令。
- 沒有宣稱 `角色^[18Dh]^[0]` 存的是什麼（形狀上是排隊中的法術編號）。
- 沒有宣稱空白鍵那一段清 `+198h` 的用意。
