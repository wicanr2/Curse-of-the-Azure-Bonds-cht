# 第七百四十輪：`+13h` 與 `+15h` 是兩個施法屬性

狀態：`READY`。等級：`exact`（流程）／`strong inference`（欄位是智力／睿智）。
日期：2026-08-14
位置：DOS `overlay-12:15E6h`。

## 流程

```text
角色^[13h] := 7
角色^[15h] := 7
<overlay-24 entry#20>(角色, '<名字> is stupid'（CS:15CFh）, 0Ah, 1)

if DS:4FBAh = 5 then
    角色^[18Dh]^[1] := 0
    if 角色^[18Dh]^[0] > 0 then
        <overlay-24 entry#20>(角色, '<名字> lost a spell'（CS:15D9h）, 0Ch, 1)
        <overlay-24 entry#16>(角色, 角色^[18Dh]^[0])
        角色^[18Dh]^[0] := 0
```

## 為什麼 `7` 這個值是關鍵

spec 728 的施法資格檢查（`overlay-22:0020h`）用的門檻是：

| 法術分類 | 檢查的欄位 | 門檻 |
|---|---|---|
| 0 | `角色^[15h]` | `<= 8` 就不能施放 |
| 1 | `角色^[15h]` | `<= 8` 就不能施放 |
| 2 | `角色^[13h]` | `<= 8` 就不能施放 |

把兩個欄位都設成 **7**，三類法術的第一道檢查同時失敗——**這個角色從此什麼都
不能施放**。訊息 `is stupid` 也對得上。

所以 `+15h` 與 `+13h` 是兩個施法用的屬性值（AD&D 裡對應智力與睿智，
分別管法師系與牧師系）。設成 7 而不是 0，是為了讓它落在
「合法屬性值但低於門檻」的範圍。

## 順帶把記憶中的法術也清掉

`DS:4FBAh = 5`（戰鬥畫面）時多做一段：`+18Dh^[1]` 清 0，若 `+18Dh^[0] > 0`
就再顯示 `lost a spell`、呼叫 `<overlay-24 entry#16>(角色, +18Dh^[0])`、
然後把 `+18Dh^[0]` 也清 0。

`entry#16` 就是 spec 733 裡「`Lose it?` 回答 `Y`」與「`Spell Aborted`」呼叫的
同一支——**扣掉一個已記憶的法術**。這裡把它用在「正在準備施放的那一個」上。

兩則訊息的顏色不同（`0Ah` 與 `0Ch`），所以第二則在畫面上是另一種強調。

## 明確不宣稱

- `+18Dh^[0]` 與 `^[1]` 分別存什麼（前者被當成 `entry#16` 的參數，看起來是
  法術編號）。
- 非戰鬥畫面為何不清法術。
- `+13h`／`+15h` 哪一個是智力、哪一個是睿智（spec 728 的分類 0／1／2 還沒對到
  具體職業）。
