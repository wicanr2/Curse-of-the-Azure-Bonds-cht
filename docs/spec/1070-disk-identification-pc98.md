## ★★ 期望的磁碟種類由 `DS:0A816h`（檔案類別）決定

```pascal

if DS:0A816h = 0 then 期望 := 6;
if DS:0A816h = 2 then 期望 := 7;
repeat
    if not <sub_5738h>() then begin                { 沒有磁碟 }
        顯示('セーブディスクを入れて、' ＋ 'リターン・キーを押してください。');
        continue
    end;
    種類 := <sub_7DCh>(0);
    if 種類 = 期望 then break;                     { ★ 對了就走 }
    …依 種類 顯示「這是哪一張片」…

```

★ `DS:0A816h` 就是 spec 1043／1069 的**檔案類別**
（`0` ＝ `*.guy`／Curse、`1` ＝ `*.cha`／Pool、`2` ＝ `*.sav`／Hillsfar）。
⇒ **期望的磁碟種類碼：`0` → `6`、`2` → `7`、其餘 → `4`。**
