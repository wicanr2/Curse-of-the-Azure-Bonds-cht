# 1063 — 防拷轉輪（PC-98 側）：同一張表、同一條公式，重試上限 3 次

- 證據等級：`exact`（PC-98 側 310 條逐條讀完）
- 作法見 spec 783；DOS 對側見 spec 1062

## `pc98 overlay-03:00131h`（`retf`）

原本待解讀。

## ★★★ 公式與答案表兩平台完全相同

```asm
02DF  mov  cx, 0Ch        ; 路徑 × 12
02F2  add  ax, 22h        ; ＋34
02F5  sub  ax, dx         ; −dethek
0304  add  [bp+var_5], 24h ; 夾到 0..35
0321  mov  dx, 25h        ; 方框 × 37
032A  mov  al, [di+0FCh]  ; ★ 表基底 ＝ DS:00FCh
```

| | DOS | PC-98 |
|---|---|---|
| 答案表基底 | `DS:0000h` | **`DS:00FCh`** |
| 表內容 | 6 × 37 | **逐 byte 相同** |
| 公式 | `(espruar ＋ 22h − dethek) ＋ 路徑 × 0Ch ＋ (5 − 方框) × 2`，mod `24h` | **相同** |
| `Random` 上界 | `1Ah` / `16h` / `3` / `6` | **相同** |
| 第二組符文索引 | `＋1Ah` | **相同** |

> ★★★ **同一張 6 × 37 的表、同一條公式**——
> 轉輪防拷在兩個平台是**同一份資料**，remake 只需要實作一次。

## ★★ PC-98 看得到重試上限：3 次

```asm
03AF  cmp  [bp+var_1], 2
03B3  ja   short loc_3B8      ; ★ 第 3 次錯就不再重來
03B5  jmp  loc_19E            ; 否則整個畫面重畫、重抽一題
```

失敗三次之後：

```pascal
<far 0893:0000h>(DS:483Ch);
<far 0893:0000h>(DS:4844h);
DS:7F16h := 9;
顯示('目に見えぬ力が、きみを〈奈落〉に放りこんだ！');   { 44 bytes }
Delay(3E8h);                                            { 1000 }
<far 07E3:0077h>();                                     { 形狀上是離開遊戲 }
```

★ DOS 側的上限判斷落在匯出沒有反組譯的區段（spec 1062 已註明），
**PC-98 這裡補上了「三次」這個數字**。

## 中文化：PC-98 的譯法可以直接參考

| DOS（spec 1062） | PC-98 | bytes |
|---|---|---|
| `'Align the espruar and dethek runes shown below, on translation wheel like this:'` | 「次のエスプルーアー文字とデテーク文字とを合わせてください。」 | 58 |
| `'-..-..-..'` | 「－・・－・・－・・」 | 18 |
| `'- - - - -'` | 「－　－　－　－　－」 | 18 |
| `'.........'` | 「‥‥‥‥‥‥‥‥‥」 | 18 |
| `'under the '` ＋ 圖樣 ＋ `'path.'` | 「で示された経路の、」 | 18 |
| `'Type the character in box number '` ＋ 數字 | 數字 ＋「番のマスには何とありますか？」 | 28 |

| `'An unseen force hurls you into the abyss!'` | 「目に見えぬ力が、きみを〈奈落〉に放りこんだ！」 | 44 |

> ★★★ **PC-98 把三個路徑圖樣改成全形符號**（`－・・`、`－　－`、`‥‥`）
> ——**圖樣本身被翻譯了**，因為它是文字不是圖形。
> ⇒ 中文版可以照做（用全形符號），不必沿用 DOS 的半形點與破折號。
> ★★★ PC-98 把語序整個重排：**數字在前**（「N 番のマスには…」），
> 而 DOS 是 `'…box number ' ＋ N`。中文跟 PC-98 比較自然。

⚠ `'espruar'`／`'dethek'` PC-98 譯成「エスプルーアー」「デテーク」——
中文可作「艾斯普魯亞文」「德西克文」或保留原文。

## 明確不宣稱
