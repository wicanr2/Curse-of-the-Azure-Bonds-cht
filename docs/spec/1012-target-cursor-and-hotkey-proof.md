# 1012 — 目標游標畫面：50×25 的戰場、半格距離，以及熱鍵機制差異的鐵證

- 證據等級：`exact`（DOS 側 493 條逐條讀完；PC-98 對側 521 條，
  多出來的 28 條是 DOS 沒有的熱鍵表填寫，已逐條讀完）
- 作法見 spec 783

## `dos overlay-13:033ACh` ↔ `pc98 overlay-13:0329Fh`（`retf 18h`）

兩側原本都是待解讀。這是**玩家用方向鍵挑戰場格子**的那個畫面。

### 簽章（24 bytes ＝ 12 word）

從被呼叫者的堆疊框重建，第一個宣告的在最高位址：

```pascal
procedure 選格子(施法者:  遠指標;   { bp+1Ah }
                 起點:    遠指標;   { bp+16h — 進來是游標起點，之後當區域變數用 }
                 射程:    byte;     { bp+14h }
                 模式:    byte;     { bp+12h }
                 arg_A:   byte;     { bp+10h }
                 arg_8:   byte;     { bp+0Eh }
             var 選定了:  byte;     { bp+0Ah，遠指標 }
             var 結果:    記錄);    { bp+06h，遠指標，7 bytes }
```

★ **`結果` 那 7 bytes 的版面是 `+0..3` 目標遠指標、`+4` 欄、`+5` 列**——
與 `DS:6E52h` 那張「已選目標清單」（筆距 7、數量 `DS:6E91h`）**是同一種記錄**。

## ★★ `far 0A54:08D4h` 是 Turbo Pascal 的集合成員判斷，不是字串比對

主迴圈的條件長這樣：

```asm
mov  al, [bp+var_2A]        ; 目前鍵
push ax
mov  di, offset unk_3359    ; ← 看起來像字串，其實是集合
push cs / push di
call far ptr 0A54h:8D4h
jz   繼續
```

`0A54:08D4h` 在常駐執行檔裡的 Borland 符號是 **`@Set@MemberOf$q4Byte`**。
所以第二個運算元是 **32 bytes 的集合點陣圖**，不是 Pascal 短字串。

```
3359h: 01 20 00 00 00 00 00 00  20 00 10 00 00 00 …   ⇒ 集合 = [#0, #13, 'E', 'T']
```

> ⚠ **`function_strings.py` 這類工具會把集合常數的前兩個 byte 讀成
> 「長度 1 的字串 `' '`」。看到某個「字串」只有一兩個字元、
> 而呼叫的又是 `0A54:08D4h`，就要當成集合去讀 32 bytes。**

迴圈因此是

```pascal
鍵 := ' ';
while not (鍵 in [#0, #13, 'E', 'T']) do begin … end;
```

——**按 T／Enter（選定）、E／0（取消）才離開，方向鍵一律繼續繞。**

## 主迴圈做什麼

```pascal
<overlay-32 entry#13>(欄, 列, 3, 方向);          { 把游標往 方向 移一格並重畫 }
欄 += dx[方向];  列 += dy[方向];                 { 九格方向表，spec 999 }
欄 := clamp(欄, 0, 31h);  列 := clamp(列, 0, 18h);   { ★ 50 × 25 的戰場 }

<overlay-32 entry#9>(欄, 列, @佔用者, @地形);
可選 := <overlay-31 entry#5>(施法者欄, 施法者列, @欄, @列, @距離, 地圖);
距離 := 距離 div 2;                               { ★ 半格制 }

if 模式 <> 0 then
    印字(0, 17h, 0Ah, 0, 'Range = ' ＋ Str(距離) ＋ '  ');

{ ── 這一格站的是誰 ── }
目標 := NIL;
if 可選 then
    if 佔用者 > 0 then 目標 := 遠指標(DS:6D35h ＋ 佔用者 × 4)
    else if 地形 = 1Fh then
        for i := 1 to DS:6E91h do
            if (byte[6E56h ＋ i×7] = 欄) and (byte[6E57h ＋ i×7] = 列) then
                目標 := 遠指標(DS:6E52h ＋ i×7);

if 目標 <> NIL then begin DS:75E5h := 1; <overlay-24 entry#5>(目標) end
else <清矩形>(15h, 26h, 1, 17h);

if (射程 < 距離) or (byte[26A2h ＋ 地形 × 4] = 0FFh) then 可選 := 0;
…（`模式 = 1` 時再過 `sub_1144`／`entry#41`／`entry#43`／`entry#32`／`entry#42` 五道）…
```

★ **`距離 div 2` ——射程也是半格制**，與 spec 1008 的移動力（顯示時 `div 2`）同一套。

★ **地形碼 `1Fh` ＝「這一格站著東西」**：spec 748 記過雲霧解除時
「有生物站著就改畫 `1Fh`」，這裡是消費端——`1Fh` 時要另外去
`DS:6E52h` 那張 7 bytes 一筆的清單裡按座標找人。

★ 座標夾在 `0..31h` × `0..18h` ＝ **50 欄 × 25 列**，
與 spec 994／999／1002 的戰場尺寸一致。

`byte[26A2h ＋ 地形 × 4] = 0FFh` 是 spec 994 的地磚查表哨兵——**不能選**。

## ★★★ 熱鍵機制差異的鐵證

DOS 的選單只有三個字串：

| 位址 | 內容 |
|---|---|
| `CS:3385h` | `'Center Exit'` |
| `CS:3391h` | `'Target '` |
| `CS:3399h` | `'(Use Cursor keys) '` |

**熱鍵就藏在大寫字母裡**——`C`entre、`E`xit、`T`arget，
與 `[#0, #13, 'E', 'T']` 那個集合、以及 `cmp al, 43h ; 'C'` 完全吻合。
DOS 沒有任何「熱鍵表」。

PC-98 同一個位置改成日文，而且**多了 28 條指令專門填熱鍵表**：

```asm
複製(unk_326B「 中央 」, DS:0A369h, 6);   mov byte ptr ds:0A33Bh, 43h  ; 'C'
複製(unk_3272「やめる」, DS:0A37Eh, 6);   mov byte ptr ds:0A33Eh, 45h  ; 'E'
複製(unk_3279「 決定 」, DS:0A362h, 6);   mov byte ptr ds:0A33Ah, 54h  ; 'T'
mov byte ptr ds:0A385h, 6
```

把位址攤開來看：

| 選項 | 文字寫到 | ＝ `DS:0A338h ＋ i × 7` | 熱鍵寫到 | ＝ `DS:0A334h ＋ i` |
|---|---|---|---|---|
| 「決定」 | `0A362h` | **i = 6** | `0A33Ah` | **i = 6** |
| 「中央」 | `0A369h` | **i = 7** | `0A33Bh` | **i = 7** |
| 「やめる」 | `0A37Eh` | **i = 10** | `0A33Eh` | **i = 10** |

> ★★★ **兩個索引完全對齊，而且正是 spec 755 讀出來的那兩張平行陣列
> （`DS:0A338h ＋ i × 7` 的 7 bytes 選項文字、`DS:0A334h ＋ i` 的 1 byte 熱鍵）。**

**這是 DOS／PC-98 熱鍵機制差異最乾淨的一個實例**：
同一個選單，DOS 靠選項字串裡的大寫字母，PC-98 靠一張獨立的熱鍵表。
spec 977／978 從選單 routine 那一端推出這條規則，這裡是資料端的獨立佐證。

**中文化必須跟 PC-98**：Big5 漢字的次位元組落在 `40h..7Eh`，
含 `43h`（C）、`45h`（E）、`54h`（T），照 DOS 的做法會把漢字的第二個 byte
當成熱鍵（spec 993）。

## PC-98 的字串

| 位址 | 內容 | 對應 DOS |
|---|---|---|
| `CS:3261h` | 6 bytes Shift-JIS | `'Range = '` |
| `CS:3268h` | `'  '` | `'  '` |
| `CS:326Bh` | 「 中央 」 | `Center` |
| `CS:3272h` | 「やめる」 | `Exit` |
| `CS:3279h` | 「 決定 」 | `Target` |
| `CS:3280h` | 「（テン・キーを使ってください）」 | `'(Use Cursor keys) '` |

★ 三個選項都是**固定 6 bytes ＝ 3 個全形字**（複製長度寫死 `6`），
中文同樣只有 **3 個字**的空間：「中央」「取消」「確定」剛好。
⚠ 那個 `mov ax, 6` 是寫死的複製長度，**不是字串本身的長度**。

## 按鍵表

方向鍵與 spec 1008 用同一組小鍵盤擴充掃描碼：

`48h`→0、`49h`→1、`4Dh`→2、`51h`→3、`50h`→4、`4Fh`→5、`4Bh`→6、`47h`→7；
`43h`（C）→ 把游標拉回中心（`entry#13(欄, 列, 0, 8)`）並設方向 8（原地）；
其他鍵一律設方向 8。
