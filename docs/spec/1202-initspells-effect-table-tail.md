# 1202 — `INITSPELLS` 的尾段：七個特殊攻擊效果碼在這裡接上 handler

- 證據等級：`exact`（兩平台 `INITSPELLS` 的賦值序列逐位元組解出、stub 目標
  對回 TPOV 控制記錄；判讀腳本 `scripts/spell_visual_table.py` 的
  `effect_assignments()` 可重生）
- 對應工作項：法術／特殊攻擊視覺（spec 1126 的「未歸屬演出常式」段）、
  RE-07 怪物特殊攻擊
- 上游 spec 1005（效果分派表）、1071（PC-98 法術分派表初始化）、
  1126（法術演出槽）；被本輪接上語意的 handler 見 spec 720／722／723／725／
  735／847／981／415

## 一句話

`INITSPELLS`（DOS `overlay-22:630Bh`＝entry#10、PC-98 `66EBh`）不只填法術
分派表——**尾段另外往 CALLEFFECT 的效果分派表（DOS `DS:6FA6h`、PC-98
`DS:0A040h`，spec 1005）寫七格**，把七個特殊攻擊效果碼接上 overlay-22 尾端
的 handler。spec 1126 那七支「未歸屬的演出常式」全部由此歸屬。

## 賦值序列（兩平台互相印證）

樣式都是 Borland 的 far pointer 賦值：`mov ax, stub位移；mov dx, 控制段；
mov [槽], ax；mov [槽+2], dx`。效果碼 ＝ `(槽位址 − 基底) ÷ 4`；
兩平台七格的**槽間距完全相同**（0／8／16／160／168／180／184），
效果碼對應因此一致。

## 這張表解開了什麼

1. **spec 1126 的「未歸屬演出常式」歸屬完畢**：那七個 `entry#24` 呼叫點
   （`58C0h`／`59FEh`／`5B9Eh`／`5D29h`／`5EA9h`／`5F98h`／`608Dh`）各自落在
   上表 handler 的 body 內。特殊攻擊的視覺只用槽 18／19／23（COMSPR 區塊
   5／6／10）——**與玩家法術共用同三組圖**，game pack 現有資產已涵蓋。
2. **spec 1005「六個效果碼從未被指定」被推翻**：86／88／90／128／131／132
   不是 NIL，是由 `INITSPELLS` 指定的（當時的掃描只涵蓋 overlay-12 的
   初始化函式，沒有掃到 overlay-22 這一段）。spec 1005 正文已改。
3. **CoAB 的載體**（`MON*SPC`，見 `docs/audit/monster-ai-coverage.md`）：
   `56h`×1、`5Ah`×2、`7Eh`×2、`80h`×2、`83h`×1、`84h`×1；`58h` 沒有怪帶。
   `84h`（丟電光）remake 已接（spec 415 的 MonsterSpellRules）；
   **其餘五碼 remake 尚未實作**——原作有動作、remake 沒有，是已知缺口
   （吐酸／區域吐酸／噴火／龍息火／凝視）。

## 明確不宣稱

- 效果 126 是**雙重寫入**：overlay-12 的初始化把它指到 entry#120
  （`289Ch`，第三處麻痺凝視，spec 747），`INITSPELLS` 又指到 `6022h`
  （凝視攻擊，spec 722）。兩個都是凝視家族，但**哪一個最後生效取決於兩支
  初始化的執行順序**，本輪沒有從常駐 init 鏈判定；要下結論需 runtime 驗證。
- 沒有宣稱五個未實作特殊攻擊的完整 remake 行為——handler 語意在各自 spec
  裡是 `exact`，但選目標模式（`41h`／`3Dh`／`33h`／`24h`）與傷害旗標的
  轉錄是實作工作，不在本規格。
- 沒有宣稱 `INITSPELLS` 尾段與 overlay-12 的初始化（spec 1005）之外
  還有沒有第三處寫效果表。本輪對「entry#109..115 的呼叫端」掃過：
  全部 overlay 的 far call（far-call-map）、DOS 常駐段的 far call 與
  資料指標常數、全部 DOS overlay 的資料指標常數（各有正對照）——
  都是零，與「只被分派表間接呼叫」一致；但**沒有**對其餘 overlay 逐一掃
  「往 `6FA6h` 表寫入」這種形式。
