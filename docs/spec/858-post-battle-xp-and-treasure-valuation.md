# 858 — 戰後結算：財寶折算成經驗值，AD&D 一版幣值表整組落地

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼完全相同，62 條差異全是位址與節點尺寸）
- 作法見 spec 783

## `overlay-05:00039h` ↔ `overlay-05:00039h`（兩平台各 278 條，同位址）

`retf 4` ＝ 一個指向 longint 的遠指標（回傳每人份經驗值）。

```pascal
if DS:8B56h <> 0 then begin
    結果^ := 遠指標(DS:6506h)^[0E5h] * 64h;          { 固定值路線，64h ＝ 100 }
    離開;
end;

總 := 0;
p := 遠指標(DS:650Ah);
while p <> NIL do begin
    物品 := p^[14Dh];
    if (p^[197h] = 1) and (p^[195h] <> 0) and (p^[195h] <> 3) then begin
        DS:47ECh := 1;
        for i := 0 to 6 do                                    { 七種財寶 }
            longint[6F70h + i*4] := longint[6F70h + i*4] + word(p^[0FBh + i*2]);
        總 := 總 + p^[13Ch] + p^[12Ch] * p^[13Eh];

        if 遠指標(DS:4F9Dh)^[5C6h] <> 1 then
            while 物品 <> NIL do begin
                舊 := 遠指標(DS:6F8Ch);
                GetMem(DS:6F8Ch, 3Fh);
                <far 14F3h+2>(p, 物品, 0, 0, 0, 0);
                Move(物品^, 遠指標(DS:6F8Ch)^, 3Fh);
                遠指標(DS:6F8Ch)^[34h] := 0;
                遠指標(DS:6F8Ch)^[2Ah] := 舊;                  { 前插到戰利品鏈 }
                物品 := 物品^[2Ah];
            end;
    end;
    p := p^[189h];
end;

總 := 總 + longint[6F70h] div 0C8h;      { 銅 }
總 := 總 + longint[6F74h] div 14h;       { 銀 }
總 := 總 + longint[6F78h] div 2;         { 琥珀金 }
總 := 總 + longint[6F7Ch];               { 金 }
總 := 總 + longint[6F80h] * 5;           { 白金 }
總 := 總 + longint[6F84h] * 0FAh;        { 寶石 }
總 := 總 + longint[6F88h] * 898h;        { 珠寶 }

q := 遠指標(DS:6F8Ch);
while (q <> NIL) and (q <> 遠指標(DS:650Eh)) do begin
    if 有號(q^[32h]) > 0 then 總 := 總 + q^[32h] * 190h;
    q := q^[2Ah];
end;

結果^ := 總 div (遠指標(DS:4F9Dh)^[67Ch] - DS:8B57h);
```

## 七個累加器：前五格與 spec 812 對上，後兩格本支新增

`+0FBh` 起七個 word，逐一累加到 `DS:6F70h` 起的七個 longint。
前五格的幣別名稱早由 `DS:0773h` 的名稱表定案（spec 773／812），
本支的換算係數是**獨立的第二份證據**，而且補上了 812 沒算的後兩格：

| 索引 | 欄位 | 累加器 | 係數 | AD&D 一版 |
|---|---|---|---|---|
| 0 | `+0FBh` | `DS:6F70h` | **÷ 200** | 200 cp ＝ 1 gp → **銅幣** |
| 1 | `+0FDh` | `DS:6F74h` | **÷ 20** | 20 sp ＝ 1 gp → **銀幣** |
| 2 | `+0FFh` | `DS:6F78h` | **÷ 2** | 2 ep ＝ 1 gp → **琥珀金幣** |
| 3 | `+101h` | `DS:6F7Ch` | **×1（直接加）** | **金幣** |
| 4 | `+103h` | `DS:6F80h` | **× 5** | 1 pp ＝ 5 gp → **白金幣** |
| 5 | `+105h` | `DS:6F84h` | **× 250** | 寶石折 250 gp（**812 沒算這格**） |
| 6 | `+107h` | `DS:6F88h` | **× 2200** | 珠寶折 2200 gp（**812 沒算這格**） |

前四項的比例（200 : 20 : 2 : 1 : 1/5）與 AD&D 一版錢幣換算表**逐項相符**。

spec 812 的身價計算用 `DS:0CA2h` 的權重表（1／10／100／200／1000，
單位是銅幣）除以 200；本支不查表，把係數直接編進程式碼，但**換算比例完全一致**。
兩處獨立、單位不同（812 以銅幣為中間單位、本支直接算金幣），結論相同。

812 的「明確不宣稱」曾問「後兩格為什麼不計入總價」——**答案是那兩格不是錢**：
寶石與珠寶只有在戰後結算折成經驗值時才有 gp 估值（250／2200），
身價計算刻意只算真正的貨幣。

而「把折算後的金幣值直接加進經驗值」正是 AD&D 一版的
**1 gp 財寶 ＝ 1 XP**；魔法物品另計，本支用 `+32h × 400`。

## 順帶定案兩個 runtime 常式

換算的方向把 Turbo Pascal longint 算術常式分了出來：

| 呼叫 | PC-98 | 用在 | 判定 |
|---|---|---|---|
| `0A54h:0294h` | `0A65h:0299h` | 銅／銀／琥珀金換算、最後除以人數 | **longint 除法** |
| `0A54h:0279h` | `0A65h:027Eh` | 白金 ×5、寶石 ×250、珠寶 ×2200 | **longint 乘法** |
| `0A54h:0329h` | `081Fh:0043h` | `(var 指標, 3Fh)` | **GetMem**（spec 789 已定案） |

乘與除的分工與 spec 812 一致（該規格由 `DS:0CA2h` 權重表推得），**兩處互相佐證**。

`3Fh`／PC-98 `67h` 正是物品節點大小（spec 832／849），兩處獨立佐證。

⚠ `0A54h:025Dh` 收 `(來源, 目的, 3Fh)`，形狀與 `Move` 相同，
但 spec 522／695 認定的 `Move` 是 **`0A54h:1ABDh`**（IDA 原始符號
`@Move$qm3Anyt14Word`）。兩個不同位址、同一種形狀，**本規格不宣稱它們是同一支**。

## 結果是「每人份」

最後除以 `遠指標(DS:4F9Dh)^[67Ch] − DS:8B57h`。`+67Ch` 是隊伍人數
（overlay-20:00020h 用同一格當掃描上界）。除完寫回 `arg_0` 的 longint——
**這正是 spec 857 `overlay-05:00351h` 收的那個「每人份」參數**，
同一個 overlay 裡的上下游。

## 計入條件：`+197h` ＝ 1 且 `+195h` 不是 0 也不是 3

`+195h` 的狀態名稱表（spec 825，`DS:0FE0h`）：`0` ＝ `Okay`、`3` ＝ `Running`。
所以**還站著的、以及逃走的，都不算經驗值**——只有倒下的才計入。
`+197h` ＝ 1 是「算進這次結算」的那一方的旗標（本規格不宣稱它就是陣營碼）。

## 兩個累加器沒有在本支初始化

`DS:6F70h` 起的七個 longint 與戰利品鏈頭 `DS:6F8Ch`，**本支只累加與讀取，
沒有清零**。`DS:6F8Ch` 還靠「是不是 NIL」決定要不要開新鏈。
清零必須由呼叫端負責；沒清的話財寶會跨場次累積。
remake 實作時要把清零點找出來，不能照抄成「函式自己管」。

## PC-98：62 條差異全是位址與節點尺寸

物品節點的 `+32h`↔`+5Ah`、`+2Ah`↔`+52h` 正好是 spec 832 的 `+28h` 位移；
`3Fh`↔`67h` 是節點大小；角色記錄的 `+14Dh`↔`+14Eh`、`+195h`↔`+196h`、
`+197h`↔`+198h` 是那個 1 byte 差（spec 849）。**沒有一處是邏輯差異。**

## 明確不宣稱

- 沒有宣稱 `DS:8B56h` ＝ 1 走的那條固定值路線是什麼場合（`+0E5h × 100`）。
- 沒有宣稱 `far 14F3h+2(角色, 物品, 0, 0, 0, 0)` 做什麼（在 GetMem 與 Move 之間）。
- 沒有宣稱 `遠指標(DS:4F9Dh)^[5C6h] = 1` 是什麼設定（形狀上是「這場不撿東西」）。
- 沒有宣稱 `DS:8B57h`（從人數扣掉的那個數）是什麼。
- 沒有宣稱物品節點 `+32h` 的名稱（形狀上是魔法加值／等級，每點 400 經驗值）。
- 沒有宣稱 `DS:650Eh` 那個當終止哨兵的節點是誰。
- 沒有宣稱 `0A54h:025Dh` 是什麼（形狀是三參數複製，但與已定案的 `Move` 不同位址）。
