spec 830 讀出 AI 回合會呼叫 `本模組 1388h`，也讀出恐慌訊息的條件是

的處理常式**——`CALLEFFECT` 以效果碼索引 `DS:6FAAh` 的函式指標表，
第 35 筆（`23h`）指向 `overlay-12:00A0Eh`（spec 1005 的對照表）。所以那一支沒有

同一件事的另一面：**法術「混亂」（編號 82）的 `+0Ah` 就是 `23h`**，所以那支法術
的效果就是讓目標跑一次士氣崩潰的四段表。

### 門檻是傷勢，不是固定值

`士氣 >= 100 − HP百分比`。滿血時門檻 0（一定過），剩一成血時門檻 90。
把它寫成「士氣歸零才崩」會讓怪物打到剩一滴血還在死戰。

`+0F7h` 最高位沒設代表**沒有士氣資料**，直接離開——不是當成 0。當成 0 會讓
沒有資料的怪物一律逃走。

### 跑不跑得掉看移動率，不擲骰

- `overlay-13 entry#2(角色)`：移動率換算（spec 806 的 `+06h` 就是它算的）。
  讀 `+1A5h`，我方再加一個全域修正，夾在 1..`60h`，乘 2，再套效果 `12h`。
- `overlay-13 entry#26(角色)`：走全場，用 `overlay-24 entry#30`（回傳「對面那一隊」
  的 `+197h` 值）過濾出敵方、要求 `+196h <> 0`，取 **`entry#2 div 2` 的最大值**。

所以判準是 `對面最快的一半 ≤ 自己的一半`。**兩邊都是整數除法**：移動率 4 對上 5
折半之後都是 2，算跑得掉。

⚠ 這與 spec 799 的「走出戰場邊界」是**不同的兩支**：那一支平手時擲 1d2，
這一支不擲骰。

## 恐慌訊息

spec 830 的 AI 回合在 `1388h` 之後判：

```pascal
if (角色^[18Dh]^[14h] <> 0) and (角色^[18Dh]^[10h] = 0) then
    印(名字 + 'flees in panic');
```

`+14h` 是**本回合**撤退（每回合開頭清掉），`+10h` 是**已經正式逃走**（spec 831
的四段表裡「逃走」那一段設的）。所以訊息只在「這一回合剛崩」時出現一次，
已經跑掉的人不會每回合再被通報。
