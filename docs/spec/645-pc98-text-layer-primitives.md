# 第六百四十五輪：Shift-JIS 首位元組判斷與 PC-98 文字層定址

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：PC-98 `PC98-GAME.EXE` 的 `12A80h`、`14187h`、`14342h`、`1562Ah`、`1692Dh`。

## `14342h`：Shift-JIS 首位元組判斷

```asm
mov  [bp+var_2], 0
mov  al, [bp+arg_0]
cmp  al, 81h
jb   短：不是
cmp  al, 9Fh
jbe  短：是
cmp  al, 0E0h
jb   短：不是
cmp  al, 0FCh
ja   短：不是
是:  mov [bp+var_2], 1
```

回傳 1 的條件是 **`81h..9Fh`** 或 **`0E0h..0FCh`**——標準的 Shift-JIS 首位元組
範圍。傳一個 byte 進去，回答「這個 byte 是不是雙位元組字的第一個」。

### 對中文化的意含

這是**中文化必須改的那一支**。Big5 的首位元組範圍是 `A1h..F9h`（含使用者造字區
則到 `FEh`），與 Shift-JIS 只有部分重疊：

| 範圍 | Shift-JIS | Big5 |
|---|---|---|
| `81h..9Fh` | 首位元組 | 首位元組（擴充區） |
| `A1h..DFh` | **半形片假名（單位元組）** | **首位元組** |
| `E0h..FCh` | 首位元組 | 首位元組 |

關鍵差異在 `A1h..DFh`：Shift-JIS 把它當成單位元組的半形片假名，Big5 把它當成雙
位元組字的開頭。沿用原判斷會讓大量中文字被切成兩個單位元組——**畫面上看起來是
亂碼，而不是缺字**。

改法是把整個範圍併成 `81h..FEh`（Big5 首位元組），但要先確認遊戲不再需要半形
片假名。

## `1692Dh`：VRAM 位址計算

```text
DS := arg_2
DI := (arg_A × 50h + arg_C) × 2
CX := byte(arg_4)
SI := arg_0
<sub_16966>() ; <sub_169B6>()
```

`50h` ＝ 80，是 PC-98 文字畫面的欄數。所以 `arg_A` 是列、`arg_C` 是欄，
`(列 × 80 + 欄) × 2` 就是文字 VRAM 的位移——**每格兩個 byte**，與
[spec 636](636-pc98-text-vram-and-disk-bios.md) 由 `FillChar` 的長度換算出來的
結論一致。

進出成對地保存 `SS`／`DS`／旗標並 `cld`，是直接操作 VRAM 的常式風格。
`retn 0Eh` ＝ 7 個 word 參數。

## `14187h`：平面基底

```text
word_241DE := 0A800h + arg_0 × 800h
```

| `arg_0` | 結果 |
|---|---|
| 0 | `A800h` |
| 1 | `B000h` |
| 2 | `B800h` |
| 3 | `C000h` |

前三個正是 PC-98 圖形 VRAM 的三個顏色平面。第四個 `C000h` 不是標準平面位址
（PC-98 的第四平面在 `E000h`），所以 `arg_0` 的有效範圍多半是 `0..2`，
但**函式本身沒有做範圍檢查**。

## 其餘兩支

```text
12A80h:  byte_241E2 := byte_241E3        ← 先把現值挪成「前一個」
         byte_241E3 := arg_0             ← 再寫入新值

1562Ah:  <sub_19259>((byte_241A6 × word_241DE 之外的 word_280BA) div 2)
```

`12A80h` 是**一格深度的歷史**：呼叫一次，舊值變成「前一個」。順序不能顛倒。

`1562Ah` 的乘法是無號（`mul`）、除法也是無號（`div`），除數固定 2。
