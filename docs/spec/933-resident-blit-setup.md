# 933 — 常駐的 blit 設定層：兩種深度、兩種內迴圈

- 證據等級：`exact`（三支逐條讀完；內迴圈 `sub_15388h` 見 spec 931）
- 位置：DOS `START.EXE` 的 `14BDAh`、`14DD3h`、`14E62h`
- 作法見 spec 783

## 共同骨架 —— `retn 0Eh`

三支的簽章相同：`(目的表面, 來源表面, arg_8, arg_A, arg_C)`，
前兩個是遠指標，後三個是 word（`arg_8` 只用低位）。

```pascal
sub sp, 1Ch;  sub sp, 1Ch;          { 兩段各 1Ch bytes 的區域 }
push ss;  push ds;                  { 內迴圈會改 DS }

var_8  := arg_A shl 3;              { 列 → 位元組，8 為單位 }
var_C  := var_8 × 目的^[2];
var_14 := arg_C;
var_12 := 目的^[2] − 來源^[2] − arg_C;
var_10 := 來源^[2] shl n;
var_A  := 來源^[0];
var_E  := 來源^[11h] × arg_8;
{ var_C、var_14、var_12 各再左移 n 位 }
bx := var_8;   cx := var_A;
var_1A := 0;  var_18 := 0;  var_16 := 0;
<內迴圈>();

pop ds;  pop ss;
```

表面記錄用到的欄位：`+0`（高）、`+2`（**寬**）、`+11h`（每張的位元組數）、
以及只有兩支會讀的 `+13h`（遮罩緩衝遠指標）。完整標頭見 spec 934。

## 三支的差別只有兩處

| | 位移量 `n` | `var_6` | 讀 `+13h`／`+15h` | 內迴圈 |
|---|---|---|---|---|
| `14BDAh` | **1**（×2） | `var_14 shl 1` | 是 | `sub_15388h` |
| `14DD3h` | **2**（×4） | `var_14`（不移） | 否 | `sub_15329h` |
| `14E62h` | **2**（×4） | `var_14`（不移） | 是 | `sub_15388h` |

- **`n` ＝ 每個像素佔幾個位元組的對數**：`14BDAh` 走一種深度，
  另外兩支走深度加倍的那一種。
- **`+13h` 是遮罩緩衝的遠指標**（`+13h` 位移、`+15h` 段，spec 934 的
  `GetMem(@表面^[13h], 總量)` 直接證明），只有走 `sub_15388h` 的兩支會讀。
  spec 931 記到 `sub_15388h` 的內迴圈做
  `es:[di+17h] := (es:[di+17h] and 來源A) or 來源B`，
  其中一個來源就是那塊遮罩。`sub_15329h` 不讀它，是純複製。
  表面配置時**旗標 bit 0 決定要不要配遮罩**，也就決定它能不能走這條路。

所以三支構成 **2 × 2 的組合**（兩種深度 × 有無遮罩），
其中「深度 ×2 ＋ 無遮罩」那一格不存在於這批未解讀的函式裡
（可能已在別處，本規格沒有查）。

## `cld` 的有無

`14DD3h` 與 `14E62h` 進來就 `cld`，`14BDAh` 沒有。
`sub_15388h` 內迴圈自己用 `std` 做過反向搬移（spec 931 的
`1995Ah` 片段也用 `std`），所以**方向旗標在這裡不是恆定的**——
`14BDAh` 依賴呼叫端把 DF 清好。⚠ 這是一個隱性前置條件。

## 明確不宣稱

- 沒有宣稱表面記錄的完整版面（只用到 `+0`、`+2`、`+11h`、`+13h`、`+15h`）。
- 沒有宣稱 `arg_8`／`arg_A`／`arg_C` 的語意（形狀上分別是
  來源的第幾張圖、目的的起始列、目的的起始欄）。
- 沒有宣稱 `sub_15329h` 的內容（本規格只由「不讀遮罩欄位」推出它沒有遮罩）。
- ~~沒有宣稱 `var_1A` 是什麼。~~ → spec 940 的裁切版由旗標 bit 2 決定 `var_1A`，
  所以它是內迴圈的一個開關；本組三支一律寫 0，永遠走那條路。
- 沒有宣稱 `var_18`／`var_16` 這兩個清 0 的區域變數是什麼
  （在 spec 940 的裁切版裡它們是左裁與右裁，本組不裁切所以恆為 0）。
