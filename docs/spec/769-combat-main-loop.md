# 769 — 戰鬥主迴圈，以及攻擊前的兩道檢查

- 證據等級：`exact`（以補洞後的匯出逐條讀完，見 spec 761）

## `overlay-08:00F3h`（DOS）— 戰鬥主迴圈

`retf`，不收參數。它把 spec 749／750 兩端接了起來：

```pascal
DS:4FBAh := 5;                              { 進戰鬥狀態 }
DS:72A0h := 00C1h:007Ah;                    { 換掉選目標掛鉤 }
本模組 0885h();
repeat
    結束 := (DS:6F90h = 0) or (DS:6F91h = 0);
    if not 結束 then begin
        <014Dh:00BBh>();
        角色 := DS:650Ah;
        while 角色 <> NIL do begin
            <呼叫>(角色);
            角色 := 角色^[189h];
        end;
        DS:4F9Dh^[596h] := 0;
        本模組 01ABh(@p);                     { 取下一個行動者 }
        while p <> NIL do begin
            本模組 026Bh(p);                  { 讓它行動 }
            本模組 01ABh(@p);
        end;
        本模組 0997h(@結束);
    end;
until 結束;
本模組 004Dh();                              { spec 749 的戰鬥收尾 }
DS:4FC9h := 1;
```

四件事：

- `DS:4FBAh := 5` 與 spec 750 的戰鬥開場結尾一致，spec 756 的
  `overlay-19:3656h` 判「不在戰鬥」用的也是這個值。
- `DS:72A0h` 被指到 **overlay-13 entry#18 `@2220h`**。spec 749 記錄過收尾時
  這個掛鉤會被換回 `overlay-22 entry#4`（一般的選目標程序），這裡就是**換成
  戰鬥版**的那一處——先前找不到的另一半補上了。
- 離開條件是 `DS:6F90h` 或 `DS:6F91h` 任一為 0（兩邊的存活人數一類的計數），
  外加 `0997h` 可以把旗標設起來。
- 迴圈跑完直接呼叫 `004Dh`，也就是 spec 749 逐條讀過的收尾程序。**開場
  （`overlay-10:1C3Eh`）、主迴圈、收尾三段現在是一條完整的鏈。**

## `overlay-08:0EE9h`（DOS）— 攻擊前的兩道檢查

`retf 0Ch`，三個遠指標（`arg_0` 是輸出旗標）：

```pascal
if <014Dh:00EDh>(攻擊者) and not <014Dh:00F2h>(攻擊者) then
    顯示('Not with that weapon')            { CS:0ED4h，20 字元 }
else if 本模組 0C94h(目標, 攻擊者) then begin
    攻擊者^[18Dh]^[0Ah] := 目標;             { 設定目前目標 }
    if <呼叫>(目標, 攻擊者) then
        輸出^ := 1
    else begin
        <呼叫>(目標, 攻擊者);
        <呼叫>(@輸出, 0, 0, 目標, 攻擊者);
    end;
end;
```

第一道檢查是**兩個條件的組合**：`00EDh` 為真而 `00F2h` 為假才拒絕。訊息
`'Not with that weapon'` 只在這一種組合下出現——單看訊息會以為是「武器不對」，
實際上要兩個述詞一起成立。

與 spec 766 的 `overlay-13:1144h` 對照：那裡是**借用後還原**目標欄位，這裡是
**直接寫進去不還原**。同一個欄位兩種用法，remake 要分開處理。

## `overlay-07:018EEh`（DOS）— 20 個 word 的轉送包裝

`retf 28h`（20 個 word）。它把兩個字串參數各自複製到本地緩衝（上限 `28h` 與
`0FFh`），其中一個再經過本模組 `16D3h` 處理，然後把**16 個參數**原封不動轉給
`loc_16A8+1`：

```
(本地字串A, 本地字串B, arg_1E, arg_1C, arg_1A, arg_18, arg_16, arg_14,
 arg_12, arg_10, arg_E, arg_C, arg_8, arg_4, arg_0)
```

`16D3h` 的輸出寫進 `var_153`，而 **`var_153` 之後整支沒有再被讀**——若
`16D3h` 是「就地改寫」型（改的是 `var_129`）就說得通，否則那次呼叫的結果被
丟掉了。本輪沒有讀 `16D3h`，不下結論。

## 明確不宣稱

- 沒有宣稱 `014Dh:00EDh` / `014Dh:00F2h` 兩個述詞的內容，因此
  `'Not with that weapon'` 的實際觸發條件只能照抄那個組合。
- 沒有宣稱 `overlay-13 entry#18` 的戰鬥版選目標程序做什麼（尚未讀）。
- 沒有宣稱 `0997h` 在什麼情況下把結束旗標設起來。
