# 第六百三十三輪：陣營編碼 —— `+11Bh mod 3` 是善／中立／惡

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：PC-98 `overlay-12` 的 `022Dh`、`0264h`、`003Ch`、`0397h`、`0470h`、
`06F9h`、`072Eh`、`09B9h`（皆 52..60 bytes，皆 `retf 0Ah`）。

## 兩支互補的陣營判斷

```text
022Dh:  if DS:9594h^[11Bh] in {2, 5, 8} then
            DS:0A02Ch := DS:0A02Ch + 2
            DS:0A039h := DS:0A039h − 2

0264h:  if DS:9594h^[11Bh] in {0, 3, 6} then
            （動作完全相同）
```

`+11Bh` 是 `ALIGNMENT`（[spec 499](499-pc98-alignment-conditional-effects.md) 由
Borland type table 定出）。兩組值 `{0,3,6}` 與 `{2,5,8}` 相差固定的 2，而且
**都是每隔 3 取一個**：

| 值 | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| `mod 3` | 0 | 1 | 2 | 0 | 1 | 2 | 0 | 1 | 2 |

所以陣營是 **9 個值的一維編碼**，`value mod 3` 是善惡軸（`0` = 善、`1` = 中立、
`2` = 惡）、`value div 3` 是守序混亂軸。`0264h` 針對善、`022Dh` 針對惡，兩支是
互補的一對。

漏掉的 `{1,4,7}`（中立）**兩支都不處理**——不是忘了寫，是這一對只針對善與惡。

## 效果是 `+2` 與 `−2`

兩支都做同一件事：`DS:0A02Ch` 加 2、`DS:0A039h` 減 2。AD&D 的
**Protection from Evil／Good** 正是「AC +2、對方攻擊 −2」。這讓
`DS:0A02Ch` 是護甲類、`DS:0A039h` 是攻擊類的推斷成立到 `strong inference`，
本輪不寫進結論。

## 其餘六支

```text
003Ch:  if DS:0A036h = 0 then 回傳 0
        else 回傳 1，並呼叫 <sub_1437>(arg_8, arg_6, arg_4, arg_0, arg_2, 1)

0397h:  if arg_2^[3] = 0 then
            備妥 'は窒息した。'，<far 013Eh:0005h>(arg_6, arg_8, 6, 訊息)
        else
            dec arg_2^[3]                    ← 倒數計時，歸零才發作

0470h:  p := arg_6^[18Eh]^[0Ah]              ← 兩層間接
        DS:0A03Dh := p
        if p^[14Ch] and 2 <> 0 then inc DS:0A039h

072Eh:  與 0470h 逐指令相同，只差遮罩是 4（0470h 是 2）

06F9h:  if arg_0 = 0 and <sub_1547>(@var_4, 18h, DS:9594h) = 0 then
            DS:0A035h := 1
            DS:0A039h := DS:0A039h − 4

09B9h:  <far 013Eh:002Ah>(arg_0, arg_2, arg_4, arg_6, arg_8, 2Bh)
        <far 013Eh:002Ah>(arg_0, arg_2, arg_4, arg_6, arg_8, 2Ch)
        ← 同一組參數連續套用兩個相鄰的 id
```

`0397h` 的 `+3` 是**效果節點上的倒數計時器**：每次呼叫減 1，減到 0 那次才發作。
所以「窒息」不是立刻生效，而是撐幾回合。

`0470h`／`072Eh` 是同一份程式碼的兩個遮罩版本（`2` 與 `4`）——`p^[14Ch]` 是位元
旗標欄位，一支查一個 bit。

## 明確不宣稱

- 效果 id `2Bh`／`2Ch`／`18h` 與 `sub_1437`／`sub_1547`／`013Eh:0005h` 的語意。
