# 1040 — `CHECKSPECIALS` DOS 側：補上 spec 624 漏掉的兩張換算表與兩個未定項

- 證據等級：`exact`（DOS 側 293 條逐條讀完）
- 作法見 spec 783；PC-98 對側見 spec 624

## `dos overlay-07:007F1h`（`retf`）

原本待解讀。PC-98 對側 `overlay-07:08BDh` 已由 spec 624 讀完。
DOS 這一支 `07F1h`..`0B6Ah` ＝ 889 bytes，對 PC-98 的 875 bytes。

骨架與 spec 624 完全一致：`arg_0` 是 byte 旗標指標（進門設 `1`、
整條鏈落空才在出口設 `0`），`addr := addr − 7C00h` 之後一路比對。
角色紀錄取自 `DS:6506h`（PC-98 `DS:9594h`）。

|---|---|---|

| `7C9Bh` | `+0E0h` | 同 |

| `7CBBh`／`BDh`／`BFh`／`C1h`／`C3h` | `+0FBh`／`FDh`／`FFh`／`101h`／`103h`（word） | 同 |

★ `+192h` 與 `+1A5h` 兩格在 PC-98 各 ＋1，與「`+18Dh` 起差 1」一致。
★★ **spec 624 漏了 `7CE4h` 的 `and 1`**——讀出來的是**最低位元**，不是整個 byte。

## ★★ 補上 `7CC9h` 的公式

spec 624 只記「`+116h` 與 `+10Eh`」。DOS 側寫得完整：

```pascal
7CC9h := <overlay-25 entry#10>(…) × 角色^[116h] ＋ 角色^[10Eh];
```

三個量都先 `cbw`（有號）。

## ★★★ 補上 `7ECFh` 的換算表（spec 624 只寫了「`+1Bh`」）

`+1Bh` 是屬性組 `+11h ＋ i × 2` 的第 6 個（**魅力**）。
讀 `7ECFh` 不是直接回傳魅力，而是查一張**十二段的換算表**：

| `+1Bh` | 回傳 | | `+1Bh` | 回傳 |
|---|---|---|---|---|
| 3 | 0 | | 0Dh（13） | 30 |
| 4 | 5 | | 0Eh（14） | 35 |
| 5 | 10 | | 0Fh（15） | 40 |
| 6 | 15 | | 10h（16） | 50 |
| 7 | 20 | | 11h（17） | 55 |
| 8..0Ch（8–12） | 25 | | 12h..19h（18–25） | 60 |

> ★★★ **形狀上是一組百分比**（0／5／10／…／60，8–12 與 18–25 各壓成一段）。
> ⚠ 本規格不宣稱它是折扣、忠誠度還是反應調整——只確定索引是魅力、輸出是這十二個值。
> ⚠ **範圍外的魅力（0..2）不會寫 `var_2`**，落到出口讀未初始化值，
> 與下面 `7D0Dh` 同一類。

## ★★★ 關掉 spec 624 的一個未定項：`7F12h`

spec 624 記「`7F12h` | `DS:8BF4h` | byte」，沒說是什麼。DOS 側是

```asm
0B40  mov  al, ds:5BEEh
```

⇒ **`7F12h` 讀的是資料片編號**（spec 892／1029／1033／1038 的同一格 `DS:5BEEh`）。

## 三個要算的（與 spec 624 對照）

```pascal
7D00h:  結果 := ord(角色^[196h] <> 0) ? 1 : 80h;
        if DS:8B6Dh = 1 then 結果 := 0;
        DS:8B6Dh := 0;                       { ★ 讀一次就清掉 }

7D0Ch:  if (角色^[197h] = 0) and (角色^[198h] <> 0) then 80h
        else if 角色^[197h] = 1              then 81h
        else                                      0;

7EB1h／7EB4h: 兩者 body 完全相同，都是 <near 0790h>() 再零延伸
```

★ 角色欄位 `+196h`／`+197h`／`+198h` 對 PC-98 的 `+197h`／`+198h`／`+199h`（各 ＋1）。
★ 一次性旗標 `DS:8B6Dh` ＝ PC-98 `DS:0BDFFh`。

## ★ `7D0Dh` 讀未初始化值：DOS 側也成立

```asm
0A3D  cmp  ax, 10Dh
0A40  jnz  short loc_A45
0A42  jmp  loc_B64          ; ← 直接跳出口
```

出口是 `mov ax, [bp+var_2]`，而 `var_2` 在這支函式裡**從未初始化**。
旗標仍是 `1`，呼叫端不會察覺。**spec 624 記的原作行為在兩平台都一樣，remake 要照抄。**

## 明確不宣稱

- 沒有宣稱 `7ECFh` 那張換算表的語意（只確定索引是魅力）。
- 沒有宣稱 `overlay-25 entry#10`（`7CC9h` 的乘數）回傳什麼。
- 沒有宣稱 `near 0790h`（`7EB1h`／`7EB4h` 共用的那支）做什麼。
- 沒有宣稱 `DS:8B6Dh` 由誰設成 1。
- 沒有宣稱 `+192h` 的其他位元是什麼（這裡只取最低位元）。
