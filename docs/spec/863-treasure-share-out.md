# 863 — 戰利品分錢：七種幣別平分，裝不下的留在公用池

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼完全相同，20 條差異全是位址）
- 作法見 spec 783

## `overlay-21:0064Fh` ↔ `overlay-21:00669h`（兩平台各 382 條）

`retf` ＝ 無參數。動的是 spec 858 累積起來的那七個 longint 池
（`DS:6F70h`，PC-98 `DS:0A00Eh − 4`）與角色的 `+0FBh` 七格錢包。

```pascal
人數 := <本模組 05F9h>();
FillChar(每人[0..6], 0Eh, 0);   FillChar(餘[0..6], 0Eh, 0);

for j := 0 to 6 do
    if 有號(longint[6F70h + j*4]) > 0 then begin
        每人[j] := longint[6F70h + j*4] div 人數;
        餘[j]   := longint[6F70h + j*4] mod 人數;
    end else begin
        每人[j] := 0;  餘[j] := 0;
    end;

{ ① 先每人一份 }
p := 遠指標(DS:650Ah);
while p <> NIL do begin
    if p^[0F7h] >= 80h then                        { 士氣沒崩的才分 }
        for j := 6 downto 0 do
            if <本模組 0073h>(p, 每人[j], var 可裝) then begin
                p^[0FBh + j*2] := p^[0FBh + j*2] + 可裝;
                餘[j] := 餘[j] + 每人[j] − 可裝;    { 裝不下的退回公用 }
                <本模組 0057h>(p, 可裝);
            end else begin
                p^[0FBh + j*2] := p^[0FBh + j*2] + 每人[j];
                <本模組 0057h>(p, 每人[j]);
                if 餘[j] > 0 then                   { 無號 }
                    if not <本模組 0073h>(p, 1, var 可裝) then begin
                        p^[0FBh + j*2] := p^[0FBh + j*2] + 1;   { 餘數多給 1 }
                        <本模組 0057h>(p, 1);
                        dec(餘[j]);
                    end;
            end;
    p := p^[189h];
end;

{ ② 剩下的再走一遍，能塞多少塞多少 }
for j := 6 downto 0 do
    if 餘[j] > 0 then begin
        p := 遠指標(DS:650Ah);
        while p <> NIL do begin
            空間 := <本模組 001Bh>(p) − p^[187h];
            if 空間 > 0 then                        { 無號 }
                if 餘[j] > 空間 then begin
                    p^[0FBh + j*2] := p^[0FBh + j*2] + 空間;
                    <本模組 0057h>(p, 空間);  餘[j] := 餘[j] − 空間;
                end else begin
                    p^[0FBh + j*2] := p^[0FBh + j*2] + 餘[j];
                    <本模組 0057h>(p, 餘[j]);  餘[j] := 0;
                end;
            p := p^[189h];
        end;
    end;

{ ③ 寫回公用池 }
DS:7564h := 0;
for j := 0 to 6 do begin
    longint[6F70h + j*4] := 餘[j];
    if longint[6F70h + j*4] <> 0 then DS:7564h := 1;
end;
```

## 接上 spec 858 的公用池

spec 858 記著「`DS:6F70h` 起的七個 longint 本支只累加與讀取，沒有清零，
清零必須由呼叫端負責」。本支就是消費端：**分完之後把剩下的寫回去**，
並用 `DS:7564h` 標記「公用池還有沒有東西」。

七格的幣別由 spec 858 的換算係數定案：
**0 銅、1 銀、2 琥珀金、3 金、4 白金、5 寶石、6 珠寶**。
角色端的 `+0FBh + j*2` 是同一組順序（spec 812 的身價計算只用前 5 格）。

**分配從 `j = 6` 往 `0`**——珠寶、寶石、白金先進包，銅幣最後。
負重滿的時候先卡住的是最不值錢的那幾種。

## `0A54h:0294h` 同時給商與餘

同一組運算元呼叫兩次：第一次取 `dx:ax`（商）寫進 `每人[j]`，
第二次取 `cx`（餘）寫進 `餘[j]`。所以那支 32 位元除法
**商在 `dx:ax`、餘在 `bx:cx`**——spec 812／858 只用到商，這裡補上餘數的位置。

（同一組運算元算兩次是編譯器沒有共用子式，不是兩種不同的計算。）

## 三個負重常式

| 呼叫 | 形狀 | 讀作 |
|---|---|---|
| `本模組 001Bh(角色)` | 回 word | 負重上限 |
| `本模組 0057h(角色, 量)` | `retf 6` | 增加負重 |
| `本模組 0073h(角色, 量, var 可裝)` | `retf 0Ah` | 真 ＝ 裝不下，並回填可裝的量 |

`p^[187h]` 是目前負重（`001Bh` 的回傳減掉它就是剩餘空間）。
**錢幣與寶石都算重量**，這是 Gold Box 會出現「錢多到走不動」的來源。

## 兩個分配上的細節

- **士氣崩的不分錢**：第一輪跳過 `+0F7h < 80h` 的人（`+0F7h` 最高位是士氣，
  見 spec 831／836）。第二輪**沒有這道檢查**，所以剩下的錢還是可能塞給他。
- `每人[j]` 與 `餘[j]` 是 word，但來源是 longint。總量超過 65535 時會截斷。
  遊戲內的錢幣量能不能到那個級距，本規格沒有查。

## 明確不宣稱

- 沒有宣稱 `本模組 05F9h()` 怎麼算人數（是不是含倒下的人）。
- 沒有宣稱 `DS:7564h` 由誰讀（形狀上是「公用池還有東西」的旗標，
  用來決定要不要開分贓畫面）。
- 沒有宣稱負重的單位。
