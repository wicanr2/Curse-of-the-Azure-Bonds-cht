# 1023 — 捲動清單選單：`Next`／`Prev`／`Exit` 是動態接上去的

- 證據等級：`exact`（DOS 側 312 條、PC-98 側 360 條，兩邊各自逐條讀完）
- 作法見 spec 783

## `dos overlay-26:00DF9h` ↔ `pc98 overlay-26:00ED3h`（＝ `entry#5`）

兩側原本都是待解讀。這一支被商店（spec 1013）、轉職（spec 1021）、
物品選單等等叫過——**是整個遊戲的「清單選單」共用常式**。

## ★★ 它是 `entry#3` 的外層

`entry#3`（`overlay-26:03D4h`）只會「顯示一行選項、等一個鍵」。
`entry#5` 在它外面加上**捲動**與**三個自動選項**：

```pascal
if 清單鏈頭 = NIL then begin 結果 := 0;  exit end;
DS:7294h := 1;

可選數 := 從鏈頭數到第一個 `+29h = 0` 為止;      { 前綴 }
總數   := 整條鏈的長度;

…把捲動位置 `DS:7292h` 夾進範圍、畫出可見的那幾筆…

選項行 := 呼叫端給的字串;
if 還有下面沒顯示到 then 選項行 := 選項行 ＋ ' Next';   { CS:0DE7h }
if 捲動位置 > 0      then 選項行 := 選項行 ＋ ' Prev';   { CS:0DEDh }
if 要有離開          then 選項行 := 選項行 ＋ ' Exit';   { CS:0DF3h }

鍵 := <entry#3>(選項行, …);
```

★★ **`' Next'`／`' Prev'`／`' Exit'` 是執行期接上去的**，
不是呼叫端字串的一部分——所以呼叫端（例如 spec 1013 的 `'Buy'`、
spec 1021 的 `'Select'`）只給自己那幾個選項就好。

★★ **熱鍵一樣藏在大寫字母裡**：`N`ext、`P`rev、`E`xit。

## ★★ 兩套按鍵模式

```pascal
if 游標模式 then case 鍵 of                       { DOS 用小鍵盤擴充掃描碼 }
    47h {Home}: 移到最前;
    4Fh {End} : 移到最後;
    49h {PgUp}: 上一頁（要 ' Prev' 有出現）;
    51h {PgDn}: 下一頁（要 ' Next' 有出現）;
end
else case 鍵 of                                   { 字母模式 }
    'P': 上一頁;
    'N': 下一頁;
    1Bh {ESC}, 'E', 0: 離開（結果清 0）;
end;
```

★ **ESC（`1Bh`）與 `E` 等價**——兩個都離開。

⚠ **PC-98 的游標模式用的是完全不同的四個碼**：`32h`（`'2'`）、`33h`（`'3'`）、
`38h`（`'8'`）、`39h`（`'9'`）——**NEC 鍵盤的數字鍵**，不是 IBM PC 的擴充掃描碼。
（字母模式的 `P`／`N`／`E`／ESC 兩平台相同。）

## ★★★ 三個自動選項在 PC-98 的落點

PC-98 把 `' Next'`／`' Prev'`／`' Exit'` 換成日文，並寫進那兩張平行表：

| 選項 | 文字寫到 | ＝ `DS:0A338h ＋ i × 7` | 熱鍵寫到 | ＝ `DS:0A334h ＋ i` |
|---|---|---|---|---|
| Prev | `DS:0A369h` | **i = 7** | `DS:0A33Bh` | **i = 7** |
| Next | `DS:0A370h` | **i = 8** | `DS:0A33Ch` | **i = 8** |
| Exit | `DS:0A37Eh` | **i = 10** | `DS:0A33Eh` | **i = 10** |

> ★★★ **兩張表的索引再一次完全對齊**（spec 755 的版面、
> spec 1012／1013／1022 的三個實例，加上這裡的第四個）。
> **`entry#5` 自己就會填熱鍵表**，所以呼叫端不必管。

## 中文化

| 字串 | 長度 | 備註 |
|---|---|---|
| `' Next'` | 5 | 熱鍵 `N` |
| `' Prev'` | 5 | 熱鍵 `P` |
| `' Exit'` | 5 | 熱鍵 `E`，ESC 也可以 |

⚠ 三個都是 **5 字元**，PC-98 那邊是 `DS:0A338h ＋ i × 7` 的 **6 bytes ＝ 3 個全形字**。
中文「下頁」「上頁」「離開」各 2 字，塞得下。

★ **中文化只要改 PC-98 的那兩張表就好**——`entry#5` 會自己把熱鍵字母寫進
`DS:0A334h ＋ i`，不需要在文字裡放大寫字母。

## 明確不宣稱

- 沒有宣稱那一長串參數（`arg_0`..`arg_24`）各是什麼，
  只確認 `arg_E` 是清單鏈頭、`arg_C` 決定要不要 `' Exit'`、
  `arg_12`..`arg_18` 是四個邊界、`arg_20`／`arg_24` 是兩個字串。
- 沒有宣稱 `DS:7292h`（捲動位置）與 `DS:7294h` 由誰重設。
- 沒有宣稱 `sub_74`／`sub_D6B`／`sub_88A`／`sub_A56`／`sub_AF8`／`sub_CD9` 做什麼。
- 沒有宣稱「游標模式」旗標（`var_57`）從哪裡來。
- 沒有宣稱節點 `+29h`（可選旗標）與 `+2Ah`（next）之外的版面。
