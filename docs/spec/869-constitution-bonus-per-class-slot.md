# 869 — 體質加值總和：逐職業槽各算一份，`DS:427Fh` 是完整的 AD&D 表

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側只差有號／無號碼型）
- 作法見 spec 783

## `overlay-17:045E9h` ↔ `overlay-17:04CBBh`（DOS 93 條／PC-98 92 條）

`retf 4` ＝ 一個角色遠指標。

```pascal
總 := 0;
for c := 0 to 7 do begin                              { 八個職業槽 }
    if 有號(角色^[109h + c]) <= 0 then continue;      { 這個職業沒等級 }
    if 角色^[109h + c] >= byte[3EB9h + c] then continue;  { 無號：過了 HD 上限 }

    總 := 總 + byte[427Fh + 角色^[19h]];              { 體質加值 }

    if 角色^[75h] in [2, 3, 4] then                    { 戰士類的額外加值 }
        case 角色^[19h] of
          11h:       總 := 總 + 1;
          12h:       總 := 總 + 2;
          13h, 14h:  總 := 總 + 3;
          15h..17h:  總 := 總 + 4;
          18h, 19h:  總 := 總 + 5;
        end;

    if (c = 4) and (角色^[109h + c] = 1) then 總 := 總 * 2;   { 遊俠 1 級 }
end;
結果 := 總;
```

## `DS:427Fh`（PC-98 `DS:7314h`）＝ 體質加值表，直接用體質當索引

**兩平台逐 byte 相同**：

| 體質 | 3 | 4–6 | 7–14 | 15 | 16 | 17–25 |
|---|---|---|---|---|---|---|
| 值 | `0FEh`（−2） | `0FFh`（−1） | 0 | 1 | 2 | 2 |

索引 0..2 與 26 之後不是這張表的內容（`0`／`8`／`0DDh`），有效範圍是 **3..25**。

加上戰士類的額外加值之後，**整張表就是 AD&D 一版的完整體質表（含 20–25）**：

| 體質 | 17 | 18 | 19 | 20 | 21 | 22 | 23 | 24 | 25 |
|---|---|---|---|---|---|---|---|---|---|
| 戰士類（職業碼 2／3／4） | ＋3 | ＋4 | ＋5 | ＋5 | ＋6 | ＋6 | ＋6 | ＋7 | ＋7 |
| 其餘職業 | ＋2 | ＋2 | ＋2 | ＋2 | ＋2 | ＋2 | ＋2 | ＋2 | ＋2 |

逐格與 AD&D 一版相符。

### 與 spec 866 的關係

`overlay-17:02515h`（spec 866）算的是**同一件事的另一個入口**：
它把整張表寫死在分支裡，而且**只做到 19**（體質 ≥ 20 回傳未初始化的堆疊值）。
本支查表 ＋ 分支，做到 25。**兩支在 3..19 這段的結果完全一致**，
所以 866 的那個缺口是它自己的邊界，不是規則不同。

## 每個有等級的職業槽各給一份

`+109h + c` 是八個職業槽的等級（spec 850 同一組欄位、同一張 `DS:3EB9h` HD 上限表：
Cleric 10、Druid 15、Fighter 10、Paladin 10、Ranger 11、Magic-User 12、
Thief 11、Monk 19）。**過了 HD 上限的職業槽不再給體質加值**——
與 spec 850「過了上限就改加固定值」一致：固定值那段不含體質修正。

## ⚠ 遊俠 1 級是把「累積到現在的總和」乘 2

`c = 4`（Ranger，spec 857 的職業編號）且該槽等級為 1 時，`總 := 總 * 2`。
乘的是**跑到目前為止的整個累加值**，不只是這一槽的貢獻。
單職業遊俠沒有差別；多職業角色若在遊俠槽之前已經累加過別的職業，
那些也會被一起乘 2。**兩平台一致**，不是反組譯問題。
（遊俠 1 級擲 2d8 見 spec 850，這裡是體質加值也跟著加倍。）

## PC-98：只差有號／無號碼型

DOS 零擴充成 `ax` 後用 `cmp ax, n` ＋ `jl`／`jg`；PC-98 直接 `cmp al, n` ＋
`jb`／`ja`。值域 0..255，結果相同（spec 783 第 c 類）。少的那一條是 `xor ah, ah`。
