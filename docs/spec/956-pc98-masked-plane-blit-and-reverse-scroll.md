# 956 — PC-98 帶遮罩的三平面貼圖，與反向捲動

- 證據等級：`exact`（兩支逐條讀完，來源是 `PC98-GAME.EXE.asm`）
- 位置：`PC98-GAME.EXE` 的 `13EACh`、`19947h`
- 作法見 spec 783

## ★ `13EACh`（108 行，`retn 0Eh`）：帶遮罩的三平面貼圖

參數與 spec 949 的 `13E22h`（無遮罩版）相同：
`(目的表面, 來源表面, 張號, 列, 欄)`。

```pascal
高 := 目的^[0];   寬 := 目的^[2];   每平面 := 高 × 寬;
di := 目的 ＋ 17h ＋ (列 shl 3) × 目的^[2] ＋ 欄;
列差 := 目的^[2] − 來源^[2];
每列字數 := 來源^[2] div 2;

遮罩 := 來源^[13h];                                { ★ 遮罩緩衝遠指標 }
遮罩位移 := 遮罩 ＋ 來源^[0] × 來源^[2] × 張號;    { 每張 高 × 寬 }
si := 來源 ＋ 17h ＋ 來源^[11h] × 張號;

for 平面 := 1 to 3 do begin
    for y := 1 to 來源^[0] do begin
        for x := 1 to 每列字數 do begin
            es:[di] := (es:[di] and word(遮罩位移)) or word(ds:si);
            si := si ＋ 2;   di := di ＋ 2;   遮罩位移 := 遮罩位移 ＋ 2;
        end;
        di := di ＋ 列差;
    end;
    遮罩位移 := 遮罩起點;                          { ★ 每個平面都從頭讀遮罩 }
    di := 平面起點 ＋ 每平面;
end;
```

### 遮罩三個平面共用

`13E22h`（無遮罩）與本支的唯一差別就是每個 word 多做一次
`and 遮罩` 再 `or`。關鍵在於**遮罩指標在每個平面開始時被重設回起點**
（`lds bx, [bp+var_6]`），而來源指標 `si` 是連續讀下去的——
所以**一張遮罩給三個平面共用**，遮罩每張只佔 `高 × 寬` bytes，
主資料每張佔 `來源^[11h]`（三個平面份）。

這解釋了 spec 947 釋放表面時為什麼要分開算兩個大小：
`甲 ＝ 張數 × 來源^[11h]`（主資料）與 `乙 ＝ 高 × 寬 × 張數`（遮罩）。

⚠ 與 `13E22h` 一樣，每列以 **word** 為單位，**寬是奇數時最後一個 byte
不會被處理**。

## `19947h`（119 行）：反向的區塊搬移

`198AEh`（spec 955）的反向版：`std` 之後從**右下往左上**搬，
給來源與目的重疊、且目的在來源之後的情況用。

```pascal
if (bx = 0) or (cx = 0) then 離開;
if byte_280DAh <> 50h then begin ax := ax shl 1;  dx := dx shl 1 end;

{ 起點改成矩形的右下角 }
ax := ax ＋ dx − 1;   di := di ＋ cx − 1;
si := <sub_199F5h>(來源右下);   di := <sub_199F5h>(目的右下);
bx := (50h − 寬) shl 1;
std;

for y := 1 to 高 do begin
    { ★ 同樣檢查這一列的兩端，是全形字的一半就先改成空白 }
    …
    rep movsw;                                     { 反向 }
    si := si − bx;   di := di − bx;
end;

{ 屬性平面（word_280D4h ＋ 200h）用 movsb ＋ dec si／dec di }
cld;
```

方向旗標**進來設 `std`、離開前 `cld`** ——所以呼叫端不必自己還原。
全形保護的判定與 `198AEh` 相同（bit 15 或字碼 bit 7），
只是最後一格的位移是 `−(寬 − 1) × 2`（反向）。

⚠ 字碼平面的 `rep movsw` 前後有一組 `add di, 2` ／ `sub di, 2`
夾著 `<sub_19B7Dh>` 呼叫——**反向搬移時 `di` 指的是最後一個 word 的起點，
呼叫那個鉤子之前要先補回 2**。這是反向搬移特有的修正，正向版沒有。
