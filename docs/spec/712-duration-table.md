# 第七百一十二輪：效果持續時間，`5A0h` ＝ 一天

狀態：`READY`。等級：`exact`（算式）／`strong inference`（單位）。
日期：2026-08-14
位置：DOS `overlay-22:0E11h`（`sub_E11h`，`retf 2`，一個 word 參數）。

## 算式

```text
函式 sub_E11h(id: byte): word

id = 28h            → 1d6 × 10
id = 39h 或 3Dh      → 5d4
id = 3Bh            → 1d4 × 10 + 40
id = 3Fh            → DS:4FBAh = 5 ? 2d10 × 10 : (1d10 + 10) × 10
id = 43h            → 5A0h（1440）
其他                 → 表[id].+5 × <overlay-24 entry#36>(id) + 表[id].+4
```

`表` 就是 spec 705 的 `DS:37DAh`，一格 16 bytes。到目前為止已知被讀的欄位：

| 格內位移 | 讀它的地方 |
|---|---|
| `+0` | `overlay-24:28B3h` |
| `+2`、`+3` | `overlay-22:0D67h`（spec 705） |
| `+4`、`+5` | 本輪 |
| `+6` | `overlay-22:0D67h` |

`(+2, +3)` 與 `(+4, +5)` 是**兩組形狀相同的係數**：都是
`高位欄 × entry#36 的回傳值 + 低位欄`。所以同一個 id 有兩個各自獨立的線性公式，
由呼叫端決定用哪一組。

## `5A0h` 是關鍵

`5A0h` ＝ 1440 ＝ **24 × 60**。整組數字放在一起看：

| id | 值域 |
|---|---|
| `28h` | 10、20 … 60 |
| `39h`／`3Dh` | 5..20 |
| `3Bh` | 50、60 … 80 |
| `3Fh`（一般） | 110、120 … 200 |
| `3Fh`（`DS:4FBAh = 5`） | 20、30 … 200 |
| `43h` | 1440 |

全部是 10 的倍數（`39h`／`3Dh` 的 `5d4` 例外），而最大值正好是一天的分鐘數。
所以單位**幾乎確定是分鐘**——`43h` 那個效果持續一整天。這個推論只靠 `1440` 這
一個數字，沒有第二條證據，所以標為推論而非定案。

`3Fh` 的兩條分支上限相同（都是 200）但下限差很多（20 對 110）：
`DS:4FBAh = 5` 那條是 `2d10 × 10`，另一條是 `(1d10 + 10) × 10`。也就是同一個
效果在某個情境下**可能短很多，但不會更長**。

## 呼叫端

`4432h` 用 `id = 49h`、`4822h` 用 `id = 52h`——兩個都落在「其他」那條，走表格
公式。所以上面五個特例是寫死的例外，不是主要路徑。

## 明確不宣稱

- `DS:4FBAh = 5` 是什麼情境。
- `overlay-24 entry#36` 回傳什麼。
- id `28h`／`39h`／`3Bh`／`3Dh`／`3Fh`／`43h` 各代表哪個效果。
- 單位是分鐘還是「回合」而回合恰好是分鐘（AD&D 的 turn ＝ 10 分鐘，
  `10 的倍數` 這個特徵和 turn 也相容）。
