# 1092 — PC-98 角色數值調整：機制與 DOS 逐項相同，兩張表基底是 `DS:701Bh` 與 `DS:7207h`

- 證據等級：`exact`（PC-98 側 1,205 條逐條讀完，`filled` 匯出無破洞）
- 作法見 spec 783；DOS 對側見 spec 1086

## `pc98 overlay-17:02E9Bh`（`retf`）

原本待解讀。範圍 `2E9Bh`..`3A9Fh`。這是 spec 1086 的 PC-98 對側。

⚠ 兩支的**助憶碼相似度只有 0.29**，但那是編譯結果的差異
（PC-98 把索引算式攤成不同的常數基底），**語意是逐項對得上的**。

## 一、進門的門檻：多一道整段略過

```pascal
if bank0^[1E4h] <= 1 then 直接進入編輯;              { ★ DOS 沒有這一段 }

可改 := (經驗值 = 0) or (= 208Dh) or (= 30D4h) or (= 61A8h);
if 可改 and (角色^[0E6h] = 0) then 進入編輯
else begin 印(角色名 ＋ 'の数値は変更できない');  離開 end;
```

★ 四個經驗值（0／8,333／12,500／25,000）與 `角色^[0E6h] = 0` 的條件
**與 DOS 完全相同**——兩平台獨立確認 spec 1086 更正後的讀法。
★ `bank0^[1E4h]` 就是 spec 1085 用來決定主選單 `L`（載入）能不能按的同一格。

## ★★ 二、兩張上下限表的基底

| | DOS（spec 1086） | PC-98 |
|---|---|---|
| 第一張（種族） | `DS:3F86h ＋ 種族 × 10h` | **`DS:701Bh ＋ 種族 × 10h`** |
| ├ 力量那一格 | `＋ 角色^[119h]` | **同** |
| └ 智力那一格 | `DS:3F8Ch`（＝ 基底 ＋ 6） | **`DS:7021h`（＝ 基底 ＋ 6）** |
| 第二張（`角色^[75h]`） | `DS:4172h ＋ 值 × 6` | **`DS:7207h ＋ 值 × 6`** |
| 其餘四個屬性 | 基底 ＋ 7..10 | **`7022h`..`702Ah`** ／ **`7208h`..`720Ch`** |

★ **索引算式一格不差**（`shl di, 4` 與 `di ×2 ＋ di ×4` 的 ×6 展開都一樣）。
★ 角色欄位也全部相同：`+11h ＋ i × 2`（屬性）、`+1Ch`（力量百分比）、
`+74h`（種族）、`+75h`、`+78h`（最大 HP）、`+119h`、`+127h`／`+129h`（經驗值）、
`+12Dh`、`+1A5h`。

⚠ 兩張表在**資料段**，本規格不宣稱內容。

## 三、其餘結構

八個欄位（六屬性 ＋ 最大 HP ＋ 名字）、`4Bh`／`4Dh` 加減、力量百分比獨立一階、
名字逐 byte 編輯——**全部與 spec 1086 相同**，不重複描述。

呼叫對照：

| 用途 | DOS | PC-98 |
|---|---|---|
| 重畫 | `near 2724h` | `near 2DB7h` |
| 兩個表查詢 helper | `near 46ECh` ／ `near 47C6h` | `near 4DB4h` ／ `near 4E8Eh` |
| 進出畫面 | `overlay-19 entry#1` ／ `entry#2` | **同兩個 entry** |
| 印字 | `overlay-24 entry#7` | **同一個 entry** |
| 收尾 | `overlay-25 entry#2` | **同一個 entry** |

## 中文化

| PC-98 | bytes | 建議 |
|---|---|---|
| 「の数値は変更できない」 | 20 | 「 的數值無法調整」（接在角色名後） |
| 「数値調整：」 | 10 | 「數值調整：」 |
| 「   決定　                     やめる    」 | 40 | ⚠ **整列 40 bytes 的選項行**，兩個詞的欄位固定（spec 1043 同一種寬度） |

⚠ DOS 的對應選項行是 `'Keep Exit'`（9 bytes，靠熱鍵字母）；
**PC-98 是 40 bytes 的固定欄位排版**——兩平台的中文化做法不同，
PC-98 要照 spec 1077 的格子寬度排。
⚠ 名字編輯同樣是**逐 byte 搬移**，對雙位元組沒有保護（spec 1086 同一個問題）。

## 明確不宣稱

- 沒有宣稱 `DS:701Bh`／`DS:7207h` 兩張表的內容。
★★★ **`角色^[119h]` ＝ 性別、`角色^[75h]` ＝ 職業組合編號**（見 spec 1086 同一條）。
- 沒有宣稱 `角色^[0E6h]`／`[12Dh]`／`[1A5h]` 是什麼欄位。
★ `bank0^[1E4h]` ＝ **上一個 block／scene 編號**（spec 1097 §一）⇒ `<= 1` 是
「**還在第一個 block（剛建完角）才准改數值**」，與 spec 1086 的「經驗值還停在
建角時發下來的值」是同一件事的兩道閘。
- 沒有宣稱 `near 2C1Ch`／`near 278Ch`／`near 4DB4h`／`near 4E8Eh` 的內容。
