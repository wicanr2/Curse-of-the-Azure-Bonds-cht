## 已確認契約

  遊戲狀態、選單游標或文字頁面。最後選擇保存到使用者設定。
- A6 是淺色精修石框；左上場景／人物區保留原版雙層框，內層為窄幅、明亮但非
  螢光的黃金雕刻紋飾。其他分隔線保持纖細，內容優先。
- F1 開關 Help；F3 開關目前 GEO 地圖攻略；Esc 一律關閉最上層 overlay／取消
  當前可取消操作。
- F6 依 `zh-TW → zh-CN → ja → en` 即時循環語系，並寫入
  `coab-ui-settings/1` 的 `language`。當前可追溯的訊息、原版 ECL 選項、
  F1／F3 overlay、攻略說明與地區字型同步切換；玩家輸入姓名不翻譯。
  英文劇情來自原版 game pack，其他新語系依
  [`coab-multilingual-translation.md`](../knowledge/coab-multilingual-translation.md)
  以離線 AI 產生，不宣稱人工校譯。
- F3 攻略底圖固定使用原版 11×11 AREA-map symbols 與原版隊伍方向標記，不受 F2
  theme 影響；攻略事件以獨立金色標記疊加。探索模式只畫已探索格／已發現事件，
  完整模式畫目前 viewport 的全部原版地圖格與所有事件。先前的 remake 16×16
  灰色格線已排除。
- 攻略預設只顯示探索資訊。玩家可主動要求完整事件點與說明；第一次必須確認
  劇透警告，確認狀態保存。每個事件點各自記錄本專案攻略、Clue Book 或 GEO／ECL
  證據；目前沒有完整《軟體世界》攻略掃描，不得把未取得的內容冒稱為該攻略原文。
- F4 依序切換 640×480、1024×768、1280×960，最後選擇保存。A6 框線、文字、
  UI 圖示按目前邏輯解析度繪製；忠實 theme 的原版像素素材使用最近鄰，不捏造細節。
- 視窗可任意拉伸；最終 framebuffer 非等比填滿整個視窗，使用者接受寬高比變形。
- F5／F9 保持存／讀檔。F10 有可存進度時先自動存檔，成功才離開；失敗顯示錯誤
  並留在遊戲。沒有可存隊伍時直接離開。

## 實作邊界

- 設定檔只保存 UI 偏好，不混入隊伍／劇情存檔。
- 探索足跡不得每走一格就在 `Update` 同步寫磁碟；採八個新格一批，並在關閉攻略或
  F10 離開時沖刷尾段。

### F7 外觀設定（2026-08-29 READY）

- F7 開啟草稿式設定；Esc 取消、Enter 套用並保存、R 恢復預設。
- 手繪框樣式 A／B／C；外框 4..20px（步進 2、預設 10），內框 1..12px
  （步進 1、預設 8）。原版 theme 不讀手繪框參數；切回手繪 theme 恢復玩家值。
- 閱讀文字與介面文字各自設定 12..36px（步進 1、預設 24／16），粗體亦分開。
- 框線不得遮擋文字。先安全換行；固定狹窄欄仍放不下時只縮小該次繪製，不能改寫
  玩家保存的期望字級。
- 場景／人物圖必須填滿左上金框的透明開口。640×480 基準開口是
  `image.Rect(51,39,235,230)`（184×191；Max exclusive），不可誤寫右界 234 而留下
  1px 黑縫。
- `coab-ui-settings/1` 維持向後相容；舊檔缺少新增欄位時套用上述預設值。
- `original` theme 的 640×480 畫面與既有第一人稱 oracle 不得改變；高解析度只改
  呈現與 UI 層，不把 modern theme 的幾何當成原版證據。
- 攻略事件資料屬 CoAB game pack；可重用 renderer／overlay 機制不得硬編本作劇情。
- 測試採代表性抽樣：全域鍵優先序、設定 round-trip、F10 成功／失敗、三種解析度、
  兩種 theme、探索／完整攻略與劇透確認各至少一個正負對照。

## 2026-08-28 現代美術契約與全量接線

使用者確認現代 theme 不是只換 UI：`picture`、戰鬥 `sprite`、圖示與 `tileset`
都必須重新繪製。採**混合式、構圖忠實重繪**：

- `picture` 使用高清手繪，保留原版姿態、構圖、辨識色與敘事功能。
- `sprite` 使用現代像素畫，保留 Gold Box 戰術格、輪廓、朝向與 footprint。
- `tileset` 使用高清手繪材質，保持索引、碰撞、方向與地形語意。
- A6 使用細石雕文飾；左上畫面採雙層框及極細明亮金色內框。框線不得吃掉內容。
- 現代資產是與忠實資產分離的原子群組；F2 切換不得覆寫原版匯出 PNG。
- 提高解析度時，現代 `picture` 直接從高清來源縮放，不能先降到原版像素尺寸再放大。

現行全量接線涵蓋清冊的 15 個資產族：場景人物、BIGPIC、PIC／SPRIT 動畫、CPIC、
角色建立與場景頭身、戰鬥符號、隊伍合成、AREA tiles、戰場地形、第一人稱符號與
天空。高清手繪集中於敘事 picture／BIGPIC；大量小圖採 edge-aware 雙解析度現代
像素層，保留原動畫 delay／anchor、戰術 footprint、索引及碰撞語意。這是「所有
唯一視覺均有獨立現代入口」，不冒稱每個 8×8 牆符號皆為獨立高清插畫。

品質完成度另由 `docs/audit/modern-a6-art-quality.json` 計算，不可拿入口清冊替代：
28／28 個單格 PIC 已完成 23 幅高清手繪；多格 PIC 亦完成 28／28 組、124／124 格
逐序列手繪。byte-identical 的入口共用同一組影格；這項共用不降低來源序列覆蓋率，
也不應被灌成彼此不同的畫作數。release PIC 固定為 512×512，仍高於 1280×960
模式的最大實際顯示區；保留的生成 atlas 才是再製來源。曾使用 1024×1024 交付影格，
但 eager loader 在 2 GiB 容器的正常 `-inner-ritual` 路徑遭終止，因此不能作為可玩
交付。改為 512×512 後，同一路徑成功啟動、顯示並輸出正常劇情截圖。

Docker／Xvfb 已由正常 `-inn`、`-inner-ritual`、`-world-map`、`-tilverton-dungeon`
與 `-encounter` 路徑抽拍，證實高清靜態／動畫 picture、BIGPIC、第一人稱符號、
戰場圖塊與兩套 A6 frame 由 runtime 載入。PNG 尺寸、alpha、全來源映射及清冊由測試與
`docs/audit/modern-a6-asset-inventory.json` 固定。

### A6 邊框勘誤

第一版 runtime slice 曾錯用 agent 自行繪製的灰色斜線刻紋，與使用者已選定的
`A6 精修石框・明亮金雕內框` 候選稿不一致，已刪除該視覺實作。現行 frame 直接以
選定稿的淺色精修石材、連續金雕鏈飾與藍寶石交點作為唯一來源，套回既有 Gold Box
分區幾何；不得再用「同樣很細」把其他紋理冒充 A6。

使用者先要求只加粗最外圈，外框曾由約 7 px 調為 18px；2026-08-29 依實際畫面
先收斂為 14px，隨後依同輪畫面檢視固定為 **10px**。內部分隔線與左上金雕內框
維持原細度，避免壓縮內容或把
整套介面再次變成厚框。
