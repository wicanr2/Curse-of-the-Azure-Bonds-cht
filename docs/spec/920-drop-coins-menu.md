# 920 — 丟棄錢幣：七種幣別的選單，與全形空白的補齊規則

- 證據等級：`exact`（兩平台都逐條讀完；相似度 0.975）
- 作法見 spec 783

## `overlay-19:02FA9h`（DOS 283 條）↔ `overlay-19:02FE5h`（PC-98 291 條）

`retf` ＝ 無參數。

| | DOS | PC-98 |
|---|---|---|
| 補齊用的空白 | `' '`（1 byte） | `'　'`（全形，2 bytes） |
| 選單提示 | `'Select type of coin '` | `'貨幣の種類を選んでください'` |
| 選單按鍵列 | `' Select'` | `'決定'` |
| 數量提示（前） | `'How much '` | `'どれだけ'` |
| 數量提示（後） | `'will you drop? '` | `'捨てますか？'` |
| 熱鍵字串 | — | `' 決定 '` → `DS:0A362h`，限長 6 |

```pascal
repeat
    <sub_597h>();
    節點 := NIL;  項數 := 0;
    for i := 0 to 6 do
        if 角色^[0FBh ＋ i × 2] <> 0 then begin        { 角色 ＝ 遠指標(DS:6506h) }
            inc(項數);
            前 := 節點;
            GetMem(節點, 2Eh);
            節點^[2Ah] := 前;                          { ★ 往回接 }
            Str(角色^[0FBh ＋ i × 2], 0, @數字, 0Fh);
            補 := 8 − byte[0F93h ＋ i × 0Bh];          { 幣別名的長度 }
            節點^[0] := 限長(空白 × 補 ＋ 幣別名(i) ＋ ' ' ＋ 數字, 28h);
            節點^[29h] := 0;
        end;
    尾 := 節點;

    選單('Select type of coin ', ' Select',
         0Dh, 0Ah, 0Fh, 0Ch, 7, 19h, 0Dh,
         節點, 1, @var_16, @var_8, @選中);             { sub_16A9 }

    if 選中 = NIL then 結束 := 1                       { 取消 }
    else begin
        幣別 := <loc_1151h+1>(@名稱, 選中);
        問句 := 限長('How much ' ＋ 名稱 ＋ 'will you drop? ', 0FFh);
        數量 := <loc_1156h+1>(0Ah, @問句, 角色^[0FBh ＋ 幣別 × 2]);
        <loc_1160h+1>(角色, 數量, 幣別);
        結束 := 1;
        for i := 0 to 6 do
            if 有號(角色^[0FBh ＋ i × 2]) > 0 then 結束 := 0;   { 還有錢就再來一輪 }
    end;

    if 尾 <> NIL then 釋放鏈(@尾);                     { loc_16B6h+2 }
until 結束 <> 0;
```

## 七種幣別

`角色^[0FBh ＋ i × 2]`，`i` ＝ 0..6（迴圈上界 `cmp var_1, 6`）。
既有規格已定名其中兩格：`+101h` ＝ 金幣（i ＝ 3）、`+103h` ＝ 白金（i ＝ 4）。
名稱表在 **`DS:0F93h`（DOS，stride `0Bh` ＝ `string[10]`）**／
**`DS:2057h`（PC-98，stride `9` ＝ `string[8]`）**，`[0]` 是長度。

## ★ 補齊規則：全形空白要除以 2

```
DOS  ：補 := 8 − 幣別名長度
PC-98：補 := (8 − 幣別名長度) div 2
```

`8` 是最長幣別名的欄寬。DOS 用半形空白，PC-98 用全形空白（2 bytes），
所以**要達到同樣的視覺寬度只需一半的個數**。

整份差異只有 `cwd / mov cx,2 / idiv cx` 三條。

**繁中版同理**：如果幣別名用中文（全形），補齊的空白數要按全形算，
不能沿用 DOS 的 byte 數。

## 選單節點：`string[40]` ＋ 旗標 ＋ next

| | DOS | PC-98 |
|---|---|---|
| 節點大小 | `2Eh` ＝ 46 | `56h` ＝ 86 |
| 文字欄位 | `+0`，限長 `28h` ＝ 40 | `+0`，限長 `50h` ＝ 80 |
| 旗標 | `+29h` | `+51h` |
| next | `+2Ah`（dword） | `+52h`（dword） |

`41 ＋ 1 ＋ 4 ＝ 46` ✓／`81 ＋ 1 ＋ 4 ＝ 86` ✓，
差的 `28h` 就是 **40 欄 → 80 欄**那條全域規則（spec 783 的差異類別 (a) 之外，
是字串欄位加寬）。

## ★ 選單順序是反的

每個新節點的 `next` 指向**前一個**，而傳給選單的是**最後建立的那一個**。
所以清單從**幣別索引最大的**開始往下走到 0。

## 迴圈到錢清空為止

丟完之後重新掃七格，只要還有任何一格 `> 0`（有號比較）就再開一次選單。
**取消才能離開**，或者把錢全部丟光。

## 明確不宣稱

- 沒有宣稱七種幣別各是什麼（只有 i ＝ 3 金幣、i ＝ 4 白金已定名）。
- 沒有宣稱 `sub_16A9` 那 14 個參數的排列（只知道第一個是提示字串、
  倒數第一個帶回選中的節點）。
- 沒有宣稱 `loc_1151h+1`／`loc_1156h+1`／`loc_1160h+1` 的內部行為
  （形狀上分別是「從節點取回幣別索引與名稱」、「輸入數量並夾在上限內」、「扣款」）。
- 沒有宣稱節點 `+29h`／`+51h` 那個旗標的用途。
