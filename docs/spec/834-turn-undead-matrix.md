# 834 — Turn Undead：`DS:0367h` 就是 AD&D 的轉化不死矩陣

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側**助憶碼完全相同**；矩陣取自常駐
  資料段 dump）
- 作法見 spec 783

## `overlay-13:1227h`（entry#13，兩平台各 190 條）

| | DOS | PC-98 |
|---|---|---|
| 宣告 | `'turns undead...'`（15） | — |
| 被驅離 | `'is turned'`（9） | — |
| 被摧毀 | `'Is destroyed'`（12，**開頭 I 大寫**） | — |
| 沒效果 | `'Nothing Happens...'`（18，**H 大寫**） | — |

## 表：DOS `DS:0367h`／PC-98 `DS:075Bh`，索引式 `base + 種類 × 0Ah + 欄`

`種類` ＝ 目標的 `+0E9h`，`欄` ＝ 1..10 的職業等級級距。

**這就是 AD&D 一版的轉化不死矩陣**（Skeleton／Zombie／Ghoul／Shadow／Wight／
Ghast／Wraith／Mummy／Spectre／Vampire 十列，數字是需要擲到的點數）。

編碼：

| 值 | 程式行為 | AD&D 表上的寫法 |
|---|---|---|
| 2..20 | 1d20 要 ≥ 這個值才驅離 | 數字 |
| `1` | 1d20 必過 → **自動驅離** | `T` |
| `0`、`0FFh`（−1） | `abs` 後是 0 或 1，1d20 必過，而且 `v ≤ 0` 走摧毀那條 → **自動摧毀** | `D` |
| `63h`（99） | 1d20 到不了 99 → **不可能** | `—` |

⚠ **`0` 與 `0FFh` 程式行為完全相同**（都是自動摧毀）。表上兩種寫法並存，但程式只
分 `> 0` 與 `≤ 0` 兩類，沒有第三條路。

**種類 1..10 這 100 個 byte 兩平台逐 byte 相同**（由兩份 `dseg` dump 直接比對）。
種類 0 那一列與種類 11 之後都是別的資料——DOS 那裡已經是 ASCII `'Area Cast…'`，
PC-98 是 Shift-JIS，**表的有效範圍就是種類 1..10**。

## 四個規則細節

- **1d20 只擲一次**，整批目標共用；1d12 決定這一次最多影響幾個。
- **「摧毀」不佔那 1d12 的額度**：`剩` 減到 0 時，若還有 `額外`（初值 6）且這次是
  摧毀（`v < 0`），就把 `剩` 加回 1。所以**摧毀最多可以再多做 6 個**。
- **第一個沒過就整批停**（`停 := 1`）——不是逐個判定。
- 等級級距的算法有一處不一致：`L` 在 1..8 時**用的是 `+109h` 而不是 `L`**。
  多職業角色（`+111h` 有值）在這個區間會取到第一職業的等級。

## `+0E9h` ＝ 不死生物的種類（1..10）

spec 815 的 `overlay-13:1433h` 就是這裡的目標挑選器，它挑 `+0E9h` **最小**且
`> 0` 的、門檻初值 `0Dh`（13）——正好蓋住 1..10。所以那一支是**先挑最弱的不死生物
下手**，spec 815 的「明確不宣稱」該項已可關閉。

## 狀態欄位 `+195h` ＝ 8 是「被摧毀」

完整的狀態名稱表見 spec 825（`DS:0FE0h`，每筆 `0Dh`）。本支寫的 `8` 是 `Gone`。

PC-98 對應的是 `+196h`／`+197h`（整份角色記錄自 `+18Dh` 起就比 DOS 多 1 byte，
與 spec 806 一致）。

## PC-98 的差異只有位址

22 個差異區塊全部是同一類：`arg_0` ↔ `arg_2`、`+18Dh` ↔ `+18Eh`、
`+195h/196h` ↔ `+196h/197h`、表基底 `367h` ↔ `75Bh`、字串與近呼叫的目標位址。
**沒有一處是邏輯差異**，這一支兩平台共用同一份判讀。

## 中文化

四句訊息的大小寫不規則（`'Is destroyed'` 的 `I`、`'Nothing Happens...'` 的 `H`），
是四個獨立的字串常數。`'turns undead...'` 與 `'Nothing Happens...'` 都以三個
半形句點結尾。

## 明確不宣稱

- 沒有宣稱十個種類各對應哪一種不死生物（順序與 AD&D 表一致，但遊戲內的名稱表沒讀）。
- 沒有宣稱 `+18Dh^[11h] := 1` 的意義（22 bytes 記錄裡 `+11h` 的第一個用途）。
- 沒有宣稱 `far 1652h` 回傳什麼（形狀上是「要不要把第二職業算進來」）。
- 沒有宣稱 `1944h` / `194Dh+1` / `1505h+4` / `1570h+2` / `158Ah+1` 各做什麼。
