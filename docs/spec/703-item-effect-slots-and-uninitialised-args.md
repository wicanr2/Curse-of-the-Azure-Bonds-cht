# 第七百零三輪：物品的三個效果槽，以及一處未初始化的參數

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-22` 的 `617Bh`、`4289h`、`4432h`。

## `617Bh`：從物品身上拔掉一個效果

```text
found := 0
for k := 1 to 3 do
    if (物品^[3Bh + k] and 7Fh) = arg_0 then found := k    ← 不 break，取最後一個
if found = 0 then 返回
物品^[3Bh + found] := 0
物品^[30h] := 物品^[30h] − 1
if 物品^[30h] < 0D2h then                                  ← 無號比較
    <overlay-24 entry#17>(角色, 物品)                       ← spec 695 的移除並釋放
retf 0Ah
```

`3Bh + 1..3` ＝ `+3Ch`、`+3Dh`、`+3Eh`——**正好是 spec 696 建構子最後三個參數的
落點**。所以物品節點尾端那三個 byte 是三個效果槽，`and 7Fh` 表示低 7 位是編號、
最高位是另一個旗標。

`+30h`（建構子的第 3 個參數）是次數。遞減後**小於 `0D2h`（無號）** 才把整個
物品從角色身上移除並釋放。所以 `0D2h..0FFh` 這一段遞減之後仍不觸發移除——
把它當成單純的「用完就沒了」會提早銷毀物品。

比對迴圈**沒有提早跳出**，三個槽都會掃，`found` 留下的是**最後一個**符合的槽。
三個槽裝同一個編號時，被清掉的是最後一個。

## `4289h`：用哨兵值判斷下游有沒有動過

```text
<sub_F06h>(DS:6F97h, 0, 0, 0, 8, 空字串（CS:4288h）)
p := DS:6506h^[18Dh]^[0Ah]
DS:6F93h := 40h                                  ← 先寫哨兵
<overlay-23 entry#4>(p, 9)
if DS:6F93h = 40h then                           ← 沒被改動才繼續
    <overlay-23 entry#2>(0, [bp−4], [bp−2], DS:6506h, 40h)
```

`DS:6F93h` 是**呼叫前寫入、呼叫後比對**的哨兵：下游改了它就代表發生了某件事，
於是跳過後面。這種控制流不會出現在呼叫圖裡。

### `[bp−4]` 與 `[bp−2]` 從頭到尾沒有被寫入

`sub sp, 0Ah` 配置了 10 bytes 的區域空間，其中

- `bp−9` 是字串拼接的目的緩衝，
- `bp−8`..`bp−5` 存 `p`（`mov [bp−8], ax` ／ `mov [bp−6], dx`），
- `bp−4` 與 `bp−2` **整支函式沒有任何一條指令寫過**，卻在 `42ECh`／`42EFh`
  被推給 `overlay-23 entry#2`。

同一支 `entry#2` 在 `overlay-22:262Fh` 的同樣兩個參數位置推的是**明確的 0**
（`xor ax,ax` ＋ `xor dx,dx`）。所以這裡傳出去的是堆疊殘值。

> 這一條要**實機驗證**再決定 remake 怎麼寫：可能是原作的 bug，也可能那兩個
> 參數在 `entry#2` 的這條路徑上根本不會被讀。照抄「傳 0」會改變行為，
> 照抄「傳未初始化」在別的語言裡是未定義行為。

## `4432h`：三段接力

```text
r := <sub_E11h>(DS:6506h, 4, 49h)
<overlay-23 entry#21（PUTEFFECT）>(r, 0, 0, 0, 0, 空字串（CS:4425h）)
<sub_F06h>(DS:6F97h, 0, 0, 0, 0, 'is affected'（CS:4426h）)
```

`CS:4425h` 與 `CS:4426h` **緊鄰**：前者是長度 0 的空字串，後者長度 11。
反組譯裡兩個 `mov di, offset` 只差 1，很容易看成同一個字串的偏移；實際是兩條
獨立的 Pascal 字串。

`is affected` 在 DOS `overlay-22` 裡有四份（`1DC9h`、`24C1h`、`3172h`、`4426h`，
見 `docs/audit/duplicate-strings.md`）。

## 明確不宣稱

- `sub_E11h`、`overlay-23 entry#4` 的行為。
- `DS:6F93h` 哨兵的語意、`40h` 為何是它的初值。
- `物品^[3Ch..3Eh]` 最高位那個旗標代表什麼。
- `DS:6506h^[18Dh]^[0Ah]` 指向什麼。
