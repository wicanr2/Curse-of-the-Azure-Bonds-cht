# 866 — 體質的 HP 加值：AD&D 一版的表，含「戰士類才能超過 ＋2」

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側只差有號／無號的碼型）
- 作法見 spec 783

## `overlay-17:02515h` ↔ `overlay-17:0278Ch`（DOS 53 條／PC-98 52 條）

`retf 2` ＝ 一個 word（職業碼）。對象是 `遠指標(DS:6506h)`
（spec 864 讀到的「現在在講誰」全域）。

```pascal
體質 := 遠指標(DS:6506h)^[19h];              { +19h ＝ 體質，spec 857 }

if      體質 = 3                        then r := 0FEh      { −2 }
else if (體質 >= 4)  and (體質 <= 6)    then r := 0FFh      { −1 }
else if (體質 >= 7)  and (體質 <= 0Eh)  then r := 0
else if 體質 = 0Fh                      then r := 1
else if 體質 = 10h                      then r := 2
else if (體質 >= 11h) and (體質 <= 13h) then
    if 職業 in [2, 3, 4] then r := 體質 − 0Eh
    else                      r := 2;
結果 := r;
```

## 逐格對上 AD&D 一版

| 體質 | 本支 | AD&D 一版 |
|---|---|---|
| 3 | −2 | −2 |
| 4–6 | −1 | −1 |
| 7–14 | 0 | 0 |
| 15 | ＋1 | ＋1 |
| 16 | ＋2 | ＋2 |
| 17 | ＋3（戰士類）／＋2 | ＋3（戰士類）／＋2 |
| 18 | ＋4（戰士類）／＋2 | ＋4（戰士類）／＋2 |
| 19 | ＋5（戰士類）／＋2 | ＋5（戰士類）／＋2 |

`體質 − 0Eh` 就是 17→3、18→4、19→5。

**「戰士類」＝ 職業碼 2、3、4**，對照 spec 857 由職業名稱表定案的編號
（0 Cleric、1 Druid、**2 Fighter、3 Paladin、4 Ranger**、5 Magic-User、
6 Thief、7 Monk）——正是 AD&D 一版允許加值超過 ＋2 的那三個職業。
**這同時是 `+19h` ＝ 體質、以及那組職業編號的第二份獨立佐證。**

## ⚠ 體質 ≥ 20 回傳未初始化的值

`var_2` 只在各分支裡被寫。體質大於 `13h`（19）時所有分支都不成立，
函式直接讀 `var_2` 回傳——**堆疊上的殘值**。
兩平台一致，不是反組譯問題。原版的體質上限應該到不了 20，
但 remake 要補一個明確的預設值。

## PC-98：只差有號／無號的碼型

DOS 把 byte 零擴充成 `ax` 後用 `cmp ax, n` ＋ `jl`／`jg`（有號）；
PC-98 直接 `cmp al, n` ＋ `jb`／`ja`（無號）。
值域是 0..255，兩種寫法結果相同——spec 783 的第 c 類，不是邏輯差異。
少的那一條是 `xor ah, ah`。
