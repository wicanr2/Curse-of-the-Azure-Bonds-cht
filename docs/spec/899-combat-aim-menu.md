# 899 — 瞄準選單：六個選項一次寫出 PC-98 的欄位陣列

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-13:03040h`（DOS 177 條）↔ `overlay-13:02EBBh`（PC-98 217 條）

`retf 10h` ＝ 8 個 word。

| | DOS | PC-98 |
|---|---|---|
| 距離 | `'Range = '` | `'距離＝'` |
| 選項 | `'Target '` ＋ `'Next Prev Manual '` ＋ `'Center Exit'` | `' 決定 '`／`' 次順 '`／`' 前順 '`／`' 手動 '`／…／… |
| 標題 | `'Aim:'` | — |

```pascal
距離 := <far 1593h+2>(起點, 目標);
r    := <本模組 29A2h>(起點, 目標);

if 顯示距離 then
    訊息('Range = ' ＋ Str(距離) ＋ '  ');

if 距離 <= 上限 then begin
    if not 顯示距離 then begin
        if 可以選 then 選項 := '…' else 選項 := '';
    end
    else if （起點 ≠ 目標）then begin
        if not <far 15BCh+1>(目標) then 選項 := '…'
        else if <far 15C6h+1>(目標, var 暫) then
            if <far 1590h>(目標, 1) and <far 15C1h+1>(目標) then 選項 := '…';
    end;
end;

選項 := 前綴 ＋ 選項 ＋ 後綴;
<far 194Dh+1>(1, 3, 起點);
DS:75E5h := 1;
<far 1505h+4>(起點);
結果 := <far 169Bh+4>(var 有選中, 0, 1, 0Fh, 0Ah, 0Dh, 選項, 'Aim:');
```

DOS 把選項字串拼起來（`'Target '` ＋ `'Next Prev Manual '` ＋ `'Center Exit'`），
**中間那一段是三個選項擠在一個常數裡**，靠空白分隔。

## PC-98 一次寫出六組欄位，把陣列基底夾出來

PC-98 不拼字串，而是逐格寫兩塊陣列：

| 索引 | 標籤位址 | 標籤 | 熱鍵位址 | 熱鍵 |
|---|---|---|---|---|
| 0 | `DS:0A33Fh` | `' 決定 '` | `DS:0A335h` | `54h` `'T'`（Target） |
| 1 | `DS:0A346h` | `' 次順 '` | `DS:0A336h` | `4Eh` `'N'`（Next） |
| 2 | `DS:0A34Dh` | `' 前順 '` | `DS:0A337h` | `50h` `'P'`（Prev） |
| 3 | `DS:0A354h` | `' 手動 '` | `DS:0A338h` | `4Dh` `'M'`（Manual） |
| 4 | `DS:0A35Bh` | （Center） | `DS:0A339h` | `43h` `'C'`（Center） |
| **9** | `DS:0A37Eh` | （Exit） | `DS:0A33Eh` | `45h` `'E'`（Exit） |

標籤位址差 **7**（`0A346h − 0A33Fh` 等），熱鍵位址差 **1**。
所以兩塊陣列的**0 起算基底**是：

```
標籤欄位   DS:0A33Fh，每欄 7 bytes（string[6]）
熱鍵字元   DS:0A335h，每項 1 byte
```

spec 894 從 `0A338h ＋ 7 × 索引` 的算式推出的基底是 **1 起算**的寫法，
本支的六組連續位址把 0 起算的基底夾定了。spec 894 已回頭改正。

**`Exit` 固定在索引 9**——spec 865／879／885／894 看到的
`0A37Eh`／`0A33Eh` 全都是它。

## 每個標籤剛好三個全形字

`' 決定 '`、`' 次順 '`、`' 前順 '`、`' 手動 '` 都是**半形空白 ＋ 兩個全形字 ＋ 半形空白**
＝ 6 bytes，塞滿 `string[6]`。中文版同樣只有 6 bytes 可用。

DOS 的 `'Manual'`／`'Center'` 在 PC-98 是 `' 手動 '` 與 Center 那一格，
語意一一對應。

## PC-98 另外把 `arg_4` 存進 `DS:0BE2Ch`

`mov al, [bp+arg_4]; mov ds:0BE2Ch, al` —— `DS:0BE2Ch` 正是 spec 888 讀到的
「PC-98 髒區重繪的前置條件」。所以那一格是**這一支設的**，
用來讓後面的重繪知道現在在瞄準。

## 明確不宣稱

- 沒有宣稱 `far 15BCh+1`／`15C6h+1`／`15C1h+1`／`1590h` 四個條件各判什麼。
- 沒有宣稱 `本模組 29A2h` 的回傳值用在哪（本支存下來但沒再讀）。
- 沒有宣稱 DOS 那三個擠在一起的選項怎麼被選單常式拆開。
- 沒有宣稱索引 5..8 是哪些選項（本支沒有用到）。
