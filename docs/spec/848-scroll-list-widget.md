# 848 — 捲動清單的三支巢狀程序：游標、翻頁、跳過空行

- 證據等級：`exact`（DOS 側三支逐條讀完；PC-98 側助憶碼序列完全相同，差異全是位址）
- 作法見 spec 783

## `overlay-26`（MENUS）的三支，兩平台各自對應

| DOS | PC-98 | 條數 | 作用 |
|---|---|---|---|
| `00BF9h` | `00C90h` | 77 | 沿著清單跳過整頁，遇到 `+29h` ＝ 0 就停 |
| `00CD9h` | `00D70h` | 49 | 翻頁：把視窗頂端加減一整頁並夾限 |
| `00D6Bh` | `00E02h` | 44 | 游標移一格，視窗跟著追 |

三支都是**巢狀程序**：`arg_0` 是外層函式的 `bp`，所有狀態都從那個 frame 取。
`retf 4` ＝ `(靜態鏈, 方向)`，`方向` ≠ 0 往下、＝ 0 往上。

## 外層 frame 的欄位

| 存取 | 內容 |
|---|---|
| `ss:[靜態鏈+0Ah]` | 遠指標 → **游標行號**（word） |
| `ss:[靜態鏈−59h]` | **視窗高度**（一頁幾行，word） |
| `ss:[靜態鏈−56h]` | **總筆數**（word） |
| `ss:[靜態鏈+14h]`／`+16h` | 清單鏈頭（遠指標） |
| `DS:7292h`（PC-98 `DS:0A32Ch`） | **視窗頂端的行號**（word，全域不是區域） |

## 游標移一格（`00D6Bh`）

```pascal
if 方向 <> 0 then begin
    inc(游標^);
    if 有號(頂端 + 視窗高 − 1) < 有號(游標^) then 游標^ := 頂端;
end else begin
    dec(游標^);
    if 有號(游標^) < 有號(頂端) then 游標^ := 頂端 + 視窗高 − 1;
end;
<00BF9h>(靜態鏈, 方向);
```

**游標走出視窗就繞回另一端**——不是把視窗捲動，而是游標本身環繞。真正的捲動由
翻頁那一支負責。

## 翻頁（`00CD9h`）

```pascal
偏移 := 游標^ − 頂端;                       { 先記住游標在視窗裡的相對位置 }
if 方向 <> 0 then begin
    頂端 := 頂端 + 視窗高;
    if 有號(總筆數 − 視窗高) < 有號(頂端) then 頂端 := 總筆數 − 視窗高;
end else begin
    頂端 := 頂端 − 視窗高;
    if 有號(頂端) < 0 then 頂端 := 0;
end;
游標^ := 頂端 + 偏移;                       { 相對位置保持不變 }
<00BF9h>(靜態鏈, 方向);
<0088Ah>(靜態鏈, 頂端);
```

**翻頁時游標在畫面上不動**——記住相對位置再放回去。夾限是「頂端最多到
`總筆數 − 視窗高`」與「頂端最少 0」，沒有處理 `總筆數 < 視窗高` 的情形
（那時 `總筆數 − 視窗高` 會是負數，頂端被夾成負值）。

## 跳過不能選的行（`00BF9h`）

```pascal
走過 := 0;
while 有號(走過) < 有號(視窗高) do begin
    節點 := <0011h>(鏈頭, 游標^);
    if 節點^[29h] = 0 then break;
    inc(走過);
    if 方向 <> 0 then inc(游標^) else dec(游標^);
    { 同樣的環繞夾限 }
end;
```

`節點^[29h]`（PC-98 `+51h`）**正是 spec 843 那個顯示行節點的「屬性」欄位**——
節點大小 DOS `2Eh`／PC-98 `56h`、`+00h` 文字、`+29h`／`+51h` 屬性、`+2Ah`／`+52h` next。
兩處位移完全對上，可以確認是同一種節點。

在這裡屬性的作用是**「＝ 0 就停」**。spec 843 讀到的那三個呼叫點都傳 0，
所以非 0 的來源在別處（尚未讀到）。

⚠ 迴圈最多跑 `視窗高` 次，但**每次都重新從鏈頭走到 `游標^`**（`0011h` 是「取第 n 個
節點」）。清單長時這是 O(視窗高 × 游標位置)——原版可以接受，remake 直接改成
維護節點指標即可，行為不變。

## 明確不宣稱

- 沒有宣稱 `本模組 0011h(鏈頭, n)` 的實作（形狀上是「取第 n 個節點」，回傳在 `dx:ax`）。
- 沒有宣稱 `本模組 0088Ah(靜態鏈, 頂端)` 做什麼（形狀上是重畫視窗）。
- 沒有宣稱屬性欄位非 0 時代表什麼。
- 沒有宣稱外層函式是誰（三支都只從靜態鏈取狀態）。
