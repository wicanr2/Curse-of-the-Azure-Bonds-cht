# 1042 — 上鎖的門：三個手段各有旗標，全不可用時直接跳過選單

- 證據等級：`exact`（PC-98 側 190 條逐條讀完）
- 作法見 spec 783

## `pc98 overlay-14:00BCCh`（`retf`）

原本待解讀。這是 spec 1026（撞門機率表）的**呼叫端**。

```pascal
<overlay-26 entry#3>();                       { 十格初始化 }
成功 := 0;
if DS:7F27h <> 4 then exit;                   { 畫面模式必須是 4 }
if bank1^[592h] >= 0FFh then begin
    bank1^[592h] := 0;  exit                  { ★ 到上限就重置後離開 }
end;
DS:0A66Ch := 1;
地形 := <overlay-30 entry#5>(DS:0A2A9h, DS:0A2AAh, DS:0A2ABh);
if 地形 = 1 then 成功 := 1
else if 地形 in [2, 3] then …門選單…;
```

★ `DS:0A2A9h`／`0A2AAh`／`0A2ABh` 是**隊伍座標與朝向**（spec 1022／1026 同一組），
`overlay-30 entry#5` 也是 spec 1026 用的那支地形查詢。

## ★★ 三個手段、三個旗標、三個槽

| 選項 | 文字 | 條件 | 文字槽 | 熱鍵槽 | 熱鍵 |
|---|---|---|---|---|---|
| 撞 | 「蹴破る」(6) | `DS:0A81Ah <> 0` | `0A362h`（i ＝ 6） | `0A33Ah` | **`B`**（Bash） |
| 開鎖 | 「鍵開け」(6) | `DS:0A81Bh <> 0` 且 `<sub_27Bh>(6)` 成立 | `0A369h`（i ＝ 7） | `0A33Bh` | **`P`**（Pick） |
| 敲門 | 「ノック」(6) | `DS:0A81Ch <> 0` 且 `<sub_6C0h>(1Fh)` 非零 | `0A370h`（i ＝ 8） | `0A33Ch` | **`K`**（Knock） |
| 離開 | 「やめる」(6) | 一律 | `0A37Eh`（i ＝ 10） | `0A33Eh` | `E` |

★ 四個位址都符合 `文字 ＝ 0A338h ＋ i × 7`、`熱鍵 ＝ 0A334h ＋ i`
（spec 1030／1032 的版面，又一次）。
★★ **熱鍵仍是英文大寫字母**（`B`／`P`／`K`／`E`），文字全是日文
——與 spec 1030 的結論一致。

> ★★ **三個手段全都不可用時，連選單都不顯示**：
> `var_3` 保持 1，直接叫 `<sub_3Eh>(座標, 朝向)` 就走
> ——⚠ **不是顯示一個只有「やめる」的選單**。

## 分支

```pascal
提示 := '鍵がかかっている';                    { 16 bytes ＝ 8 個全形字 }
鍵 := <overlay-26 entry#5>(…);
case 鍵 of
  'B': 成功 := <sub_2F5h>();                   { ★★★ spec 1026 的撞門機率表 }
  'P': if <overlay-30 entry#5>(座標, 朝向) = 2 then 成功 := <sub_5B4h>()
       else DS:0A81Bh := 0;                    { ★ 地形變了就把開鎖旗標關掉 }
  'K': 成功 := <sub_714h>();
end;
if 成功 <> 0 then <sub_807h>();
<overlay-24 entry#38>();
```

> ★★★ **`sub_2F5h` 就是 `pc98 overlay-14:002F5h`**——spec 1026 那張
> AD&D 1e Open Doors 兩欄機率表的本體。這支是它唯一被叫到的地方。
> ★ `'P'` 分支會**再查一次地形**：不是 `2` 就把 `DS:0A81Bh` 關掉
> （形狀上是「這扇門已經不是上鎖狀態了」）。

收尾把 `DS:0A309h`／`DS:0A30Eh` 設回 `0FFh`
——與 spec 1029 的「`0FFh` ＝ 尚未載入的哨兵」同一種寫法。

## 中文化

| PC-98 | bytes | 建議中文 |
|---|---|---|
| 「蹴破る」 | 6 | 撞開 |
| 「鍵開け」 | 6 | 開鎖 |
| 「ノック」 | 6 | 敲門 |
| 「やめる」 | 6 | 離開 |
| 「鍵がかかっている」 | 16 | 門上了鎖 |

⚠ 四個選項各 **6 bytes ＝ 3 個全形字**（spec 1030 的欄位寬度）。

## 明確不宣稱

- 沒有宣稱 `DS:0A81Ah`／`0A81Bh`／`0A81Ch` 三個旗標由誰設定。
- 沒有宣稱 `sub_27Bh(6)`（開鎖的額外條件）與 `sub_6C0h(1Fh)`（敲門的額外條件）在檢查什麼。
- 沒有宣稱 `sub_5B4h`（開鎖）、`sub_714h`（敲門）、`sub_807h`（成功後）、`sub_3Eh` 做什麼。
- 沒有宣稱 `bank1^[592h]` 是什麼計數（只知道到 `0FFh` 就重置）。
- 沒有宣稱地形碼 `1`（直接成功）代表什麼。
