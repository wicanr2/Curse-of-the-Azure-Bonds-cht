# 819 — `Spits Acid`：25% 機率、距離 4 以內、打完掛兩個效果

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的差異已逐條列出）
- 作法見 spec 783

## `overlay-12:2657h`（entry#113，DOS 109 條／PC-98 112 條）

| | DOS | PC-98 |
|---|---|---|
| 訊息 | `'Spits Acid'`（10） | `'は酸を吹いた。'`（14 bytes） |

`retf 0Ah` ＝ 5 個 word。依宣告順序：`(角色, 參數4, 參數2)`，`角色` 是遠指標。

```pascal
目標 := 角色^[18Dh]^[0Ah];                        { 目前目標，spec 782 }
DS:6FA3h := 目標;

if <far 145Dh>(1, 64h) > 19h then 離開;           { 1..100 骰，> 25 就不發動 }
if <far 1595h>(目標, 角色) >= 4 then 離開;        { 無號：距離 4 以上不發動 }

暫存 := <far 1598h+2>(角色);
顯示(角色名 ＋ 'Spits Acid');
<far 1554h>(0Ah, 1);
<far 1566h+2>(17h);
<far 156Ch+1>(取x(角色), 取y(角色), 取x(目標), 取y(目標), 1, 1Eh);
<far 1494h>(<far 1462h>(目標, 8, 4), <far 1457h+1>(2, 目標, 3, 0));
<far 143Eh+1>(角色, 79h, longint(參數4:參數2));
<far 143Eh+1>(角色, 50h, longint 0);
```

### 兩道門檻

- **機率 25%**：`145Dh(1, 64h)` 擲 1..100，大於 `19h`（25）就整支不做事。
- **距離 4 以內**：`1595h(目標, 角色)` 回傳 ≥ 4 就不做事（無號比較）。

兩道都不過就**什麼都不做也不印訊息**——玩家看不到「失敗」。

### 效果碼 79h 與 50h

`143Eh+1` 的形狀是 `(角色, 碼, longint)`，與 spec 796 的 `0141h:002Fh`（移除效果）
相同。這裡連續掛兩個：**`79h`（121）帶著呼叫端傳進來的 longint，`50h`（80）帶
`longint 0`**。

⚠ 第一個掛在 **`角色`**（發動者）身上，不是目標——兩次都是。

### 座標取用的兩支

`192Ah+1` 與 `1930h` 成對出現，各取一個座標分量；spec 817 的機會攻擊用的是
`192Ah+1` 與 `192Dh+3`。三支都是 `(角色遠指標) → byte`，**本規格不宣稱哪一支是 x
哪一支是 y**。

`156Ch+1` 收「發動者的兩個分量、目標的兩個分量、`1`、`1Eh`」，形狀上是一段從 A
到 B 的動畫。

### PC-98 多一段 ×7

PC-98 在對應位置多出 `xor ah, ah` ／ `mov cx, 7` ／ `imul cx`——**把某個 byte
乘以 7**。DOS 沒有這一段。

這與 spec 760 記過的 `overlay-13:040B8h` 是同一種形狀（DOS 用寫死的常數、PC-98
改成算出來的）。**凡是出現常數／算式差異的配對，兩平台都必須各自判讀**，本規格
只把 PC-98 這一段標出來，不宣稱它算的是什麼。

## 明確不宣稱

- 沒有宣稱 `far 1595h` 回傳的是格數還是別的距離量。
- 沒有宣稱 `far 1598h+2` / `1554h` / `1566h+2` / `1494h` / `1457h+1` / `1462h`
  各做什麼。`1462h` 的結果是 `1494h` 的第一個參數（先推的先宣告）。
- 沒有宣稱效果碼 `79h` / `50h` 的名稱。
- 沒有宣稱 PC-98 那段 `× 7` 乘的是什麼。
- 沒有宣稱這一支由哪個怪物觸發（訊息前面接的是 `角色` 的名字）。
