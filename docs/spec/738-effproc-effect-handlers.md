# 第七百三十八輪：解除恐懼、剋制加成、追加傷害，與「實際生效的武器」

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-12` 的 `2C94h`、`2AD6h`、`27FAh`、`0FAAh`。

## `2C94h`：把 `4A8Fh` 做的事一項一項還原

```text
if arg_0 <> 0 then
    if 角色^[0F7h] = 0B3h then
        角色^[0F7h] := 0
        角色^[198h] := 0
    角色^[18Dh]^[10h] := 0
```

對照 spec 724 的恐懼（`overlay-22:4A8Fh`）：

| 套用時（`4A8Fh`） | 解除時（本輪） |
|---|---|
| `+0F7h <= 7Fh` 才設成 `0B3h` | `+0F7h = 0B3h` 才清成 0 |
| `+198h := 1` | `+198h := 0` |
| `+18Dh^[10h] := 1` | `+18Dh^[10h] := 0` |

**`+0F7h` 的還原是有條件的**：只有值正好是 `0B3h` 才清。spec 734 的操縱屍體會把
它設成 `0B2h`（當原值 `> 7Fh` 時），那種情況下解除恐懼**不會動到它**。
兩個效果對同一個 byte 的處理不對稱，順序會影響結果。

`+18Dh^[10h]` 則是無條件清成 0——即使 `+0F7h` 那一段沒進去。

## `2AD6h`：對特定目標的傷害加成

```text
p := 角色^[18Dh]^[0Ah]                    ← 目前鎖定的目標（spec 722）
DS:6FA3h := p
if (p^[14Bh] and 8) <> 0 then
    DS:6F94h := DS:6F94h + 角色^[10Dh]     ← 累加，不是覆寫
```

`+14Bh` 的 bit 3 是目標的某個類別旗標；命中就把攻擊者的 `+10Dh`（第一職業欄位，
spec 728）加進傷害。這是「對某類敵人有加成」的形狀。

和 spec 737 的 `255Ah`（把傷害**覆寫**成 `1d6+1`）對照：同一個全域
`DS:6F94h`，一支覆寫一支累加，**執行順序決定結果**。

## `27FAh`：換一種傷害型別再打一次

```text
DS:6F95h := 0Ah                            ← 傷害旗標換成 0Ah
d := ROLLDAMAGEDICE(2, 8)
<overlay-23 entry#20>(角色^[18Dh]^[0Ah], d, 0, 0)
```

不動 `DS:6F94h`，而是**直接對目標再結算一次 `2d8`**。所以這是附加傷害不是修正值。
`DS:6F95h` 設完之後沒有還原——與 spec 706 那支「改完會還原」的相反。

## `0FAAh`：取實際生效的武器，失敗就退回原本那件

```text
r := NIL
if 角色^[151h] <> NIL then
    ok := <overlay-24 entry#43>(角色, @r)        ← spec 697 的武器選擇
    if ok = 0 或 r = NIL then r := 角色^[151h]
回傳 r（DX:AX）
```

`entry#43` 就是 spec 697 讀過的 `overlay-24:30A0h`。那支用 `var` 參數帶回結果、
回傳值只表示「有沒有找到」——這裡把兩者都檢查了：**回傳 0 或帶回 `NIL` 都算失敗**，
兩個條件缺一不可。spec 697 特別記過「只看回傳值拿不到節點」，這支正好示範了
正確的用法。

失敗時退回 `角色^[151h]` 本身，所以呼叫端一定拿得到非 `NIL`（前提是 `+151h` 非
`NIL`）。

## 明確不宣稱

- `+0F7h`、`+198h`、`+18Dh^[10h]`、`+14Bh` bit 3、`+10Dh` 的語意。
- 傷害旗標 `0Ah` 代表哪一種傷害。
- 這三支各自對應哪一個效果編號（`overlay-12` 是 EFFPROCS，應該有一張
  效果編號 → 處理程序的表，本輪沒有找到它）。
