# 第七百零七輪：復活的四道門檻，與範圍效果的傷害旗標

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-22` 的 `44D3h`、`3947h`。

## `44D3h`：復活

```text
p := DS:7435h
if p^[195h] <> 6 且 p^[195h] <> 1 then 返回        ← 只有這兩個狀態能復活
if p^[18h] <= 0 then 返回                          ← 無號 ja，次數必須大於 0
if p^[74h] = 2  then 返回                          ← 這一類不能復活

DS:6F9Ch := 1
<overlay-23 entry#3>(p, 20h, 0)                    ← 解除效果 20h
<overlay-23 entry#3>(p, 37h, 0)                    ← 解除效果 37h
DS:6F9Ch := 0

p^[195h] := 0                                      ← 狀態歸 0
p^[196h] := 1
p^[18h]  := p^[18h] − 1                            ← ⚠ 次數扣掉，不可逆
<overlay-23 entry#24>(p, 4)
p^[1A4h] := 1                                      ← HP 設成 1，不是設成上限
<overlay-24 entry#20>(p, 'is raised'（CS:44C9h）, 0Ah, 1)
```

四道門檻缺一不可，而且**三個是 early return**——只要有一個不過，連訊息都不會
顯示，玩家看不到任何回饋。

`p^[18h]` 每復活一次減 1 且**沒有任何地方加回去**（本輪範圍內）。這是 AD&D
「能被復活的次數有限」那條規則的實作。remake 若漏掉這個遞減，角色會變成可以
無限復活。

復活後 HP 是 **1**，不是上限也不是任何骰值。

`DS:6F9Ch` 在兩次 `entry#3` 期間立起——和 spec 704 的 `2FD1h` 是同一個旗標、
同一種用法（解除效果時立起）。

## `3947h`：兩段互相獨立的判斷

```text
<overlay-32 entry#9>(@a, @b, arg_A, arg_C)          ← 兩個 var 參數帶回 a、b

第一段：
if a > 0 且 byte[26A2h + a×4] = 0FFh 且 [4F99h]^[1CCh] = 1 且 arg_0^ = 0
    then arg_0^ := 1
    else arg_0^ := 0                                ← ⚠ 否則一律覆寫成 0

第二段：
if b > 0 且 b <> arg_4 then
    目標 := far [6D35h + b×4]
    DS:6F95h := 0Ch                                 ← 傷害旗標
    r := <overlay-23 entry#8>(目標, arg_8, 2, 目標, arg_6, 0)
    <overlay-23 entry#20>(r)
    <overlay-24 entry#24>(13h)
    DS:6F95h := 0
retf 0Eh
```

第一段的 `else` 分支**無條件把 `arg_0^` 寫成 0**——包括「本來就是 1」的情況。
所以這不是「條件成立就設旗標」，是「每次呼叫都重算」。連續呼叫時前一次的結果
不會保留。

四個條件裡有一個是 `arg_0^ = 0`，也就是**只有原本是 0 才會被設成 1**；原本是 1
時前三個條件即使全過也會落到 `else` 被清成 0。這個自我否定的結構很容易在改寫
時被「簡化」掉。

`DS:6F95h` 是傷害旗標（PC-98 側對應 `DS:A02Fh`，`overlay-12:2461h` 那筆讀它的
bit 1）。這裡在呼叫前設 `0Ch`、呼叫後歸 0，所以 `0Ch` 只在那三個呼叫期間有效。

`[6D35h + b×4]` 是 spec 699 那張 4 bytes 一格的 far 指標表。

## 明確不宣稱

- `+18h`、`+74h`、`+195h`、`+196h` 的欄位名稱與值域。
- `DS:26A2h` 那張 4 bytes 一格的表。
- `overlay-32 entry#9`、`overlay-23 entry#8`／#20／#24 的行為。
- 傷害旗標 `0Ch` 代表哪一種傷害。
