# 第七百零九輪：`DS:7431h` 是目標陣列，`DS:7435h` 只是它的第一格

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-22` 的 `1C39h`、`24CDh`。

> spec 681 早先已從「計數 ＋ 第 1 筆」的形狀推出同一個基底。本輪是從 `1C39h`
> 的迴圈算式獨立得到的第二條證據，不是新發現。

## 結構

`1C39h` 的迴圈把這件事講清楚了：

```text
n := DS:7434h
for k := 1 to n do
    p := far [7431h + k × 4]
    ...
```

`7431h + 1 × 4 = 7435h`、`7433h + 1 × 4 = 7437h`——**先前一路被當成「目標」的
`DS:7435h`／`DS:7437h`，就是這個陣列的第 1 格**。

| 位址 | 內容 |
|---|---|
| `DS:7431h` | far 指標陣列的基底，一格 4 bytes，**1-based** |
| `DS:7434h` | 筆數 |
| `DS:7435h`／`7437h` | 第 1 格（＝多數 opcode 用的「目標」） |

`7434h`（筆數）落在 `7431h` 起算的第 0 格範圍內。索引從 1 起，所以第 0 格
本來就用不到，那個 byte 被拿去放筆數。

這解釋了先前一堆 opcode 的寫法：`if DS:7434h <> 0`（spec 700 的治療系）其實是
**「目標清單非空」**，而不是「有一個叫做 7434h 的旗標」。單目標法術就是
`n = 1` 的特例。

## `1C39h`：把不符合的目標從清單裡拿掉

```text
複製 arg_0 → 區域緩衝（上限 28h）
DS:6F9Dh := 1
for k := 1 to DS:7434h do
    p := far [7431h + k×4]
    清掉 := (p^[197h] <> arg_4)
             或 (p^[197h] = arg_4 且 DS:6F97h = 1 且 DS:4FBAh = 5
                 且 <overlay-24 entry#32>(p, 1) > 0)
    if 清掉 then [7431h + k×4] := NIL
<sub_F06h>(DS:6F97h, 0, 0, 0, 0, 緩衝)
retf 6
```

條件的形狀值得看一眼：**類別相符的那一支反而可能被清掉**。相符之後還要三個
額外條件都成立才清；三個裡有任何一個不成立，該格保留。所以這不是「留下相符的」，
是「留下相符 **且** 不滿足那三個條件的」。

清掉的方式是把該格寫成 `NIL`，**筆數 `DS:7434h` 不變**——後面的迴圈仍會走完
全部 `n` 格，只是踩到 `NIL`。所以下游必須自己檢查 `NIL`。

## `24CDh`：狀態 1 直接清空目標

```text
p := DS:7435h
if p^[195h] = 1 then
    DS:7435h := 0 ; DS:7437h := 0                 ← 把第 1 格清成 NIL
else
    if <overlay-24 entry#27>(p, 37h, @node) then
        if p^[1A4h] = 0 then p^[1A4h] := 1        ← HP 為 0 補成 1
        <sub_F06h>(DS:6F97h, 0FFh, 1, 0, 0, 'is affected'（CS:24C1h）)
        <overlay-23 entry#2>(4Eh, p, 0, 1)
        <overlay-23 entry#11>(p, 0Fh, 0Ah, 0FFh, 1)
```

第一條路**只清第 1 格、不動筆數**，和 `1C39h` 是同一種做法。

`p^[1A4h] = 0` 時補成 1 的寫法，和 spec 707 復活那支把 HP 設成 1 是同一個模式。

效果編號 `37h` 在 spec 707 的復活流程裡也被解除，所以它是死亡相關的效果。

`sub_F06h` 這次的第二、三個參數是 `0FFh` 與 `1`，和先前看過的
`(0, 0, 傷害量, 8)`（spec 701）、`(0, 0, 0, 8)`、`(n, 0, 0, 8)` 都不同——
這幾個欄位是模式選擇，不是固定值。

## 明確不宣稱

- `+197h` 那個「類別」的值域。
- `DS:6F9Dh`、`DS:6F97h`、`DS:4FBAh = 5` 各代表什麼。
- `overlay-24 entry#32`、`overlay-23 entry#11` 的行為。
- `sub_F06h` 前五個參數的完整語意。
