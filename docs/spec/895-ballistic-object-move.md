# 895 — 結局動畫的拋物線移動：定點 ×32 加重力

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側差異逐條列出）
- 作法見 spec 783

## `overlay-18:00843h`（DOS 151 條）↔ `overlay-18:00748h`（PC-98 154 條）

`overlay-18` ＝ ENDSTUFF。`retf 14h` ＝ 10 個 word，其中四個是 var 參數。

```pascal
if 要畫 then <本模組 006Ah>();

fx := 座標x^ shl 5;                                { ×32，定點 }
fy := 座標y^ shl 5;

if 要畫 and (8 < 座標y^) and (座標y^ < 41h) then
    存 := <本模組 0032h>(座標y^, 座標x^);          { 記下這一格原本的樣子 }

for i := 1 to 步數 do begin
    fx := fx ＋ 速度x^;
    fy := fy ＋ 速度y^ ＋ 1;
    nx := fx div 20h;   ny := fy div 20h;
    inc(速度y^);                                    { ★ 每步加 1 ＝ 重力 }

    if 要畫 and (8 < 座標y^) and (座標y^ < 41h) then begin
        <本模組 0000h>(存, 座標y^, 座標x^);         { 把舊格還原 }
        存 := <本模組 0032h>(ny, nx);               { 記下新格 }
        <本模組 0000h>(Random(7) ＋ 8, ny, nx);     { 畫上去 }
    end;

    <far 09ABh:029Eh>(0Fh);                         { 延遲 }
    座標x^ := nx;  座標y^ := ny;
end;

if 要畫 and (8 < 座標y^) and (座標y^ < 41h) then
    <本模組 0000h>(存, 座標y^, 座標x^);             { 收尾還原 }

{ 最後再算一步，但不畫 }
fx := fx ＋ 速度x^;  fy := fy ＋ 速度y^ ＋ 1;  inc(速度y^);
座標x^ := fx div 20h;  座標y^ := fy div 20h;
```

## 定點 ×32 ＋ 每步 `inc(速度y)` ＝ 拋物線

座標用 `shl 5`／`idiv 20h` 做 **1/32 格的定點數**，
`速度y^` 每一步加 1——**這是等加速度**，也就是重力。
`速度x^` 不變，所以軌跡是拋物線。

`速度x^` 與 `速度y^` 都是 **var 參數**，函式跑完會把最後的速度寫回去，
所以呼叫端可以分段呼叫、軌跡連續。

畫上去的字元是 `Random(7) ＋ 8`（`0A54h:1105h` ＝ Turbo Pascal `Random`），
也就是 **8..14 之間隨機挑一個**——每一格長得不一樣。

可見範圍 `8 < y < 41h` 與 spec 867 的判斷**完全一致**（PC-98 同樣是 `42h`），
兩支都在 ENDSTUFF 裡處理同一個畫面。

## ⚠ PC-98 用遊戲速度當延遲，DOS 寫死

| | 延遲值 |
|---|---|
| DOS | `0Fh`（常數） |
| PC-98 | **`DS:7F16h`**（＝ DOS 的 `DS:4FA9h`，遊戲速度） |

這是 `DS:4FA9h` 的**第三個消費端**，而且是唯一一個
**DOS 根本不看速度值**的地方：

| 出處 | 用法 |
|---|---|
| spec 881 | 門檻 ＝ 每格延遲 × (速度 ＋ 3)（兩平台都用） |
| spec 890 | 動畫重播 速度 ＋ 1 次（兩平台都用） |
| **本支** | **延遲值本身；DOS 固定 `0Fh`、PC-98 才用速度值** |

所以 DOS 版的結局動畫**不受速度設定影響**，PC-98 版會。
remake 要選一邊，或兩邊都做。

PC-98 另外把可見上界改成 `42h`（同 spec 867）、
多一段 `× 14h`（20）的換算，並且畫格的呼叫多一個參數。

## 明確不宣稱

- 沒有宣稱 `本模組 0032h(y, x)` 與 `0000h(值, y, x)` 的實作
  （形狀上是「讀一格」與「寫一格」）。
- 沒有宣稱 `8..14` 那七個值是什麼字元／圖磚。
- 沒有宣稱 PC-98 多出來的 `× 20` 用在哪一個座標。
