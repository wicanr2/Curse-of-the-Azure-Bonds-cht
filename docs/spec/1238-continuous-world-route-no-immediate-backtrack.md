# 1238 — 連續世界路線重放不立即折返

狀態：`READY`（測試重放策略；不改遊戲旅行規則）

## 問題與證據

`route-clean-716.json` 是各段戰役決策的聯集，不是一條從標題到結局的逐步行程。
連續 session 在立石群選阿沙本福德後，聯集查表又於阿沙本福德選回立石群，
因此 `0x50`／`0x51` 間形成完全合法、但不增加覆蓋的立即折返。3000 幀控制組只
走過 128 格、記到 163 句，最後進展停在第 2230 幀。

## 修正

- 按鍵重放器在「從這裡可以前往」選單記住上一個出發地。
- 路線候選若立刻回到上一個出發地，只在測試重放器內排除；若沒有其他錄製候選，
  交回既有探索策略選擇。
- 路線查表與 fallback 兩種目的地選擇都更新出發地，避免只修其中一條路。
- 遊戲的世界旅行圖、ECL 記憶體與玩家可選目的地完全不變；真人仍可自由折返。

## 驗證與限制

- 無強化、真實鍵盤接縫、`route-clean-716.json`、4000 幀上限：session 在第 1604
  幀第一次全滅前走過 128 格、記到 185 句、進入 `ECL3/0x10`，原文 fallback 0。
- 相較控制組，世界選單循環已解除，新增 22 句並由 `0x50`／`0x51` 推進到 `0x10`。
- 新的停止原因是正常強度隊伍全滅；本規格不宣稱一般強度連續通關，也不把測試
  重放策略當成原版旅行 AI 或產品規則。
