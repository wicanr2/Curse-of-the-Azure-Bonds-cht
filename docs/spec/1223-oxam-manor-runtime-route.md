# 1223：奧克薩姆莊園正常選項路徑與實跑覆蓋

狀態：`READY`（2026-08-27）

## 問題

`ECL4/0x25` 有 745 條靜態可達指令，舊實跑只執行 73 條（9.8%）。最大未覆蓋
叢集從 `0x84C6` 起連續 409 條，正是奧克薩姆莊園的房間、樓梯、遭遇與寶物。

玩家進莊園必須依序：進入 `SHOP`、離開貨架，再於下一層選單選
`GO TO THE TOWER`。走訪器原本每一場固定選同一索引，所以不可能組出這條路；
抵達地城後又把 GEO 門當牆，門後內容仍全部漏掉。

## 修正

1. `ECL4/0x25` 新增依具名選項走的策略，避免選單插入項目後索引靜默漂移。
2. 走訪遇到 GEO 明確標成門（旗標 2／3）時直接開門再繼續。這是內容盤點，
   問的是門開後能否執行；不宣稱強化走訪隊伍擲出了原版開鎖結果。
3. 正對照要求具名高塔策略必須完成轉場，不能以其他策略走到的格數假綠。
4. 新路徑抓到向上螺旋梯的英文落回；新增獨立 stable ID
   `dexam.circular-stairway-up`。`WHAT TO YOU DO?` 與無標點的 `WHAT DO YOU DO`
   維持共用子程式片段，不建立可能誤攔其他頁面的短文字規則。
