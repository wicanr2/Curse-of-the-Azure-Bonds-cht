# 831 — 士氣失敗的四種結果（1d100 分四段）

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的差異已逐條列出）
- 作法見 spec 783

## `overlay-12:0A0Eh`（entry#37，DOS 168 條／PC-98 167 條）

`retf 0Ah` ＝ 5 個 word。依宣告順序：`(角色, 參數4, 參數2)`。

```pascal
r := <far 145Dh>(1, 64h);                          { 1..100 }

if (r >= 1) and (r <= 0Ah) then begin              { 1..10 }
    <far 143Eh+1>(角色, 23h, longint 0);
    角色^[18Dh]^[10h] := 1;
    角色^[198h] := 1;
    if 角色^[0F7h] <= 7Fh then 角色^[0F7h] := 0B3h;
    角色^[18Dh]^[0Ah] := NIL;                      { 清掉目前目標 }
    <far 1499h>(角色, 8Eh, 0Ah, 0, 1, 1, 0, 名字 ＋ 'runs away');
end
else if (r >= 0Bh) and (r <= 3Ch) then begin       { 11..60 }
    <far 1572h>(角色, 1, 名字 ＋ 'is confused');
    <far 1558h+1>();
    <本模組 0075h>(0, 參數2, 參數4, 角色);
end
else if (r >= 3Dh) and (r <= 50h) then begin       { 61..80 }
    <far 1499h>(角色, 89h, 1, 角色^[197h], 1, 1, 0, 名字 ＋ 'goes berserk');
    <本模組 143Ah>(0, longint 0, 角色, 89h);
end
else if (r >= 51h) and (r <= 64h) then begin       { 81..100 }
    <far 1572h>(角色, 1, 名字 ＋ 'is enraged');
    <far 1558h+1>();
end;

if <far 1457h+1>(角色, 4, 0FEh) then
    <far 143Eh+1>(角色, 23h, longint 0);
```

## 四段的骰值與訊息

| 骰（1d100） | DOS | PC-98 |
|---|---|---|
| 1..10 | `'runs away'`（9，`CS:09E0h`） | `'は逃げ去った。'`（14 bytes） |
| 11..60 | `'is confused'`（11，`CS:09EAh`） | `'は混乱した。'`（12 bytes） |
| 61..80 | `'goes berserk'`（12，`CS:09F6h`） | `'は狂暴化した。'`（14 bytes） |
| 81..100 | `'is enraged'`（10，`CS:0A03h`） | `'は怒りに我を忘れた。'`（20 bytes） |

四段的機率是 **10% / 50% / 20% / 20%**，加起來剛好 100，**沒有落空的骰值**。

## 「逃走」那一段做了五件事

1. 掛效果碼 `23h`（35）。
2. `+18Dh^[10h] := 1`——就是 spec 815 挑目標時要求為 0 的那個欄位，也是 spec 830
   判「恐慌逃走」訊息的條件之一。**逃走的人不會被選為目標，也不會再被選中行動。**
3. `+198h := 1`。
4. **士氣補滿**：`+0F7h` ≤ `7Fh`（最高位沒設）時直接寫 `0B3h`——就是 spec 758／798
   認過的「上限 102」編碼值。
5. **清掉目前目標**（`+18Dh^[0Ah]` 兩個 word 都寫 0）。

## 收尾的條件式移除

不論落在哪一段，最後都問一次 `1457h+1(角色, 4, 0FEh)`，成立就 `143Eh+1(角色, 23h,
longint 0)`——**與「逃走」那一段掛的是同一個碼 `23h`**。所以 `143Eh+1` 在這裡
比較像「切換／設定」而不是單純的「掛上」。

## 中文化：`berserk` 的拼法陷阱

本支是 `'goes berserk'`（12）。專案另一處有 `goes berzerk`（**`z`**）——
**兩個字串各自獨立，不能用單一取代**。同理 `'is Poisoned'`（spec 829，大寫 P）
與 `'is not poisoned.'`（spec 796，小寫 p）也是分開的。

## PC-98 的差異都在比較的號誌性

九個差異區塊裡有六個是同一類：**DOS 用有號跳躍（`jge` / `jle` / `jl` / `jg`），
PC-98 用無號（`jnb` / `jbe` / `jb` / `ja`）**，而且 DOS 多一條 `xor ah, ah`
（把骰值零延伸成 word 再比）。骰值範圍是 1..100，兩種比較法結果相同，
**是編譯器版本差異，不是行為差異**。

## 沒有任何 far call 打到這一支

用 spec 1112 的對照表掃過兩平台所有 far call：**整份遊戲只有一處 far call 進
overlay-12，而且是 entry#2**。`0A0Eh` ＝ entry#37（TPOV 控制記錄裡的 stub 表，
`0A0Eh` 是第 37 個 stub 的目標）沒有任何靜態呼叫點。

所以「什麼時候做士氣檢定」**還沒有答案**：這一支要嘛經由函式指標表間接叫到，
要嘛在同一個 overlay 內被近呼叫而 IDA 沒認出來。在找到觸發點之前，remake 這一側
有規則（四段表與逃走的狀態變更）但**沒有觸發**，覆蓋報告要照這個口徑寫。
