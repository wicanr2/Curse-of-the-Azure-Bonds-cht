# 1230：原版戰場邊界與戰鬥終止狀態

狀態：`READY`（2026-08-27）

## 問題與修正

COMPREP 已投影原版 TACMAP 座標，但移動逃跑判定與點選法術游標仍固定使用
fallback 的 32×16。原版合法的 x=32 因而落在邊界外，玩家靠近敵人反被判逃跑。

- 原版座標模式改用 spec 1200 證實的 50×25；32×16 只留給 fallback。
- 特殊攻擊共同傷害路徑與 `TurnUndead` 摧毀整批後都呼叫 `updateStatus()`，
  不再留下 HP 0、狀態卻為 `StatusActive` 的矛盾。
- 載入非戰鬥存檔會清除上一場 battle 與暫態戰鬥 UI。

## 玩家路徑與結果

- 贊提爾巡邏敗戰 → 法庭 → 有罪 → 競技場 → 敗戰 → 回城的 ECL 鏈已走通。
- `TestRealNewGameRunsToTheEnding` 從新遊戲走到結局。
- 同版實跑覆蓋：**9,607／14,177（67.8%）**，較 spec 1228 增加 131；圖外 0。

完整戰役測試使用單人快速角色。50×25 修正後，它不再靠假逃跑存活；測試只在
POSTCOM 已完成後恢復各獨立覆蓋樣本，最終戰前提高耐久以取得勝利結局。這證明
ECL／戰鬥／POSTCOM／結局垂直鏈，不是一般隊伍平衡證據。正常強度完整通關仍是
獨立驗收閘門。

50×25 是已證實尺寸，但不代表所有 COMPREP 逐格佈陣都已逐格同原版。
