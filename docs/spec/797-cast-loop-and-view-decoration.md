# 797 — 施法選單的外迴圈、第一人稱視野的裝飾繪製

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-15:04CBh`（entry#2，77 條，差異 15 條）— 選法術的外迴圈

| | DOS | PC-98 |
|---|---|---|
| 訊息 | `'has no spells memorized'`（23，**沒有句點**） | `'は呪文をまったく覚えていない。'`（30 bytes，**有句點**） |

```pascal
用過 := 0;  var_2 := 0FFFFh;
DS:7555h := 0;  DS:7557h := 0;
DS:7294h := 1;
if <本模組 0391h>(1) then
    repeat
        選 := <far 102Bh+1>(0, 1, @var_2, @var_3);
        if 選 <> 0 then begin
            用過 := 1;
            <1EC9h+4>(1, 11h, 26h, 16h);
            <11D8h+1>(選, 0, 1, @var_5);
        end
        else if var_3 <> 0 then
            用過 := 1
        else begin
            <far 1554h>(角色, 名字 ＋ 'has no spells memorized', 0Ah, 1);
        end;
    until 選 = 0;
if 用過 <> 0 then <sub_15A9>();
```

`retf`（無參數）。

- **`sub_15A9` 只在迴圈裡至少發生過一件事時才呼叫**（`用過` 旗標）；三條路裡有
  兩條會把它設起來，只有「沒有記憶法術」那條不會。
- `var_2` 的初值是 `0FFFFh`（不是 0），而且以位址傳給 `102Bh+1`——所以它是
  「上次選到哪」之類的往返狀態，`−1` 是「還沒選過」。
- `DS:7555h` / `DS:7557h` 兩個相鄰的 word 一起清零（可能是一個 longint 或遠指標）。

**中文化**：DOS 的 `'has no spells memorized'` 結尾**沒有句點**，PC-98 譯文加了
句點。這是又一處「PC-98 沒有照抄原文標點」的例子——中文版跟著語感走即可。

## `overlay-10:03ECh`（entry#8，78 條，**差異 2 條**）— 視野的底圖與裝飾

兩平台只差一個全域位址（`DS:4A0Fh` ↔ `DS:7AC5h`）。呼叫的 `sub_48` 就是 spec 786
的 `overlay-10:0048h`（把一格寫進 `DS:6E92h` 螢幕緩衝，簽名 `(x位移, y位移, 磚)`）。

```pascal
for y := 2 to 4 do
    for x := 0 to 5 do
        寫格(x, y, 16h);                     { 6 × 3 的底 }

if DS:4A0Fh = 1 then
    for k := 2 to 4 do begin
        寫格(k − 1, k, 04h);
        寫格(k,     k, 03h);
        寫格(k + 1, k, 0Dh);
    end
else if DS:4A0Fh = 3 then begin
    寫格(1, 2, 08h);
    寫格(5, 4, 00h);
end;
```

`retf 2` ＝ 一個 word，**本體從來不讀它**——與 spec 784 的 `overlay-10:02F6h`
同一種形狀，是巢狀程序收到的靜態鏈。

三件事：

- **底圖先鋪滿再蓋裝飾**：`16h` 那塊 6 × 3 無條件先畫，兩個 `DS:4A0Fh` 分支再
  蓋上去。所以 `16h` 是「空」的磚碼（spec 771 那四組寫死參數第三欄也是 `16h`，
  對得起來）。
- `DS:4A0Fh = 1` 那條是**三格寬的斜線**：`k` 從 2 到 4，每列畫
  `(k−1, k)`＝`04h`、`(k, k)`＝`03h`、`(k+1, k)`＝`0Dh`。三種磚碼固定，位置隨 `k`
  往右下走。
- `DS:4A0Fh` **只處理 1 和 3**；其他值（含 0、2）畫完底圖就結束。

## 明確不宣稱

- 沒有宣稱 `DS:4A0Fh` 的 1 / 3 各代表什麼場景。
- 沒有宣稱磚碼 `03h` / `04h` / `08h` / `0Dh` / `00h` 畫出什麼。
- 沒有宣稱 `far 102Bh+1` 的回傳值是法術編號還是選單索引。
- 沒有宣稱 `var_3` 不為 0 代表什麼（形狀上是「另一種結束」）。
- 沒有宣稱 `DS:7555h` / `DS:7294h` 由誰讀。
