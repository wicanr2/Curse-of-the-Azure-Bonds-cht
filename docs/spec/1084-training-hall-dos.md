# 1084 — DOS 訓練所：AD&D 1e 的亞人等級上限整張表，連主屬性例外都照抄

- 證據等級：`exact`（DOS 側 900 條逐條讀完，`filled` 匯出無破洞）
- 作法見 spec 783

## `dos overlay-17:04D2Ah`（`retf`，無參數）

原本待解讀。範圍 `4D2Ah`..`56BBh`。這是**訓練所升級**的主流程。
角色取自 `DS:6506h`（目前角色，spec 1076）。

⚠ IDA 把兩個 `DS:` 位址標成程式標籤：`loc_4FC7+1` ＝ **`DS:4FC8h`**、
`dword ptr loc_4F9D` ＝ **`DS:4F9Dh`（bank 1）**。兩處都沒有 `cs:` 前綴，
所以是資料段——**遇到 `cmp byte ptr loc_XXXX, 0` 這種寫法要先確認段**。

## 一、兩道門檻

```pascal
if (角色^[195h] <> 0) and (DS:7587h = 0) then begin
    印('we only train conscious people');  exit;          { spec 1061 的倒下原因 }
end;
金錢 := <overlay-19 entry#11>(角色);                       { 32-bit }
if (金錢 < 3E8h) and (DS:7587h = 0) and (DS:4FC8h = 0) and (DS:8B6Fh = 0) then begin
    印('Training costs 1000 gp.');  exit;
end;
```

★ **`DS:7587h` 是「免費訓練」開關**——`dos overlay-17:001DDh` 的
`'Free training on'`／`'Free training off'` 就是切這一格。
開著的時候**連昏迷、沒錢、經驗不足全部略過**。
★ `DS:4FC8h` 與 `DS:8B6Fh` 是另外兩個「這次不收費」的旗標。

## ★★★ 二、亞人等級上限：AD&D 1e 原表，含主屬性例外

`角色^[74h]` 是**種族**。對每一個有等級的職業槽 `j`（`角色^[109h ＋ j] > 0`），
先判斷「這一職是不是已經到頂」：

| 種族 | 職業槽 | 上限（主屬性 ≤ 16 ／ ＝ 17 ／ ≥ 18） | 判定用的屬性 |
|---|---|---|---|
| **1** | 2（戰士） | **7 ／ 8 ／ 9** | `+11h` 力量 |
| **2** | 2（戰士） | **5 ／ 6 ／ 7** | `+11h` 力量 |
| **2** | 5（法師） | **9 ／ 10 ／ 11** | `+13h` 智力 |
| **3** | 2（戰士） | **5 ／ 5 ／ 6**（只看 ≥ 18） | `+11h` 力量 |
| **4** | 0（牧師） | **5**（固定） | — |
| **4** | 2、4（戰士、遊俠） | **6 ／ 7 ／ 8** | `+11h` 力量 |
| **4** | 5（法師） | **6 ／ 7 ／ 8** | `+13h` 智力 |
| **5** | 2（戰士） | **4 ／ 5 ／ 6** | `+11h` 力量 |

> ★★★ 這幾組數字**逐一對上 AD&D 1e 的 Racial Level Limits**：
> 矮人戰士 7/8/9、精靈戰士 5/6/7、精靈法師 9/10/11、
> 地精戰士 5/6、半精靈牧師 5、半精靈戰士 6/7/8、半精靈法師 6/7/8、
> 半身人戰士 4/5/6。
> ⇒ **`+74h` 的種族編號定案：`1` ＝ 矮人、`2` ＝ 精靈、`3` ＝ 地精、
> `4` ＝ 半精靈、`5` ＝ 半身人**；`0`（人類）沒有任何分支 ⇒ **無上限**。
> ⇒ 職業槽 `2` ＝ 戰士、`4` ＝ 遊俠、`5` ＝ 法師、`0` ＝ 牧師，
> **第五次確認職業槽順序**（牧師／德魯伊／戰士／聖騎士／遊俠／法師／盜賊／武僧）。
>
> ⚠ 表裡**沒有**盜賊、德魯伊、武僧、聖騎士的上限——那幾職在原作裡不設限。
> ⚠ 屬性比的是**目前值**（`+11h`／`+13h`，spec 1079 的奇數位移），
> 所以**戴著加屬性的裝備真的能突破亞人上限**。

## ★★★ 三、經驗值需求表

```pascal
需求 := dword[DS:4291h ＋ 職業槽 × 63h ＋ (等級 ＋ 1) × 4];
if (需求 > 角色的經驗值 dword[+127h]) and (DS:7587h = 0) then 跳過這一職;
```

★ 一筆 4 bytes（32-bit），一個職業一列，**列距 `63h` ＝ 99 bytes**。
⚠ 99 不是 4 的倍數 ⇒ 相鄰兩列會錯開一個 byte；本規格照組語記錄，
不宣稱這是刻意的還是原作的瑕疵。
★ `角色^[127h]`／`[129h]` 是 32-bit 經驗值。

★ 免費訓練時另有一條路：**直接把角色的經驗值補到下一級的門檻**
（`角色^[127h] := 需求`）。

## ★★ 四、能不能在這裡訓練

```pascal
可訓練遮罩 := bank1^[550h];                    { DS:4F9Dh^ }
所有職業遮罩 := OR( DS:3EA8h[j] )              { j 為有等級的職業槽 }
可升級遮罩   := OR( DS:3EA8h[j] )              { j 為經驗夠且未到上限的職業槽 }

if (所有職業遮罩 and 可訓練遮罩) = 0 then 印("We don't train that class here")
else if (可升級遮罩 and 可訓練遮罩) = 0 then begin
    DS:7586h := 1;  印('Not Enough Experience');
end;
```

★ `DS:3EA8h` 是**八個職業槽的位元遮罩表**（`DS:3EB9h` 名望等級表在它後面 `11h` bytes）。
★ **`bank1^[550h]` 是「這一間訓練所收哪些職業」**——每個城鎮可以不一樣。

## 五、確認畫面

```pascal
印(角色名 ＋ ' will become:');
for j := 0 to 7 do if 可升級 then
    印('    a level ' 或 'and a level ', Str(等級 ＋ 1), ' ', 職業名[j]);
if 問('Do you wish to train? ') = 'Y' then begin
    印('Congratulations...');
    if (DS:7587h = 0) and (DS:8B6Fh = 0) then 扣錢(角色, 3E8h);   { 1000 gp }
    …升級…
end;
```

★ **職業名稱表在 `DS:0CB6h ＋ 職業槽 × 1Bh`（一筆 27 bytes）**。
★ 第一行用 `'    a level '`（前面四個空白），第二行起用 `'and a level '`
——**兩個字串都是 12 個字元，靠等寬對齊**。

## ★★ 六、實際升級

```pascal
for j := 0 to 7 do if 有等級 then begin
    inc 職業數;
    if 可升級 then begin
        inc 角色^[109h ＋ j];                          { ★ 等級 ＋1 }
        if 角色^[0E7h] > 0 then begin                  { ★ 還有「等級流失」待補 }
            角色^[0E8h] := 角色^[0E8h] − (角色^[0E8h] div 角色^[0E7h]);
            dec 角色^[0E7h];
        end;
    end;
end;
<overlay-25 entry#1>(角色);

{ 施法職業：等級變高就抽新法術 }
if (角色^[10Eh] > 舊值) or (角色^[10Dh] > 8) then
    repeat 槽 := <overlay-19 entry#12>(…, 4, 4) until 槽 > 0;
    角色^[78h ＋ 槽] := 1;

{ 免收費那條路另外給幾個固定旗標 }
case 角色^[10Eh] of
  2: 角色^[87h] := 1;
  3: begin 角色^[9Ah] := 1;  角色^[82h] := 1 end;
  4: 角色^[97h] := 1;
  5: 角色^[0A7h] := 1;
end;

{ HP }
if 角色^[0E5h] > 角色^[0E6h] then begin
    加值 := <near 4A12h>(可升級遮罩, 角色);
    角色^[12Ch] := 角色^[12Ch] ＋ max(加值 div 職業數, 1);
    體質加值 := <near 45E9h>(角色);
    增加 := max((加值 ＋ 體質加值) div 職業數, 1);
    差額 := 角色^[78h] − 角色^[1A4h];                  { 先記住已受傷多少 }
    角色^[78h] := 角色^[78h] ＋ 增加;                  { 最大 HP }
    角色^[1A4h] := 角色^[78h] − 差額;                  { ★ 目前 HP 同步加上去 }
end;
```

> ★★ **多職業的 HP 加值要除以職業數**——與 spec 1055／1079 的
> 「多職平均」是同一條規則，這裡是第三次確認。
> ★★ **升級時目前 HP 跟著最大 HP 一起加**（先算出受傷差額再補回），
> 所以**受傷狀態下訓練不會被治好，也不會白拿**。
> ★ `角色^[0E7h]`／`[0E8h]` 是一組「等級流失」的補償欄位：每升一級還一格。

## 中文化

| DOS | 位址 | 長度 | 建議 |
|---|---|---|---|
| `'we only train conscious people'` | `CS:4C6Ah` | 30 | 「我們只訓練清醒的人。」 |
| `'Training costs 1000 gp.'` | `CS:4C89h` | 23 | 「訓練費用為 1000 gp。」 |
| `"We don't train that class here"` | `CS:4CA1h` | 30 | 「這裡不訓練這個職業。」 |
| `'Not Enough Experience'` | `CS:4CC0h` | 21 | 「經驗值不足」 |
| `' will become:'` | `CS:4CD6h` | 13 | 「 將成為：」（接在角色名後） |
| `'    a level '` | `CS:4CE4h` | 12 | ⚠ 前面四個空白是**對齊用**，要保留同寬 |
| `'and a level '` | `CS:4CF3h` | 12 | 「以及 」——⚠ 與上一行同寬 |
| `'Do you wish to train? '` | `CS:4D00h` | 22 | 「要接受訓練嗎？」（熱鍵 `Y`，見 spec 1060） |
| `'Congratulations...'` | `CS:4D17h` | 18 | 「恭喜⋯⋯」 |

⚠ `'    a level '` 與 `'and a level '` 是**兩個等寬的行首**，
中文化要一起改，而且**改完仍要等寬**，否則多職業角色的清單會參差。
⚠ 職業名稱來自 `DS:0CB6h` 的 27 bytes 一筆的表，**不在本支裡**——
中文化時要一起換，並注意 27 bytes ＝ 全形 13 字的上限。
