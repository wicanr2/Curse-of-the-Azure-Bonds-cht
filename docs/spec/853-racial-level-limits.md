# 853 — 種族的職業等級上限：兩平台**零差異**

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼與**運算元完全相同，實質差異 0 條**）
- 作法見 spec 783

## `overlay-24:03162h` ↔ `overlay-24:0347Eh`（兩平台各 110 條）

這是目前讀過**唯一一支連運算元都一模一樣**的函式——沒有位址差、沒有碼型差。
表示它只碰角色記錄裡位移相同的欄位（`+74h`、`+11h`、`+109h`），完全不碰全域。

`retf 6` ＝ 3 個 word。依宣告順序：`(角色, 職業索引)`。回傳 1 ＝ **已到上限**。

```pascal
結果 := 0;
lv := 有號(角色^[109h + 職業]);
if lv <= 0 then 離開;

case 角色^[74h] of                                   { 種族 }
  1: if (職業 = 2) and ( (lv = 8) and (角色^[11h] =  11h)
                       or (lv = 7) and (角色^[11h] <  11h) ) then 結果 := 1;
  2: if (職業 = 2) and ( (lv = 7)
                       or (lv = 6) and (角色^[11h] =  11h)
                       or (lv = 5) and (角色^[11h] <  11h) ) then 結果 := 1;
  3: if (職業 = 2) and ( (lv = 6)
                       or (lv = 5) and (角色^[11h] <  12h) ) then 結果 := 1;
  4: if (職業 = 0) and (lv = 5) then 結果 := 1
     else if (職業 = 2) and ( (lv = 8)
                            or (lv = 7) and (角色^[11h] =  11h)
                            or (lv = 6) and (角色^[11h] <  11h) ) then 結果 := 1;
  5: if (職業 = 2) and ( (lv = 6)
                       or (lv = 5) and (角色^[11h] =  11h)
                       or (lv = 4) and (角色^[11h] <  11h) ) then 結果 := 1;
end;
```

所有 `角色^[11h]` 的比較都是**無號**。

## 兩個新欄位

| 位移 | 內容 |
|---|---|
| `+74h` | **種族碼**。`0` 沒有任何上限（case 全部不中）；`1`..`5` 各有一組 |
| `+11h` | 一個屬性值，門檻是 `11h`（17）與 `12h`（18） |

`+11h` 的門檻正是 AD&D 用來放寬種族等級上限的**力量 17／18**，而且只在
職業索引 2（Fighter，spec 845／850 的職業順序）上生效——形狀上是力量，
但本規格**不宣稱**（角色記錄的屬性欄位版面還沒有直接證據）。

## 換算成上限

| 種族碼 | 職業 2（Fighter）的上限 | 其他 |
|---|---|---|
| 0 | 無上限 | 無 |
| 1 | `+11h` < 17 → 7；＝ 17 → 8；> 17 → 不受此檢查 | 無 |
| 2 | < 17 → 5；＝ 17 → 6；≥ 17 → 7 | 無 |
| 3 | < 18 → 5；否則 6 | 無 |
| 4 | < 17 → 6；＝ 17 → 7；≥ 17 → 8 | **職業 0（Cleric）上限 5** |
| 5 | < 17 → 4；＝ 17 → 5；≥ 17 → 6 | 無 |

其中兩組能直接對上 AD&D 一版：

- **種族 5 ＝ Halfling**：Fighter 4，力量 17 ＋1、18 ＋2 → 4／5／6，一格不差。
- **種族 4 ＝ Half-elf**：Fighter 6 起跳到 8，且 **Cleric 上限 5**——
  AD&D 的半精靈牧師上限正是 5。

其餘三個種族碼本規格**不指名**（只有 Fighter 一欄可比，不足以區分）。

補一個旁證：`overlay-24:00025h`（武器加值計算）讓**種族 2** 在使用物品類型 `24h`
或 `25h` 時命中 ＋1。AD&D 的精靈正好有「用弓與長劍時 ＋1」的種族加值，而精靈的
Fighter 上限也是 7——兩項都對得上，但物品類型 `24h`／`25h` 是不是弓與長劍還沒查，
所以仍不指名。

⚠ 判定寫的是 `lv ＝ 某值` 而不是 `lv ≥ 某值`。**等級被別的途徑推過上限之後，
這支就不再回報「到頂」**——它偵測的是「正好卡在上限」，不是「超過上限」。

## 明確不宣稱

- 沒有宣稱 `+74h` 的 1..5 各是哪個種族（除了上面兩組有直接對應的）。
- 沒有宣稱 `+11h` 是力量。
- 沒有宣稱除了職業 0 與 2 之外的職業為什麼沒有上限檢查。
