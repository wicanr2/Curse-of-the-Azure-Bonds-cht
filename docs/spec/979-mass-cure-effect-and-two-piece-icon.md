# 979 — 群體解除效果：等級決定人數上限；戰鬥圖示由上下兩塊拼成

- 證據等級：`exact`（兩支逐條讀完）
- 作法見 spec 783

## `pc98 overlay-22:03AE5h`（90 條，`retf 8`）— 群體解除某一種效果

`(訊息字串 arg_0, 陣營 arg_4, 效果編號 arg_6)`。

```pascal
限長(訊息^, 本地, 28h);                            { 40 字 }
DS:0A037h := 1;
額度 := <overlay-24 entry#36>(DS:0A031h);          { 施法者等級，spec 已記 }
for i := 1 to DS:0A520h do begin
    p := 遠指標[0A51Dh ＋ i × 4];
    if (p^[198h] = 陣營) and (額度 > 0) then begin  { 無號 }
        dec(額度);
        if <overlay-23 entry#16>(p, 效果編號) then  { CUREEFFECT }
            遠指標[0A51Dh ＋ i × 4] := NIL;
    end
    else
        遠指標[0A51Dh ＋ i × 4] := NIL;
end;
<本模組 0F62h>(DS:0A031h, 0, 0, 0, 0, @本地);
```

### 三件事

1. **人數上限就是施法者等級。** `overlay-24 entry#36` 是既有規格的「施法者等級」
   （依法術屬性表的類別取不同職業等級）。額度用完之後，剩下的目標
   **不是跳過而是被移出清單**（設 NIL）。
2. **只對指定陣營生效。** `p^[198h]` 是 PC-98 的陣營欄（DOS `+197h`，既有結論）。
   陣營不合的一律移出清單。
3. **`CUREEFFECT` 失敗的留在清單裡。** 只有回傳真才設 NIL——
   身上沒有那個效果的目標會**留在清單中**，與「陣營不合」和「額度用完」
   的處置不同。本規格不宣稱下游怎麼用這份清單。

`DS:0A51Dh` 起是**候選目標的遠指標表，每格 4 bytes**，格數在 `DS:0A520h`。
（`di − 5AE3h` 的位移以無號展開就是 `0A51Dh`。）

### 中文化

訊息字串被 `0A65h:0649h` **硬切到 40 個半形格 ＝ 20 個全形字**，
與 spec 975 的提示字串同一個上限。這一支的訊息由呼叫端給，不是常數。

## `dos overlay-17:03B99h`（101 條，`retf 6`）— 畫一個由上下兩塊拼成的圖示

```pascal
if DS:4FE6h = 0 then
    <0297h:1D8Dh>(arg_4 × 3, arg_2 × 18h, 0Ch, 18h, 3, @DS:25A2h, 遠指標(DS:4FE8h))
else begin
    <0297h:1D8Dh>(arg_4 × 3, arg_2 × 18h, 0Ch, 18h, 0, @DS:25A2h, 遠指標(DS:4FE8h));
    <overlay-33 entry#6>(arg_4,     arg_2, 0, 0, 19h);
    <overlay-33 entry#6>(arg_4 ＋ 3, arg_2, 0, 1, 19h);
end;
<overlay-33 entry#6>(arg_4,     arg_2, 0, 0, 0Ch);
<overlay-33 entry#6>(arg_4 ＋ 3, arg_2, 0, 1, 0Ch);
<0297h:1316h>();
```

參數順序照 spec 977 定案的推疊順序寫（`(座標B, 座標A, 模式, 編號, 組)`，
`組` 是最後一個）。

### ★ 一個圖示 ＝ 兩塊，上下相接

同一個「組」連畫兩次，**編號 `0` 與 `1`、座標 B 相差 3**。
`overlay-33 entry#6` 貼圖時座標各乘 3（既有結論），所以兩塊在螢幕上
相差 9 個單位——**上下相接的兩塊拼成一個完整圖示**。

圖庫表是 `遠指標(DS:65D6h ＋ 組 × 8 ＋ 編號 × 4)`（既有結論），
每組 8 bytes ＝ **每組正好兩個編號**，與這裡「一組畫兩塊」完全吻合。
**「組」是圖示、「編號」是上下半**。

用到的兩個組是 `19h`（25）與 `0Ch`（12）。

### `DS:4FE6h` 又出現一次

`DS:4FE6h = 0` 走一條、非 0 走另一條，兩條的差別是：

| | `DS:4FE6h = 0` | `<> 0` |
|---|---|---|
| `0297h:1D8Dh` 的第 5 個參數 | `3` | `0` |
| 組 `19h` 的那對圖示 | 不畫 | **畫** |

spec 976 讀 `dos overlay-28:000CCh` 時，`DS:4FE6h` 同樣是「走簡化路徑還是
完整路徑」的開關。**兩處都是顯示相關的分支**，本規格不宣稱它代表什麼
（形狀上是某種顯示模式或畫面已就緒旗標）。

### `0297h:1D8Dh` 的形狀

九個 word：`(y × 3, x × 18h, 0Ch, 18h, 模式, @DS:25A2h, 目標畫布)`。
`18h` ＝ 24、`0Ch` ＝ 12 是一組寬高常數，`x` 的步距也是 `18h`——
**格寬 24**。`DS:4FE8h` 是目標畫布的遠指標（`overlay-33 entry#6` 貼圖時
用的是同一個），`DS:25A2h` 是一份資料常數。

## 明確不宣稱

- 沒有宣稱 `本模組 0F62h`（收 6 個參數的收尾呼叫）做什麼。
- 沒有宣稱 `DS:0A037h := 1` 的意義。
- 沒有宣稱 `DS:0A51Dh` 那份清單是誰建的、`NIL` 之後由誰讀。
- 沒有宣稱 `0297h:1D8Dh` 與 `0297h:1316h` 各做什麼，也沒有宣稱
  `DS:25A2h` 的內容。
- 沒有宣稱組 `19h` 與 `0Ch` 各是哪一個圖示。
- 沒有宣稱 `dos overlay-17:03B99h` 沒用到的 `arg_0` 是什麼。
