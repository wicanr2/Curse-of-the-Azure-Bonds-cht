# 996 — PC-98 的結局圖片序列：`CED1.DAX`..`CED9.DAX`

- 證據等級：`exact`（逐條讀完；字串與常數由 overlay 原始 bytes 讀出）
- 作法見 spec 783

## `pc98 overlay-18:00B9Bh`（183 條，`retf 0`）

DOS 側沒有對應函式（單邊）。三個字串常數：
`CS:0B88h` ＝ `'CED'`、`CS:0B8Ch` ＝ `'.DAX'`、`CS:0B91h` ＝ `'CED9.DAX'`，
另有 `CS:0B9Ah` 的**空字串**（長度 0）。

```pascal
<019Eh:06B5h>(0, 0, 27h, 18h);                      { 清整個文字畫面 }

FillChar(0A800h:3E80h, 3E80h, 0);                   { ★ 三個圖形平面各清 16000 bytes }
FillChar(0B000h:3E80h, 3E80h, 0);
FillChar(0B800h:3E80h, 3E80h, 0);

<本模組 1979h>();
t0 := <0418h:133Dh>();                               { 32-bit 計時器 }

for i := 1 to 8 do begin
    repeat
        Str(i, 寬度 0, 數字[2]);
        路徑 := DS:8D40h ＋ 'CED' ＋ 數字 ＋ '.DAX';
    until <0723h:0426h>(路徑) <> 0;                   { ⚠ 載入失敗就無限重試 }

    路徑 := DS:8D40h ＋ 'CED' ＋ 數字 ＋ '.DAX';       { 再組一次 }
    <本模組 1951h>(0);
    repeat until <0418h:133Dh>() − t0 > 3E8h;         { 等 1000 個計時單位 }
    t0 := <0418h:133Dh>();
end;

路徑 := DS:8D40h ＋ 'CED9.DAX';
<本模組 1951h>(1);                                    { ★ 最後一張的旗標是 1 }
<07E3h:02C7h>();
<0418h:12EFh>(0Dh, 0, '');                            { 空提示，形狀上是等按鍵 }
<019Eh:06B5h>(0, 0, 27h, 18h);
<本模組 1985h>();
```

## ★ 九張圖，前八張自動輪播、第九張停住

`CED1.DAX`..`CED8.DAX` 由迴圈組出（`'CED' ＋ Str(i) ＋ '.DAX'`），
每張顯示到計時器走過 `3E8h`（1000）個單位為止；
**`CED9.DAX` 是寫死的字串常數**，而且 `本模組 1951h` 的旗標從 `0` 換成 `1`
——最後一張的處理方式不同（形狀上是「不自動換頁、等玩家按鍵」）。

`0418h:133Dh` 回傳 `dx:ax` 的 32-bit 值，比較時先比 `dx` 再比 `ax`
（`jg` 出去、`jl` 回去、`cmp ax,3E8h; jbe` 回去）——**是有號 32-bit 比較**，
所以計時器溢位時這個迴圈會提早結束一次。本規格不宣稱計時單位是多少秒。

## ★ 三個圖形平面各 `3E80h` bytes

`0A800h`／`0B000h`／`0B800h` 是 PC-98 圖形 VRAM 的三個平面（既有結論：
只用三個平面 ⇒ 8 色）。這裡從**偏移 `3E80h` 起清 `3E80h` bytes**——
`3E80h` ＝ 16000 ＝ 80 bytes × 200 行，正好是**半個平面**。
所以清的是**下半（或第二頁）**，上半保留。

⚠ 這是本專案第一次直接看到「平面的一半」被當成獨立單位處理，
與 spec 975 讀到的 `out 0A6h`（繪圖頁選擇）屬同一個雙緩衝機制。
**本規格不宣稱清的是下半螢幕還是第二頁**——兩者在位址上無法區分。

## ⚠ 載入失敗會無限重試

`repeat … until <0723h:0426h>(路徑) <> 0` **沒有次數上限、沒有取消鍵**。
`0723h:0426h` 與 spec 977 定案的 `0723h:01EDh`（「請放入磁片」開檔器）
同屬 `0723h` 段，形狀上也是「開不了就提示換片」——
所以實務上是靠那一層跟玩家互動，但**這一層本身沒有出口**。

⚠ 路徑字串**組了兩次**（`until` 迴圈裡一次、迴圈外再一次）。
第二次的結果才是實際使用的那一份。這是無害的重複，但 remake 照抄時
不要以為第一次的結果會被沿用。

## 中文化

`'CED'`／`'.DAX'`／`'CED9.DAX'` 是**檔名，不能翻**。
本支沒有任何給玩家看的文字——**結局的文字（如果有）在圖片裡**，
屬於美術素材，要靠重繪處理，不是換字串。

`DS:8D40h` 是路徑前綴（與 spec 975 的 `DS:8BF6h`、spec 977 的
`'EST\'` 子目錄是同一套路徑機制的不同欄位）。

## 明確不宣稱

- 沒有宣稱 `本模組 1951h`／`1979h`／`1985h` 各做什麼
  （`1951h` 的參數 `0`／`1` 是本支唯一的差別）。
- 沒有宣稱 `0418h:133Dh` 的計時單位。
- 沒有宣稱 `0723h:0426h`、`07E3h:02C7h`、`0418h:12EFh` 的行為。
- 沒有宣稱 `DS:8D40h` 與 `DS:8BF6h` 的關係。
- 沒有宣稱 DOS 版的結局用什麼機制（單邊，沒有對應函式）。
