# 832 — 凝視石化與「反射」裝備（物品 `+2Fh`..`+31h` 任一為 `76h`）

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的差異已逐條列出）
- 作法見 spec 783

## `overlay-12:1A65h`（entry#80，DOS 162 條／PC-98 169 條）

| | DOS | PC-98 |
|---|---|---|
| 凝視 | `'gazes...'`（8） | — |
| 反射 | `'reflects it!'`（12） | — |
| 石化 | `'is Stoned'`（9） | — |

`retf 0Ah` ＝ 5 個 word。依宣告順序：`(角色, 參數4, 參數2)`。

```pascal
目標 := 角色^[18Dh]^[0Ah];
DS:6FA3h := 目標;

<far 1554h>(角色, 名字 ＋ 'gazes...', 0Ah, 0);
<far 1566h+2>(12h);
<far 156Ch+1>(取x(角色), 取y(角色), 取x(目標), 取y(目標), 4, 2Dh);
if not <far 1576h+1>(角色, 7Fh, @暫存) then goto 收尾;

換過 := 0;
p := DS:6FA3h^[14Dh];                                  { 目標的物品鏈 }
while (p <> NIL) and (換過 = 0) do begin
    if p^[34h] <> 0 then                               { 裝備中，spec 807 }
        if (p^[2Fh] = 76h) or (p^[30h] = 76h) or (p^[31h] = 76h) then begin
            <far 1554h>(目標, 名字 ＋ 'reflects it!', 0Ch, 0);
            <far 156Ch+1>(取x(目標), 取y(目標), 取x(角色), 取y(角色), 4, 2Dh);
            換過 := 1;
            DS:6FA3h := 角色;                          { 反射回發動者 }
        end;
    p := p^[2Ah];
end;

收尾:
if not <far 1457h+1>(DS:6FA3h, 0, 1) then
    <far 1435h>(DS:6FA3h, 7, 名字 ＋ 'is Stoned');
```

## 物品的 `+2Fh` / `+30h` / `+31h` ＝ 三個屬性槽，值 `76h` 會反射凝視

這是物品節點的新欄位群：**三個相鄰的 byte，任一等於 `76h`（118）就算「會反射」**，
而且**必須是裝備中的**（`+34h` ≠ 0）。

物品節點的版面到此累積（DOS，節點 `3Fh` ＝ 63 bytes）：

| 位移 | 內容 | 出處 |
|---|---|---|
| `+2Ah` | next | 789／794 |
| `+2Eh` | 類型（索引 `DS:5CF6h` 那張表） | 804 |
| `+2Fh` / `+30h` / `+31h` | **三個屬性槽**（`76h` ＝ 反射凝視） | 本支 |
| `+32h` / `+33h` | 兩個數值 | 804 |
| `+34h` | 裝備中 | 807 |
| `+36h` | 被詛咒 | 794 |
| `+39h` | 數量 | 789 |
| `+3Ah` | 定價（word） | 823 |
| `+3Ch` / `+3Dh` / `+3Eh` | 三個效果槽（法術編號 ＋ 最高位旗標） | 803 |

## 反射的實作是「換掉 `DS:6FA3h`」

`DS:6FA3h` 一開始是目標；反射成立時被改寫成**發動者**，收尾的石化判定跟著作用在
發動者身上。**動畫也跟著反向重播一次**（同一支 `156Ch+1`，但起訖對調）。

⚠ 反射迴圈**找到一件就停**（`換過` 旗標同時當迴圈條件），多件反射裝備不會疊加。

## 收尾的石化是「否定式」

`if not <far 1457h+1>(DS:6FA3h, 0, 1) then 石化` ——`1457h+1` 在 spec 829／831 是
「這個效果已經在了嗎」的形狀，這裡回真反而**不**石化。所以那次查詢問的是
「有沒有免疫／已經石化」。

## 中文化：`'is Stoned'` 是共用的字串嗎？

`overlay-13:042FDh` 也有一句 `'is Stoned'`（見 `docs/audit/function-strings.md`）。
兩個 overlay 各自內嵌一份，**是兩個獨立的字串常數**，翻譯要各改各的。

## PC-98 的三處不同

- 兩處多出 `xor ah, ah` ／ `mov cx, 0Ah` ／ `imul cx`（**把某個 byte 乘 10**），
  DOS 沒有。與 spec 819 的 `× 7` 是同一類「DOS 用常數、PC-98 改成算式」的差異。
- 第三個 `76h` 的判斷 DOS 是 `jnz` 直接跳過，PC-98 改成 `jz` ＋ `jmp`，
  **分支結構不同**。

兩處都不是反組譯錯位，**PC-98 這一支要各自判讀**，本規格只把差異標出來。
