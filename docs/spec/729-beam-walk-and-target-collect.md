# 第七百二十九輪：射線走訪與目標收集（`sub_175Bh`）

狀態：`READY`。等級：`exact`。日期：2026-08-14
位置：DOS `overlay-22:175Bh`（`retf 0Ch` ＝ 6 個 word，約 880 bytes）。

`3947h`、`4A8Fh`、`54EBh`、`56C4h`、`5AA8h` 都呼叫它，是範圍／射線類法術的共同
底層。

## 四段

### 一、收集方向序列

```text
<sub_15FBh>(bp, arg_6, arg_8, arg_A, arg_C)
n := 0
while <overlay-31 entry#3>(@區域) <> 0 do
    方向[n] := var_5；n := n + 1
序列長度 := n − 1
```

### 二、沿序列走，用「成本」當射程

```text
arg_2 := arg_2 × 2                       ← 射程先乘 2
成本 := var_6
n := 0
while 成本 < arg_2 且 未中止 do
    if arg_8 ∉ 1..48 或 arg_6 ∉ 1..23 then 中止
    else
        d := 方向[n]
        if d ∈ {0, 2, 4, 6} then 成本 := 成本 + 2      ← 正交
        elif d ∈ {1, 3, 5, 7} then 成本 := 成本 + 3    ← 斜向
        arg_8 := arg_8 + byte [2694h + d]              ← dx
        arg_6 := arg_6 + byte [269Dh + d]              ← dy
        n := (n = 序列長度) ? 0 : n + 1                ← ⚠ 序列會循環重用
```

**正交 2、斜向 3**，而射程參數進來先乘 2——所以射程的單位是「半格」。這正好對上
spec 720／699 那個「原始欄位除以 2」的距離：**整套距離系統都以半格為單位，
斜向算 1.5 格**（2:3）。

地圖邊界是 `x ∈ 1..48`、`y ∈ 1..23`。

`DS:2694h`（dx）與 `DS:269Dh`（dy）是兩張 8 個元素的方向表，相差 9。
**它們在 resident 的資料段，不在 `overlay-22.bin` 裡**——直接去 `.bin` 的
`2694h` 讀會得到毫無關係的位元組。

方向序列走完會**繞回開頭重來**，所以射線可以比序列長。

### 三、蒐集沿途的單位

```text
<sub_163Eh>(bp, @arg_6, @arg_8)
<overlay-31 entry#5>(DS:6E92h, @暫存, @arg_A 區, @arg_8, arg_A, arg_C)
repeat
    if <overlay-31 entry#3>(@區域) <> 0 then
        <overlay-32 entry#9>(@a, @b, …)
        if a > 0 then
            若 a 不在已收集清單裡（線性比對）then 加進清單
until 結束
```

去重是**線性比對整個已收集清單**，沒有雜湊也沒有排序；清單長度沒有上限檢查。

### 四、依模式畫效果，再填目標陣列

```text
if arg_0 > 1 then
    用 [0A10h + i]／[0A18h + i]／[0A20h + i]／[0A28h + i] 四張表算出兩組座標
    <sub_163Eh> 各正規化一次
    <sub_15FBh> ＋ <sub_168Bh>（畫）
    if arg_0 > 2 then 再畫另一組

DS:7434h := 0
for 清單中的每一項 do
    p := far [6D35h + 項目 × 4]
    if p <> DS:6506h then                     ← ⚠ 跳過施法者自己
        DS:7434h := DS:7434h + 1
        [7431h + 位置 × 4] := p
```

**施法者自己會被排除**（`cmp dx, [6506h+2]` ＋ `cmp ax, [6506h]` 兩個 word 都相等
才跳過）。這是 spec 725 那個「有不同類的就取消」之外，另一道自傷保護。

寫入用的索引（`bp−75h`）和讀取用的索引（`bp−74h`）**是兩個不同的計數器**——
跳過施法者時只有讀取的那個前進。所以目標陣列裡不會留空洞。
