# 887 — 驅除疾病：六個疾病效果碼一次清掉，冷卻 7 天

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-19:037ECh`（DOS 145 條）↔ `overlay-19:039CAh`（PC-98 210 條）

`retf 4` ＝ 一個施術者遠指標。

| | DOS | PC-98 |
|---|---|---|
| 選人 | `'Cure whom? '` | `'誰を治療しますか？'` |
| 沒生病 | `'is not diseased'` | `'は病気にかかっていない'` |
| 追問 | `'cure anyway: '` | `'それでも治療しますか？'` |
| 完成 | `' is cured'` | `'は治療を受けた'` |

```pascal
<far 15A9h>();
目標 := 遠指標(DS:650Ah);
暫 := 'Cure whom? ';
<本模組 15B8h>(var 目標, 1);
if 目標 = NIL then begin <本模組 0083h>();  離開 end;

有病 := 0;
for DS:7747h := 1 to 6 do
    if <far 1577h>(目標, byte[827h ＋ DS:7747h], var 值) then 有病 := 1;

答 := 'Y';
if 有病 = 0 then begin
    訊息(目標名 ＋ 'is not diseased');
    答 := <far 16ABh+3>('cure anyway: ', 0Fh, 0Ah, 0Dh);
    <far 1559h>();
end;

if 答 = 'Y' then begin
    DS:6F9Ch := 1;
    for DS:7747h := 1 to 6 do
        <far 143Dh+2>(NIL, byte[827h ＋ DS:7747h], 目標);   { 逐一清掉 }
    DS:6F9Ch := 0;

    if 施術者^[191h] > 0 then dec(施術者^[191h]);            { 無號：用掉一次 }

    if not <far 1577h>(施術者, 8Dh, var 值) then
        <far 1464h+3>(施術者, 8Dh, 2760h, 0, 1);            { 掛冷卻 }

    訊息(目標名 ＋ ' is cured');
end;
<本模組 0083h>();
```

## `2760h` ＝ 10080 ＝ 7 天

時鐘的最小可加單位是分（spec 877：`DS:7566h` 索引 1，每次 ±5）。
`10080 ＝ 7 × 24 × 60`——**整整七天**。

AD&D 一版的聖騎士能力就是「每週可以驅除疾病一次」。
配上 `+191h`（用掉一次就減 1）與這一支跟 spec 870 相鄰的位置，
**`overlay-19` 這兩支是聖騎士的兩個能力**：按手治療與驅除疾病。
spec 870 原本只能說「形狀相符」，這一支把整組坐實。

`8Dh` 是冷卻用的效果碼——先確認身上沒有才掛，所以**掛著就不能再用**。

## `DS:827h`（PC-98 `DS:1363h`）＝ 六個疾病效果碼，**1 起算**

```
1F  22  2B  2C  32  39
```

索引 0 的 `04` 與索引 7 之後不屬於這張表
（DOS 索引 7 是 `0B9h`、PC-98 是 `44h`——**兩平台不同**，
再次確認有效範圍就是 1..6）。

`1Fh` 同時出現在 spec 861 的「戰鬥結束要清掉的 19 個效果碼」與
spec 864 的四個免疫碼裡，三處一致。

## PC-98：一樣的 NPC 名字對照

PC-98 多出來的 65 條就是 spec 870 那段：目標 `+0F7h > 80h` 時，
把 `ALIAS`／`DRAGONBAIT`／`AKABAR BEL AKAS` 換成片假名再組訊息
（字串在 `3961h`／`3967h`／`3972h`／`397Dh`／`398Ch`／`399Ch`）。
**spec 870 說「同一段在隔壁又出現一次」，這就是那一次。**

## 中文化

`'cure anyway: '` 是 Yes／No 追問，回傳值直接跟 `'Y'`（`59h`）比對——
**答案的按鍵是硬寫的 `Y`，不在字串裡**。中文版的提示文字可以翻，
但要保留「按 Y」這件事，或連同 `16ABh+3` 的鍵表一起改。

## 明確不宣稱

- 沒有宣稱 `+191h` 的名稱（形狀上是剩餘使用次數）。
- 沒有宣稱六個疾病效果碼各是什麼病。
- 沒有宣稱 `DS:6F9Ch := 1` 在清效果期間代表什麼。
- 沒有宣稱 `far 1464h+3` 的五個參數（同 spec 870 未定名）。
