# 807 — 丟棄物品前的兩道關卡（裝備中、抄寫中的卷軸）

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-19:0EC5h`（entry#26，101 條，差異 25 條）

| | DOS | PC-98 |
|---|---|---|
| 裝備中 | `'Must be unreadied'`（17） | `'装備をはずしてください'`（22 bytes） |
| 警告上句 | `' was going to scribe from that scroll'`（37，**開頭一個空白**） | `'はその巻物から呪文を書き写そうとしています。'`（44 bytes） |
| 警告下句 | `'is it Okay to lose it? '`（23，**結尾一個空白**） | `'この巻物からの書き写しを中止しますか？'`（38 bytes） |

```pascal
可 := 0;
if 物品^[34h] <> 0 then begin
    顯示('Must be unreadied');
    <far 154Fh>();
end
else if not <far 11DBh+3>(物品) then
    可 := 1
else if (物品^[3Ch] > 7Fh) or (物品^[3Dh] > 7Fh) or (物品^[3Eh] > 7Fh) then begin
    <far 155Eh>(0, 15h, 1, DS:6506h);
    DS:65A0h := DS:6506h^[0] + 2;
    DS:65A1h := 15h;
    <0542h:04A4h>(1, 15h, 26h, 16h, 0Eh, 0, 0,
                  名字 ＋ ' was going to scribe from that scroll');
    if <far 16ABh+3>(0Dh, 0Ah, 0Fh, 'is it Okay to lose it? ') = 'Y' then
        可 := 1;
end
else
    可 := 1;
<far 1ECDh>(16h, 26h, 15h, 1);
結果 := 可;
```

`retf 4` ＝ 一個物品遠指標，回傳 `al`。

### 物品 `+34h` ＝ 裝備中

spec 789 讀到「對半分」時發現複製出來的新節點會把 `+34h` 清成 0，當時只記成
「不繼承」。現在清楚了：**`+34h` ≠ 0 就是裝備中，裝備中的東西不能丟**，所以
分出來的那一半當然要清掉。

### 抄寫中的卷軸會擋一次

第三個條件檢查物品的三個效果槽 `+3Ch` / `+3Dh` / `+3Eh`（PC-98 `+64h`..`+66h`）
有沒有任何一個 `> 7Fh`。照 spec 803 的編碼，最高位為 1 就是**還沒抄完**——於是
跳出警告，答 `'Y'` 才放行。

⚠ 注意門檻是 **`> 7Fh`**（含 `80h`），與 spec 803 抄寫程序用的 **`> 80h`**
（不含 `80h`）差一個值。**值恰好是 `80h`（法術編號 0、最高位為 1）的槽會被這裡
擋下來，卻永遠不會被抄寫程序處理。** remake 兩處都要照抄，不能統一。

### 中文化：兩句要當一整段看

DOS 把警告拆成兩個字串：上句**開頭有一個空白**（前面接角色名），下句**結尾有一
個空白**（後面接輸入游標）。PC-98 兩句都重寫成完整的日文句子，上句以 `は` 接在
名字後、下句改成問句並用全形 `？`。

中文版照 PC-98 的作法即可，但要記得**這是兩個獨立的字串常數**，分別由
`0542h:04A4h`（畫在畫面上）與 `16ABh+3`（帶提問的輸入）使用，位置與呼叫方式不同，
不能合併成一句。

`DS:65A0h := DS:6506h^[0] + 2` ／ `DS:65A1h := 15h` 是在擺放那段警告文字之前
先設定的兩個座標值——`DS:6506h^[0]` 是角色記錄的第 0 個 byte（Pascal 字串的長度
位元組，即**名字長度**），所以第一個值是**跟著名字長度算出來的欄位**。
**中文名字長度改變會直接影響這個版面。**

## 明確不宣稱

- 沒有宣稱 `far 11DBh+3` 判物品的什麼（形狀上是「這件東西要不要多問一次」）。
- 沒有宣稱 `0542h:04A4h` 前七個參數各自的意義。
- 沒有宣稱 `far 155Eh` / `far 1ECDh` 做什麼；只確定兩者的後四個參數
  （`16h, 26h, 15h, 1`）成對出現，形狀上是開窗與關窗。
- 沒有宣稱 `DS:65A0h` / `DS:65A1h` 是欄或列。
