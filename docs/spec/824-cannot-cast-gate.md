# 824 — 施法／記憶／抄寫的共同閘門：三句訊息是拼出來的

- 證據等級：`exact`（兩平台各自逐條讀完；DOS 側匯出有一處錯位，已用原始位元組
  確認）
- 作法見 spec 783；錯位的判定方式見 spec 811

## `overlay-15:0391h`（entry#7，DOS 115 條／PC-98 114 條）

`retf 2` ＝ 一個 word（動作代碼 1／2／3），回傳 `al`（1 ＝ 可以做、0 ＝ 不行）。

```pascal
緩衝 := '';
if (動作 = 1) and (word(DS:4F99h^[1CAh]) > 0) then
    緩衝 := 'cannot cast spells in this area'
else if (DS:6506h^[195h] = 1) or (DS:6506h^[196h] = 0) then begin
    緩衝 := 'is in no condition to ';
    case 動作 of
    1: 緩衝 := 緩衝 ＋ 'cast any spells';
    2: 緩衝 := 緩衝 ＋ 'memorize spells';
    3: 緩衝 := 緩衝 ＋ 'scribe any scrolls';
    end;
end;
if 緩衝 = '' then
    結果 := 1
else begin
    結果 := 0;
    <far 1554h>(DS:6506h, 緩衝, 0Ah, 1);
end;
```

### 三個動作代碼對上紮營選單的三個項目

| 代碼 | 訊息尾巴 | 對應 |
|---|---|---|
| 1 | `'cast any spells'`（15） | `Cast`（spec 816 的 `C`） |
| 2 | `'memorize spells'`（15） | `Memorize`（`M`） |
| 3 | `'scribe any scrolls'`（18） | `Scribe`（`S`） |

**只有代碼 1 會檢查地點**（`DS:4F99h^[1CAh]` ＞ 0 就整區不能施法）；記憶與抄寫
不受地點限制。

### 訊息是兩段拼起來的，而**兩平台拼的方向相反**

| | 共用片段 | 三個變動片段 | 拼法 |
|---|---|---|---|
| DOS | `'is in no condition to '`（22，**結尾一個空白**） | `'cast any spells'`（15）／`'memorize spells'`（15）／`'scribe any scrolls'`（18） | 共用片段**在前** |
| PC-98 | `'状態ではない'`（12 bytes） | `'は呪文を唱えられる'`／`'は魔法を記憶できる'`／`'は魔法を書き写せる'`（各 18 bytes） | 共用片段**在後** |

英文把否定放句首（`is in no condition to …`），日文放句尾（`…られる状態ではない`），
所以 PC-98 版**把串接的順序整個倒過來**：

```
DOS  : 緩衝 := 共用片段;  暫存 := 緩衝;  緩衝 := 暫存 ＋ 動作片段;
PC-98: 緩衝 := 共用片段;  暫存 := 動作片段;  緩衝 := 暫存 ＋ 緩衝;
```

**這不是換字串，是換程式結構。** 中文的語序與日文接近（「…無法施展法術」），
沿用 PC-98 的拼法即可；若要沿用 DOS 的拼法，三個動作片段就得各自改寫。

另一句 `'cannot cast spells in this area'`（31，PC-98 `'ここでは、魔法が使えない'`
24 bytes）是完整的一句，與前面那組**沒有共用片段**。

四個字串都用 `0A54h:064Eh(28h, @緩衝, @常數)` 存進同一個 40 bytes（`28h`）的區域
緩衝——**中文譯文連同前綴不能超過 40 bytes**。

### 「不能做」的條件

`(DS:6506h^[195h] = 1)` 或 `(DS:6506h^[196h] = 0)`。狀態 1 在 spec 821 是
Raise Dead 認的兩個死亡狀態之一；`+196h` ＝ 0 在 spec 784 是「目前 HP 不計入
隊伍血量」的那個條件。**兩者取聯集**。

### DOS 側匯出的一處錯位

`03A9h` 被解成 `retf 1`。原始位元組是

```
C4 3E 99 4F        les di, ds:4F99h
26 83 BD CA 01 00  cmp word ptr es:[di+1CAh], 0
76 16              jbe short loc_3C4
```

PC-98 側解對了。兩平台的助憶碼序列扣掉這一處之後一致。

## 明確不宣稱

- 沒有宣稱 `DS:4F99h^[1CAh]` 由誰設定（形狀上是「這一區禁不禁魔法」）。
- 沒有宣稱 `far 1554h` 做什麼；只確定它收 `(角色, 字串, 0Ah, 1)`，
  是本專案到處出現的「顯示一句話」形狀。
- 沒有宣稱動作代碼 1..3 之外的值會怎樣（`case` 沒有 `else`，緩衝維持只有前綴）。
