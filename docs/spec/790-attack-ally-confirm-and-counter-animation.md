# 790 — 「攻擊友軍」確認會讓一批角色改陣營、計數動畫

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-13:2F3Ch`（entry#20，67 條，差異 16 條）— Attack Ally

| | DOS | PC-98 |
|---|---|---|
| 提問 | `'Attack Ally: '`（13，**結尾一個空白**） | `'味方を攻撃するのですか？'`（24 bytes，全形 `？`） |

```pascal
邊 := <far 1584h+2>(參數2, 參數0);
if (邊 = 目標^[197h]) or (目標^[198h] <> 0) then
    結果 := 1                                  { 正常攻擊，不問 }
else begin
    顯示('Attack Ally: ');
    if <far 16ADh+1>(0Dh, 0Ah, 0Fh) <> 'Y' then
        結果 := 0
    else begin
        結果 := 1;
        DS:758Ch := 1;
        word(DS:4F9Dh^[666h]) := 1;
        p := DS:650Ah;
        while p <> NIL do begin
            if (p^[195h] = 0) and (p^[0F7h] > 7Fh) then begin
                p^[197h] := 1;                 { 改陣營 }
                q := p^[18Dh];
                q^[0Ah] := 0;  q^[0Ch] := 0;   { 清掉目前目標的遠指標 }
            end;
            p := p^[189h];
        end;
        <far 158Ah+1>();
    end;
end;
```

`retf 8` ＝ 4 個 word；回傳 `al`（0／1）。

三件事：

- **提問只在「打的不是該打的那一邊」時出現**：`1584h+2` 算出這次該敵對的陣營，
  與目標的 `+197h` 不符才算打到友軍。`+198h` 不為 0 是另一條豁免。
- 答 `'Y'` 之後，**狀態正常（`+195h` ＝ 0）且士氣旗標為 1（`+0F7h` 最高位，
  spec 758）的角色，陣營一律改成 1**，並把戰鬥狀態 `+18Dh` 的 `+0Ah`／`+0Ch`
  （目前目標的遠指標，spec 782）清成 0——**改邊的同時把手上的目標丟掉**。
- 兩個旗標同時被設起來：`DS:758Ch`（byte）與 `DS:4F9Dh^[666h]`（word）。

`+197h` ＝ 1 這個值就是 spec 784 算隊伍血量百分比時篩的那個陣營。

**中文化**：`'Attack Ally: '` 結尾那個空白是字串常數的一部分（後面接輸入游標）。
PC-98 譯文把它改寫成完整問句並用全形問號，**沒有保留結尾空白**——所以這個
排版不是必須的，中文版可以照 PC-98 的作法寫成一句。

## `overlay-20:03B9h`（entry#2，67 條，**差異 2 條**）— 數字往上跳的動畫

兩平台只差一個全域基底（`DS:4F99h` ↔ `DS:7F05h`）。

```pascal
for i := 0 to 6 do 暫存[i] := word(DS:4F99h^[18Ch + i * 2]);
for k := 1 to 次數 do begin
    inc(暫存[索引]);
    <本模組 02D8h>(@暫存);
end;
for i := 0 to 6 do word(DS:4F99h^[18Ch + i * 2]) := 暫存[i];
<本模組 0020h>(索引, 次數);
```

`retf 4` ＝ 2 個 word：`(索引, 次數)`。

- **先把 7 個 word 抄進區域陣列，動畫跑完再原封不動寫回**，真正的變更由最後的
  `0020h` 負責。所以這一段純粹是視覺效果，中途離開不會留下副作用。
- 遞增是**累加的**（不是每次重設），所以畫面上那個數字是一格一格往上跳到
  `原值 + 次數`。
- `次數` 為 0 時整個迴圈不跑（`1 > 次數` 直接跳過），但 7 個值仍會被抄出再寫回。

### IDA 的位址顯示要換算

原文是 `add ax, 4BC6h` ／ `shl ax, 1` ／ `es:[di+6A00h]`，算出來是
`(i + 4BC6h) * 2 + 6A00h`＝`i * 2 + 1018Ch`，**在 16 位元下迴繞成
`18Ch + i * 2`**。IDA 把常數折進位移顯示成 `+6A00h`，直接照抄會錯。

## 明確不宣稱

- 沒有宣稱 `1584h+2` 怎麼算出那個陣營碼。
- 沒有宣稱 `+198h` 不為 0 是什麼狀態。
- 沒有宣稱 `DS:758Ch` 與 `DS:4F9Dh^[666h]` 由誰讀。
- 沒有宣稱 `DS:4F99h^[18Ch]` 那 7 個 word 是什麼；只確定 `overlay-20:02D8h`
  拿整個陣列去做事、`0020h` 才是真正動它的那一支。
