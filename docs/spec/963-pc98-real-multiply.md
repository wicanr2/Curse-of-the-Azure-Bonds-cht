# 963 — 6-byte real 的乘法，與三支浮點運算共用的收尾

- 證據等級：`exact`（逐條讀完，來源是 `PC98-GAME.EXE.asm`）
- 位置：`PC98-GAME.EXE` 的 `1B0A7h`
- 作法見 spec 783

## `1B0A7h`（146 行）

輸入是兩個 `Real`：`dx:bx:ax`（指數 `al`）與 `di:si:cx`（指數 `cl`）。

```
if (al = 0) or (cl = 0) then 跳 loc_1B1A5（結果為 0）;

符號 := (dx xor di) and 8000h;
指數 := al ＋ cl（16 位元相加，進位收在 dh）;
兩邊補上隱含最高位（or 8000h）;

if 其中一個的低 24 bits 是 0 then
    走「短乘法」：三個 16×16 部分積
else
    走「長乘法」：把六個 word 推上堆疊，做九個 16×16 部分積並逐層進位;

loc_1B178:
    最高位還沒立起來就左移一位並減指數;
    指數 := 指數 − 8081h;                        { ★ 還原偏置 }

loc_1B18A:                                        { ★ 三支共用的收尾 }
    ax := ax ＋ 80h;  adc bx, 0;  adc dx, 0;      { ★ 四捨五入 }
    進位就右移一位並加指數;
    if 指數 的 bit 14 立起來 then 跳 loc_1B1A5;    { 上溢／下溢 → 0 }
    inc(指數);
    套上符號;
    返回;

loc_1B1A5:  ax := 0;  bx := 0;  dx := 0;  返回;
```

## ★ `loc_1B18Ah` 是共用的正規化收尾

spec 948 的除法（`1B1ACh`）結尾寫的是 `jmp loc_1B18A`，
本支的乘法也走到同一個標籤——**兩支共用捨入、溢位檢查與符號套用**。

`add ax, 80h` 是把尾數最低位再往上半個 LSB，也就是**四捨五入**
（Turbo Pascal 的 `Real` 是 40 bits 尾數，`80h` 正好是第 41 位）。

`loc_1B1A5h` 同樣是三支共用的「回傳 0」出口
（spec 948 的除以零也跳這裡）。

## 兩條乘法路徑

低 24 bits 為 0（也就是尾數只有高 16 bits 有值）時走短路徑，
只做三個部分積；否則把六個 word 推上堆疊當索引，做完整的
九個 `16 × 16` 部分積。**短路徑不是近似，是數學上等價的省略**。

## 明確不宣稱

- 沒有宣稱指數偏置 `8081h` 與 spec 948 除法的 `8080h` 為什麼差 1
  （形狀上是乘法多算了一次隱含位）。
- 沒有宣稱 `test ch, 40h` 判溢位的邊界是否涵蓋所有情況。
