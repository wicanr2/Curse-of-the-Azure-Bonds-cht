# 820 — 神殿的四種治療（`Heal` 補到最大值減 1d4，並清掉八個效果碼）

- 證據等級：`exact`（DOS 側逐條讀完，尾端三條由原始位元組手動解碼；PC-98 側的
  差異已逐條列出）
- 作法見 spec 783；錯位的判定方式見 spec 811

## `overlay-04:043Dh`（entry#6，DOS 193 條／PC-98 192 條）

`retf 2` ＝ 一個 word（服務編號 1..4）。

| 編號 | DOS 名稱 | PC-98 | 價 | 效果 |
|---|---|---|---|---|
| 1 | `'Cure Light Wounds'`（17） | `'キュア・ライト・ウーンズ'`（24 bytes） | `64h`（100） | 1d8 |
| 2 | `'Cure Serious Wounds'`（19） | `'キュア・シリアス・ウーンズ'`（26 bytes） | `15Eh`（350） | 2d8 ＋ 1 |
| 3 | `'Cure Critical Wounds'`（20） | `'キュア・クリティカル・ウーンズ'` | `258h`（600） | 3d8 ＋ 3 |
| 4 | `'Heal'`（4） | `'ヒール'` | `1388h`（5000） | 見下 |

```pascal
case 服務 of
1: if 顯示('Cure Light Wounds') 且 <本模組 00F3h>(64h) = 'Y' then
       <0141h:008Eh>(0, <0141h:004Dh>(1, 8), DS:6506h);
2: … <0141h:004Dh>(2, 8) + 1   …  價 15Eh
3: … <0141h:004Dh>(3, 8) + 3   …  價 258h
4: if 顯示('Heal') 且 <本模組 00F3h>(1388h) = 'Y' then begin
       r := <0141h:004Dh>(1, 4);                        { 1d4 }
       n := 角色^[78h] − 角色^[1A4h] − r;               { 最大 HP − 目前 HP − 1d4 }
       <0141h:008Eh>(0, n, DS:6506h);
       <0141h:002Fh>(DS:6506h, 21h, longint 0);         { 失明 }
       for i := 1 to 6 do
           <0141h:002Fh>(DS:6506h, byte[0DDh + i], longint 0);   { 六個疾病碼 }
       <0141h:002Fh>(DS:6506h, 44h, longint 0);
       <0141h:0098h>(DS:6506h, 1);
       <0141h:0098h>(DS:6506h, 2);
   end;
end;
```

### 三個治癒術的骰數與戰鬥中施法相同

spec 815 的 `overlay-15:1EFDh` 算「全隊能治多少」時用的是同樣的 1d8 / 2d8+1 /
3d8+3，法術編號 3 / 3Ah / 47h。**神殿服務與法術效果共用同一組骰數**，但走的是
不同的常式（這裡是 `0141h:008Eh`，那裡是 `145Bh+2`）。

### `Heal` 補到「最大值減 1d4」

`角色^[78h] − 角色^[1A4h] − 1d4` ——先算出缺多少，再扣掉 1d4。與 AD&D 的
`Heal`（治好全部但留 1d4 點）一致。

⚠ **沒有夾制**：缺的量小於骰出來的 1d4 時，`n` 是 byte 相減會**迴繞成很大的值**。
呼叫端沒有擋，`0141h:008Eh` 收到的就是那個值。

### `Heal` 一次清掉八個效果碼

`21h`（失明，spec 785）＋ `DS:0DDh[1..6]` 那六個疾病碼（spec 796）＋ `44h`。
迴圈**不會提早結束**，六個一律照清。

最後連續兩次 `<0141h:0098h>(DS:6506h, 1)` 與 `(DS:6506h, 2)`——DOS 側的匯出把第二
次解成 `add dl, [bx+si-66h]` ／ `cbw` ／ `add [bx+di+1], al`，原始位元組是

```
FF 36 08 65   FF 36 06 65   B0 02   50   9A 98 00 41 01
push ds:6508h push ds:6506h mov al,2 push ax call far 0141h:0098h
```

PC-98 側解對了（`mov al, 2` ／ `push ax` ／ `call far 013Eh:0098h`）。

## 明確不宣稱

- 沒有宣稱 `0141h:008Eh` 是加 HP（形狀上是 `(0, 量, 角色)`）。
- 沒有宣稱 `0141h:0098h` 做什麼，也沒有宣稱參數 `1` 與 `2` 的差別。
- 沒有宣稱效果碼 `44h` 是什麼。
- 沒有宣稱服務編號 1..4 之外的值會怎樣（`case` 沒有 else，直接返回）。
