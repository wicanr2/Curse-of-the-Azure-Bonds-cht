# 890 — 戰鬥中的四格動畫：速度值直接當重複次數

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側差異逐條列出）
- 作法見 spec 783

## `overlay-24:021DDh`（DOS 158 條）↔ `overlay-24:0240Ah`（PC-98 162 條）

`retf 0Ah` ＝ 5 個 word。

```pascal
緩衝 := arg_0^;                                        { 上限 0FFh }

if DS:4FBAh <> 5 then begin                            { 不是模式 5 就只印訊息 }
    <本模組 17D6h>(1, 0Ah, @緩衝, …);
    離開;
end;

<本模組 1AAAh>((arg_4 <> 0) ? 16h : 17h);

if not <far 191Bh+1>(1, …) then
    <far 191Fh+2>(8, 3, <far 192Eh+2>(…), <far 192Bh>(…));

if arg_4 <> 0 then <far 0713h:0020h>(word[25B3h＋1])
else               <far 0713h:0020h>(word[25B1h＋1]);

<本模組 17D6h>(0, 0Ah, @緩衝, …);

次數 := (arg_4 <> 0) ? DS:4FA9h : 0;
k := <far 1938h+2>(…);
x := byte[67C6h ＋ k] * 3;
y := byte[680Eh ＋ k] * 3;

for i := 0 to 次數 do
    for j := 0 to 3 do begin
        <far 3353h+1>(遠指標(DS:4FE8h), 遠指標(DS:75E0h), 5, j, y, x);
        <far 0297h:1316h>();
        <far 09ABh:029Eh>(46h);                        { 延遲 }
        <far 3353h+1>(遠指標(DS:4FE8h), 遠指標(DS:4FECh), 0, 0, y, x);
    end;

<far 0297h:1316h>();
if 次數 = 0 then <far 0542h:0B33h>();
```

## `DS:4FA9h` 的第二個消費端：直接當重複次數

spec 881 讀到動畫播放迴圈用 `每格延遲 × (DS:4FA9h ＋ 3)` 當門檻。
**這裡是完全不同的用法**：外圈跑 `0..DS:4FA9h`，也就是
**整套四格動畫重播 `速度值 ＋ 1` 次**。

- 速度值 0 → 播 1 次（最快）
- 速度值 9 → 播 10 次（最慢）

方向仍然一致（值越大越慢，spec 885 有遊戲自己印的字佐證），
但兩處的實作機制不同——**remake 不能只做一套換算**。

⚠ `arg_4 ＝ 0` 時 `次數` 固定 0（只播一次）且結尾多叫一次
`far 0542h:0B33h`。所以那個參數形狀上是「這是不是玩家看得到的動作」。

## `DS:67C6h` 與 `DS:680Eh` ＝ 戰鬥員的畫面座標

spec 888 讀到這兩個陣列在靜態 dump 裡全是 `0FFh`，是執行期才填的。
本支給出用途：**用戰鬥員索引取出，各乘 3 就是貼圖座標**——
與 spec 880 的「呼叫端給格子座標，貼圖前乘 3」是同一個換算。

## PC-98：多乘一次 `12h`

PC-98 在其中一個座標上多一段 `xor ah, ah / mov cx, 12h / imul cx`（×18），
DOS 兩個座標都只乘 3。形狀上是 PC-98 的字元格尺寸不同所致。
另外迴圈收尾的跳躍結構也不同（多 4 條）。**本規格不宣稱哪一個座標。**

## 明確不宣稱

- 沒有宣稱 `far 3353h+1` 的六個參數（形狀上是「把某一格畫上去」）。
- 沒有宣稱 `far 09ABh:029Eh(46h)` 的單位（形狀上是延遲）。
- 沒有宣稱 `DS:75E0h`／`DS:4FECh` 兩張圖各是什麼（一張畫上去、一張蓋回去）。
- 沒有宣稱 `DS:4FBAh ＝ 5` 是哪一種畫面模式（spec 876 讀到 0/1/2/3/4/6，
  **獨缺 5**——本支正好是 5 的使用者）。
