# 934 — 表面配置（標頭 `17h` bytes）與格線座標的字串輸出

- 證據等級：`exact`（逐條讀完）
- 位置：DOS `START.EXE` 的 `145C9h`、`15772h`
- 作法見 spec 783

## `145C9h`（72 條）：配置一個表面 —— `retf 0Ch`

```pascal
配置表面(@表面, 旗標 arg_4, 張數 arg_6, 寬 arg_8, 高 arg_A);

每張位元組 := 高 × 寬 × 2;
if byte_211A6h <> 0 then 每張位元組 := 每張位元組 × 2;
總量 := 張數 × 每張位元組;

GetMem(@表面, 總量 ＋ 17h);
FillChar(表面^, 總量 ＋ 17h, 0);

表面^[0]   := 高;
表面^[2]   := 寬;
表面^[8]   := 張數;
表面^[11h] := 每張位元組;

if odd(旗標) then begin
    GetMem(@表面^[13h], 總量);          { 遮罩緩衝 }
    FillChar(表面^[13h]^, 總量, 0);
end;
```

### 表面記錄的標頭是 `17h` ＝ 23 bytes

| 位移 | 內容 |
|---|---|
| `+0`（word） | 高 |
| `+2`（word） | 寬（＝ spec 933 用來算列位移的那一格） |
| `+8` | 張數 |
| `+11h`（word） | 每一張的位元組數 |
| **`+13h`（dword）** | **遮罩緩衝的遠指標**（`odd(旗標)` 才配置） |

像素資料緊接在 `+17h` 之後——spec 931 的內迴圈寫 `es:[di+17h]`，
正是**跳過標頭寫第一個像素**。

### ★ 這關掉 spec 933 的一個推論

spec 933 把 `+13h` 與 `+15h` 當成兩個獨立欄位。
本支的 `GetMem(@表面^[13h], 總量)` 直接證明**那是一個遠指標**
（`+13h` 是位移、`+15h` 是段）。所以 spec 933 那兩支
「讀 `+13h`／`+15h`」的函式，讀的是**遮罩緩衝的位址**，
而不是兩個遮罩常數——`sub_15388h` 的 `and`／`or` 兩個來源
一個來自主資料、一個來自那塊遮罩。

**旗標的 bit 0 ＝ 這張表面帶不帶遮罩**，直接決定它能不能走
`sub_15388h` 那條路。

### ★ `byte_211A6h` 是顯示模式旗標

spec 932 記到它 ＝ 0 時顏色要過 `DS:256Dh` 的轉換表；
本支則是它 **≠ 0 時每列位元組加倍**。
兩處合起來：`byte_211A6h` 區分**兩種顯示模式**，
一種每像素位元組數是另一種的兩倍、而且不需要顏色轉換。

## `15772h`（53 條）：格線座標的字串輸出 —— `retf 0Ch`

```pascal
畫字串(字串 arg_0, arg_4, arg_6, 列 arg_8, 欄 arg_A);

s := 限長(字串, 0FFh);
if (arg_A > 27h) or (arg_8 > 27h) then 離開;        { ★ 無號 }
for i := 1 to length(s) do begin
    <sub_15606h>(1, s[i], 1, arg_4, arg_6, arg_8, arg_A);
    inc(arg_A);
end;
```

`27h` ＝ 39，**兩個座標的上界都是 39**——這一層走的是
**40 × 40 的格線座標系**，不是 spec 932 那個 80×25 的文字座標系。

⚠ 邊界檢查只在**進入時做一次**：字串長到讓 `arg_A` 超過 39 時，
迴圈不會停，後面的字元照畫。

## 三套並存的輸出層

到這裡常駐裡的文字輸出已經有三條互不相干的路：

| 出處 | 座標系 | 底層 |
|---|---|---|
| spec 930／931 | 80×25 文字 | 直接寫 `0B800h`／`0B000h`，累積後 `rep movsw` |
| spec 932 | 80×25 文字 | `int 10h` AH=02h/09h，一次一個字元 |
| **本支** | **40×40 格線** | `sub_15606h`（圖形） |

## 明確不宣稱

- 沒有宣稱表面記錄 `+4`、`+6`、`+9`..`+10h` 那幾格是什麼（本支填 0 之後沒再寫）。
- 沒有宣稱旗標 bit 0 以外的位元。
- 沒有宣稱 `<sub_15606h>` 的七個參數各是什麼（只知道第二個是字元、
  最後兩個是列與欄）。
- 沒有宣稱 `byte_211A6h` 對應哪兩種實際顯示卡。
