# 889 — 力量增強：依職業擲不同骰，超過 18 轉成百分比力量

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側助憶碼完全相同，9 條差異全是位址）
- 作法見 spec 783

## `overlay-22:02BF9h` ↔ `overlay-22:02EB2h`（兩平台各 148 條）

`retf` ＝ 無參數。對象是 `遠指標(DS:7435h)`。

```pascal
加成 := 0;
p := 遠指標(DS:7435h);

if (有號(p^[10Eh]) > 0) or (p^[116h] > p^[0E6h]) then r := <far 145Dh>(4, 1);
if (有號(p^[109h]) > 0) or (p^[111h] > p^[0E6h])
   or (有號(p^[10Fh]) > 0) or (p^[117h] > p^[0E6h]) then r := <far 145Dh>(6, 1);
if (有號(p^[10Bh]) > 0) or (p^[113h] > p^[0E6h]) then r := <far 145Dh>(8, 1);

n := r ＋ p^[11h];                                    { 力量 }

if n > 12h then begin                                 { 無號，12h ＝ 18 }
    if （盜賊／法師／某三個職業槽都沒有等級）then
        n := 12h
    else begin
        加成 := (n − 12h) * 0Ah ＋ p^[1Ch];
        if 加成 > 64h then 加成 := 64h;               { 100 }
        n := 12h;
    end;
end;

if <far 148Eh+1>(var 暫, 加成, n, p) then begin
    暫 := r ＋ 64h;
    <far 1466h+1>(1, 暫, <本模組 0E11h>(DS:6F97h, 26h, p));
    <far 14A4h+4>(0, p);
end;
```

## 骰數依職業，逐項對上 AD&D 一版的 Strength

`+109h ＋ c` 是八個職業槽的等級（spec 850／869／884）：

| 條件用的欄位 | 職業槽 `c` | 職業 | 骰 | AD&D 一版 |
|---|---|---|---|---|
| `+10Eh` | 5 | Magic-User | **1d4** | 1d4 |
| `+109h` | 0 | Cleric | **1d6** | 1d6 |
| `+10Fh` | 6 | Thief | **1d6** | 1d6 |
| `+10Bh` | 2 | Fighter | **1d8** | 1d8 |

三個 `if` 依序覆寫，所以**多職業角色拿到最後一個成立的骰**——
戰士那一條排最後，所以戰士／法師雙職業擲 1d8。

每個條件都有第二個分支 `p^[111h ＋ c] > p^[0E6h]`，
形狀上是「這個職業槽雖然沒有現役等級，但曾經有」。本規格不定名。

## 超過 18 就轉成百分比力量 `+1Ch`

`(n − 18) × 10 ＋ p^[1Ch]`，上限 `64h` ＝ 100，然後把力量壓回 18。
**這就是 AD&D 一版的 18/01 ～ 18/00 百分比力量**：
超過 18 的每一點折成 10 個百分點。

`+1Ch` 因此定名為**百分比力量**——位置也對得上：
spec 884 讀到六個屬性佔 `+10h..+1Bh`（每項 2 bytes），
`+1Ch` 就在六個屬性的正後方。

⚠ 百分比是**累加**在原有的 `p^[1Ch]` 上，不是取代。所以對已經是
18/50 的戰士再施一次，會從 50 往上加。上限夾在 100（＝ 18/00）。

## PC-98：9 條差異全是位址

`DS:7435h`↔`0A521h`、`DS:6F97h`↔`0A031h`，其餘是呼叫目標。
**助憶碼序列完全相同**，兩平台共用同一份判讀。

  （形狀上是「把新力量寫回去並回報成不成功」）。
