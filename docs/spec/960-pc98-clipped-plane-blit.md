# 960 — PC-98 帶裁切的三平面貼圖：旗標字選三條路

- 證據等級：`exact`（逐條讀完，來源是 `PC98-GAME.EXE.asm`）
- 位置：`PC98-GAME.EXE` 的 `13F71h`
- 作法見 spec 783

## `13F71h`（157 行，`retn 14h`）

`(目的表面 arg_0, 來源表面 arg_4, 旗標 arg_8, 張號 arg_A,
上下 arg_C, 左右 arg_E, @結果 arg_10)`。

`arg_C`／`arg_E` 是**有號座標**（`cmp ax, 8000h; ja` 判負），
與 DOS 的 spec 940 同一種寫法。

```pascal
{ ── 上下（一「列」＝ 8 掃描線）── }
y := 上下 shl 3;
if y < 0 then begin
    高      := 來源^[0] − (−y);
    來源起  := (−y) × 來源^[2];
    目的起  := 0;
end else begin
    來源起  := 0;
    目的起  := y × 目的^[2];
    剩      := 目的^[0] − 來源^[0] − y;
    if 剩 < 0 then 高 := 來源^[0] ＋ 剩 else 高 := 來源^[0];
end;

{ ── 左右 ── }
if 左右 < 0 then begin
    左裁 := −左右;
    寬   := 目的^[2] − 來源^[2] ＋ 左裁;
    目的起 := 目的起 ＋ 左裁;
end else begin
    來源起 := 來源起 ＋ 左右;
    if 目的^[2] >= 左右 ＋ 來源^[2] then begin
        左裁 := 0;   寬 := 目的^[2] − 來源^[2];
    end else begin
        左裁 := 左右 ＋ 來源^[2] − 目的^[2];
        寬   := 左右 − 來源^[2];
    end;
end;

{ ── 完全在畫面外就直接返回 ── }
if (高 < 0) or (來源^[2] < 左裁) then 離開;      { 無號比較 }

每平面來源 := 來源^[0] × 來源^[2];
遮罩       := 來源^[13h];                        { spec 934 的遮罩緩衝 }
來源起 := 來源起 ＋ 來源^[11h] × 張號;
遮罩起 := 遮罩起 ＋ 每平面來源 × 張號;           { ★ 遮罩每張只佔 高 × 寬 }
每平面目的 := 目的^[2] × 目的^[0];

結果^[0] := 高;
結果^[2] := 來源^[2] − 左裁;                     { 實際搬了多寬 }

{ ── 旗標字選內迴圈 ── }
if 旗標 and 1 = 0 then
    <sub_14131h>()                               { 無遮罩 }
else begin
    if 旗標 and 4 <> 0 then <sub_1408Bh>();      { 額外的一段 }
    <sub_140C7h>();                              { 有遮罩 }
end;
```

## 與 DOS 的 spec 940 逐點對應

| | DOS（spec 940） | PC-98（本支） |
|---|---|---|
| 有號座標判負 | `cmp ax, 8000h` ＋ `ja` | 同 |
| 上下的單位 | `shl 3`（8 掃描線） | 同 |
| **旗標 bit 0** | 0 → `sub_15329h`（無遮罩）／1 → `sub_15388h`（有遮罩） | 0 → `<sub_14131h>`／1 → `<sub_140C7h>` |
| **旗標 bit 2** | 設 `var_1A := 1` | **多呼叫一支 `<sub_1408Bh>`** |
| 回報實際尺寸 | 沒有 | **有**（`arg_10^[0]` 高、`arg_10^[2]` 寬） |

★ **PC-98 版多一個 `@結果` 參數**，把裁切後實際搬了多大回報給呼叫端；
DOS 版沒有這個。

★ 旗標 bit 2 在 DOS 只是設一個變數給內迴圈看，在 PC-98 **變成另外呼叫一支**
——同一個位元，兩平台的實作方式不同。

遮罩的位移用 `來源^[0] × 來源^[2] × 張號`，與 spec 956 的
`13EACh` 一致：**一張遮罩三個平面共用，每張只佔 `高 × 寬`**。
