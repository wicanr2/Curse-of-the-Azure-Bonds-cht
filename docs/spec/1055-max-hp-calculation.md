# 1055 — HP 上限計算：八個職業的生命骰、名望等級之後改固定加值、多職業取平均

- 證據等級：`exact`（DOS 側 242 條逐條讀完）
- 作法見 spec 783

## `dos overlay-17:047C6h`（`retf 4`）

原本待解讀。參數是一個遠指標（角色）。

```pascal
職業數 := 0;  總和 := 0;
for j := 0 to 7 do begin
    等級 := 角色^[109h ＋ j];
    if 等級 <= 0 then continue;                    { 這個職業槽沒等級 }
    加值 := <sub_2515h>(j);                        { 形狀上是體質加值 }
    上限 := byte[3EB9h ＋ j];
    inc(職業數);
    if 等級 < 上限 then …生命骰那一段…
                  else …固定加值那一段…;
end;
結果 := 總和 div 職業數;                            { ★★★ 多職業取平均 }
```

★ `+109h ＋ j`（八個職業槽的等級）與 **職業順序**都與 spec 1034 相同：
**牧師／德魯伊／戰士／聖騎士／遊俠／法師／盜賊／武僧**
——這是第二次獨立確認。

## ★★★ 生命骰（等級 < 上限）

`總和 := 總和 ＋ (加值 ＋ 骰面) × 等級`

| j | 職業 | 骰面 | 特例 | ＝ 1e |
|---|---|---|---|---|
| 0 | 牧師 | **8** | | d8 ✓ |
| 1 | 德魯伊 | **8** | | d8 ✓ |
| 2 | 戰士 | **10** | | d10 ✓ |
| 3 | 聖騎士 | **10** | | d10 ✓ |
| 4 | 遊俠 | **8** | **等級 ＋ 1** | **1 級就有 2d8** ✓ |
| 5 | 法師 | **4** | | d4 ✓ |
| 6 | 盜賊 | **6** | | d6 ✓ |
| 7 | 武僧 | **4** | **等級 ＋ 1** | **1 級就有 2d4** ✓ |

> ★★★ **八個職業的生命骰全部符合 AD&D 1e**，
> 而且**遊俠與武僧「1 級多一顆骰」是用「等級 ＋ 1」實作的**——
> 兩個 1e 的特例在這裡各佔一個分支。
> ★ 每級都取**骰子最大值**（8／10／4／6）再加 `sub_2515h(j)`
> ⇒ 這算的是 **HP 上限**，不是擲出來的值。

## ★★★ 名望等級之後（等級 ≥ 上限）

`超出 := 等級 − 上限 ＋ 1`

| j | 職業 | 上限 | 公式 | ＝ 1e |
|---|---|---|---|---|
| 0 | 牧師 | **10** | `超出 × 2 ＋ 72` | 9d8 ＝ 72，之後 ＋2／級 ✓ |
| 1 | 德魯伊 | **15** | **固定 112** | 14d8 ＝ 112，之後不再成長 ✓ |
| 2 | 戰士 | **10** | `超出 × 3 ＋ 90` | 9d10 ＝ 90，之後 ＋3／級 ✓ |
| 3 | 聖騎士 | **10** | `超出 × 3 ＋ 90` | 同戰士 ✓ |
| 4 | 遊俠 | **11** | `超出 × 2 ＋ 88` | 11d8 ＝ 88，之後 ＋2／級 ✓ |
| 5 | 法師 | **12** | `超出 × 1 ＋ 44` | 11d4 ＝ 44，之後 ＋1／級 ✓ |
| 6 | 盜賊 | **11** | `超出 × 2 ＋ 60` | 10d6 ＝ 60，之後 ＋2／級 ✓ |
| 7 | 武僧 | **19** | **固定 72** | 18d4 ＝ 72，之後不再成長 ✓ |

上限表在 **`DS:3EB9h`**：`10 15 10 10 11 12 11 19`。

> ★★★★ **八個職業的「名望等級」與之後的固定加值，一格不差地等於
> AD&D 1e，包括德魯伊與武僧「到頂就不再長」這兩個特例。**
>
> ★★★ **這一段完全不加 `sub_2515h(j)`（體質加值）**
> ——正是 1e 的規則：**名望等級之後體質加值不再套用**。

## ★★★ 多職業取平均

```pascal
結果 := 總和 div 職業數;
```

⇒ **多職業角色的 HP 是各職業 HP 的平均**（整數除法，餘數丟掉）
——1e 的多職業規則。
