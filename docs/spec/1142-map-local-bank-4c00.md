# 1142 — `4C00` 一段是 map-local bank，remake 目前是全域的

- 證據等級：`exact`（守衛條件逐位元組讀出）＋ `measured`（實機值量到）
- 作法見 spec 783

## 症狀：走到了卻沒有反應的五間房

密斯卓諾內城逐間走過之後，**九間出得來、五間安靜**：

| 房間 | 格子 | 地形 | 守衛 | 走到時的值 |
|---|---|---|---|---|
| 廚房 | `(13,14)` | `0x8C` | `COMPARE AND 4C06,0 4C07,0` | `4C06=0x0A`／`4C07=0x80` |
| 冥想中的祭司 | `(14,11)` | `0x8E` | 同上 | 同上 |
| 禮拜中的祭司 | `(14,8)` | `0x8F` | 同上 | 同上 |
| 停屍架與棺木 | `(10,1)` | `0x93` | `COMPARE AND 4C0F,0 4C0E,0` | `4C0F=0x07`／`4C0E=0x6A` |
| 食品儲藏室 | `(14,4)` | `0x91` | `COMPARE 4C0B,1 → EXIT` | `4C0B=1` |

不是走錯格：位置與地形碼都對（地形碼就是 `ON GOTO (C04F & 0x7F)` 的索引）。
**這條 session 根本沒進過那五間房**，旗標卻已經是「進過」的值。

## 原因：守衛看的是別張地圖留下的值

廚房那一支（`ECL6/0x43` 位移 `0x0DDD`）：

```
COMPARE AND  4C06, 0, 4C07, 0
IF <>        → EXIT            { 兩個都得是 0 才演 }
SAVE 1 → 4C06                  { once-only 標記 }
PRINTCLEAR "YOU HAVE COME INTO THE KITCHEN. ..."
```

走到那裡時量到的是 **`4C06 = 0x0A`、`4C07 = 0x80`**——兩個都不是 0，所以直接
`EXIT`。這兩個值是**前面幾張地圖**寫的：`4C07 = 0x80` 是眼魔洞穴那一段
（`ECL4/0x22`）留下的，campaign 測試本來就斷言過它。

## ★ 這一段記憶體在原作是 map-local

`4C00` 起的這一段在原作是**跟著地圖走的 bank**，換地圖時整批換掉；
remake 目前只有一份全域的，於是別張地圖的值會漏進來。

先前 `4C03` 已經踩過同一件事：眼魔洞穴的交接用 game pack 的不透明
`set_memory` 把它歸零，當時記成 `strong inference` 的「map-local bank 重建」。
本則是**第二個獨立案例**，而且症狀不是崩潰或錯字，是**三間房安靜地不演**——
沒有測試釘住的話，看起來就像那三間房本來就沒有內容。

## 目前的處置

`TestRealNewGameRunsToTheEnding` 把內城一樓九間、二樓五間逐間走過，
壓不住的五間標成 `suppressed`：**現在出不來是預期的，哪天出得來測試會紅**，
提醒把清單更新。同一段另外釘住三個成因（`4C07 != 0`、`4C0B == 1`、`4C0F != 0`），
成因消失時也要重驗。

## 明確不宣稱

- 沒有宣稱 bank 是在哪個時機換的（`NEWECL`？`LOAD FILES`？載地圖時？）。
  只宣稱「同一份全域記憶體跨地圖沿用」會讓這三間房被壓掉。
- 沒有宣稱 `4C06`／`4C07` 在原作各代表什麼；只宣稱這一支的守衛要它們都是 0。
- 沒有宣稱其餘九間房不受影響——只確認它們這一次出得來。
- 沒有宣稱那些旗標是被哪一張地圖寫成現在的值；只確認寫的不是內城。
