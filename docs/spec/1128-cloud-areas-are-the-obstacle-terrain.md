# 1128 — 兩種雲就是那兩種障礙格，而且是第四種演出通道

- 證據等級：`exact`（兩支雲霧 handler 逐條讀完：`ov22@2799h` 惡臭之雲、
  `ov22@4F3Eh` 致命毒雲；`ADDEFFECT` ＝ `ov23 entry#11 @13EEh`）
- 對應工作項：`ENG-09` 的法術演出確認
- 上游 spec 1119（兩種障礙格）、spec 1126（演出通道）、spec 1125（解除魔法的後半）

## 兩支雲霧 handler 除了兩個常數以外一模一樣

呼叫序列逐條對過，完全相同。差別只有兩個立即數：

| | 惡臭之雲（34）| 致命毒雲（91）|
|---|---|---|
| 掛的效果碼 | `28h`（`ov22@2854h`）| `5Bh`（`ov22@4FF9h`）|
| **寫進地圖格的地形碼** | **`1Eh`**（`ov22@2B21h`）| **`1Ch`**（`ov22@53FDh`／`5464h`）|
| 物件清單頭 | `DS:755Bh` | `DS:755Fh` |

`ov23 entry#11` 是 `ADDEFFECT`：配 9 bytes 的 `EFFECTREC`、串到目標的 `+0F2h`、
把效果碼寫 `+0`、持續時間寫 `+1..+2`。地形碼則是另外直接寫進地圖格的 `+7`。

## ★★ 這解掉了 spec 1119 缺的那一半

spec 1119 讀完了「地形碼 `1Eh` 豁免過得了就走、`1Ch` 等級 `≥ 7` 就走」，
但**沒有找到是誰把那兩個碼寫上去的**。答案就是這兩支法術：

| 地形碼 | 誰寫的 | 走過去的條件（spec 1119）|
|---|---|---|
| `1Eh` | **惡臭之雲** | 豁免過關（或身上有那六個效果之一）|
| `1Ch` | **致命毒雲** | `有號(+0E5h) ≥ 7`（或那四個效果之一）|

兩張豁免／等級規則就此有了意義：**低階角色繞開毒雲、七級以上的老手硬闖**，
而惡臭之雲是靠體質（豁免）硬撐。spec 1125 讀到的「解除魔法後半段處理地形
`1Ch`／`1Eh` 上的物件」也因此有了對象——那一段就是**把雲吹散**。

## 演出：這是第四種通道

spec 1126 量到的三個圖組槽是 `<overlay-24 entry#24>` 那條路的全部。雲不走那條路：

| 通道 | 形狀 | 例子 |
|---|---|---|
| 四格動畫（`entry#24`）| 一次播完就結束 | 共用施法投射物、閃電電弧、魔法命中 |
| **持續區域格** | **寫進地圖格，效果活著就一直畫** | **惡臭之雲、致命毒雲** |
| 產生器 | 由參數合成，沒有 COMSPR 區塊 | 睡眠的 twinkle（`pc98.twinkle`）|
| 八方向投射物 | 依方向選格 | 弓箭（`overlay-13` 的 11 個直接 blit 點）|

所以「法術有沒有演出」這個問題的答案不是一張表就講得完——**要先問它走哪一種
通道**。只數 `entry#24` 的呼叫點會把雲與睡眠算成沒有演出。

## remake 這一側

- `PersistentAreaKind.ObstacleTerrainCode()`：惡臭之雲 → `1Eh`、致命毒雲 → `1Ch`。
- `Battle.PersistentAreaTerrainCode(x, y)`：戰鬥中鋪出來的雲當作地形碼來源。
- `obstacleBlocks` 在沒有外部地形碼來源時退回上面那一支。★ 先前
  `ObstacleTerrainBlocks` 規則完整，但**地形碼查詢從來沒有人掛上**，所以那段
  規則實際上一次都沒跑過——雲就是那個缺掉的生產者。
- ⚠ 退回路徑一律回報 `onMap = true`：它不知道地圖邊界，而呼叫端把
  `onMap = false` 當成「擋住」，謊報出界會讓所有移動全部卡死。

## 明確不宣稱

- 沒有宣稱雲格用哪一個 COMSPR 區塊。game pack 目前記的是惡臭之雲區塊 4、
  致命毒雲區塊 2，那來自更早一輪的影片比對，本輪**沒有從位元組重新驗**。
- 沒有宣稱兩種雲疊在同一格時原作怎麼取捨。原作把地形碼直接寫進地圖格
  （後寫的蓋掉先寫的），但兩份物件清單是分開的；remake 照建立順序回答。
- 沒有宣稱效果碼 `28h`／`5Bh` 的 handler 各自做什麼；本規格只用到「哪一支法術
  掛哪一個碼」。
- 沒有宣稱雲的格子形狀與擴散規則與原作逐格相同——那是 `CastStinkingCloud`／
  `CastCloudkill` 既有的實作，本輪沒有重新量。
