# 1028 — 角色檢視選單：七個選項全部按狀態動態接上

- 證據等級：`exact`（DOS 側 303 條、PC-98 側 281 條，兩邊各自逐條讀完）
- 作法見 spec 783

## `dos overlay-19:00B75h` ↔ `pc98 overlay-19:00B82h`（＝ `entry#5`）

兩側原本都是待解讀。這是 spec 1015 的 **`V`（View）鍵**、
以及 spec 1022 地城主選單 `V` 鍵叫的那一支。

```pascal
if DS:4FBAh = 5 then <overlay-32 entry#5>();      { 畫面模式 5 要先做一件事 }
鍵 := ' ';
DS:4AF8h := 遠指標(DS:6506h);                      { 現在在看誰 }
repeat
    <sub_83>();                                    { 畫角色卡 }
    …依狀態把選項一個一個接起來…
until 鍵 in [#0, 'E'];
```

離開條件的集合常數是 `[#0, 'E']`（`CS:0B08h`，`@Set@MemberOf`）。

## ★★ 七個選項與它們的出現條件

| 選項 | 長度 | 出現條件 |
|---|---|---|
| `'Items '` | 6 | `角色^[14Dh]`（物品鏈頭）非 NIL |
| `'Spells '` | 7 | **`角色^[1Eh ＋ i]`（i ＝ 0..53h）有任何一格非 0** |
| `'Trade '` | 6 | 有錢，且 `DS:4FBAh <> 5`，且 `+0F7h ≥ 80h` 或 `+196h = 0` 或 `+195h <> 1` |
| `'Drop '` | 5 | 有錢 |
| `'Heal '` | 5 | `<sub_35F1>()` 成立 |
| `'Cure '` | 5 | `<sub_3656>()` 成立 |
| `'Exit'` | 4 | 一律 |

★★★ **`'Spells '` 的條件掃的正是 `+1Eh` 起的 84 格記憶法術清單**
——與 spec 1016（重算施法能力時掃 `for i := 0 to 53h`）
與 spec 1021（轉職時 `FillChar(角色^[1Eh], 54h, 0)`）**第三次對上**。

★ 「有錢」是掃 `word(角色^[0FBh ＋ i × 2])`，`i ＝ 0..6`
——**七種貨幣**，與 spec 1000 的「錢也算重量」同一組欄位。

★ **熱鍵一樣是大寫字母**：**I**tems、**S**pells、**T**rade、**D**rop、
**H**eal、**C**ure、**E**xit。

## ★★★ PC-98：七個選項、七個熱鍵槽

PC-98 把七個選項換成**各 6 bytes ＝ 3 個全形字**，並寫進熱鍵表：

| 選項 | PC-98 | 熱鍵槽 |
|---|---|---|
| Items | 「 ｱｲﾃﾑ 」 | `DS:0A335h`（i ＝ 1） |
| Spells | 「 魔法 」 | `DS:0A336h`（i ＝ 2） |
| Trade | 「 渡す 」 | `DS:0A337h`（i ＝ 3） |
| Drop | 「捨てる」 | `DS:0A338h`（i ＝ 4） |
| Heal | 「 回復 」 | `DS:0A33Bh`（i ＝ 7） |
| Cure | 「 治療 」 | `DS:0A33Ch`（i ＝ 8） |
| Exit | 「抜ける」 | `DS:0A33Eh`（i ＝ 10） |

★ **熱鍵表是 `DS:0A334h ＋ i`（i ＝ 0..10，共 11 bytes，到 `0A33Eh` 為止），
選項文字是 `DS:0A338h ＋ i × 7`（i ＝ 1..10，從 `0A33Fh` 開始）**——
兩者**不重疊**，spec 755／1012／1013／1022／1023 的版面在這裡再確認一次。

⚠ 中文各選項也只有 **3 個字**：物品／法術／交易／丟棄／治癒／解毒／離開。

## 明確不宣稱

- 沒有宣稱 `sub_83`（畫角色卡）、`sub_35F1`／`sub_3656`（Heal／Cure 的條件）做什麼。
- 沒有宣稱 `DS:4AF4h`／`DS:4AF8h` 這兩個全域的完整用途
  （`4AF8h` 存的是目前在看的角色）。
- 沒有宣稱 `'Trade '` 那三個條件（`+0F7h`／`+196h`／`+195h`）的語意。
- 沒有宣稱 `DS:4FBAh = 5`（畫面模式 5）時 `overlay-32 entry#5` 做什麼。
