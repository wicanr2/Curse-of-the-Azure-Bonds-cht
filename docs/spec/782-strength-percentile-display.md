# 782 — 力量百分位的顯示（`18(00)` 那一格）

- 證據等級：`exact`（以補洞後的匯出逐條讀完，見 spec 761）

## `overlay-19:09B3h`（DOS）

`retf 4`。四條字串常數把它定死：

| 位址 | 長度 | 內容 |
|---|---|---|
| `CS:09AAh` | 1 | `0` |
| `CS:09ACh` | 2 | `00` |
| `CS:09AFh` | 1 | `(` |
| `CS:09B1h` | 1 | `)` |

```pascal
if 參數0 <> 0 then 顏色 := 0Dh else 顏色 := 0Ah;
欄 := 5;
<開窗>(索引 + 7, 0Bh, 索引 + 7, 5);
值 := DS:6506h^[11h + 索引 * 2];
if 值 < 0Ah then inc(欄);                      { 無號：個位數往右挪一格 }
繪字(欄, 索引 + 7, 顏色, 0, 數值轉字串(值));

if (索引 = 0) and (DS:6506h^[11h] = 12h) and (DS:6506h^[1Ch] > 0) then begin
    s := 數值轉字串(DS:6506h^[1Ch]);
    if DS:6506h^[1Ch] < 0Ah  then s := '0' + s;      { 補前導 0 }
    if DS:6506h^[1Ch] = 64h  then s := '00';         { 100 顯示成 00 }
    繪字(7, 7, 顏色, 0, '(' + s + ')');
end;
```

三點：

- **能力值陣列在 `DS:6506h^[11h]`，每筆 2 bytes**，第一個參數之外的那個索引
  選第幾項；每一項畫在 `索引 + 7` 這一列。
- 個位數的值會**往右挪一格**（`欄` 由 5 變 6），這樣個位與十位靠右對齊。
- 只有**索引 0（力量）且值等於 `12h`（18）且百分位 `+1Ch` 大於 0** 時才畫
  括號那一段。百分位小於 10 補前導 `0`，等於 100 直接顯示 `00`——**這就是
  AD&D 的 `18/00` 記法**，只是這裡用括號寫成 `18(00)`。
- 顏色由第一個參數二選一：非 0 用 `0Dh`、0 用 `0Ah`。

`+11h`（力量）與 `+1Ch`（百分位）這一對與既有結論（傷害加值用的那組）一致，
這裡是**顯示端**的確認。

## PC-98 版怎麼處理——直接可抄的先例

`overlay-19:09BCh` 是同一支的 PC-98 版，135 條指令逐條同構，**唯一的差別是那
四條常數換成全形**：

| | DOS | PC-98 |
|---|---|---|
| 補零 | `'0'`（1 byte） | `'０'`（2 bytes） |
| 百分位 100 | `'00'`（2） | `'００'`（4） |
| 左括號 | `'('`（1） | `'（'`（2） |
| 右括號 | `')'`（1） | `'）'`（2） |

**對齊的程式碼一個字都沒改**——`欄 := 5 或 6`、百分位固定畫在第 7 欄第 7 列
全部照舊。也就是說繪字程序自己處理全形的寬度，呼叫端只換字串常數就成立。

中文版可以照這個作法：把 `（`、`）`、`０` 換成全形，欄位算式不動。

## 中文化要注意

`(`、`)`、`0`、`00` 是四條各自獨立的常數，畫的時候用字串接合組起來，所以
**只要替換常數就能換成全形**（PC-98 版已經這樣做了）。欄位靠 `欄 := 5 或 6`
硬編碼，百分位那一段固定畫在第 7 欄第 7 列——版面本身不能靠改常數調整。

## 明確不宣稱

- 沒有宣稱 `DS:6506h^[11h]` 起那串 2-byte 欄位共有幾項、順序是什麼。
- 沒有宣稱 `<開窗>` 那四個參數的意義。
- 沒有宣稱顏色 `0Dh` / `0Ah` 對應什麼狀態。
