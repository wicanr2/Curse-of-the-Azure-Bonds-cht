# 868 — 角色檔三件組 `.guy`／`.swg`／`.fx`：PC-98 三個檔各自換前綴

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-16:00C7Eh`（DOS 63 條）↔ `overlay-16:01261h`（PC-98 117 條）

`retf 4` ＝ 一個遠指標。三個副檔名字串**兩平台完全相同**（沒有在地化）：
`'.guy'`、`'.swg'`、`'.fx'`。

### DOS：前綴組一次，三個副檔名共用

```pascal
暫 := DS:5BF0h;                              { 0A54h:0634h 建字串 }
暫 := 暫 ＋ <far 0636h:0618h>(arg_0);        { 0A54h:06C1h 串接 }
路徑 := 暫;                                   { 0A54h:064Eh，上限 50h }

<far 0636h:0192h>(路徑 ＋ '.guy');
<far 0636h:0192h>(路徑 ＋ '.swg');
<far 0636h:0192h>(路徑 ＋ '.fx');
```

### PC-98：整段重做三次，而且前綴常數各不相同

```pascal
for 每一個 (常數, 副檔名) in
      [(DS:0A2Dh, '.guy'), (DS:0A37h, '.swg'), (DS:0A28h, '.fx')] do begin
    暫 := DS:8BF6h;
    暫 := 暫 ＋ 常數;
    暫 := 暫 ＋ <far 0723h:05BDh>(arg_0);
    路徑 := 暫;                               { 上限 50h }
    <far 0723h:00FFh>(路徑 ＋ 副檔名);
end;
```

**這是真的邏輯差異（spec 783 的第 d 類）**，不是編譯器碼型：

| | DOS | PC-98 |
|---|---|---|
| 前綴 | `DS:5BF0h` 一份 | `DS:8BF6h` ＋ **每個副檔名一個不同的常數** |
| 組法 | 前綴組一次，三個副檔名共用 | 整段重組三次 |
| 條數 | 63 | 117 |

也就是說 **PC-98 把三個檔放在三個不同的位置**，DOS 三個檔同一個目錄。
remake 若要同時支援兩種資料版本，路徑組法不能只寫一套。
