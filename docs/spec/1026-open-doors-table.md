# 1026 — 撞門：AD&D 1e 的 Open Doors 兩欄機率表

- 證據等級：`exact`（DOS 側 303 條逐條讀完；PC-98 側 299 條）
- 作法見 spec 783

## `dos overlay-14:00302h` ↔ `pc98 overlay-14:002F5h`

兩側原本都是待解讀。整支沒有字串。

```pascal
成功 := false;
p := 遠指標(DS:650Ah);                       { 隊伍鏈頭 }
while (p <> NIL) and not 成功 do begin
    地形 := <overlay-30 entry#5>(DS:720Fh, DS:7210h, DS:7211h);
    if 地形 = 3 then …上鎖那一欄…
                else …一般那一欄…;
    p := p^[189h];                            { 下一個隊員 }
end;
```

★ **隊伍每個人各擲一次，任何一人成功就停**——這是 Gold Box「全隊一起撞門」的作法。

判定用的兩個欄位是角色的 **`+11h`（力量）** 與 **`+1Ch`（18/xx 百分位）**
——`+10h ＋ i × 2` 那組屬性的第 0 項（spec 1017）與既有的百分位欄位。

## ★★★ 一般門（地形碼 ≠ 3）

| 力量 | 擲骰 | 成功條件 | ＝ |
|---|---|---|---|
| 15 | 1d6 | `= 1` | **1/6** |
| 16–17 | 1d6 | `≤ 2` | **2/6** |
| 18（百分位 ≤ 50） | 1d6 | `≤ 3` | **3/6** |
| 18（百分位 51–99） | 1d6 | `≤ 4` | **4/6** |
| 18（百分位 100） | 1d6 | `≤ 5` | **5/6** |
| 19–20 | 1d8 | `≤ 7` | **7/8** |
| 21 | 1d10 | `≤ 9` | **9/10** |
| 22–23 | 1d12 | `≤ 11` | **11/12** |
| 24 | 1d20 | `≤ 19` | **19/20** |
| 25 | — | — | （另一段） |

> ★★★ **這就是 AD&D 1e《Players Handbook》力量表的 Open Doors 欄，一格不差**
> ——包含 18/51–99 與 18/00 的兩級跳，以及 19 之後改用 d8／d10／d12／d20。

## ★★★ 上鎖／頂住的門（地形碼 ＝ 3）

| 力量 | 擲骰 | 成功條件 |
|---|---|---|
| 18（百分位 91–99） | 1d6 | `= 1` |
| 18（百分位 100） | 1d6 | `≤ 2` |
| 18（其餘百分位） | — | **打不開**（`DS:7588h := 0`） |
| 19–20 | 1d6 | `≤ 3` |
| 21–22 | 1d6 | `≤ 4` |
| 23 | 1d6 | `≤ 5` |
| 24 | 1d8 | `≤ 7` |
| 25 | — | （另一段） |

> ★★★ **這是同一張表的第二欄**（1e 的括號欄：
> 「locked, barred, or magically held doors」）。
> ⚠ **力量 18 且百分位 ≤ 90 的人連骰都不用骰**——直接判定打不開。

★ `DS:7588h := 0` 是「這個人打不開」的標記；成功時不寫。

## 兩平台

DOS 303 條、PC-98 299 條，**兩張機率表的門檻與骰子完全相同**。
差異只在位址（`DS:720Fh`／`7210h`／`7211h` → `DS:0A2A9h`／`0A2AAh`／`0A2ABh`，
與 spec 1022 一致）。

## 明確不宣稱

- 沒有宣稱力量 25 那一段的門檻（兩欄都落在 `cmp ax, 19h` 之後的分支）。
- 沒有宣稱 `DS:7588h` 除了「打不開」之外還有什麼用途。
- 沒有宣稱 `overlay-30 entry#5` 回傳的地形碼除了 `3` 之外的值。
- 沒有宣稱撞門成功之後由誰把門打開（本支只設旗標）。
