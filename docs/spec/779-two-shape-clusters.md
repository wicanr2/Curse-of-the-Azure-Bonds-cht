# 779 — 兩組同形函式：音樂起播（兩種音源）、兩張錯開一格的分段表

- 證據等級：`exact`（逐條讀完其中一支，另一支的運算元差異已窮舉）
- 工具：`scripts/shape_clusters.py`

## 找法

`shape_clusters.py` 在同一個平台、同一個模組內找助憶碼序列（只取到最後一條
`ret`）完全相同、且長度 `>= 12` 條的待解讀函式。全庫只剩 **2 組共 4 支**——
複製貼上型的重複在先前幾輪已經清得差不多了。

## `START.EXE:196E0h` 與 `1974Ah`（DOS）— 兩種音源的起播

43 條指令，只差 **4 個運算元**（扣掉分支目標）：

| | `196E0h` | `1974Ah` |
|---|---|---|
| 通道區塊起點 `DI` | `176h` | `310h` |
| 曲目表基底 | `[si + 4A8h]` | `[si + 548h]` |

```
DS := seg045
SI := 曲目編號
word[17278h] := 曲目編號
SI := 曲目編號 * 8
byte[17251h] := 1              { 忙碌旗標：更新期間設 1 }
byte[17252h] := 4              { 四個通道 }
DI := 176h                     { 1974Ah 是 310h }
repeat
    AX := word[SI + 4A8h]      { 1974Ah 是 +548h }
    if AX <> 0 then begin
        for BX := 2Eh downto 0 step −2 do word[BX + DI] := 0;   { 清 30h bytes }
        word[DI + 2] := AX;                                     { 資料指標 }
        BX := 4 − byte[17252h];
        byte[BX + 152h] := 低位(word[17278h]);
        word[DI] := 1;                                          { 啟用 }
    end;
    DI := DI + 30h;  SI := SI + 2;
    dec(byte[17252h]);
until byte[17252h] = 0;
byte[17251h] := 0
```

- **每個通道的狀態區塊是 `30h`（48）bytes**，共四個，`+0` 是啟用旗標、`+2` 是
  資料指標。
- 曲目表以 `曲目編號 × 8` 為位移、每個通道再 `+2`——所以**每首曲子有 8 bytes、
  四個通道各佔一個 word**（第 5..8 個 byte 沒被這支讀）。
- `byte[17251h]` 是**忙碌旗標**：整段更新期間為 1，結束歸零。這是對計時器中斷
  的重入保護（中斷處理程序看到 1 就不能動這些區塊）。
- 通道為 0（沒有資料）時整個區塊**不會被清掉**，維持前一首的內容。

配合 spec 772 的音效命令分派——裝置 `0` 走 `196E0h`、裝置 `1` 走 `1974Ah`——
這對函式就是**兩種音源各自的起播**。兩者的通道區塊位置不同（`176h` 與 `310h`），
所以兩套狀態是分開的。

## PC-98 `overlay-24:1394h` 與 `1416h` — 兩張錯開一格的分段表

54 條指令，差異全在常數。輸入是 `p^[17h]`，比較全部是**無號**：

| `1394h` 的輸入 | 回傳 | | `1416h` 的輸入 | 回傳 |
|---|---|---|---|---|
| `01h`..`03h` | `0FCh`（−4） | | `00h`..`02h` | `0FCh`（−4） |
| `04h`..`06h` | 輸入 − `07h` | | `03h`..`05h` | 輸入 − `06h` |
| `0Fh`..`12h` | 輸入 − `0Eh` | | `10h`..`12h` | 輸入 − `0Fh` |
| `13h`..`14h` | `4` | | `13h`..`14h` | `3` |
| `15h`..`17h` | `5` | | `15h`..`17h` | `4` |
| `18h`..`19h` | `6` | | `18h`..`19h` | `5` |
| 其他 | `0` | | 其他 | `0` |

兩張表的關係是**輸入區間往下錯開一格、輸出各減 1**（最後三段），而
`13h`..`19h` 這幾段的輸入區間兩邊完全相同、只有輸出差 1。

⚠ 兩支都有**沒被涵蓋的輸入區間**會落到 `0`：`1394h` 是 `00h` 與 `07h`..`0Eh`，
`1416h` 是 `06h`..`0Fh`。`0` 同時是「查無此段」與某些輸入的正常結果，兩者
分不出來。

## 明確不宣稱

- 沒有宣稱 `p^[17h]` 是什麼欄位，也沒有宣稱兩張表的輸出代表什麼。
- 沒有宣稱曲目表每首 8 bytes 裡後 4 個 byte 的用途。
- 沒有宣稱 `byte[152h]` 那個以 `4 − 通道` 索引的陣列是什麼。
- 沒有宣稱 `176h` 與 `310h` 兩套通道區塊分別對應哪個硬體。
