# 918 — 會反彈的直線投射物走訪器（閃電束等四個法術共用）

- 證據等級：`exact`（兩平台都逐條讀完；相似度 0.994，只有一個差異區塊）
- 作法見 spec 783

## `overlay-22:03A03h`（DOS 266 條）↔ `overlay-22:03CB1h`（PC-98 268 條）

`retf 8` ＝ 4 個 byte 參數。**四個呼叫端共用**：

| 呼叫端（DOS） | 參數 `(arg_0, arg_2, arg_4, arg_6)` | 台帳 |
|---|---|---|
| `03C98h` | `(1, 4, r, 7)` | 已解讀／spec 759 |
| `03FF4h` | `(0, 4, 14h, 3)` | 已解讀／spec 628 |
| `057E3h` | — | 待解讀 |
| `05F2Fh` | — | 待解讀，帶 `'throws lightning'` |

```pascal
命中 := 0;
設圖磚(13h);                                       { loc_1567h+1 }
查格(起y, 起x, @上一個佔用者, @地形);              { DS:7559h／DS:755Ah ＝ 起點 }
已走 := 0;   方向 := 1;
施法者y := 取Y(角色);   施法者x := 取X(角色);       { loc_192Bh／loc_1930h }
額外 := arg_0;

if (施法者y = 起y) and (施法者x = 起x) then 離開;   { 起點就是施法者 → 不做事 }

剩餘 := arg_6 × 2;                                 { 射程 }
DS:6F9Dh := 1;                                     { 「投射物在飛」旗標 }

while 剩餘 > 0 do begin                            { 無號 }
    FillChar(@線, 18h, 0);
    線.起y := 起y;   線.起x := 起x;
    線.終y := 起y ＋ (起y − 施法者y) × 方向 × 剩餘;
    線.終x := 起x ＋ (起x − 施法者x) × 方向 × 剩餘;
    直線初始(@線);                                 { loc_1898h+2 }

    repeat                                          { 一段 }
        前y := lo(線.目前y);   前x := lo(線.目前x);
        if (線.起y <> 線.終y) or (線.起x <> 線.終x) then
            repeat
                還有 := 直線下一步(@線);           { sub_189F }
                查格(線.目前y, 線.目前x, @佔用者, @地形);
                if byte[26A2h ＋ 地形 × 4] = 1 then 命中 := 0;
                if 還有 = 0 then break;
                if (佔用者 > 0) and (佔用者 <> 上一個佔用者) then break;
                if 地形 = 0 then break;
                if byte[26A2h ＋ 地形 × 4] > 1 then break;
            until 線.步數 >= 剩餘;                  { 無號 }

        if 地形 = 0 then 剩餘 := 0;

        軌跡動畫(32h, 4, 線.目前x, 線.目前y, 前x, 前y);     { loc_156Ch+1 ＝ spec 914 同一支 }
        結算(線.目前y, 線.目前x, arg_4, arg_2, 上一個佔用者, @命中);  { sub_3947 ＝ spec 707 }
        上一個佔用者 := 佔用者;

        if 命中 <> 0 then begin                    { ★ 反彈 }
            起y := lo(線.目前y);   起x := lo(線.目前x);
            FillChar(@回線, 18h, 0);
            回線.起y := 起y;  回線.起x := 起x;
            回線.終y := 施法者y;  回線.終x := 施法者x;
            直線初始(@回線);
            repeat until 直線下一步(@回線) = 0;     { 只為了量距離 }
            if (額外 <> 0) and (回線.步數 <= 8) then 線.步數 := 線.步數 ＋ 8;
            方向 := −方向;
            額外 := 0;   上一個佔用者 := 0;
        end;

        已走 := 線.步數 − 已走;
        if 已走 < 剩餘 then 剩餘 := 剩餘 − 已走 else 剩餘 := 0;
        已走 := 線.步數;
    until (命中 <> 0) or (剩餘 = 0);
```

## 24 bytes 的直線走訪記錄

`FillChar(…, 18h, 0)` 之後只寫四個欄位，其餘由 `直線初始` 填。
兩份記錄（`線` 與 `回線`）在堆疊上相鄰，同一組位移各出現一次，
所以版面可以直接讀出來：

| 位移 | 內容 |
|---|---|
| `+0`（word） | 起 y |
| `+2`（word） | 起 x |
| `+4`（word） | 終 y |
| `+6`（word） | 終 x |
| `+0Eh`（word） | 目前 y |
| `+10h`（word） | 目前 x |
| `+16h`（word） | 已走步數 |

`+8`..`+0Ch` 與 `+12h`..`+14h` 本支沒有讀。

## 兩個查詢結果的角色

`查格`（`sub_190D` ＝ `overlay-32 entry#9`，spec 707 用同一支）帶回兩個 byte：

- **地形碼**：拿去查 `byte[26A2h ＋ 碼 × 4]`。本支用到三個判別：
  `= 1` → 把 `命中` 清 0；`> 1` → 這一段到此為止；`= 0` → 走出地圖，射程歸零。
  spec 707 的 `= 0FFh` 是第四個。
- **佔用者編號**：`> 0` 且與上一個不同就停下來結算。spec 707 用它查
  `far[6D35h ＋ 編號 × 4]` 取得目標。

`上一個佔用者` 的初值是**起點那一格的佔用者**，所以**投射物不會打到自己**；
每結算一段就更新，所以**同一個目標不會被連打兩次**。

## ★ 反彈

`結算` 把 `命中` 設成 1 時（spec 707 的四個條件，其中一個是
`byte[26A2h ＋ 地形 × 4] = 0FFh`），本支把**起點搬到撞擊格、`方向` 變號**，
於是下一段的終點從「遠離施法者」變成「朝向施法者」——**投射物沿原路彈回來**。

`arg_0` ＝ 1 的呼叫端（spec 759 那支）多一道懲罰：**撞擊點離施法者 8 格以內時，
步數多算 8**，等於反彈後射程縮短。`arg_0` 用過一次就歸 0，所以只在第一次反彈生效。

四個呼叫端之一是 `'throws lightning'`（`overlay-22:05F2Fh`），與 AD&D 閃電束
「打到牆會反彈」的規則一致；但本支是**共用的走訪器**，不是閃電束專屬。

## ⚠ PC-98 的動畫延遲改用遊戲速度

| | 軌跡動畫的延遲 |
|---|---|
| DOS | 常數 `32h` |
| PC-98 | **`DS:7F16h`（＝ `DS:4FA9h` 遊戲速度）× `0Ch`** |

**這是 `DS:4FA9h` 的第五個消費端**，而且是「DOS 用常數、PC-98 才看速度」
的第三例：

| 出處 | DOS 看不看速度 |
|---|---|
| spec 881 | 看（每格延遲 × (速度 ＋ 3)） |
| spec 890 | 看（重播 速度 ＋ 1 次） |
| spec 895 | **不看**（固定 `0Fh`） |
| spec 914 | **不看**（常數 `0Ah`／`32h`／`14h`） |
| **本支** | **不看**（常數 `32h`） |

整份差異區塊只有這三條指令；其餘 21 條差異全是位址。

## 明確不宣稱

- 沒有宣稱 `26A2h` 那張 stride 4 的表是什麼（只知道 `0`／`1`／`>1`／`0FFh`
  四種判別各觸發什麼）。
- 沒有宣稱 `arg_2` ＝ 4（兩個已知呼叫端都傳 4）與 `arg_4` 的意義；
  它們原封不動轉給 spec 707 的結算。
- 沒有宣稱 `DS:6F9Dh` 由誰讀。
- 沒有宣稱「命中 ≠ 0 就反彈」以外的離開條件組合是否可能無窮迴圈
  （`剩餘` 每段都會扣，形狀上會收斂）。
