# 999 — 毒霧（noxious）：2×2 的格子、30 bytes 的節點，順帶定案效果節點建構子

- 證據等級：`exact`（DOS 側 433 條逐條讀完；PC-98 對側 433 條**助憶碼序列
  完全相同**，相似度 1.000）
- 作法見 spec 783

## `dos overlay-22:02799h` ↔ `pc98 overlay-22:02A52h`（各 433 條，相似度 **1.000**）

兩側原本都是待解讀。字串 `CS:2781h` ＝ `'Creates a noxious cloud'`（23 字元）。

```pascal
DS:6F9Dh := 1;
等級 := <overlay-24 entry#36>(DS:6F97h);            { 施法者等級，法術編號在 DS:6F97h }

{ ── 一、在鏈上接一個節點，順便數同一個施法者已經有幾朵雲 ── }
n := 0;
p := 遠指標(DS:755Bh);
if p = NIL then begin
    GetMem(@DS:755Bh, 1Eh);  p := 遠指標(DS:755Bh);
end
else begin
    while p^[4] <> NIL do begin
        if p^[0] = 遠指標(DS:6506h) then inc(n);     { 同一個施法者 }
        p := p^[4];
    end;
    GetMem(@p^[4], 1Eh);  p := p^[4];
end;
FillChar(p^, 1Eh, 0);

{ ── 二、掛效果 ── }
<overlay-23 entry#11>(遠指標(DS:6506h), 28h, 等級, 等級 ＋ (n shl 4), 1);

p^[0]  := 遠指標(DS:6506h);        { 施法者 }
p^[1Ch] := n;                       { 實例編號 }
p^[1Ah] := DS:7559h;                { 中心 x }
p^[1Bh] := DS:755Ah;                { 中心 y }

{ ── 三、四個格子 ── }
for i := 1 to 4 do begin
    k := byte[27D7h ＋ i];                          { ＝ 8, 2, 3, 4 }
    x := DS:7559h ＋ 有號(byte[2694h ＋ k]);
    y := DS:755Ah ＋ 有號(byte[269Dh ＋ k]);
    <overlay-32 entry#9>(x, y, @佔用者, @第二平面[i]);
    p^[10h ＋ i] := ord((佔用者 > 0) and (byte[26A2h ＋ 佔用者×4] < 0FFh));
    …（若該格已經是雲，走另一段把既有的雲併掉）…
    遠指標(DS:6E92h)^[7 ＋ y×32h ＋ x] := 1Eh;      { ★ 地圖上標成「雲」 }
end;

{ ── 四、訊息與收尾 ── }
<overlay-24 entry#20>(角色, 名字 ＋ 'Creates a noxious cloud', 0, 0Ah);

<overlay-23 entry#5>(…);
```

## ★★ 效果節點建構子的簽章定案

`overlay-23 entry#11` 在本支的呼叫是
`(角色, 28h, 等級, 等級 ＋ (n shl 4), 1)`，
在 spec 981 的麻痺凝視是 `(目標, 34h, 3Ch, 0FFh, 0)`。
把它代回 spec 849／862 的效果節點版面：

| 參數 | 落到節點的 | 本支 | 麻痺凝視 |
|---|---|---|---|
| 第 2 個 | `+0` 效果碼 | `28h`（40） | `34h`（52） |
| 第 3 個 | `+1`（word）剩餘時間 | **等級** | `3Ch`（60） |
| 第 4 個 | `+3` 低 4 bits 等級／高 4 bits 實例編號 | **`等級 ＋ (n shl 4)`** | `0FFh`（不可驅散） |
| 第 5 個 | 旗標 | `1` | `0` |

★ **第四個參數的 `等級 ＋ (n shl 4)` 與 spec 862 的「低 4 bits ＝ 效果等級、
高 4 bits ＝ 實例編號」一格不差**——那份規格當初是從時間推進端推的，
這裡是從建構端，兩個獨立來源對上。

所以簽章是

```pascal
procedure 掛效果(角色: 遠指標; 效果碼, 剩餘時間, 等級與實例, 旗標: byte);
```

★ **毒霧的持續時間就是施法者等級**（回合數），
而且**同一個施法者放的第 n 朵雲會拿到實例編號 n**——
`+3` 的高 4 bits 因此最多到 15 朵。

## ★ 方向表定案：`DS:2694h`／`DS:269Dh` 是九格位移

靜態 bytes 直接讀出來：

| 索引 | dx | dy | 方向 |
|---|---|---|---|
| 0 | 0 | −1 | 上 |
| 1 | ＋1 | −1 | 右上 |
| 2 | ＋1 | 0 | 右 |
| 3 | ＋1 | ＋1 | 右下 |
| 4 | 0 | ＋1 | 下 |
| 5 | −1 | ＋1 | 左下 |
| 6 | −1 | 0 | 左 |
| 7 | −1 | −1 | 左上 |
| **8** | **0** | **0** | **原地** |

★ **0..7 與 spec 991 由浮點算出來的八方向編碼完全一致**（0 上、順時針），
**第 9 格（索引 8）是「不動」**。spec 989 記過 DOS `DS:2694h` ↔
PC-98 `DS:489Eh`，現在內容也定了。

## ★ 毒霧是 2×2

`DS:27D7h` 前五個 byte 是 `00 08 02 03 04`，迴圈跑 `i = 1..4`
（`cmp [bp+var_11], 4; jz` 收尾），所以用到的是索引 1..4 ＝
**`8`（原地）、`2`（右）、`3`（右下）、`4`（下）**——
**中心格加右、右下、下，正好一個 2×2 的方塊**。

節點的 `+11h`..`+14h` 各記一格「這一格算不算數」。

## ★ 地圖值 `1Eh`（30）＝ 雲

四個格子都會寫 `遠指標(DS:6E92h)^[7 ＋ y×50 ＋ x] := 1Eh`，
而迴圈裡也用 `佔用者 = 1Eh` 判斷「這一格已經有雲」並走合併分支。
索引式與 spec 994 的地形鋪設（`地圖^[7 ＋ 列×50 ＋ 欄]`）相同。

`byte[26A2h ＋ 佔用者 × 4] < 0FFh` 用的是**地磚查表**——
DOS `DS:26A2h` ↔ PC-98 `DS:48AFh`（spec 994），
`0FFh` 是「這一格不能放」的哨兵。

## 30 bytes 的雲節點版面

| 位移 | 內容 |
|---|---|
| `+0`（dword） | 施法者遠指標 |
| `+4`（dword） | next |
| `+11h`..`+19h` | **九格旗標**（1 ＝ 這一格算數）；本支只用前四格，見 spec 1003 |
| `+1Ah` | 中心 x |
| `+1Bh` | 中心 y |
| `+1Ch` | 實例編號 |

`+8`..`+10h` 與 `+1Dh` 本支沒有寫入，`FillChar` 之後維持 0。
鏈頭在 `DS:755Bh`（毒雲那一支是 `DS:755Fh`，相差 4 bytes，見 spec 1003）。

## 中文化

`'Creates a noxious cloud'` 是 overlay 內嵌字串，接在名字後面
（`名字 ＋ 訊息`），中文語序相同（「◯◯◯製造了一團毒霧。」），
**可以直接換字串**。

⚠ 訊息走的是 `overlay-24 entry#20` 的**戰鬥訊息框**（spec 982），
**一行只有 8 個漢字**，這句要折兩行。
