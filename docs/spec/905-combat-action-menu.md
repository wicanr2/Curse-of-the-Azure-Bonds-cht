# 905 — 戰鬥行動選單：六個選項依狀態動態組合

- 證據等級：`exact`（兩平台各自逐條讀完）
- 作法見 spec 783

## `overlay-08:0076Ch`（DOS 200 條）↔ `overlay-08:00795h`（PC-98 185 條）

`retf 8` ＝ 4 個 word：`(var 選到的鍵, 角色遠指標)`。

| DOS | PC-98 標籤 | PC-98 熱鍵 | 顯示條件 |
|---|---|---|---|
| `'Move '` | `' 移動 '` | `4Dh` `'M'` | `角色^[18Dh]^[6] > 0`（還有移動力） |
| `'View Aim '` | `'ｷｬﾗｸﾀｰ'` ＋ 另一格 | `56h` `'V'`／`41h` `'A'` | 無條件 |
| `'Use '` | `' 使う '` | `55h` `'U'` | `角色^[14Ch] > 0`（PC-98 另判 `+14Dh`） |
| `'Cast '` | `' 魔ｶｹﾙ'` | `43h` `'C'` | 有記憶法術 ＋ 能施法 ＋ `遠指標(DS:4F99h)^[1CAh] = 0` |
| `'Turn '` | `' 退散 '` | — | 牧師 ＋ **`角色^[18Dh]^[11h] = 0`** |
| `'Quick Done'` | `' 自動 '` | — | 無條件（最後接上） |

```pascal
選項 := '';
if 角色^[18Dh]^[6] > 0 then 選項 := 選項 ＋ 'Move ';       { 無號 }
選項 := 選項 ＋ 'View Aim ';
if 角色^[14Ch] > 0 then 選項 := 選項 ＋ 'Use ';            { 無號 }

有法術 := 0;
for i := 0 to 53h do
    if 角色^[1Eh ＋ i] > 0 then 有法術 := 1;               { 無號 }
if 有法術 and (角色^[18Dh]^[1] <> 0)
   and (遠指標(DS:4F99h)^[1CAh] = 0) then
    選項 := 選項 ＋ 'Cast ';

if ((有號(角色^[109h]) > 0)
    or ((有號(角色^[111h]) > 0) and <far 0160h:0052h>(角色)))
   and (角色^[18Dh]^[11h] = 0) then
    選項 := 選項 ＋ 'Turn ';

repeat
    選項 := 選項 ＋ 'Quick Done';
    選到^ := <far 0167h:002Fh>(var 有選中, 0, 1, 0Fh, 0Ah, 0Dh,
                               選項, 'Quick Done' 的標題);
    if 有選中 and not <0A54h:08D4h>(合法鍵表, 選到^) then 選到^ := 0;
until <0A54h:08D4h>(結束鍵表, 選到^);
<far 0167h:0034h>();
```

## 關掉 spec 834 的 `+18Dh^[11h]`

spec 834（Turn Undead）記著「沒有宣稱 `+18Dh^[11h] := 1` 的意義」，
只知道那是 22 bytes 戰鬥狀態裡 `+11h` 的第一個用途。

**本支是它的讀取端**：`'Turn '` 這個選項只有在 `+18Dh^[11h] = 0` 時才出現，
而 spec 834 的 Turn Undead 一開始就把它設 1。所以那一格是
**「這一回合已經驅散過了」**——用過就從選單消失。

而且顯示條件是 `+109h > 0`（牧師槽的等級）或
`+111h > 0` 且 `far 0160h:0052h(角色)` ——**只有牧師會看到這個選項**，
與 AD&D 的 Turn Undead 是牧師能力一致。

## 三個既有欄位的讀取端

| 欄位 | 出處 | 這裡的用法 |
|---|---|---|
| `+18Dh^[06h]` | spec 860 的移動力（半格） | `> 0` 才顯示 `'Move '` |
| `+18Dh^[01h]` | spec 836 的「能施法」 | 配「有記憶法術」才顯示 `'Cast '` |
| `+1Eh ＋ i` | spec 788／836 的法術記憶欄 | 掃 `0..53h` 找有沒有非零 |

⚠ 這裡的掃描是 `for i := 0 to 53h`（含 `+1Eh`），
與 spec 836 的 AI 掃描 `1..53h`（不含 `+1Eh`）**不一樣**——
spec 836 記的那個 off-by-one 在玩家這一側不存在。

## ⚠ DOS 把兩個選項擠在一個字串

`'View Aim '` 是**一個常數**裡放兩個選項（`V` 與 `A`），
靠空白分隔給選單常式拆。PC-98 拆成兩格（標籤 `DS:0A346h` 與 `DS:0A362h`，
熱鍵 `DS:0A336h` ＝ `'V'` 與 `DS:0A33Ah` ＝ `'A'`）。

PC-98 的五組位址與 spec 899 定出的基底完全吻合：

```
標籤 DS:0A33Fh ＋ 7 × {0, 1, 2, 3, 5}  = 0A33Fh 0A346h 0A34Dh 0A354h 0A362h
熱鍵 DS:0A335h ＋ 1 × {0, 1, 2, 3, 5}  = 0A335h 0A336h 0A337h 0A338h 0A33Ah
```

**中文化跟 PC-98 拆開**，不要沿用 DOS 那種「一個字串兩個選項」的寫法。

## 明確不宣稱

- 沒有宣稱 `角色^[14Ch]` 是什麼（`+14Dh` 是物品鏈，形狀上是可用道具數）。
- 沒有宣稱 `遠指標(DS:4F99h)^[1CAh]` 是什麼（`≠ 0` 時不能施法）。
- 沒有宣稱 `far 0160h:0052h(角色)` 判什麼。
- 沒有宣稱 `'Quick Done'` 那兩個選項各做什麼。
