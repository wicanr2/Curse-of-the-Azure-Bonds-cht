# 826 — `engulfs`：角色名就在記錄的 `+0`；PC-98 把一句拆成兩個片段夾住目標名

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的差異已逐條列出）
- 作法見 spec 783

## `overlay-13:403Fh`（entry#37，DOS 117 條／PC-98 128 條）

| | DOS | PC-98 |
|---|---|---|
| 片段 A | `'engulfs '`（8，**結尾一個空白**） | `'は'`（2 bytes） |
| 片段 B | **沒有** | `'を包みこんだ。'`（14 bytes） |

`retf 0Ah` ＝ 5 個 word。依宣告順序：`(角色, 參數4, 參數2)`，`角色` 是遠指標。

```pascal
目標 := 角色^[18Dh]^[0Ah];
if DS:6FA0h <> 2 then 離開;
if 目標^[196h] = 0 then 離開;
if <far 1575h+2>(@暫存, 3Ah, 目標) then 離開;      { 已經被吞了 }
if <far 1575h+2>(@暫存, 0Dh, 目標) then 離開;
目標 := 角色^[18Dh]^[0Ah];                          { 重讀一次 }

緩衝 := 角色名 ＋ 'engulfs ';                       { 0A54h:0634h(角色, @緩衝, @片段A) }
緩衝 := 緩衝 ＋ 目標^;                              { 0A54h:06C1h(目標遠指標) }
<far 1552h+2>(緩衝, 1, 0Ch);

<far 1466h+1>(目標, 3Ah, 0, <far 1939h+1>(目標), 0);
<far 1439h+1>(3Ah, 目標, longint 0, 0);
<far 1466h+1>(目標, 0Dh, 0, <far 145Ah+3>(2, 4), 0);
<far 1466h+1>(角色, 8Bh, 0, <far 1939h+1>(目標), 1);
```

### 角色記錄的 `+0` 起就是名字（Pascal 字串）

`0A54h:06C1h` 是字串串接，DOS 這裡直接把**目標的遠指標**推進去當來源：

```
40D0  les di, [bp+var_9]      { 目標 }
40D3  push es
40D4  push di
40D5  call far ptr 0A54h:06C1h
```

要能當字串用，**記錄的第 0 個 byte 必須是長度**。這與 spec 807 讀到的
`DS:65A0h := DS:6506h^[0] + 2`（拿名字長度算欄位）互相印證：**角色／戰鬥員記錄
從 `+0` 起就是一個 Pascal 字串的名字**。

⚠ 中文化的直接影響：名字欄位是**定長的 Pascal 字串**，長度位元組在 `+0`。
中文名字每字兩 bytes，可放的字數只有英文的一半，而版面計算（spec 807）是拿長度
位元組直接算欄位的。

### PC-98 把一句拆成兩段夾住目標名

DOS 只有一個片段，句子是 `<角色名>engulfs <目標名>`。

PC-98 改成 `<角色名>は<目標名>を包みこんだ。`——**目標名被夾在兩個片段中間**，
而且取目標名不是直接推指標，是先呼叫 `<0418h:1C96h>(緩衝, 目標)`（多半是為了
處理雙位元組）再串接。

這是繼 spec 824 之後**第二個「PC-98 改了句子結構而不只是換字串」的例子**。
中文語序與日文接近（「甲把乙吞了進去」），沿用 PC-98 的兩段式即可。

### 三個效果碼

`1466h+1(對象, 碼, 0, 值, 旗標)` 連掛三個：

| 碼 | 對象 | 值 | 旗標 |
|---|---|---|---|
| `3Ah`（58） | 目標 | `1939h+1(目標)` | 0 |
| `0Dh`（13） | 目標 | `145Ah+3(2, 4)`（形狀上是 2d4） | 0 |
| `8Bh`（139） | **角色**（發動者） | `1939h+1(目標)` | 1 |

另外 `<far 1439h+1>(3Ah, 目標, longint 0, 0)` 也帶 `3Ah`。

**進場的兩道守衛查的正是 `3Ah` 與 `0Dh`**——已經掛著就不重複發動。

### PC-98 多一道狀態守衛

在 `目標^[197h] = 0` 之前，PC-98 多判一次 `+197h`（同一個欄位）並在不符時跳到
後段——DOS 沒有這一段。
