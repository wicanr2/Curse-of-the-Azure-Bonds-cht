# 940 — 帶裁切的 blit 設定：四邊各自算裁切量，旗標字選內迴圈

- 證據等級：`exact`（三支逐條讀完）
- 位置：DOS `START.EXE` 的 `14C6Eh`、`151B1h`、`14EFFh`
- 作法見 spec 783

## 共同骨架 —— `retn 14h`

`(目的表面 arg_0, 來源表面 arg_4, 旗標 arg_8, arg_A, 上下 arg_C, 左右 arg_E)`。

`arg_C`／`arg_E` 是**有號座標**——用 `cmp ax, 8000h; ja` 判負。

```pascal
遮罩A := 來源^[13h];   遮罩B := 來源^[15h];      { 遮罩緩衝遠指標，spec 934 }

{ ── 左右 ── }
if arg_E < 0 then begin 左裁 := −arg_E;  x偏移 := 0 end
else                begin 左裁 := 0;     x偏移 := arg_E end;
if 目的^[2] < arg_E ＋ 來源^[2] then begin
    右裁 := arg_E ＋ 來源^[2] − 目的^[2];   餘寬 := 0;
end else begin
    右裁 := 0;   餘寬 := 目的^[2] − arg_E − 來源^[2];
end;

{ ── 上下（一「列」＝ 8 條掃描線）── }
if arg_C < 0 then begin
    上裁 := (−arg_C) shl 3;
    高    := 來源^[0] − 上裁;
    來源起 := 上裁 × 來源^[2];
    目的起 := 0;   y偏移 := 0;
end else begin
    來源起 := 0;
    y偏移 := arg_C shl 3;
    目的起 := y偏移 × 目的^[2];
    if y偏移 ＋ 來源^[0] > 目的^[0] then 高 := 目的^[0] − y偏移
    else                                 高 := 來源^[0];
end;

{ ── 完全在畫面外就直接返回 ── }
if (來源^[2] < 左裁) or (來源^[2] < 右裁)
   or (來源起 > 來源^[11h]) or (目的起 > 目的^[11h])
   or (高 > 來源^[0]) then 離開;                { 全部無號比較 }

{ ── 換算成位元組（n 依深度而定）── }
x偏移 shl n;  左裁 shl n;  右裁 shl n;  餘寬 shl n;
來源起 shl n;  目的起 shl n;
每列 := (來源^[2] − 左裁 − 右裁) shl n;
來源起 := 來源起 ＋ 來源^[11h] × arg_A;         { 選第幾張圖 }

{ ── 旗標字選內迴圈 ── }
if 旗標 and 1 = 0 then
    <sub_15329h>()                              { 無遮罩，純複製 }
else begin
    var_1A := (旗標 and 4 <> 0);
    <sub_15388h>();                             { 有遮罩 }
end;
```

## 三支的差別只有位移量

| | 位移量 `n` | `var_6`（＝ `x偏移` 的另一份） |
|---|---|---|
| `14C6Eh` | **1**（×2） | `x偏移 shl 1` |
| `151B1h` | **2**（×4） | `x偏移 shl 2` |
| `14EFFh` | **2**（×4） | **`x偏移` 不移** |

與 spec 933 那三支（不裁切版）是**同一組排列**：
`14BDAh`↔`14C6Eh`、`14DD3h`／`14E62h`↔`151B1h`／`14EFFh`。
所以常駐裡有 **裁切／不裁切 × 兩種深度 × `var_6` 移不移** 的完整矩陣。

## ★ `arg_8` 是旗標字

| bit | 意義 |
|---|---|
| 0 | **用遮罩**（走 `sub_15388h`）；為 0 走 `sub_15329h` 純複製 |
| 2 | 設 `var_1A := 1` |

這關掉 spec 933 的待答項的一部分：**`var_1A` 是內迴圈的一個開關，
由旗標 bit 2 決定**。spec 933 那三支不裁切的版本一律寫 `var_1A := 0`，
所以它們永遠走 bit 2 為 0 的那條路。

## 裁切的粒度

上下裁切以 **8 條掃描線為一單位**（`shl 3`），左右裁切以**像素**為單位。
這與 spec 937 的 8×8 字元格一致——整個繪圖層以 8 掃描線的「列」為單位。

⚠ 五道「完全在畫面外」的檢查**全部是無號比較**，而 `左裁`／`右裁`
是由有號減法算出來的。上游若送進極端值，負數會被當成極大的無號數而
提早返回（等於整張不畫），**不會越界寫入**——這一點是安全的。

## 明確不宣稱

- 沒有宣稱旗標 bit 1、bit 3 以及 bit 3 以上的位元。
- 沒有宣稱 `arg_A`（乘上 `來源^[11h]`，形狀上是「第幾張圖」）。
- 沒有宣稱 `sub_15329h` 的內容。
- 沒有宣稱 `var_1A` 在 `sub_15388h` 裡實際控制什麼。
