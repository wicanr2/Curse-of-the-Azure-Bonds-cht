# 786 — 錢超重就進 Pool（把金錢欄位徹底對上）、轉向代價、`DS:6E92h` 是螢幕格緩衝

- 證據等級：`exact`（DOS 側逐條讀完；PC-98 側的運算元差異已逐條列出）
- 作法見 spec 783

## `overlay-21:021Ch`（entry#9，53 條）— 拿不動的錢放進 Pool

| | DOS | PC-98 |
|---|---|---|
| 訊息 | `'Overloaded.  Money will be put in Pool.'`（39，**兩個空白**） | `'持ちすぎです。お金は地面に置きますよ'`（36 bytes） |

```pascal
if 本模組 0073h(@餘裕, 數量, DS:6506h) then begin      { spec 754：會不會超過 }
    顯示('Overloaded.  Money will be put in Pool.');
    DS:6506h^[103h] := DS:6506h^[103h] + 餘裕;         { 只收得下的部分 }
    本模組 0057h(餘裕, DS:6506h);
    longint@DS:6F80h := longint@DS:6F80h + (數量 − 餘裕);   { 其餘進 Pool }
end else begin
    DS:6506h^[103h] := DS:6506h^[103h] + 數量;
    本模組 0057h(數量, DS:6506h);
end;
```

這一支把兩條先前分別推得的線**咬死在一起**：

- 角色的錢在 `+0FBh` 起的 **7 個 word**（spec 772 的七欄顯示）。
  `0FBh + 4 × 2 = 103h`——所以 `+103h` 就是**索引 4**。
- 全域的 `DS:6F70h` 起是 **8 格 4-byte 的量**（spec 773）。
  `6F70h + 4 × 4 = 6F80h`——同樣是**索引 4**。
- 金錢名稱表（`DS:0F93h`，spec 773）的**索引 4 是 `Platinum`**。
- 訊息明寫 `Money will be put in Pool`。

四者互相印證：**`DS:6F70h` 就是隊伍的 Pool，索引與角色的 `+0FBh` 陣列、與
`DS:0F93h` 的名稱表是同一套**。這一支處理的是白金幣。

⚠ **訊息裡 `Overloaded.` 之後有兩個空白**，是字串常數的一部分。PC-98 版的譯文
沒有保留那個排版（日文版直接寫成一句）。

## `overlay-13:194Ah`（entry#14，53 條，差異 5 條）— 轉向要轉幾格

```pascal
inc(p^[18Dh]^[0Fh]);                                  { 動作計數 }
目標 := 本模組 29A2h(x, y, p);                        { 朝目標的方向 }
差 := (目標 − p^[18Dh]^[09h] + 8) mod 8;              { 有號除法取餘 }
if 差 > 4 then 差 := 8 − 差;                          { 無號比較 }
p^[18Dh]^[12h] := (p^[18Dh]^[12h] + 差) mod 8;
```

- 戰鬥狀態記錄再補上三個欄位：**`+09h` 是目前面向、`+0Fh` 是動作計數、
  `+12h` 是累計的轉向量**。
- `差` 取的是**兩個方向之間的最短轉法**（0..4），順逆時針不分。
- 累計值同樣對 8 取餘，所以它是一個 0..7 的環狀量，**不是單調累加的成本**。

## `overlay-10:0048h`（entry#3，55 條，差異 4 條）— 把一格寫進螢幕緩衝

```pascal
x := 有號(DS:4A0Dh) * 5 + 有號(DS:4A0Ch) * 6 + 15h + x位移;
y := x位移之外的參數 + 有號(DS:4A0Dh) * 5 + 0Ah;
if (0 <= x <= 31h) and (0 <= y <= 18h) then
    緩衝^[y * 32h + x + 7] := 磚 + 1;
```

`DS:4A0Ch` / `DS:4A0Dh` 就是 spec 776 的視野掃描計數器（dx ∈ −6..+6、
dy ∈ −2..+2），所以這支是那四個巢狀繪圖程序之一——**spec 771 那八組寫死的
參數就是傳給它的 `(x位移, y位移, 磚 − 1)`**：

| `DS:4A0Eh = 1` | 其他 |
|---|---|
| `(3, 0, 5)`、`(4, 0, 5)`、`(3, 1, 0Ah)`、`(4, 1, 0Ah)` | 四組第三欄全是 `16h` |

投影式是 `x = 5·dy + 6·dx + 21 + x位移`、`y = 5·dy + 10 + y位移`——**每一格
在畫面上佔 6 欄寬、5 列高**，整個視野以 (21, 10) 為中心。

### 連帶的一個釐清

`DS:6E92h` 這塊 50 × 25 的緩衝區，先前由戰鬥相關的程式碼推得（spec 749／756／
759），這裡是**第一人稱視野**在用同一塊。配合 spec 785（戰鬥員的螢幕座標 ＝
世界座標 − 地圖表頭的原點），比較準確的說法是：

**`DS:6E92h` 是一塊 50 欄 × 25 列的螢幕格緩衝區**，以螢幕座標定址；戰鬥時由
表頭的 `+2` / `+3` 把世界座標換算進來，探索時由上面那條投影式換算。它不是
「戰場本身」。
