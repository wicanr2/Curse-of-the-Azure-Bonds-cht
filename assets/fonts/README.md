# 發行包字型

`NotoSansTC-Regular.ttf` 是繁體中文預設字型，來源為
<https://github.com/google/fonts/tree/main/ofl/notosanstc>。`NotoSansCJKsc-Regular.otf`
與 `NotoSansCJKjp-Regular.otf` 來源為
<https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF>，分別用於簡體中文與日文；
F6 切換語系時會同步切換地區字形，英文則沿用繁中字型的拉丁字形。

字型依 SIL Open Font License 1.1 隨包分發，完整條款見 `OFL.txt`。
專案預設明確載入這三份字型，不依賴 Linux、Windows 或 macOS 的系統字型。
